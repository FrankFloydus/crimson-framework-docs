Use a wallet for game-owned currency. Use a checked wallet commit for a shop purchase, or let the trade model manage an exchange that both players must approve. In multiplayer, run these examples' decisions on the authority. Resolve actor IDs from the session and read prices and eligibility from game-owned state.

Each example runs on its own. Attach one script to a **Node** in an empty scene, run it, and read Godot's **Output**.

## Track integer balances

[`SpatialInventoryWallet`](/api/classes/SpatialInventoryWallet) indexes balances by a positive actor ID and a nonempty currency ID. Store nonnegative integers in the smallest unit your game uses, such as credits or cents. Use [`set_balance()`](/api/classes/SpatialInventoryWallet/methods/set_balance) to load a starting balance and [`get_balance()`](/api/classes/SpatialInventoryWallet/methods/get_balance) to read it. A custom scripted wallet implements [`_get_balance()`](/api/classes/SpatialInventoryWallet/methods/_get_balance) and [`_apply_balance_changes()`](/api/classes/SpatialInventoryWallet/methods/_apply_balance_changes) to provide the same checks and rollback against its own data.

## Buy a medkit without losing credits when the bag is full

A shop purchase has two parts: changing the balance and handing over the item. [`apply_balance_changes()`](/api/classes/SpatialInventoryWallet/methods/apply_balance_changes) accepts rows with `actor`, `currency`, `before`, and `after`. The wallet verifies the expected balances, stages the new amounts, and runs the synchronous placement callback. If the callback returns an error, the wallet restores the balances. Keep the callback focused on one checked inventory change. For several placement writes, use a single [`apply_placement_changes()`](/api/classes/SpatialInventory/methods/apply_placement_changes) batch.

This player's only backpack cell is occupied by an empty ration tin. The first purchase fails and leaves the balance at 20 credits. Once the player discards the tin, the second purchase adds the medkit and deducts 6 credits.

```gdscript
extends Node

const PLAYER_ID: int = 1
const CREDITS: StringName = &"credits"
const STARTING_CREDITS: int = 20
const MEDKIT_PRICE: int = 6
const BAG_SIZE: Vector2i = Vector2i(1, 1)
const ITEM_SIZE: Vector2i = Vector2i(1, 1)
const RATION_TIN: StringName = &"empty_ration_tin"
const MEDKIT_ID: StringName = &"outpost_medkit"

func _ready() -> void:
    var bag: SpatialInventory = Inventory.grid(BAG_SIZE)
    var wallet: SpatialInventoryWallet = SpatialInventoryWallet.new()
    if bag.add(RATION_TIN, ITEM_SIZE) != OK or wallet.set_balance(PLAYER_ID, CREDITS, STARTING_CREDITS) != OK:
        push_error("Could not prepare the outpost shop example.")
        return

    var first_purchase: Error = _buy_medkit(wallet, bag)
    print("Full bag purchase: ", error_string(first_purchase), ". Credits: ", wallet.get_balance(PLAYER_ID, CREDITS))

    if bag.remove(RATION_TIN) != OK:
        push_error("Could not discard the empty tin.")
        return
    var second_purchase: Error = _buy_medkit(wallet, bag)
    if second_purchase != OK:
        push_error(error_string(second_purchase))
        return
    print("Medkit in bag: ", bag.get_item_at(Vector2i.ZERO) == MEDKIT_ID)
    print("Remaining credits: ", wallet.get_balance(PLAYER_ID, CREDITS))

func _buy_medkit(wallet: SpatialInventoryWallet, bag: SpatialInventory) -> Error:
    var balance: int = wallet.get_balance(PLAYER_ID, CREDITS)
    if balance < MEDKIT_PRICE:
        return ERR_UNAUTHORIZED

    var changes: Array[Dictionary] = [{
        "actor": PLAYER_ID,
        "currency": CREDITS,
        "before": balance,
        "after": balance - MEDKIT_PRICE,
    }]
    return wallet.apply_balance_changes(changes, _deliver_medkit.bind(bag))

func _deliver_medkit(bag: SpatialInventory) -> Error:
    return bag.add(MEDKIT_ID, ITEM_SIZE)
```

The script uses a fixed instance ID for a one-time shop item. For repeat purchases, allocate a fresh stable ID for each unit or route the purchase through your stack records. Notify the player after the purchase result. Saving wallets and item data is the game's responsibility.

## Trade a toolkit for credits

[`SpatialInventoryTrade`](/api/classes/SpatialInventoryTrade) registers two participants with separate backpacks and offer grids. One participant [`requests a trade`](/api/classes/SpatialInventoryTrade/methods/request) and the other [`accepts`](/api/classes/SpatialInventoryTrade/methods/accept). A [`whole item offer`](/api/classes/SpatialInventoryTrade/methods/offer_item) reserves the item. A [`currency offer`](/api/classes/SpatialInventoryTrade/methods/set_currency_offer) promises funds. Review both offers and [`lock each one`](/api/classes/SpatialInventoryTrade/methods/set_lock). An offer edit clears the locks. The second lock checks funds, placements, and available room and attempts settlement.

At the salvage camp, one player offers a toolkit and the other offers 7 credits. The first settlement fails because the buyer's backpack is full. After clearing room and locking again, the buyer receives the toolkit and the balances read 7 and 13.

```gdscript
extends Node

const SELLER: int = 1
const BUYER: int = 2
const CREDITS: StringName = &"credits"
const BUYER_CREDITS: int = 20
const PRICE: int = 7
const TOOLKIT_ID: StringName = &"salvage_toolkit"
const SHIPPING_CRATE_ID: StringName = &"shipping_crate"
const TOOLKIT_SIZE: Vector2i = Vector2i(2, 1)
const BAG_SIZE: Vector2i = Vector2i(4, 3)
const OFFER_SIZE: Vector2i = Vector2i(2, 2)

func _ready() -> void:
    var seller_bag: SpatialInventory = Inventory.grid(BAG_SIZE)
    var buyer_bag: SpatialInventory = Inventory.grid(BAG_SIZE)
    var wallet: SpatialInventoryWallet = SpatialInventoryWallet.new()
    if seller_bag.add(TOOLKIT_ID, TOOLKIT_SIZE) != OK:
        push_error("Could not give the seller a toolkit.")
        return
    if buyer_bag.add(SHIPPING_CRATE_ID, BAG_SIZE) != OK:
        push_error("Could not pack the shipping crate.")
        return
    if wallet.set_balance(BUYER, CREDITS, BUYER_CREDITS) != OK:
        push_error("Could not fund the buyer.")
        return

    var trade: SpatialInventoryTrade = SpatialInventoryTrade.new()
    trade.wallet = wallet
    if trade.register_participant(SELLER, seller_bag, OFFER_SIZE) != OK:
        push_error("Could not register the seller.")
        return
    if trade.register_participant(BUYER, buyer_bag, OFFER_SIZE) != OK:
        push_error("Could not register the buyer.")
        return

    if not _accepted(trade.request(SELLER)) or not _accepted(trade.accept(BUYER)):
        return
    if not _accepted(trade.offer_item(SELLER, TOOLKIT_ID)):
        return
    if not _accepted(trade.set_currency_offer(BUYER, CREDITS, PRICE)):
        return

    var seller_locked: Dictionary = trade.set_lock(SELLER, true)
    if not _accepted(seller_locked):
        return
    var blocked: Dictionary = trade.set_lock(BUYER, true)
    if blocked.error != ERR_CANT_CREATE or blocked.completed:
        push_error("Expected the full backpack to block the trade.")
        return
    print(blocked.reason)
    print("Buyer credits before clearing space: ", wallet.get_balance(BUYER, CREDITS))

    if buyer_bag.remove(SHIPPING_CRATE_ID) != OK:
        push_error("Could not unpack the shipping crate.")
        return
    if not _accepted(trade.set_lock(SELLER, true)):
        return
    var settled: Dictionary = trade.set_lock(BUYER, true)
    if not _accepted(settled) or not settled.completed:
        return

    print("Buyer received the toolkit: ", not buyer_bag.get_placement(TOOLKIT_ID).is_empty())
    print("Seller credits: ", wallet.get_balance(SELLER, CREDITS))
    print("Buyer credits: ", wallet.get_balance(BUYER, CREDITS))

func _accepted(result: Dictionary) -> bool:
    if result.error != OK:
        push_error(result.reason)
        return false
    return true
```

Check `completed` before marking a trade finished. A failed settlement clears both locks. When an incoming item cannot fit, help the player make room and lock both offers again. Prevent other inventory actions from touching [`reserved items`](/api/classes/SpatialInventoryTrade/methods/is_reserved). [`cancel()`](/api/classes/SpatialInventoryTrade/methods/cancel) attempts to return active offers. Check the [`recovery grid`](/api/classes/SpatialInventoryTrade/methods/get_recovery) when an original backpack cannot accept a return.

For partial stack offers, configure the trade's [`describe_stack`](/api/classes/SpatialInventoryTrade/properties/describe_stack), [`allocate_stack_id`](/api/classes/SpatialInventoryTrade/properties/allocate_stack_id), and [`apply_stack_changes`](/api/classes/SpatialInventoryTrade/properties/apply_stack_changes) callbacks before calling [`offer_quantity()`](/api/classes/SpatialInventoryTrade/methods/offer_quantity). The quantity records follow the same compare, stage, commit, and rollback pattern shown in [Manage items, stacks, and sorting](/inventory/items#split-ammunition-for-a-teammate). If you save an active trade, persist the [`trade snapshot`](/api/classes/SpatialInventoryTrade/methods/export_snapshot), item records, wallets, and backpacks as one game checkpoint.
