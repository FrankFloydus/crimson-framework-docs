Crimson Framework gives your Godot game the systems to start a session, bring players into a shared world, travel between levels, and pick up from a checkpoint. You decide how the game plays, what players see, and what progress they keep.

Use the systems together or add them as your game needs them. A solo game can use Crimson for an item inventory and saved progress. A co-op game can let one player host and invite friends through Steam. You can also add Steam features such as achievements and cloud saves to an existing game.
