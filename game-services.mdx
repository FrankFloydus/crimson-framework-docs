Boot once from a persistent node such as `Main`. [`Game.configure(LEVEL, PLAYER).boot(self)`](/api/classes/Game/methods/configure) gives you a [`Game`](/api/classes/Game) handle for that scene branch. Pass it directly to menus and other consumers you wire up in the boot script.

## Create the two scene assets

Make `res://scope_level.tscn` with a `Node3D` root and a `Node3D` child named `SpawnPoints`. Add two `Marker3D` children under `SpawnPoints` and move the second away from the first. Make `res://scope_player.tscn` with a `Node3D` root and a single `Camera3D` child. Each example below uses these assets and has its own main scene and script.

## Find the game from a pause menu

Create a `Node` scene with a `Button` child labeled **Return to title** and a `Label` child. Attach the script to the root and assign both controls. The root starts a solo game. The button looks up its owning game when clicked, then waits for that session to close before displaying **Title screen**. A child can resolve the scope after the parent has booted it. [`Game.for_node()`](/api/classes/Game/methods/for_node)

```gdscript
extends Node

const LEVEL: PackedScene = preload("res://scope_level.tscn")
const PLAYER: PackedScene = preload("res://scope_player.tscn")

@export var return_button: Button
@export var status_label: Label


func _ready() -> void:
    return_button.disabled = true
    return_button.pressed.connect(_return_to_title)
    var game: Game = Game.configure(LEVEL, PLAYER).boot(self)
    var started: GameResult = await game.play()
    if not started.ok:
        status_label.text = started.message
        return

    status_label.text = "Session ready"
    return_button.disabled = false


func _return_to_title() -> void:
    var game: Game = Game.for_node(return_button)
    if game == null:
        status_label.text = "No game owns this button."
        return

    return_button.disabled = true
    var result: GameResult = await game.leave()
    if not result.ok:
        status_label.text = result.message
        return_button.disabled = false
        return

    return_button.hide()
    status_label.text = "Title screen"
```

## Select a game from a debug panel

[`Game.current()`](/api/classes/Game/methods/current) returns the selected game or the only live game. When several games are live and none is selected, it returns `null`. Create a new `Node` scene with a `CheckButton` labeled **Use match as default**. Attach the script to the root and assign the button. The script boots two scopes, `Preview` and `Match`, without starting a session in either. Toggle the button and check **Output** to see [`Game.set_default()`](/api/classes/Game/methods/set_default) select or clear the match.

```gdscript
extends Node

const LEVEL: PackedScene = preload("res://scope_level.tscn")
const PLAYER: PackedScene = preload("res://scope_player.tscn")

@export var use_match_button: CheckButton

var _match_owner: Node


func _ready() -> void:
    var preview_owner: Node = Node.new()
    preview_owner.name = "Preview"
    add_child(preview_owner)

    _match_owner = Node.new()
    _match_owner.name = "Match"
    add_child(_match_owner)

    var config: GameConfig = Game.configure(LEVEL, PLAYER)
    var preview: Game = config.boot(preview_owner)
    var match_game: Game = config.boot(_match_owner)
    if not preview.boot_result().ok or not match_game.boot_result().ok:
        push_error("Could not attach both game scopes.")
        use_match_button.disabled = true
        return

    use_match_button.set_pressed_no_signal(false)
    use_match_button.toggled.connect(_select_default)


func _select_default(use_match: bool) -> void:
    var selected: Game
    if use_match:
        selected = Game.for_node(_match_owner)
        if selected == null:
            use_match_button.set_pressed_no_signal(false)
            push_warning("The match scope has retired.")
            return

    var status: int = Game.set_default(selected)
    if status != OK:
        use_match_button.set_pressed_no_signal(not use_match)
        push_error("Could not update the default game.")
        return

    var current: Game = Game.current()
    if current == null:
        print("No default game selected.")
    else:
        print("Match selected. Current phase: %d" % current.get_phase())
```

## Know when a handle expires

[`game.leave()`](/api/classes/Game/methods/leave) ends the session or cancels a pending start. The owner remains attached, so the same game can start another session. When the owner exits the scene tree, Crimson retires its attachment. A retained game handle and its scoped services cannot act on a replacement game. Boot again after the new owner enters the tree and give consumers the new handle.

## Override the LAN transport

LAN uses ENet by default. To exercise your project's provider path during a local smoke test, register a factory that logs when the transport is created and returns a fresh ENet adapter. Later you can have the factory supply a different [`SessionTransport`](/api/classes/SessionTransport) without changing the menu’s game actions.

Create a `Node` scene and attach the script to its root. Run it by itself. Look for `Created the test transport.` and then `Test host ready.` in **Output**. Those messages show that boot called the factory and the game successfully opened a LAN session with its adapter.

```gdscript
extends Node

const LEVEL: PackedScene = preload("res://scope_level.tscn")
const PLAYER: PackedScene = preload("res://scope_player.tscn")
const LOOPBACK_ADDRESS: String = "127.0.0.1"

var game: Game


class TestTransportProvider extends GameProvider:
    func _register(bindings: GameBindings) -> void:
        var status: int = bindings.session_transport(_make_transport)
        if status != OK:
            push_error("Could not register the test transport.")


    func _make_transport() -> SessionTransport:
        print("Created the test transport.")
        return ENetSessionTransport.new()


func _ready() -> void:
    var provider: GameProvider = TestTransportProvider.new()
    game = Game.configure(LEVEL, PLAYER).lan().provider(provider).boot(self)

    var result: GameResult = await game.host(LOOPBACK_ADDRESS)
    if not result.ok:
        push_error(result.message)
        return

    print("Test host ready.")
```

[`GameConfig.provider()`](/api/classes/GameConfig/methods/provider) calls the [`GameProvider`](/api/classes/GameProvider) hook during boot. Register the factory with [`GameBindings.session_transport()`](/api/classes/GameBindings/methods/session_transport). Crimson seals the bindings and resolves the factory on the scene thread before attaching the game. Each boot needs its own adapter. Use the transport override with direct LAN play. A configured Steam or other online provider owns its connection. [Migrate an existing project](/migration)
