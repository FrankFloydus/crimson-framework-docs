## Modules

| Module | Use it to |
| --- | --- |
| [Game runtime](/api/modules/game-runtime) | Boot a game scope, configure services, and start or retire game sessions. |
| [World sessions](/api/modules/world-sessions) | Mount one shared world and manage player spawning and local views. |
| [Sessions and transport](/api/modules/sessions-and-transport) | Host and join sessions, admit peers, and choose a transport. |
| [Scene loading](/api/modules/scene-loading) | Prepare scenes and coordinate when they become active. |
| [Match runtime](/api/modules/match-runtime) | Bind players to characters and apply authoritative gameplay changes. |
| [Replication](/api/modules/replication) | Distribute committed state to the players who can see it. |
| [Inventory](/api/modules/inventory) | Place items in a grid, pick up items during coordinated play, and manage equipment and trades. |
| [Save and restore](/api/modules/save-and-restore) | Store, inspect, and restore checkpoint generations. |
| [Steamworks](/api/modules/steamworks) | Use player services such as achievements, Cloud, Input, and Workshop. |
| [Steam multiplayer](/api/modules/steam-multiplayer) | Connect a Crimson game to Steam lobbies, invites, and dedicated servers. |
| [Steam publisher](/api/modules/steam-publisher) | Verify player ownership and run authorized publisher operations from a trusted backend. |

## Read a class page

Expand a module in the sidebar, open a class, then expand **Properties** or **Methods**. For example, open [Game runtime](/api/modules/game-runtime), choose [`Game`](/api/classes/Game), and follow [`play()`](/api/classes/Game/methods/play). Follow **Inherits** on a class page to find members of its base class when that class is also part of Crimson.

Each property page shows its type, access, and any documented default. Each method page shows its signature, parameters, and return value where applicable. Signals, enums, and constants are listed on their declaring class. Examples show when to use a member and what happens in the game.

Await actions such as [`game.play()`](/api/classes/Game/methods/play) directly and assign the outcome to a [`GameResult`](/api/classes/GameResult). The return value section describes each method's completion contract. Lower-level methods that return a [`GameOperation`](/api/classes/GameOperation) use its [`wait()`](/api/classes/GameOperation/methods/wait) method.
