## Read a class page

Method signatures use Godot types. `void` means the method returns no value. Read the method description before treating a returned `OK` as completion. For asynchronous operations it can mean the request started. Use the operation or request object to read the final result.

A property can have a setter, a getter, or both. A listed default is the value declared for a fresh instance. A signal lists the values passed to its connected callbacks. Enum values and constants are scoped to their declaring class.

## Choose the Steam build

Steamworks classes use the [Steam runtime setup](/steam/setup). Publisher classes have their own group and require the separate [trusted publisher build](/steam/publisher). Use those classes in the backend that holds your publisher credentials.

For workflows that compose several classes, start with the [quickstart](/quickstart) or the framework's [public API guide](https://github.com/FrankFloydus/crimson-framework/blob/v0.0.3/framework/docs/PUBLIC_API.md). The API reference documents the Godot bindings. The [architecture guide](https://github.com/FrankFloydus/crimson-framework/blob/v0.0.3/framework/docs/ARCHITECTURE.md) covers the native C++ module boundaries.
