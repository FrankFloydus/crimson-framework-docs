This reference covers the Godot scripting API in Crimson Framework v0.0.3. Open a module to see what it does, which classes it exposes, and which enums those classes define. Each class page describes its purpose, shows its inheritance, and lists the members it defines.

For a step-by-step example, start with [your first solo game](/quickstart) or the [Steamworks guides](/steam/overview).

## Read a class page

Follow **Module** to browse related classes, or **Inherits** when it links to another Crimson class. Properties list their type, default, and accessors. Methods list their argument and return types. Larger classes provide a linked method index so you can jump to a signature and its full description.

Signals list the values passed to connected callbacks. Enums and constants belong to their declaring class. For asynchronous calls, check the method description to see whether `OK` means the work started or completed, and use the returned operation or request to read the final result.
