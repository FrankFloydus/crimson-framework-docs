## Read a class page

Expand a module in the sidebar and open a class. Some modules group their classes into areas. For example, open **Game runtime**, then **Code-first game**, then **Game → Methods → play**. Follow **Inherits** on a class page to find members of its base class. [Code-first game](/api/modules/game-runtime/code-first-game) · [`play()`](/api/classes/Game/methods/play)

Each property page shows its type, access, and any documented default. Each method page shows its signature, parameters, and return value where applicable. Signals, enums, and constants are listed on their declaring class. Examples show when to use a member and what happens in the game.

Await actions such as [`game.play()`](/api/classes/Game/methods/play) directly and assign the outcome to a [`GameResult`](/api/classes/GameResult). The return value section describes each method's completion contract. Lower-level methods that return a [`GameOperation`](/api/classes/GameOperation) use its [`wait()`](/api/classes/GameOperation/methods/wait) method.

## Steam availability
