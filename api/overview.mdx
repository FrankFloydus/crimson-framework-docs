This reference covers the scripting API for Crimson Framework v0.0.3 on Godot 4.7. Use the sidebar or the list below to find a class. Each page lists the members that class defines. When a class extends another Crimson class, follow **Inherits** to look up members on its base class.

For a step-by-step example, start with [your first solo game](/quickstart) or the [Steamworks guides](/steam/overview).

## Read a class page

Method signatures use Godot types. `void` means the method returns no value. Read the method description before treating a returned `OK` as completion. For asynchronous operations it can mean the request started. Use the operation or request object to read the final result.

A property can have a setter, a getter, or both. A listed default is the value declared for a fresh instance. A signal lists the values passed to its connected callbacks. Enum values and constants are scoped to their declaring class.
