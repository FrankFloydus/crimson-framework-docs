Use [`StateReplication`](/api/classes/StateReplication) to send an initial snapshot and subsequent changes to admitted peers. The game decides what each peer can see. [`NetworkCodecs`](/api/classes/NetworkCodecs) registers game-specific binary message layouts. [`NetworkWriter`](/api/classes/NetworkWriter) and [`NetworkReader`](/api/classes/NetworkReader) encode and decode fields for a known layout. Sample [`GameNetworkDiagnostics`](/api/classes/GameNetworkDiagnostics) to inspect fixed-world movement and the local connection.

## Classes

| Class | Purpose |
| --- | --- |
| [`NetworkCodecs`](/api/classes/NetworkCodecs) | Register and run versioned codecs for game-defined message types. |
| [`NetworkDecodeResult`](/api/classes/NetworkDecodeResult) | Completed network decoding with the decoded value. |
| [`NetworkEncodeResult`](/api/classes/NetworkEncodeResult) | Completed network encoding with a binary payload. |
| [`NetworkReader`](/api/classes/NetworkReader) | Read typed fields from a bounded binary gameplay payload. |
| [`NetworkWriter`](/api/classes/NetworkWriter) | Build a bounded binary gameplay payload from typed fields. |
| [`StateReplication`](/api/classes/StateReplication) | Sends bounded, recipient-specific views of committed state over the node's Godot multiplayer scope. |
