Use SaveSlot and SaveRequest for checkpoints managed by GameRuntime. Use SaveCoordinator when you need to configure the save lifecycle directly, including participant capture, migrations, and staged restores. SavePresentation provides metadata helpers for checkpoint menus.

## Classes

| Class | Purpose |
| --- | --- |
| [`SaveCoordinator`](/api/classes/SaveCoordinator) | A scene-tree node that coordinates checkpoint capture, storage, inspection, and staged restore. |
| [`SavePresentation`](/api/classes/SavePresentation) | Static helpers for building, displaying, and decoding save slot metadata. |
| [`SaveRequest`](/api/classes/SaveRequest) | A branchable checkpoint request for a SaveSlot. |
| [`SaveSlot`](/api/classes/SaveSlot) | A handle for one checkpoint slot in a named profile. |
