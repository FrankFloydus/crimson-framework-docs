Select a coordinated game's checkpoint slot through `game.save_slot(profile, slot)`. [`SaveSlot`](/api/classes/SaveSlot) and [`SaveRequest`](/api/classes/SaveRequest) expose the slot's operations. Use [`SaveCoordinator`](/api/classes/SaveCoordinator) to configure participant capture, migrations, and staged restores directly. [`SavePresentation`](/api/classes/SavePresentation) provides metadata helpers for checkpoint menus.

## Classes

| Class | Purpose |
| --- | --- |
| [`SaveCoordinator`](/api/classes/SaveCoordinator) | Coordinates checkpoint capture, storage, and restore for a persistent game host. |
| [`SavePresentation`](/api/classes/SavePresentation) | Static helpers for building, displaying, and decoding save slot metadata. |
| [`SaveRequest`](/api/classes/SaveRequest) | A branchable checkpoint request for a SaveSlot. |
| [`SaveSlot`](/api/classes/SaveSlot) | A handle for one checkpoint slot in a named profile. |
