[`WorldSession`](/api/classes/WorldSession) and [`WorldSessionDefinition`](/api/classes/WorldSessionDefinition) support existing standalone fixed-world integrations. Use [`Game`](/api/classes/Game) for a new project, with ordinary `Marker3D` children under `SpawnPoints` and one `Camera3D` in the player scene. Existing [`PlayerSpawnPoint`](/api/classes/PlayerSpawnPoint) and [`LocalPlayerView`](/api/classes/LocalPlayerView) placements remain supported.

## Classes

| Class | Purpose |
| --- | --- |
| [`LocalPlayerView`](/api/classes/LocalPlayerView) | Selects the camera and optional hidden visuals for a local player instance. |
| [`PlayerSpawnPoint`](/api/classes/PlayerSpawnPoint) | An authored player placement in a 3D world. |
| [`WorldSession`](/api/classes/WorldSession) | Standalone fixed-world session for existing integrations. |
| [`WorldSessionDefinition`](/api/classes/WorldSessionDefinition) | Configuration for the standalone World Session API. |
