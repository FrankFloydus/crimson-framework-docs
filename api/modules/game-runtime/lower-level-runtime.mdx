Use [`GameRuntime`](/api/classes/GameRuntime) and [`GameDefinition`](/api/classes/GameDefinition) for existing scenes and lower-level integrations. These classes expose retained operations, admission rules, and provider interfaces. [`GameConfig`](/api/classes/GameConfig) can adapt a legacy definition before you move callers to [`Game`](/api/classes/Game).
