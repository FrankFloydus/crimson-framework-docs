Call `Game.configure(level, player).boot(self)` from a live scene owner. Await the direct game actions for a typed [`GameResult`](/api/classes/GameResult). Use [`GameProvider`](/api/classes/GameProvider) and [`GameBindings`](/api/classes/GameBindings) to supply a custom session transport at boot.
