Use [`Game`](/api/classes/Game) to configure a solo, LAN, or Steam game from an existing scene owner. Use [`GameConfig`](/api/classes/GameConfig) to attach a dedicated server with `boot_server(owner)`. For a coordinated game, register [`WorldDefinition`](/api/classes/WorldDefinition) destinations and use [`GameScenes`](/api/classes/GameScenes) for travel.
