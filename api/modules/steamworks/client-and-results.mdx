Use [`Steamworks`](/api/classes/Steamworks) to start a standalone attachment or access the client services attached to a game. [`SteamClient`](/api/classes/SteamClient) is the lower-level callback node for existing integrations. This area also contains app and DLC metadata, platform utilities, and the result and operation types returned by Steam actions.

**Module** [Steamworks](/api/modules/steamworks)
