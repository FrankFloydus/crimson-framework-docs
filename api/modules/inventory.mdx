Start a standalone grid with `Inventory.grid(size)` and add items by ID and footprint. Read their placements as [`InventoryItemView`](/api/classes/InventoryItemView) values. In coordinated games, use [`InventoryConfig`](/api/classes/InventoryConfig) to enable backpacks and provide pickup rules. A [`MatchInventory`](/api/classes/MatchInventory) backpack places an authorized pickup and consumes it in one commit. [`SpatialInventory`](/api/classes/SpatialInventory) and the lower-level adapters provide explicit placement, equipment, container, sorting, and trade tools.
