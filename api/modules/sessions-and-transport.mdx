Use [`Game`](/api/classes/Game) with `.lan()` for direct hosting and joining. The lower-level [`GameSession`](/api/classes/GameSession) API opens offline and network sessions over Godot multiplayer. ENet is the default direct transport. Supply a custom [`SessionTransport`](/api/classes/SessionTransport) through [`GameBindings`](/api/classes/GameBindings), or use [`SessionAuthenticator`](/api/classes/SessionAuthenticator) when a lower-level integration verifies connection proofs and resolves identities.
