Attach app features to an existing owner with `Steamworks.boot(self)`, or get the exact Steam game attachment from `game.steam()`. [`SteamConfig`](/api/classes/SteamConfig) sets the expected AppID and discovery options. Pick a service below for the capabilities your game needs.

## Service areas

| Area | Purpose |
| --- | --- |
| [Client and results](/api/modules/steamworks/client-and-results) | Start a Steam client and inspect the results of Steam operations. |
| [Lobbies and social](/api/modules/steamworks/lobbies-and-social) | Discover lobbies and parties, read friends, and update Steam presence. |
| [Servers and networking](/api/modules/steamworks/servers-and-networking) | Discover dedicated servers, inspect network paths, and exchange Steam packets. |
| [Stats and leaderboards](/api/modules/steamworks/stats-and-leaderboards) | Read or update player progression and work with Steam leaderboards. |
| [Inventory and purchases](/api/modules/steamworks/inventory-and-purchases) | Read the player's Steam inventory and start purchases through your backend. |
| [Cloud and Workshop](/api/modules/steamworks/cloud-and-workshop) | Store files in Steam Cloud and work with Steam Workshop items. |
| [Input and device](/api/modules/steamworks/input-and-device) | Read Steam Input, device information, and Remote Play sessions. |
| [Media and voice](/api/modules/steamworks/media-and-voice) | Integrate Steam capture, recording, playback, and voice features. |
| [Auth, HTTP, and diagnostics](/api/modules/steamworks/auth-http-and-diagnostics) | Request Steam tickets, use Steam web services, and inspect SDK diagnostics. |
