Use [`ControlsComponent`](/api/classes/ControlsComponent) to start movement and look for a local player after their body enters the scene. [`PlayerControl`](/api/classes/PlayerControl) reports whether the attachment is ready and can steer the player around a game-selected lock-on target. [`PlayerControlProfile`](/api/classes/PlayerControlProfile) supplies an explicit set of settings when a game needs to override the scene defaults.

## Classes

| Class | Purpose |
| --- | --- |
| [`ControlsComponent`](/api/classes/ControlsComponent) | Inspector settings for a local player's input and look. |
| [`PlayerControl`](/api/classes/PlayerControl) | Local steering and look for one scene body. |
| [`PlayerControlProfile`](/api/classes/PlayerControlProfile) | Reusable movement and look settings for a local player. |
