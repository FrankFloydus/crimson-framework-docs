Use [`GameScenes`](/api/classes/GameScenes) to travel to registered worlds in a coordinated game. [`SceneLoadManager`](/api/classes/SceneLoadManager) provides lower-level control over world replacement. Register scene IDs, choose a world container, and request a local or coordinated load. The manager prepares the scene asynchronously and reports completion or failure.

## Classes

| Class | Purpose |
| --- | --- |
| [`SceneLoadManager`](/api/classes/SceneLoadManager) | Replaces a managed world offline or across the connected peers in its Godot multiplayer scope. |
