### Method details

#### `edit`

`edit() -> SteamLobbyEdit`

Return an empty edit for this membership. Call `SteamLobbyEdit.submit()` to check live ownership and write.

#### `invite`

`invite(steam_id: String) -> Error`

Submit one Steam lobby invitation from its current owner to a selected decimal individual SteamID64. A malformed ID or the local account returns `ERR_INVALID_PARAMETER`. `OK` acknowledges submission.

#### `leave`

`leave() -> Error`

Leave this standalone membership, releasing its account reservation before `closed`. A Game-owned membership returns `ERR_UNAUTHORIZED`.

#### `listing`

`listing() -> SteamListing`

Return a detached listing using current presentation and counts while active. After closing, return the initial snapshot.

#### `members`

`members() -> SteamLobbyMember[]`

Copy up to 65 current Steam lobby members. An unavailable membership returns an empty array.

#### `open_invite_dialog`

`open_invite_dialog() -> Error`

Request the Steam invite picker for the current owner's lobby. Return `ERR_BUSY` while the overlay is still unavailable and `OK` when submitted.

#### `send_chat`

`send_chat(text: String) -> Error`

Submit nonempty UTF-8 text of up to 1024 bytes with no ASCII controls, at most once per 250 milliseconds. `OK` acknowledges submission. Use `chat_received` to observe delivery.

#### `set_joinable`

`set_joinable(open: bool) -> Error`

Set whether Steam can accept new members into this standalone lobby. The current Steam owner can call this. Game-owned lobbies and guests return `ERR_UNAUTHORIZED`.

#### `tag`

`tag(key: StringName) -> String`

Read the bounded value of one nonreserved application key. Return an empty string when unavailable or absent.

## Signals

### `chat_received`

`chat_received(member: SteamLobbyMember, text: String)`

Emitted for bounded text from a current Steam lobby member, including the local sender. A scope observes at most 20 messages per second.

### `closed`

`closed(reason: int)`

Emitted once after this view stops serving live actions. Explicit leave uses `OK`, scope teardown uses `ERR_SKIP`, and Steam-reported loss uses `ERR_CONNECTION_ERROR`.

### `members_changed`

`members_changed(members: SteamLobbyMember[])`

Emitted with a current bounded snapshot after a Steam member event for this lobby.
