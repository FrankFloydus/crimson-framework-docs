## Signals

### `chat_received`

`chat_received(member: SteamLobbyMember, text: String)`

Emitted for bounded text from a current Steam lobby member, including the local sender. A scope observes at most 20 messages per second.

### `closed`

`closed(reason: int)`

Emitted once after this view stops serving live actions. Explicit leave uses `OK`, scope teardown uses `ERR_SKIP`, and Steam-reported loss uses `ERR_CONNECTION_ERROR`.

### `members_changed`

`members_changed(members: SteamLobbyMember[])`

Emitted with a current bounded snapshot after a Steam member event for this lobby.
