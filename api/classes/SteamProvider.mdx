**Inherits** [`GameServiceProvider`](/api/classes/GameServiceProvider)

Uses the signed-in Steam client for online games, verified peer identity, and native Steam transport.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `app_id` | `int` | `0` | `get_app_id()`, `set_app_id(value)` | Expected Steam AppID for this game. Zero accepts the AppID selected by Steam when the process starts. Configure the provider before attaching the game. |
| `lobby_namespace` | `String` | `"crimson"` | `get_lobby_namespace()`, `set_lobby_namespace(value)` | Game-specific identifier checked when joining a Steam lobby. Use the same value on host and guests. Use 1 to 64 ASCII letters, digits, underscores, or hyphens. |
| `lobby_visibility` | `SteamProvider.Visibility` | `0` | `get_lobby_visibility()`, `set_lobby_visibility(value)` | Who can discover and join the hosted Steam lobby. Private requires a Steam invitation. |
| `prefer_relay_routes` | `bool` | `false` | `get_prefer_relay_routes()`, `set_prefer_relay_routes(value)` | Bias Steam listen-host route selection toward Valve relays. Direct ICE remains a fallback. The default uses Steam's normal route scoring. Dedicated sessions select their own route. |
| `virtual_port` | `int` | `0` | `get_virtual_port()`, `set_virtual_port(value)` | Steam P2P virtual port used by the host, from 0 to 65535. Zero is the standard Steam P2P port. This value is independent of the direct UDP port. |

## Methods

### `configure`

`static configure() -> SteamProvider`

Build detached settings with a private lobby and the Steam launch AppID.

### `dedicated`

`dedicated(settings: SteamServer) -> SteamProvider`

Return a branch that creates a separate SteamGameServer pipe for `GameRuntime.start_dedicated_online()`. The game remains playerless and does not acquire a signed-in Steam client. Null settings return null.

### `for_app`

`for_app(expected_app_id: int) -> SteamProvider`

Return a branch with this expected AppID. Zero uses the Steam launch AppID, and invalid IDs return null.

### `friends_only`

`friends_only() -> SteamProvider`

Return a branch that publishes a lobby joinable by friends and invitees.

### `get_app_id`

`get_app_id() -> int`

Return the configured expected AppID.

### `get_initialization_error`

`get_initialization_error() -> String`

### `get_lobby_namespace`

### `get_lobby_visibility`

`get_lobby_visibility() -> SteamProvider.Visibility`

Return the configured Steam lobby visibility.

### `get_local_steam_id`

`get_local_steam_id() -> String`

Return the signed-in SteamID64 for the uniquely identified attachment, or an empty string.

### `get_prefer_relay_routes`

`get_prefer_relay_routes() -> bool`

### `get_virtual_port`

`get_virtual_port() -> int`

Return the configured Steam P2P virtual port.

### `invisible_lobby`

`invisible_lobby() -> SteamProvider`

Return a branch whose lobby appears in Steam search and is hidden from friends visibility.

### `invite_player`

`invite_player(steam_id: String) -> Error`

Send an invitation from the uniquely attached game's current lobby. Use `GameInvites.send()` for an exact game attachment.

### `is_ready`

`is_ready() -> bool`

Return whether this Resource identifies one attached game with usable Steam. Use `SteamServices.for_game()` when the Resource is shared.

### `on_virtual_port`

`on_virtual_port(port: int) -> SteamProvider`

Return a branch with a Steam virtual port from 0 to 65535. An invalid port returns null.

### `open_invite_overlay`

`open_invite_overlay() -> Error`

Request the invite picker for the uniquely attached game's current lobby. Use `GameInvites.open_overlay()` for an exact game attachment.

### `prefer_relay`

`prefer_relay() -> SteamProvider`

Returns a branch that prefers Valve relay routes over direct ICE for incoming Steam listen connections. It adds a 500 millisecond ICE route selection penalty while preserving direct fallback. Dedicated routes are unaffected. Observe the actual chosen path with `SteamNetworking.peer_path()`.

### `private`

`private() -> SteamProvider`

Return a branch that publishes an invite-only lobby.

### `public_lobbies`

`public_lobbies() -> SteamProvider`

Return a branch whose compatible lobby appears in Steam search.

### `set_app_id`

`set_app_id(value: int) -> void`

### `set_lobby_namespace`

`set_lobby_namespace(value: String) -> void`

Set the shared lobby namespace before attaching the game.

### `set_lobby_visibility`

`set_lobby_visibility(value: SteamProvider.Visibility) -> void`

Set the lobby visibility captured when the game attaches.

### `set_prefer_relay_routes`

`set_prefer_relay_routes(enabled: bool) -> void`

Sets the route preference for the next Steam listen attachment.

### `set_virtual_port`

`set_virtual_port(value: int) -> void`

Set the Steam P2P virtual port before attaching the game.

### `with_commerce_backend`

`with_commerce_backend(backend: SteamCommerceBackend) -> SteamProvider`

Returns a new provider configuration with the selected game-owned commerce adapter. The adapter must use the game's authenticated purchasing backend. Pass null for a provider without commerce.

### `with_lobby_namespace`

`with_lobby_namespace(namespace: String) -> SteamProvider`

Return a branch with 1 to 64 ASCII letters, digits, underscores, or hyphens. An invalid namespace returns null.

### `with_message_channels`

`with_message_channels(channels: StringName[]) -> SteamProvider`

Returns an independent provider branch allowing the specified app message channels for verified, world-ready Steam Game peers. Supply at most 16 distinct channel names of up to 32 ASCII characters, or an empty list to disable Game Messages. Invalid names return null.

### `with_relay_coordinator`

`with_relay_coordinator(coordinator: SteamRelayCoordinator) -> SteamProvider`

Return a branch with the trusted hosted relay coordinator. The server uses registration and withdrawal. The signed-in guest uses fresh authorization. Null clears the adapter for a future Game.

## Signals

### `invite_received`

`invite_received(listing_id: String)`

Emitted when Steam asks the running client to join a lobby. Submit the listing to `GameRuntime.join_online()` after the user accepts it in your game.

## Constants and enums

### `Visibility`

| Name | Value | Description |
| --- | --- | --- |
| `FRIENDS_ONLY` | `1` | Joinable by Steam friends and invitees. |
| `INVISIBLE` | `3` | Appears in Steam search while hidden from friends visibility. |
| `PRIVATE` | `0` | Invite-only Steam lobby. |
| `PUBLIC` | `2` | Appears in compatible Steam lobby search. |
