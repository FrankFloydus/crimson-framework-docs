**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

Game-owned evidence for one authenticated Steam player report or server finding.

Create evidence in the trusted game backend after checking match membership. Use `player()` with the exact [`SteamIdentity`](/api/classes/SteamIdentity) the same publisher verified. Use `server()` for authoritative server evidence your policy can verify. The match reference stays in the backend and the reason code becomes Steam's app data.

### `player`

`static player(match_id: String, reason_code: int, reporter: SteamIdentity) -> SteamCheatEvidence`

Returns evidence for the `match_id` and positive `reason_code` submitted by `reporter`. Report submission checks that the identity belongs to this publisher.

### `server`

`static server(match_id: String, reason_code: int) -> SteamCheatEvidence`

Returns authoritative server evidence for `match_id` and positive `reason_code`. The game policy verifies the server and match context before approving the report.
