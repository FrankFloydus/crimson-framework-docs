## Description

Create evidence in the trusted game backend after checking match membership. Use `player()` with the exact [`SteamIdentity`](/api/classes/SteamIdentity) the same publisher verified. Use `server()` for authoritative server evidence your policy can verify. The match reference stays in the backend and the reason code becomes Steam's app data.
