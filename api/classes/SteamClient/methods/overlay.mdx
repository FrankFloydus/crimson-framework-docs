## Signature

```text
overlay() -> SteamOverlay
```

## Return value

[`SteamOverlay`](/api/classes/SteamOverlay)

## Description

Returns `null` when the scope is inactive or overlay support is unavailable. Check `SteamOverlay.is_ready()` before presenting actions that require a usable overlay.

## Example

```gdscript
extends Node

func run_overlay(steam_client: SteamClient, status_label: Label) -> void:
    var result: SteamOverlay = steam_client.overlay()
    if result == null:
        return
    var overlay_ready: bool = result.is_ready()
    status_label.text = "Overlay ready: yes" if overlay_ready else "Overlay ready: no"
```
