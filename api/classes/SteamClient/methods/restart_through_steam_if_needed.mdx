## Return value

`Error`

## Description

Call before `boot()`, any provider initialization, or the overlay bootstrap. `ERR_SKIP` means Steam requested relaunch and the calling game should quit promptly. `OK` means the current process can continue. The check requires a non-Spacewar AppID, a Steam-enabled build, and the packaged SDK runtime. It is unavailable in headless or editor contexts and reports `ERR_BUSY` after client initialization has been attempted.
