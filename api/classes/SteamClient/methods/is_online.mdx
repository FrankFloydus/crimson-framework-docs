## Signature

```text
is_online() -> bool
```

## Return value

`bool`

## Description

Check `is_ready()` for local SDK access, which may be available in Offline Mode.

## Example

```gdscript
func update_online_badge(client: SteamClient, badge: Label) -> void:
    if not client.is_ready():
        badge.text = "Steam unavailable"
    else:
        badge.text = "Steam online" if client.is_online() else "Steam offline"
```
