## Signature

```text
start(expected_app_id: int = 0) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `expected_app_id` | `int` | `0` |

## Return value

`Error`

## Description

An expected AppID of `0` uses the Steam launch AppID. Starting an active client again with its current AppID succeeds. A conflicting AppID returns `ERR_ALREADY_IN_USE`. Inspect `get_initialization_error()` for Steam initialization details.
