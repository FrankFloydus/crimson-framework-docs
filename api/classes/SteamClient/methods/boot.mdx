## Return value

[`SteamClient`](/api/classes/SteamClient)

## Description

Call on the main thread with a live owner inside the scene tree. Pass `0` to use the Steam launch AppID. If attachment succeeds, the returned node retains any initialization failure. Check `is_ready()` and `get_initialization_error()`. Returns `null` if attachment fails.

## Example

```gdscript
extends Node

const STEAM_APP_ID: int = 480

@export var status_label: Label
var _client: SteamClient

# Attach to a persistent menu. Replace the Spacewar test AppID for your game.
func _ready() -> void:
    if status_label == null:
        return
    _client = SteamClient.boot(self, STEAM_APP_ID)
    if _client == null:
        status_label.text = "The Steam client could not attach."
        return
    if not _client.is_ready():
        status_label.text = _client.get_initialization_error()
        return
    status_label.text = "Steam player services are ready."
```
