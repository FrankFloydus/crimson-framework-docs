**Inherits** `RefCounted`

Reads cached friends and manages individual Rich Presence keys.

Get this service from `SteamClient.friends()`. Use `list()` for the signed-in account's immediate friends and [`SteamPresence`](/api/classes/SteamPresence) for managed status. The individual Rich Presence calls operate on the signed-in account's keys.

## Methods

### `clear_rich_presence`

`clear_rich_presence(key: String) -> Error`

Clears one Rich Presence `key` and preserves the account's other keys. Returns `@GlobalScope.OK` when Steam accepts the update. The Game provider reserves the `connect` key for its join route.

### `is_available`

`is_available() -> bool`

Returns whether the active client exposes the Steam Friends interface on the main thread.

### `list`

`list() -> SteamFriendsResult`

Returns the current cached immediate friends as a read-only typed collection. A successful result can contain an empty array. An inactive or unavailable Steam client returns `@GlobalScope.ERR_UNAVAILABLE`.

### `rich_presence`

`rich_presence(key: String) -> String`

Returns the signed-in account's cached value for `key`, or an empty string when the key is absent or the query is unavailable.

### `set_rich_presence`

`set_rich_presence(key: String, value: String) -> Error`

Sets one Rich Presence `key` to `value`. Both must be nonempty UTF-8 strings within Steam's byte limits. Returns `@GlobalScope.OK` when Steam accepts the update. Setting a managed key explicitly removes it from [`SteamPresence`](/api/classes/SteamPresence) ownership. Use `clear_rich_presence()` to remove a key. The Game provider reserves `connect`.
