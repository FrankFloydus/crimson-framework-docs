## Description

Get this service from `SteamClient.friends()`. Use `list()` for the signed-in account's immediate friends and [`SteamPresence`](/api/classes/SteamPresence) for managed status. The individual Rich Presence calls operate on the signed-in account's keys.

## Methods

### Instance methods

#### [`clear_rich_presence`](/api/classes/SteamFriends/methods/clear_rich_presence)

Clears one Rich Presence `key` and preserves the account's other keys.

#### [`is_available`](/api/classes/SteamFriends/methods/is_available)

Returns whether the active client exposes the Steam Friends interface on the main thread.

#### [`list`](/api/classes/SteamFriends/methods/list)

Returns the current cached immediate friends as a read-only typed collection.

#### [`rich_presence`](/api/classes/SteamFriends/methods/rich_presence)

Returns the signed-in account's cached value for `key`, or an empty string when the key is absent or the query is unavailable.

#### [`set_rich_presence`](/api/classes/SteamFriends/methods/set_rich_presence)

Sets one Rich Presence `key` to `value`.
