**Inherits** `RefCounted`

## Description

Get snapshots from `SteamStats.achievements()` or `SteamStats.achievement()`. A snapshot remains readable after Steam stops. Read it again through [`SteamStats`](/api/classes/SteamStats) to observe a change.

## Properties

**[`api_name`](/api/classes/SteamAchievement/properties/api_name)**

Stable Steamworks API name.

**[`description`](/api/classes/SteamAchievement/properties/description)**

Localized Steamworks description.

**[`display_name`](/api/classes/SteamAchievement/properties/display_name)**

Localized achievement name supplied by Steam.

**[`hidden`](/api/classes/SteamAchievement/properties/hidden)**

Whether the app marks the achievement as hidden.

**[`unlocked`](/api/classes/SteamAchievement/properties/unlocked)**

Whether the signed-in player had unlocked the achievement at the time of the snapshot.

**[`unlocked_at_unix`](/api/classes/SteamAchievement/properties/unlocked_at_unix)**

Unlock time as Unix seconds.

## Methods

### Property accessors

#### [`get_api_name`](/api/classes/SteamAchievement/methods/get_api_name)

Returns the app's published achievement identifier.

#### [`get_description`](/api/classes/SteamAchievement/methods/get_description)

Returns the localized description copied from Steam, or an empty string if unavailable.

#### [`get_display_name`](/api/classes/SteamAchievement/methods/get_display_name)

Returns the localized name copied from Steam, or `api_name` as a string if unavailable.

#### [`get_unlocked_at_unix`](/api/classes/SteamAchievement/methods/get_unlocked_at_unix)

Returns the unlock time in Unix seconds, or zero when no timestamp is available.

#### [`is_hidden`](/api/classes/SteamAchievement/methods/is_hidden)

Returns whether Steam marks the achievement as hidden.

#### [`is_unlocked`](/api/classes/SteamAchievement/methods/is_unlocked)

Returns whether the signed-in player had unlocked this achievement at the time of the snapshot.
