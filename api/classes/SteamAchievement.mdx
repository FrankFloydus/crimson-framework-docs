## Description

Get snapshots from `SteamStats.achievements()` or `SteamStats.achievement()`. A snapshot remains readable after Steam stops. Read it again through [`SteamStats`](/api/classes/SteamStats) to observe a change.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `api_name` | `StringName` | — | `get_api_name()` | Stable Steamworks API name. Use it in lookups and stat drafts. |
| `description` | `String` | — | `get_description()` | Localized Steamworks description. An empty string means Steam supplied no description. For a hidden locked entry, keep the description out of the player-facing achievement list. |
| `display_name` | `String` | — | `get_display_name()` | Localized achievement name supplied by Steam. Uses `api_name` as a string when Steam omits the name. |
| `hidden` | `bool` | — | `is_hidden()` | Whether the app marks the achievement as hidden. Defaults to `false` when Steam omits the flag. Use it with `unlocked` to decide whether to show its name and description. |
| `unlocked` | `bool` | — | `is_unlocked()` | Whether the signed-in player had unlocked the achievement at the time of the snapshot. |
| `unlocked_at_unix` | `int` | — | `get_unlocked_at_unix()` | Unlock time as Unix seconds. Zero means the achievement is locked or Steam has no timestamp. Use `unlocked` to determine the unlock state. |
