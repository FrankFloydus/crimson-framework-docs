**Inherits** `RefCounted`

Scoped observation of one exact Steam dedicated Game attachment.

## Methods

### `get_initialization_error`

`get_initialization_error() -> String`

Read the safe diagnostic captured during native setup. An empty string means setup started without an immediate error.

### `inventory_verifier`

`inventory_verifier() -> SteamInventoryVerifier`

Return the verifier for the exact dedicated attachment. It validates Steam inventory proofs only for the current transport-certified and admitted identity. After teardown it reports unavailable.

### `stats`

`stats(peer_id: int) -> SteamServerPlayerStats`

Resolve Steam progression for the currently admitted remote connection with `peer_id`. Returns null for the local authority, unknown or retired peers, a Game outside its dedicated Steam session, or calls off the scene thread. The returned service is bound to this exact authenticated admission.

### `status`

`status() -> SteamServerStatus`

Read a detached readiness, advertisement, world and authenticated player count snapshot. A retired attachment returns idle status.

## Signals

### `status_changed`

`status_changed(status: SteamServerStatus)`

Emitted on the scene thread when one public status field changes, including on retirement.
