## Signature

```text
fetch(timeout_ms: int = 5000) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `timeout_ms` | `int` | `5000` |

## Return value

`Variant`

Await the call to receive [`SteamListingsResult`](/api/classes/SteamListingsResult).

## Description

The deadline accepts 100 to 15000 milliseconds. Eligible rows already copied by the deadline are returned when available.

## Example

```gdscript
extends Node

func run_fetch(
    steam_server_browser: SteamServerBrowser,
    timeout_ms: int,
    results_list: ItemList
) -> void:
    var steam_server_query: SteamServerQuery = steam_server_browser.query()
    if steam_server_query == null:
        return
    var result: SteamListingsResult = await steam_server_query.fetch(timeout_ms)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: Array[SteamListing] = result.value
    results_list.clear()
    for entry: SteamListing in payload:
        results_list.add_item(str(entry.name))
```
