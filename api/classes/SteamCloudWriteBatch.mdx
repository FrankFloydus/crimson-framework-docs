**Inherits** `RefCounted`

## Description

Keep this handle while submitting a related group of Remote Storage writes or local writes to Auto-Cloud paths. Await each asynchronous write before calling `close()`. The hint applies to the whole Steam app. Every write keeps its own outcome and Steam controls synchronization. The owning client also ends the hint when it stops or the handle is released.
