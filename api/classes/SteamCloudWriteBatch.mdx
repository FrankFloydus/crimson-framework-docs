**Inherits** `RefCounted`

Scoped Steam Cloud write-batch hint for the active AppID.

Keep this handle while submitting a related group of Remote Storage writes or local writes to Auto-Cloud paths. Await each asynchronous write before calling `close()`. The hint applies to the whole Steam app. Every write keeps its own outcome and Steam controls synchronization. The owning client also ends the hint when it stops or the handle is released.

## Methods

### `close`

`close() -> Error`

Ends this exact hint on the client thread. Returns `OK` for a closed handle. Returns `ERR_BUSY` when called from another thread while open, or `ERR_UNAVAILABLE` if Steam could not acknowledge closure.

### `is_open`

`is_open() -> bool`

Returns whether this handle still owns its Steam Cloud write-batch hint.
