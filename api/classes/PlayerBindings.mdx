## Methods

### Instance methods

#### [`bind_peer`](/api/classes/PlayerBindings/methods/bind_peer)

Binds an admitted peer to an unused player ID and returns a positive generation.

#### [`get_binding_generation`](/api/classes/PlayerBindings/methods/get_binding_generation)

Returns the current binding generation, or zero if the peer is unbound.

Returns the bound player ID, or an empty string if the peer is unbound.

#### [`unbind_peer`](/api/classes/PlayerBindings/methods/unbind_peer)
