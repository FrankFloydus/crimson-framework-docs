### Method details

#### `bind_peer`

`bind_peer(peer_id: int, player_id: String) -> int`

Binds an admitted peer to an unused player ID and returns a positive generation. Returns zero for an invalid peer ID, a blank player ID, an occupied peer or player, or generation exhaustion.

#### `get_binding_generation`

`get_binding_generation(peer_id: int) -> int`

Returns the current binding generation, or zero if the peer is unbound.

#### `get_player`

`get_player(peer_id: int) -> String`

Returns the bound player ID, or an empty string if the peer is unbound.

#### `unbind_peer`

`unbind_peer(peer_id: int, generation: int) -> bool`

Removes the binding only if `generation` matches the peer's current generation. Returns whether a binding was removed.
