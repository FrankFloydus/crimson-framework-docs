**Inherits** `RefCounted`

Reads and writes files in the active app's Steam Cloud storage.

Get this service from `SteamClient.cloud()`. Names are portable relative paths using ASCII letters, digits, periods, underscores, hyphens, and forward slashes. Each path component must be nonempty and cannot end in a period or use a reserved Windows device name. Whole-file transfers are limited by `MAX_FILE_BYTES`. A successful write observes local Steam completion. Cross-device synchronization follows Steam's separate sync lifecycle.

## Methods

### `begin_write_batch`

`begin_write_batch() -> SteamCloudWriteBatchResult`

Opens an app-wide Steam Cloud hint for a related group of Remote Storage writes, deletes, or direct disk writes in Steam Auto-Cloud paths. Keep `SteamCloudWriteBatchResult.value` alive and await each submitted asynchronous write before closing it. `ERR_BUSY` indicates that a batch is already open. Each write keeps its own result and Steam controls synchronization.

### `delete_file`

`delete_file(name: String) -> Error`

Deletes the named file from local Steam Remote Storage. Steam propagates the deletion through its sync lifecycle. Returns `ERR_BUSY` if a submitted transfer still reserves the name, or `ERR_FILE_NOT_FOUND` if the file is absent.

### `download_shared`

`download_shared(handle: String, max_bytes: int = 16777216, expected_name: String = "") -> Variant`

Use `await cloud.download_shared(handle)` to receive a [`SteamSharedCloudFileResult`](/api/classes/SteamSharedCloudFileResult) from a shared file belonging to the active Steam AppID. `handle` is a canonical unsigned decimal UGC handle, such as one returned by `share()`. `max_bytes` limits bytes copied into the result and must be between 1 and `MAX_FILE_BYTES`. Steam may download the content to its own cache before its size can be validated. Supply `expected_name` to require an exact filename match. A valid portable filename is required for every download. Use `download_shared_file()` to retain an operation for cancellation.

### `download_shared_file`

`download_shared_file(handle: String, max_bytes: int = 16777216, expected_name: String = "") -> SteamSharedCloudFileOperation`

Starts a bounded download with the same validation as `download_shared()` and returns its retained operation. The handle remains reserved until Steam reports completion and the local Steam cache entry is closed.

### `file_info`

`file_info(name: String) -> SteamCloudFileResult`

Returns local metadata for the named file. An absent file reports `ERR_FILE_NOT_FOUND`.

### `files`

`files(offset: int = 0, limit: int = 64) -> SteamCloudFilesResult`

Returns one page of local file metadata in Steam's current enumeration order. `offset` is a nonnegative zero-based index. `limit` must be between 1 and `MAX_PAGE_FILES`. An offset at or beyond the last file returns an empty successful page. The file list can change between requests.

### `is_available`

`is_available() -> bool`

Returns whether the active client exposes Steam Remote Storage on the main thread.

### `is_enabled_for_account`

`is_enabled_for_account() -> bool`

Returns the signed-in account's Steam Cloud sync preference. Returns `false` when the query is unavailable.

### `is_enabled_for_app`

`is_enabled_for_app() -> bool`

Returns the Steam Cloud sync preference for the active AppID. Returns `false` when the query is unavailable.

### `quota`

`quota() -> SteamCloudQuotaResult`

Returns total capacity and available bytes for the signed-in account's active app storage.

### `read`

`read(name: String) -> Variant`

Use `await cloud.read(name)` to receive a [`SteamBytesResult`](/api/classes/SteamBytesResult). Inspect `SteamResult.ok` before reading `SteamBytesResult.value`. Use `read_file()` to retain an operation for cancellation.

### `read_file`

`read_file(name: String) -> SteamBytesOperation`

Starts a whole-file read and returns its operation. An existing empty file completes successfully with zero bytes. A missing file completes with `ERR_FILE_NOT_FOUND`.

### `share`

`share(name: String) -> Variant`

Use `await cloud.share(name)` to receive a [`SteamStringResult`](/api/classes/SteamStringResult) containing the opaque UGC handle as a canonical unsigned decimal string. Use this with bytes intended to be shared, such as a leaderboard replay. A published handle can remain usable after local file deletion. Use `share_file()` to retain an operation for cancellation.

### `share_file`

`share_file(name: String) -> SteamCloudShareOperation`

Submits a share of an existing local file up to `MAX_FILE_BYTES` bytes and reserves its filename until Steam settles the request. Returns the retained typed share operation. An absent local file reports `ERR_FILE_NOT_FOUND`. Steam can still publish the file after the caller cancels observation.

### `write`

`write(name: String, bytes: PackedByteArray) -> Variant`

Use `await cloud.write(name, bytes)` to receive a [`SteamResult`](/api/classes/SteamResult) for local Steam write completion. Use `write_file()` to retain an operation for cancellation.

### `write_file`

`write_file(name: String, bytes: PackedByteArray) -> SteamOperation`

Submits a whole-file write and returns its operation. `bytes` must contain between 1 byte and `MAX_FILE_BYTES` bytes. The service copies the submitted bytes and holds the file name until Steam settles the transfer.

## Signals

### `local_files_changed`

`local_files_changed(changes: SteamCloudChange[], truncated: bool)`

Emitted after Steam applies local file changes for an app with dynamic Cloud sync enabled. `changes` is a read-only array of detached [`SteamCloudChange`](/api/classes/SteamCloudChange) snapshots. `truncated` is `true` when some changes could not be included. Refresh affected save data when receiving a truncated batch.
