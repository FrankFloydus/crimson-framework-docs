**Inherits** `RefCounted`

## Description

Get this service from `SteamClient.cloud()`. Names are portable relative paths using ASCII letters, digits, periods, underscores, hyphens, and forward slashes. Each path component must be nonempty and cannot end in a period or use a reserved Windows device name. Whole-file transfers are limited by `MAX_FILE_BYTES`. A successful write observes local Steam completion. Cross-device synchronization follows Steam's separate sync lifecycle.

## Methods

### Instance methods

#### [`begin_write_batch`](/api/classes/SteamCloud/methods/begin_write_batch)

Opens an app-wide Steam Cloud hint for a related group of Remote Storage writes, deletes, or direct disk writes in Steam Auto-Cloud paths.

#### [`delete_file`](/api/classes/SteamCloud/methods/delete_file)

Deletes the named file from local Steam Remote Storage.

#### [`download_shared`](/api/classes/SteamCloud/methods/download_shared)

Use `await cloud.download_shared(handle)` to receive a [`SteamSharedCloudFileResult`](/api/classes/SteamSharedCloudFileResult) from a shared file belonging to the active Steam AppID. `handle` is a canonical unsigned decimal UGC handle, such as one returned by `share()`. `max_bytes` limits bytes copied into the result and must be between 1 and `MAX_FILE_BYTES`.

#### [`download_shared_file`](/api/classes/SteamCloud/methods/download_shared_file)

Starts a bounded download with the same validation as `download_shared()` and returns its retained operation.

#### [`file_info`](/api/classes/SteamCloud/methods/file_info)

Returns local metadata for the named file.

#### [`files`](/api/classes/SteamCloud/methods/files)

Returns one page of local file metadata in Steam's current enumeration order. `offset` is a nonnegative zero-based index. `limit` must be between 1 and `MAX_PAGE_FILES`.

#### [`is_available`](/api/classes/SteamCloud/methods/is_available)

Returns whether the active client exposes Steam Remote Storage on the main thread.

#### [`is_enabled_for_account`](/api/classes/SteamCloud/methods/is_enabled_for_account)

Returns the signed-in account's Steam Cloud sync preference.

#### [`is_enabled_for_app`](/api/classes/SteamCloud/methods/is_enabled_for_app)

Returns the Steam Cloud sync preference for the active AppID.

#### [`quota`](/api/classes/SteamCloud/methods/quota)

Returns total capacity and available bytes for the signed-in account's active app storage.

#### [`read`](/api/classes/SteamCloud/methods/read)

Use `await cloud.read(name)` to receive a [`SteamBytesResult`](/api/classes/SteamBytesResult).

#### [`read_file`](/api/classes/SteamCloud/methods/read_file)

Starts a whole-file read and returns its operation.

#### [`share`](/api/classes/SteamCloud/methods/share)

Use `await cloud.share(name)` to receive a [`SteamStringResult`](/api/classes/SteamStringResult) containing the opaque UGC handle as a canonical unsigned decimal string.

#### [`share_file`](/api/classes/SteamCloud/methods/share_file)

Submits a share of an existing local file up to `MAX_FILE_BYTES` bytes and reserves its filename until Steam settles the request.

#### [`write`](/api/classes/SteamCloud/methods/write)

Use `await cloud.write(name, bytes)` to receive a [`SteamResult`](/api/classes/SteamResult) for local Steam write completion.

#### [`write_file`](/api/classes/SteamCloud/methods/write_file)

Submits a whole-file write and returns its operation. `bytes` must contain between 1 byte and `MAX_FILE_BYTES` bytes.

## Signals

### `local_files_changed`

`local_files_changed(changes: SteamCloudChange[], truncated: bool)`

Emitted after Steam applies local file changes for an app with dynamic Cloud sync enabled. `changes` is a read-only array of detached [`SteamCloudChange`](/api/classes/SteamCloudChange) snapshots. `truncated` is `true` when some changes could not be included. Refresh affected save data when receiving a truncated batch.
