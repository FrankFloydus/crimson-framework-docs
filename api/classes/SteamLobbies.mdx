**Inherits** `RefCounted`

Steam discovery and standalone social membership for one exact client scope.

## Methods

### `create`

`create(options: SteamLobbyOptions = null) -> SteamLobbyOperation`

Create a standalone social lobby. Null options use the private default. An existing membership or pending native acquisition in this account returns `ERR_BUSY`. A Game scope returns `ERR_UNAUTHORIZED`.

### `current`

`current() -> SteamLobby`

Return this scope's current exact lobby, or null when it has none.

### `friend_lobby`

`friend_lobby(friend_id: String) -> SteamListingResult`

Read a Steam friend's matching-AppID lobby locator when available. The game verifies its live namespace and owner on join.

### `is_available`

`is_available() -> bool`

Return whether this exact attachment can query Steam lobbies.

### `join`

`join(listing: SteamListing) -> SteamLobbyOperation`

Enter a standalone lobby and recheck its live social protocol, namespace, and Steam owner. A known Game listing is rejected locally. A Game scope cannot submit standalone membership.

### `query`

`query(namespace: StringName = &"") -> SteamLobbyQuery`

Build a detached gameplay lobby query. The namespace defaults to the configured Game namespace or `crimson` for standalone clients. A standalone query can opt into social lobbies with `SteamLobbyQuery.social()`.

## Signals

### `invite_received`

`invite_received(listing: SteamListing)`

Emitted by a standalone scope after the user accepts a Steam lobby invite. The listing is a candidate and must be explicitly joined.
