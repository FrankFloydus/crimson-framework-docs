## Description

Start from `SteamLeaderboards.with_details()` or `SteamLeaderboards.with_replay()`. Each modifier returns an independent branch. `submit_score()` starts the submission.

## Methods

### Instance methods

#### [`submit_score`](/api/classes/SteamScoreOptions/methods/submit_score)

Submits the signed 32-bit score to an existing board using keep-best.

#### [`with_details`](/api/classes/SteamScoreOptions/methods/with_details)

Returns a branch that sends these details with the score.

#### [`with_replay`](/api/classes/SteamScoreOptions/methods/with_replay)

Returns a branch requesting attachment of the provided Steam Remote Storage shared-file handle.
