## Description

Start from `SteamLeaderboards.with_details()` or `SteamLeaderboards.with_replay()`. Each modifier returns an independent branch. `submit_score()` starts the submission.

## Methods

### `submit_score`

`submit_score(board_name: String, score: int) -> Variant`

Submits the signed 32-bit score to an existing board using keep-best. If Steam reports that the score became the entry, attaches the requested replay. Use `await` to receive a [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult). The accepted receipt remains available if attachment fails.

### `with_details`

`with_details(details: PackedInt32Array) -> SteamScoreOptions`

Returns a branch that sends these details with the score. The submission accepts at most 64 signed 32-bit integers.

### `with_replay`

`with_replay(shared_file_handle: String) -> SteamScoreOptions`

Returns a branch requesting attachment of the provided Steam Remote Storage shared-file handle. Pass a nonzero decimal handle belonging to this app.
