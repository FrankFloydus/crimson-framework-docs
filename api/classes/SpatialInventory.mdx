**Inherits** `RefCounted`

A native grid inventory keyed by game-supplied item instance IDs.

Stores rectangular footprints, their zero-based top-left cells, and rotation. The game owns the item records and provides a stable, nonempty `StringName` instance ID for each placement. A rotated footprint swaps width and height. Call `configure()` or `import_snapshot()` before placing items. Use the grid from the main thread.

## Methods

### `apply_placement_changes`

`static apply_placement_changes(changes: Array) -> Error`

Compares current placements with expected values and atomically applies the changes across grids. Each row is a dictionary containing `inventory`, `id`, `before`, and `after`. Use placement dictionaries from `get_placement()` or an empty dictionary for absence. A stale expected placement returns `ERR_BUSY`. If any row fails validation, every grid keeps its previous state.

### `check_move`

`check_move(id: StringName, origin: Vector2i, rotated: bool) -> Error`

Returns `OK` if the item can move to `origin` with the requested rotation. The item's current cells are treated as free.

### `check_placement`

`check_placement(footprint: Vector2i, origin: Vector2i, rotated: bool = false) -> Error`

Returns `OK` if the footprint fits within the grid at `origin` and every cell it covers is free.

### `check_transfer`

`check_transfer(id: StringName, destination: SpatialInventory, origin: Vector2i, rotated: bool) -> Error`

Returns `OK` if the item can transfer to `destination`. The destination needs room for the footprint and an unused instance ID. A transfer to this grid uses `check_move()`.

### `configure`

`configure(size: Vector2i) -> Error`

Sets the grid dimensions. Both dimensions must be positive and the grid can hold up to 1,048,576 cells. Changing the dimensions of a populated grid returns `ERR_BUSY`.

### `export_snapshot`

`export_snapshot() -> Dictionary`

Returns a version 1 snapshot with `version`, `grid_size`, and `placements`. The placement dictionaries use the fields documented in `get_placement()`.

### `find_first_fit`

`find_first_fit(footprint: Vector2i, rotated: bool = false, start: Vector2i = Vector2i(0, 0)) -> Vector2i`

Returns the first valid top-left cell at or after `start`, scanning left to right and top to bottom. If `start` is past the last possible origin on its row, the search continues on the next row. Returns `Vector2i(-1, -1)` for invalid geometry, a negative start, or no fit.

### `get_grid_size`

`get_grid_size() -> Vector2i`

Returns the grid dimensions in cells.

### `get_item_at`

`get_item_at(cell: Vector2i) -> StringName`

Returns the instance ID at `cell`. A free cell or a cell outside the grid returns an empty `StringName`.

### `get_placement`

`get_placement(id: StringName) -> Dictionary`

Returns a dictionary with `id` (`StringName`), `footprint` (`Vector2i`), `origin` (`Vector2i`), and `rotated` (`bool`). The footprint is the size before rotation. An unknown ID returns an empty dictionary.

### `get_placement_revision`

`get_placement_revision() -> int`

Returns a counter for this live grid. Actual changes to its placements or dimensions advance the counter before change signals run. Compare revisions on the same grid to detect edits. The counter is independent of snapshots.

### `get_placements`

`get_placements() -> Array`

Returns an array of placement dictionaries in the format documented in `get_placement()`.

### `get_swap_target`

`get_swap_target(footprint: Vector2i, origin: Vector2i, rotated: bool = false) -> StringName`

Returns the instance ID of the sole item overlapped by this in-bounds footprint. Returns an empty `StringName` if the footprint covers free cells only, overlaps multiple items, or has invalid geometry.

### `import_snapshot`

`import_snapshot(snapshot: Dictionary) -> Error`

Validates a snapshot from `export_snapshot()` and replaces the current grid on success. An invalid snapshot preserves the current grid.

### `is_placement_deltas_enabled`

`is_placement_deltas_enabled() -> bool`

Returns whether this grid emits `placements_changed`.

### `remove`

`remove(id: StringName) -> Error`

Removes the placement with the given instance ID, freeing its cells.

### `set_placement_deltas_enabled`

`set_placement_deltas_enabled(enabled: bool) -> void`

Enables or disables `placements_changed`. Grid views enable this when bound to a model. The `changed` signal is always emitted for mutations.

### `try_move`

`try_move(id: StringName, origin: Vector2i, rotated: bool) -> Error`

Moves or rotates the item if the resulting placement fits. An unsuccessful move preserves the current placement.

### `try_place`

`try_place(id: StringName, footprint: Vector2i, origin: Vector2i, rotated: bool = false) -> Error`

Places a new item if its ID is unused in this grid and the footprint fits. Pass the footprint before rotation.

### `try_resize_item`

`try_resize_item(id: StringName, footprint: Vector2i) -> Error`

Applies a new unrotated footprint if it fits at the item's current origin and rotation. An unsuccessful resize preserves the current placement.

### `try_swap_in`

`try_swap_in(id: StringName, footprint: Vector2i, origin: Vector2i, rotated: bool, expected_id: StringName) -> Dictionary`

Places the held item if its ID is unused in this grid and the in-bounds footprint overlaps only `expected_id`. Returns the displaced placement in the format documented in `get_placement()` and emits `changed` once after committing. Returns an empty dictionary on failure and preserves the grid.

### `try_transfer`

`try_transfer(id: StringName, destination: SpatialInventory, origin: Vector2i, rotated: bool) -> Error`

Moves the item to `destination` if the placement is valid. Commits both grids before either emits `changed`. An unsuccessful transfer preserves the source placement. A transfer to this grid uses `try_move()`.

## Signals

### `changed`

`changed()`

Emitted after the grid changes.

### `placements_changed`

`placements_changed(ids: Array, full_refresh: bool)`

Emitted when placement deltas are enabled. `ids` lists the affected instance IDs. Configure and snapshot import request a full refresh by setting `full_refresh` to `true`. Transfers and batch edits finish mutating all affected grids before notifying listeners.
