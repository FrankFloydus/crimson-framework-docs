## Description

The count cannot exceed current authority capacity after outstanding reservations. Await the operation to observe Steam's response.

## Example

extends Node

func run_change_open_slots(
    steam_party_beacon: SteamPartyBeacon,

    status_label: Label

    var result: SteamPartySlotsOperation = steam_party_beacon.change_open_slots(slots)

        return
