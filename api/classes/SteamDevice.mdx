## Description

Get this service from `SteamClient.device()` after starting a Steam client. Query it on the main thread. Use the preset as a hint for initial settings and keep the player's saved choices. Steam reports platform state and accepts dashboard and keyboard requests. Use Godot's OpenXR interface for headset rendering, tracked input, and XR session lifecycle.

## Methods

### Instance methods

#### [`dismiss_keyboard`](/api/classes/SteamDevice/methods/dismiss_keyboard)

Request dismissal of this scope's current Steam keyboard. `OK` means the request was accepted.

#### [`enter_text`](/api/classes/SteamDevice/methods/enter_text)

Open the modal Steam keyboard in the active rendered window.

#### [`hardware`](/api/classes/SteamDevice/methods/hardware)

Returns the hardware family Steam reports for this game, or `HARDWARE_UNKNOWN` if the query is unavailable or the reported value is unrecognized.

#### [`is_available`](/api/classes/SteamDevice/methods/is_available)

Returns whether this exact client start can query Steam Utils on the main thread.

#### [`is_headset_streaming_enabled`](/api/classes/SteamDevice/methods/is_headset_streaming_enabled)

Returns whether Steam reports that the headset view is streaming over Steam Remote Play.

#### [`is_proton`](/api/classes/SteamDevice/methods/is_proton)

Returns whether Steam reports that the game process is running under Proton.

#### [`is_running_in_vr`](/api/classes/SteamDevice/methods/is_running_in_vr)

Returns whether Steam itself reports running in VR mode.

#### [`is_steam_deck`](/api/classes/SteamDevice/methods/is_steam_deck)

Returns whether `hardware()` identifies a Steam Deck.

#### [`open_vr_dashboard`](/api/classes/SteamDevice/methods/open_vr_dashboard)

Asks Steam to open its VR dashboard. `OK` acknowledges the SDK request.

#### [`recommended_preset`](/api/classes/SteamDevice/methods/recommended_preset)

Returns Steam's recommended starting configuration for this game and hardware. `PRESET_NONE` means Steam has no suggestion. `PRESET_UNKNOWN` means the query is unavailable or the value is unrecognized.

#### [`show_keyboard_for`](/api/classes/SteamDevice/methods/show_keyboard_for)

Open Steam's floating keyboard beside a visible, focused, editable `LineEdit` or `TextEdit` in the main game window.

## Signals

### `keyboard_dismissed`

`keyboard_dismissed()`

Emitted when Steam confirms that the floating keyboard owned by this live scope closed. Await `enter_text()` for the separate modal result.
