**Inherits** `RefCounted`

Reads Steam device and VR state and opens Steam text input.

Get this service from `SteamClient.device()` after starting a Steam client. Query it on the main thread. Use the preset as a hint for initial settings and keep the player's saved choices. Steam reports platform state and accepts dashboard and keyboard requests. Use Godot's OpenXR interface for headset rendering, tracked input, and XR session lifecycle.

## Methods

### `dismiss_keyboard`

`dismiss_keyboard() -> Error`

Request dismissal of this scope's current Steam keyboard. `OK` means the request was accepted. The keyboard remains reserved until Steam reports it closed. Returns `ERR_DOES_NOT_EXIST` when there is no keyboard and `ERR_BUSY` when another scope owns it or a prior owner is closing.

### `enter_text`

`enter_text(prompt: String, initial: String = "", max_chars: int = 64, multiline: bool = false, hidden: bool = false) -> Variant`

Open the modal Steam keyboard in the active rendered window. Await a [`SteamTextEntryResult`](/api/classes/SteamTextEntryResult). The optional prompt is limited to 1024 UTF-8 bytes and `max_chars` to 1 through 4096 Unicode characters. Initial text must fit the requested length. Hidden mode masks characters during entry. A user dismissal succeeds with an empty, unsubmitted entry. Return an unavailable result if Steam cannot open the dialog or the owning scope stops, or `ERR_BUSY` if a keyboard is already active or closing.

### `hardware`

`hardware() -> SteamDevice.Hardware`

Returns the hardware family Steam reports for this game, or `HARDWARE_UNKNOWN` if the query is unavailable or the reported value is unrecognized.

### `is_available`

`is_available() -> bool`

Returns whether this exact client start can query Steam Utils on the main thread. Some individual queries depend on additional SDK exports.

### `is_headset_streaming_enabled`

`is_headset_streaming_enabled() -> bool`

Returns whether Steam reports that the headset view is streaming over Steam Remote Play. Returns `false` if the query is unavailable.

### `is_proton`

`is_proton() -> bool`

Returns whether Steam reports that the game process is running under Proton. Returns `false` if the query is unavailable.

### `is_running_in_vr`

`is_running_in_vr() -> bool`

Returns whether Steam itself reports running in VR mode. Returns `false` if the query is unavailable. Query the OpenXR interface for the game's own XR session state.

### `is_steam_deck`

`is_steam_deck() -> bool`

Returns whether `hardware()` identifies a Steam Deck.

### `open_vr_dashboard`

`open_vr_dashboard() -> Error`

Asks Steam to open its VR dashboard. `OK` acknowledges the SDK request. Returns `ERR_UNAVAILABLE` when Steam is outside VR mode or the scope or dashboard capability is unavailable.

### `recommended_preset`

`recommended_preset() -> SteamDevice.Preset`

Returns Steam's recommended starting configuration for this game and hardware. `PRESET_NONE` means Steam has no suggestion. `PRESET_UNKNOWN` means the query is unavailable or the value is unrecognized.

### `show_keyboard_for`

`show_keyboard_for(field: Control, mode: SteamDevice.FloatingKeyboardMode = 0) -> Error`

Open Steam's floating keyboard beside a visible, focused, editable `LineEdit` or `TextEdit` in the main game window. The field's bounds are transformed to client pixels. Steam sends OS key events to the focused control. Crimson requests dismissal if the field loses focus, becomes hidden or read-only, or leaves the tree. The field keeps its normal Godot text and submit behavior. Return `ERR_BUSY` while any scope's Steam keyboard is active or closing.

## Signals

### `keyboard_dismissed`

`keyboard_dismissed()`

Emitted when Steam confirms that the floating keyboard owned by this live scope closed. Await `enter_text()` for the separate modal result.
