### `create`

`static create(context: String, title: SteamLocalizedText, users: SteamNotificationUserState[]) -> SteamNotificationSessionSpec`

Creates an immutable complete session spec. `context` is a canonical unsigned decimal string used at creation. Supply a localized title and 1 to 16 distinct verified participants.
