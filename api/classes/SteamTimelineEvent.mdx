**Inherits** `RefCounted`

Identifies an event created by a Steam Timeline service.

Pass this handle back to the issuing [`SteamTimeline`](/api/classes/SteamTimeline) to update, end, remove, or inspect an event. The handle expires when its owning client scope stops.

## Methods

### `is_open`

`is_open() -> bool`

Returns whether the handle identifies a valid range awaiting its end time.

### `is_valid`

`is_valid() -> bool`

Returns whether the handle still belongs to an active scope and its event has not been removed.
