**Inherits** `RefCounted`

A scene handle scoped to the GameRuntime that created it. Use it to load a registered world through the game's normal transition lifecycle.

## Methods

### `get_world`

`get_world() -> Node`

Return the mounted world from the originating game scope, or null if the scope is retired or no world is mounted.

### `load`

`load(world_id: StringName) -> GameOperation`

Request authority travel to a registered world ID. Await the returned GameOperation to observe the outcome, including when the originating game scope has retired.
