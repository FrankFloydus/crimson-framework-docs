## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult).

## Description

Awaiting again returns the same result.

## Example

```gdscript
extends Node

func run_wait(
    steam_http_response_operation: SteamHttpResponseOperation,
    apply_wait: Callable
) -> void:
    var result: SteamHttpResponseResult = await steam_http_response_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamHttpResponse = result.value
    if payload == null:
        return
    apply_wait.call(payload)
```
