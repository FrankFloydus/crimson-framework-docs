## Description

Create a draft with `SteamStats.edit()`. Each modifier returns an independent branch. Only `submit()` applies edits, in the order they were added. Keep the owning [`SteamStats`](/api/classes/SteamStats) scope active until submission.

## Methods

### Instance methods

#### [`set_float`](/api/classes/SteamStatsEdit/methods/set_float)

Returns a branch that sets the published float stat to an absolute value.

#### [`set_int`](/api/classes/SteamStatsEdit/methods/set_int)

Returns a branch that sets the published integer stat to an absolute value in the signed 32-bit range.

#### [`submit`](/api/classes/SteamStatsEdit/methods/submit)

Validates the draft before applying any edits.

#### [`unlock`](/api/classes/SteamStatsEdit/methods/unlock)

Returns a branch that unlocks the published achievement when the draft is submitted.

#### [`update_average_rate`](/api/classes/SteamStatsEdit/methods/update_average_rate)

Returns a branch that adds a finite accumulated count over a finite positive duration in seconds.
