**Inherits** `RefCounted`

A branchable draft of changes to the signed-in player's Steam stats and achievements.

Create a draft with `SteamStats.edit()`. Each modifier returns an independent branch. Only `submit()` applies edits, in the order they were added. Keep the owning [`SteamStats`](/api/classes/SteamStats) scope active until submission.

## Methods

### `set_float`

`set_float(name: String, value: float) -> SteamStatsEdit`

Returns a branch that sets the published float stat to an absolute value. The value must be finite and fit Steam's single-precision range.

### `set_int`

`set_int(name: String, value: int) -> SteamStatsEdit`

Returns a branch that sets the published integer stat to an absolute value in the signed 32-bit range.

### `submit`

`submit() -> SteamStatsSubmissionResult`

Validates the draft before applying any edits. If a Steam setter rejects an edit after preflight, earlier accepted edits remain in the local cache. Once every edit succeeds, submits one persistence request. The result includes edit counts for every outcome. Observe `SteamStats.stats_stored` for the app-wide backend response.

### `unlock`

`unlock(name: String) -> SteamStatsEdit`

Returns a branch that unlocks the published achievement when the draft is submitted.

### `update_average_rate`

`update_average_rate(name: String, count: float, seconds: float) -> SteamStatsEdit`

Returns a branch that adds a finite accumulated count over a finite positive duration in seconds. Steam checks whether the named stat accepts average-rate updates when the draft is applied.
