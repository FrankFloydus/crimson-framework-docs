## Description

The backend checks app, namespace, profile, virtual port and registration before acknowledging the exact request with `SteamRelayRequest.registered()` or `SteamRelayRequest.fail()`.

## Example

```gdscript
extends SteamRelayCoordinator

# The authenticated backend validates the server login and stores the exact registration.
var register_with_backend: Callable

func _register_server(request: SteamRelayRequest) -> void:
    if not register_with_backend.is_valid():
        request.fail()
        return
    var accepted: bool = await register_with_backend.call(request)
    if accepted:
        # Acknowledge late success too so Crimson can withdraw a cancelled registration.
        request.registered()
    elif not request.is_cancelled():
        request.fail()
```
