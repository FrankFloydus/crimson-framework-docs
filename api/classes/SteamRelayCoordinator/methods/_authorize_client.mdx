## Description

Complete the exact request with `SteamRelayRequest.authorize()` or `SteamRelayRequest.fail()`. Keep signing credentials off client and game-server builds.

## Example

```gdscript
extends SteamRelayCoordinator

const MAX_RELAY_TICKET_BYTES: int = 4096

# The trusted backend authenticates the client and signs a ticket for the exact registration.
var fetch_relay_ticket: Callable

func _authorize_client(request: SteamRelayRequest) -> void:
    if not fetch_relay_ticket.is_valid():
        request.fail()
        return
    var ticket: PackedByteArray = await fetch_relay_ticket.call(request)
    if request.is_cancelled():
        return
    if ticket.is_empty() or ticket.size() > MAX_RELAY_TICKET_BYTES:
        request.fail()
        return
    request.authorize(ticket)
```
