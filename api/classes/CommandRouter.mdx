### Method details

#### `advance_world`

`advance_world(world_epoch: int) -> Error`

Sets a strictly newer world epoch, clears player sequence cursors, and closes command admission. Returns `ERR\_INVALID\_PARAMETER` for an epoch that does not advance.

#### `configure`

`configure(match_id: String, world_epoch: int, possessor: PlayerPossession) -> Error`

Binds the router once to a valid match ID, positive initial world epoch, and possession service. Command admission starts closed.

#### `register_handler`

`register_handler(command_type: String, handler: Callable, requires_primary: bool = false) -> Error`

Registers a unique command type and a `handler(player\_id, intent)` callback. Set `requires\_primary` when the intent must contain the matching character ID and possession revision. The handler returns plain dictionary data with boolean `ok` and optional string `code` and `message`.

#### `reset_player_sequence`

`reset_player_sequence(player_id: String) -> Error`

Clears the dispatch cursor for one player. Call after trusted ingress revokes the old binding, before accepting commands on a replacement stream.

#### `set_accepting_commands`

`set_accepting_commands(enabled: bool) -> Error`

Opens or closes command admission after configuration. Returns `ERR\_UNCONFIGURED` before configuration or `ERR\_BUSY` during dispatch or from another thread.

#### `submit`

`submit(player_id: String, intent: Dictionary) -> Dictionary`

Validates and dispatches an intent for the supplied trusted player ID. The dictionary contains `match\_id`, `world\_epoch`, `sequence`, `type`, and a `payload` dictionary. Supply `character\_id` and `possession\_revision` together when asserting primary control. Returns a result with `ok`, `code`, and `message`. The sequence is consumed once the handler runs, even if it rejects the intent.
