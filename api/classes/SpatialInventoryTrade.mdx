description: "Coordinates an invitation and item or currency exchange between two actors. Register each actor with a backpack and route all offer edits through this model. The game owns authoritative item and identity records. Trade actions return dictionaries with a Godot error, reason, changed placements, and completion details when applicable."

### Method details

#### `accept`

`accept(actor: int) -> Dictionary`

Accept a pending invitation as its receiver and enter the active phase if the eligibility policy allows it.

#### `cancel`

`cancel(actor: int) -> Dictionary`

Cancel a pending or active trade as a participant. Active cancellation attempts to return offers to the owners, with recovery grids available when a backpack cannot accept the return.

#### `export_snapshot`

`export_snapshot() -> Dictionary`

Return a version 2 snapshot of the trade phase, offers, reservations, escrow, and recovery state. Save it alongside the backpacks and game-owned item records. Returns an empty dictionary while a change is committing.

#### `get_allocate_stack_id`

`get_allocate_stack_id() -> Callable`

Return the callback that allocates unused IDs for escrow or split stacks.

#### `get_apply_stack_changes`

`get_apply_stack_changes() -> Callable`

Return the host callback that commits quantity record changes with the paired placement transaction.

#### `get_currency_offers`

`get_currency_offers(actor: int) -> Dictionary`

Return a detached dictionary of offered amounts keyed by currency ID. The amounts are promises until settlement.

#### `get_describe_stack`

`get_describe_stack() -> Callable`

Return the callback that describes current stack records by item ID.

#### `get_initiator`

`get_initiator() -> int`

Return the actor that opened the invitation, or 0 when idle.

#### `get_item_eligibility`

`get_item_eligibility() -> Callable`

Return the callback that evaluates whether an item can be offered or exchanged.

#### `get_offer`

`get_offer(actor: int) -> SpatialInventory`

Return the actor's live offer grid, or null for an unknown actor. Use it as a projection for UI and route mutations through the trade methods.

#### `get_offer_stack`

`get_offer_stack(actor: int, offer_id: StringName) -> Dictionary`

Return the offered stack's `key`, `quantity`, `max_quantity`, `source_id`, and `record_id`. Returns an empty dictionary if the placement has no escrow stack.

#### `get_participant_eligibility`

`get_participant_eligibility() -> Callable`

Return the callback that checks whether the actors can trade at the current stage.

#### `get_phase`

`get_phase() -> int`

Return the current invitation or exchange phase.

#### `get_receiver`

`get_receiver() -> int`

Return the invited actor, or 0 when idle.

#### `get_recovery`

`get_recovery(actor: int) -> SpatialInventory`

Return the actor's recovery grid, or null for an unknown actor. Use it for returns from cancellation when the backpack lacks space.

#### `get_reserved_source_ids`

`get_reserved_source_ids(actor: int) -> StringName[]`

Return the IDs of the actor's source items reserved by their offer.

#### `get_revision`

`get_revision() -> int`

Return the revision of committed trade edits.

#### `get_wallet`

`get_wallet() -> SpatialInventoryWallet`

Return the configured [`SpatialInventoryWallet`](/api/classes/SpatialInventoryWallet), or null if no wallet is assigned.

#### `import_snapshot`

`import_snapshot(snapshot: Dictionary) -> Error`

Validate and apply a saved trade snapshot against the registered participants, their backpacks, and current host stack records. An incompatible snapshot returns an error and preserves committed state.

#### `is_locked`

`is_locked(actor: int) -> bool`

Return whether the actor has accepted their current offer by locking it.

#### `is_reserved`

`is_reserved(actor: int, id: StringName) -> bool`

Return whether the source item ID is reserved by the actor's offer. The host should keep reserved items out of unrelated moves or record edits.

#### `merge_offer_stacks`

`merge_offer_stacks(actor: int, source_id: StringName, target_id: StringName, limit: int = 0) -> Dictionary`

Merge compatible units from one escrow stack into another in the actor's offer, retaining their source allocations. A positive limit caps the units moved, and a zero limit uses available capacity.

#### `move_offer`

`move_offer(actor: int, id: StringName, origin: Vector2i, rotated: bool) -> Dictionary`

Change the placement of an offered item inside the actor's offer grid. Use the offer placement ID.

#### `offer_item`

`offer_item(actor: int, id: StringName, origin: Vector2i = Vector2i(-1, -1), rotated: Variant = null) -> Dictionary`

Offer a complete item from the actor's backpack. `Vector2i(-1, -1)` selects first fit, and a null rotation uses the source orientation. The trade reserves the source and handles escrow when the item is a stack.

#### `offer_items`

`offer_items(actor: int, ids: StringName[]) -> Dictionary`

Try to offer whole items in the caller's order. Skips items that are missing, reserved, disallowed, or unable to fit, and commits the accepted subset together.

#### `offer_quantity`

`offer_quantity(actor: int, id: StringName, amount: int, origin: Vector2i, rotated: Variant = null, target_id: StringName = &"") -> Dictionary`

Offer part of a placed stack. Set `target_id` to add the quantity to a compatible existing escrow stack. Configure all three stack callbacks before using quantity offers.

#### `register_participant`

`register_participant(actor: int, backpack: SpatialInventory, size: Vector2i, offer: SpatialInventory = null, recovery: SpatialInventory = null) -> Error`

Associate a positive actor ID with a configured backpack. Register exactly two actors while idle. The optional offer grid must be empty, and both optional offer and recovery grids must match the requested dimensions. The model creates any omitted grids.

#### `request`

`request(actor: int) -> Dictionary`

Open an invitation from the actor to the other registered participant. Eligibility checks must pass and both recovery grids must be empty. A successful request changes the phase to `REQUESTED`.

#### `set_allocate_stack_id`

`set_allocate_stack_id(value: Callable) -> void`

Set the host callback that takes the source item ID and returns a fresh unused instance ID for a stack record.

#### `set_apply_stack_changes`

`set_apply_stack_changes(value: Callable) -> void`

Set the host callback for checked quantity record edits. Stage the changes, invoke the paired commit synchronously, and roll back on failure.

#### `set_currency_offer`

`set_currency_offer(actor: int, currency: StringName, amount: int) -> Dictionary`

Set the nonnegative amount promised for a currency. Use 0 to remove an offer. Positive amounts require a wallet and sufficient current funds. The wallet changes during settlement, and a changed offer clears both locks.

#### `set_describe_stack`

`set_describe_stack(value: Callable) -> void`

Set the host callback for `key`, `quantity`, and `max_quantity` by item ID. Return an empty dictionary if the ID has no stack record.

#### `set_item_eligibility`

`set_item_eligibility(value: Callable) -> void`

Set the optional rule for offering and settling items. Return an empty string to allow the action or a reason to deny it.

#### `set_lock`

`set_lock(actor: int, locked: bool) -> Dictionary`

Lock or unlock the actor's offer. Locking the second offer attempts settlement immediately. Inspect `completed` and `error` to distinguish a settled trade from an offer that is waiting or failed validation.

#### `set_participant_eligibility`

`set_participant_eligibility(value: Callable) -> void`

Set the optional rule for participant eligibility during invitation, acceptance, offer, and settlement. Return an empty string to allow the action or a reason to deny it.

#### `set_wallet`

`set_wallet(value: SpatialInventoryWallet) -> void`

Attach the wallet used to check funds and commit currency balances during settlement. Replace or clear it while no currency offers or commits are pending.

#### `withdraw`

`withdraw(actor: int, id: StringName, origin: Vector2i = Vector2i(-1, -1), rotated: Variant = null, target_id: StringName = &"") -> Dictionary`

Return the offered item or escrow stack to the actor's backpack. Optionally specify its destination origin and rotation, or a compatible target stack ID.

#### `withdraw_items`

`withdraw_items(actor: int, ids: StringName[]) -> Dictionary`

Plan the return of several offered IDs to the actor's backpack and commit their returns together if the placement and record edits succeed.

### `Phase`

| Name | Value | Description |
| --- | --- | --- |
| `ACTIVE` | `2` | Both actors have accepted the invitation. Unlocked offers can be edited. |
| `IDLE` | `0` | There is no pending invitation or active trade. |
| `REQUESTED` | `1` | An invitation is waiting for the receiver to accept or a participant to cancel. |
