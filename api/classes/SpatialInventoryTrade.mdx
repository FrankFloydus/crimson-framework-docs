## Methods

### Instance methods

#### [`accept`](/api/classes/SpatialInventoryTrade/methods/accept)

Accept a pending invitation as its receiver and enter the active phase if the eligibility policy allows it.

#### [`cancel`](/api/classes/SpatialInventoryTrade/methods/cancel)

Cancel a pending or active trade as a participant.

#### [`export_snapshot`](/api/classes/SpatialInventoryTrade/methods/export_snapshot)

Return a version 2 snapshot of the trade phase, offers, reservations, escrow, and recovery state.

#### [`get_currency_offers`](/api/classes/SpatialInventoryTrade/methods/get_currency_offers)

Return a detached dictionary of offered amounts keyed by currency ID.

#### [`get_offer`](/api/classes/SpatialInventoryTrade/methods/get_offer)

Return the actor's live offer grid, or null for an unknown actor.

#### [`get_offer_stack`](/api/classes/SpatialInventoryTrade/methods/get_offer_stack)

Return the offered stack's `key`, `quantity`, `max_quantity`, `source_id`, and `record_id`.

#### [`get_recovery`](/api/classes/SpatialInventoryTrade/methods/get_recovery)

Return the actor's recovery grid, or null for an unknown actor.

#### [`get_reserved_source_ids`](/api/classes/SpatialInventoryTrade/methods/get_reserved_source_ids)

Return the IDs of the actor's source items reserved by their offer.

#### [`import_snapshot`](/api/classes/SpatialInventoryTrade/methods/import_snapshot)

Validate and apply a saved trade snapshot against the registered participants, their backpacks, and current host stack records.

#### [`is_locked`](/api/classes/SpatialInventoryTrade/methods/is_locked)

Return whether the actor has accepted their current offer by locking it.

#### [`is_reserved`](/api/classes/SpatialInventoryTrade/methods/is_reserved)

Return whether the source item ID is reserved by the actor's offer.

#### [`merge_offer_stacks`](/api/classes/SpatialInventoryTrade/methods/merge_offer_stacks)

Merge compatible units from one escrow stack into another in the actor's offer, retaining their source allocations.

#### [`move_offer`](/api/classes/SpatialInventoryTrade/methods/move_offer)

Change the placement of an offered item inside the actor's offer grid.

#### [`offer_item`](/api/classes/SpatialInventoryTrade/methods/offer_item)

Offer a complete item from the actor's backpack. `Vector2i(-1, -1)` selects first fit, and a null rotation uses the source orientation.

#### [`offer_items`](/api/classes/SpatialInventoryTrade/methods/offer_items)

Try to offer whole items in the caller's order.

#### [`offer_quantity`](/api/classes/SpatialInventoryTrade/methods/offer_quantity)

Offer part of a placed stack.

#### [`register_participant`](/api/classes/SpatialInventoryTrade/methods/register_participant)

Associate a positive actor ID with a configured backpack.

#### [`request`](/api/classes/SpatialInventoryTrade/methods/request)

Open an invitation from the actor to the other registered participant.

#### [`set_currency_offer`](/api/classes/SpatialInventoryTrade/methods/set_currency_offer)

Set the nonnegative amount promised for a currency.

#### [`set_lock`](/api/classes/SpatialInventoryTrade/methods/set_lock)

Lock or unlock the actor's offer.

#### [`withdraw`](/api/classes/SpatialInventoryTrade/methods/withdraw)

Return the offered item or escrow stack to the actor's backpack.

#### [`withdraw_items`](/api/classes/SpatialInventoryTrade/methods/withdraw_items)

Plan the return of several offered IDs to the actor's backpack and commit their returns together if the placement and record edits succeed.

| Name | Value | Description |
| --- | --- | --- |
| `ACTIVE` | `2` | Both actors have accepted the invitation. Unlocked offers can be edited. |
| `IDLE` | `0` | There is no pending invitation or active trade. |
| `REQUESTED` | `1` | An invitation is waiting for the receiver to accept or a participant to cancel. |
