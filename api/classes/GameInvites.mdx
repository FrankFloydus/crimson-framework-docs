**Inherits** `RefCounted`

The invite gateway for one game attachment.

## Methods

### `is_available`

`is_available() -> bool`

Return whether this exact attachment has a ready invite backend.

### `open_overlay`

`open_overlay() -> Error`

Request the current hosted Steam lobby's invite picker. `OK` means Steam accepted the request, and `ERR_BUSY` means the overlay is loading.

### `pending`

`pending() -> SteamInvite`

Return the latest invite in this attachment, including one captured from Steam Apps launch arguments or the ordinary lobby command line. Crimson ignores malformed or conflicting lobby candidates. The game decides when to join.

### `send`

`send(steam_id: String) -> Error`

Submit one invite to the selected decimal SteamID64 from the current owned lobby. `OK` means the request was submitted to Steam.

## Signals

### `received`

`received(invite: SteamInvite)`

Emitted for a Steam request to join while this game attachment is active, including Steam URL launches with a supported lobby argument. Duplicate notifications for the same lobby within two seconds are coalesced.
