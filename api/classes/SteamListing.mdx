## Methods

### `get_app_id`

`get_app_id() -> int`

Return the Steam AppID under which the listing was observed.

### `get_capacity`

`get_capacity() -> int`

Return the observed lobby member limit, or zero without a limit.

### `get_kind`

`get_kind() -> SteamListing.Kind`

Return the listing's discovery kind.

### `get_name`

`get_name() -> String`

Return the optional advertised label.

### `get_namespace`

`get_namespace() -> StringName`

Return the game namespace expected by this listing.

### `get_ping_ms`

`get_ping_ms() -> int`

Return the measured server latency in milliseconds, or minus one when unavailable.

### `get_players`

`get_players() -> int`

Return the observed lobby member count, or zero without a count.

### `get_server_steam_id`

`get_server_steam_id() -> String`

Return the Steam server identity when present. Lobby locators return an empty string.

### `get_world_id`

`get_world_id() -> StringName`

Return the advertised world identifier when available.

### `is_social`

`is_social() -> bool`

Return true when Steam metadata identified a standalone social lobby. A thin invite locator may need to join Steam membership before the selected flow can verify its type.
