## Return value

`Error`

## Description

Both must be nonempty UTF-8 strings within Steam's byte limits. Returns `@GlobalScope.OK` when Steam accepts the update. Setting a managed key explicitly removes it from [`SteamPresence`](/api/classes/SteamPresence) ownership. Use `clear_rich_presence()` to remove a key. The Game provider reserves `connect`.
