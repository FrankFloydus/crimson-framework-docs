**Inherits** `RefCounted`

Retained observation of one Cloud file share.

## Methods

### `cancel`

`cancel() -> Error`

Ends local observation and completes it with `ERR_SKIP`. Steam can still finish publishing the shared file. Returns `ERR_DOES_NOT_EXIST` when observation has already ended.

### `is_finished`

`is_finished() -> bool`

Returns whether the operation has a terminal result.

### `result`

`result() -> SteamStringResult`

Returns the same terminal result as `completed`, or `null` while observation is pending.

### `wait`

`wait() -> Variant`

Use `await operation.wait()` to receive a [`SteamStringResult`](/api/classes/SteamStringResult) before or after observation ends. A successful result contains the opaque UGC handle as a canonical unsigned decimal string.

## Signals

### `completed`

`completed(result: SteamStringResult)`

Emitted once after a pending share settles, including after cancellation or client shutdown. `result()` already returns this result during the signal.
