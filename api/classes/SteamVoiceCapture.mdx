**Inherits** `RefCounted`

Exclusive Steam microphone capture for one client scope.

## Methods

### `read_frame`

`read_frame() -> SteamVoiceFrameResult`

Polls one opaque compressed frame of up to 8192 bytes. Call once per process frame during capture. An empty poll, exhausted tail, or detached owner returns `ERR_UNAVAILABLE`.

### `start`

`start() -> Error`

Requests capture for this scope. Call after the player opts in and explicitly starts push-to-talk. Another owner or native tail cleanup returns `ERR_BUSY`. Repeating an active start from the same owner is harmless.

### `stop`

`stop() -> Error`

Requests native stop. The exact owner may read final frames for up to 300 milliseconds. Scope teardown discards those frames immediately. A detached or inactive owner returns `ERR_UNAVAILABLE`.
