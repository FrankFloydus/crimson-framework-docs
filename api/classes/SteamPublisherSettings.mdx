**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

## Description

Create this only in a server or operator process. `SteamPublisher.boot()` takes a snapshot of the configuration. The host resolves the credential by reference for each request.

## Properties

**[`app_id`](/api/classes/SteamPublisherSettings/properties/app_id)**

Positive Steamworks AppID verified by the backend and used for publisher writes.

**[`encrypted_ticket_key_ref`](/api/classes/SteamPublisherSettings/properties/encrypted_ticket_key_ref)**

Optional reference for the separate private encrypted app-ticket decryption key.

**[`environment`](/api/classes/SteamPublisherSettings/properties/environment)**

Choose Live for real Steam Wallet transactions or Sandbox for test transactions through Steam's microtransaction sandbox.

**[`host`](/api/classes/SteamPublisherSettings/properties/host)**

Attached trusted scene-tree node that resolves credential references and owns requests.

**[`moderation_policy`](/api/classes/SteamPublisherSettings/properties/moderation_policy)**

Trusted app policy for authorizing and auditing reports and sanctions.

**[`notification_store`](/api/classes/SteamPublisherSettings/properties/notification_store)**

Durable app-owned store for exact notification operations and session ownership.

**[`ownership_challenge_store`](/api/classes/SteamPublisherSettings/properties/ownership_challenge_store)**

Trusted store for atomic one-time challenge consumption.

**[`publisher_key_ref`](/api/classes/SteamPublisherSettings/properties/publisher_key_ref)**

Name of a publisher credential in the host's secret store, such as a vault identifier.

**[`purchase_store`](/api/classes/SteamPublisherSettings/properties/purchase_store)**

Trusted backend adapter for atomic pricing, order persistence, refund policy, and entitlement changes.
