**Inherits** `RefCounted`

## Description

Resolve the offer on the listener that emitted it. It expires after 1.5 seconds and can only be accepted or rejected once. Apply the game's policy before accepting and use the certified account after the connection reports ready.

## Properties

**[`endpoint`](/api/classes/SteamSocketOffer/properties/endpoint)**

The local route on which the offer arrived.

**[`expires_at_msec`](/api/classes/SteamSocketOffer/properties/expires_at_msec)**

Expiry using the clock from `Time.get_ticks_msec()`.

**[`steam_id`](/api/classes/SteamSocketOffer/properties/steam_id)**

Steam's initial account claim, or an empty string when unavailable.
