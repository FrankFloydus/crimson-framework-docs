## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamStringResult`](/api/classes/SteamStringResult).

## Description

A successful result contains the opaque UGC handle as a canonical unsigned decimal string.

## Example

```gdscript
extends Node

func run_wait(steam_cloud_share_operation: SteamCloudShareOperation, wait_label: Label) -> void:
    var result: SteamStringResult = await steam_cloud_share_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: String = result.value
    wait_label.text = "Wait: %s" % str(payload)
```
