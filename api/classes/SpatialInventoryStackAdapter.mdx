## Description

Set both callbacks to support merges and splits while keeping placement and quantity changes consistent.

## Properties

**[`apply_changes`](/api/classes/SpatialInventoryStackAdapter/properties/apply_changes)**

Callback that receives the proposed stack edits and an optional placement commit callable.

**[`describe_stack`](/api/classes/SpatialInventoryStackAdapter/properties/describe_stack)**

Callback that receives a placed item ID and returns a Dictionary with `key`, `quantity`, and `max_quantity`.

## Methods

### Instance methods

#### [`commit_detached_split`](/api/classes/SpatialInventoryStackAdapter/methods/commit_detached_split)

Recheck and commit a split through the record callback.

#### [`commit_merge`](/api/classes/SpatialInventoryStackAdapter/methods/commit_merge)

Recheck the merge plan against current records and commit the quantities through the host callback.

#### [`commit_split`](/api/classes/SpatialInventoryStackAdapter/methods/commit_split)

Recheck the split plan, then create the new stack and place it in the destination at the given origin and rotation.

#### [`get_merge_capacity`](/api/classes/SpatialInventoryStackAdapter/methods/get_merge_capacity)

Return the remaining capacity of the stack if its compatibility key matches `key`, otherwise return 0.

#### [`get_split_limits`](/api/classes/SpatialInventoryStackAdapter/methods/get_split_limits)

Return an `error` code and, on success, the current `quantity` and `max_amount` available for a split.

#### [`get_stack_key`](/api/classes/SpatialInventoryStackAdapter/methods/get_stack_key)

Return the current compatibility key, or an empty StringName if the stack record is unavailable or invalid.

#### [`get_stack_records_revision`](/api/classes/SpatialInventoryStackAdapter/methods/get_stack_records_revision)

Return the revision tracking changes to the host-owned stack records.

#### [`invalidate_stack_records`](/api/classes/SpatialInventoryStackAdapter/methods/invalidate_stack_records)

Advance the record revision after the host updates quantities or stack records outside the adapter.

#### [`plan_merge`](/api/classes/SpatialInventoryStackAdapter/methods/plan_merge)

Read the source and target records and build a checked merge plan for compatible stacks.

#### [`plan_split`](/api/classes/SpatialInventoryStackAdapter/methods/plan_split)

Plan a transfer of part of the source quantity to an unused `new_id`.
