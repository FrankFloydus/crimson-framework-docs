## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive `Dictionary`.

## Description

While pending, this method returns the completion signal. Once settled, it returns a copy of the result immediately.

## Example

```gdscript
func display_startup_result(operation: GameOperation) -> void:
    var result: Dictionary = await operation.wait()
    if result.ok:
        print("Game ready.")
    else:
        push_error(result.message)
```
