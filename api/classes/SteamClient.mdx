**Inherits** `Node`

## Description

Attach the client to a persistent node and start it on the main thread. Active scopes share the local account and the process AppID. Cached Steam services can remain available without a live connection to Valve. The client pumps Steam callbacks while active. Stopping the client, leaving the scene tree, or losing the native callback pipe invalidates its services and ends observation of outstanding operations.

#### `restart_through_steam_if_needed`

`static restart_through_steam_if_needed(app_id: int) -> Error`

Optionally asks Steam to relaunch a rendered shipping game from the player's Steam Library. Call before `boot()`, any provider initialization, or the overlay bootstrap. `ERR_SKIP` means Steam requested relaunch and the calling game should quit promptly. `OK` means the current process can continue. The check requires a non-Spacewar AppID, a Steam-enabled build, and the packaged SDK runtime. It is unavailable in headless or editor contexts and reports `ERR_BUSY` after client initialization has been attempted.

## Signals

### `runtime_lost`

`runtime_lost()`

Emitted after a fatal local Steam IPC failure invalidates this client scope. A standalone owner can defer `start()` to acquire a fresh scope after all failure observers finish. A temporary loss of network connectivity keeps the local scope active.
