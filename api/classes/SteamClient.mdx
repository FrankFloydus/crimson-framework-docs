## Description

Use `Steamworks.boot()` to attach Steam features to an existing owner. This callback node supports existing scenes and scripts. Active scopes share the local account and the process AppID. Cached Steam services can remain available without a live connection to Valve. The client pumps Steam callbacks while active. Stopping the client, leaving the scene tree, or losing the native callback pipe invalidates its services and ends observation of outstanding operations.

## Signals

### `runtime_lost`

`runtime_lost()`

Emitted after a fatal local Steam IPC failure invalidates this client scope. A standalone owner can defer `start()` to acquire a fresh scope after all failure observers finish. A temporary loss of network connectivity keeps the local scope active.
