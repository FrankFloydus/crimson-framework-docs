## Signature

```text
send(bytes: PackedByteArray, delivery: SteamDelivery.Mode = 0) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `bytes` | `PackedByteArray` | — |
| `delivery` | `SteamDelivery.Mode` | `0` |

## Return value

`Error`

## Description

Both directions allow up to 128 frames and 256 KiB per second. `ERR_BUSY` reports SDK backpressure or an exhausted outbound budget.

## Example

extends Node

func run_send(
