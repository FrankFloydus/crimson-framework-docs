## Description

Use `SteamClient.video()` after boot. Entitlement and a processed Steam Video AppID are required for playback. Identical lookups coalesce across client scopes. A pending observation times out after 15 seconds. Steam can still finish the native lookup after that.

## Methods

### Instance methods

#### [`broadcast_status`](/api/classes/SteamVideo/methods/broadcast_status)

Reads whether Steam is uploading a broadcast and how many viewers are watching.

#### [`projection_settings`](/api/classes/SteamVideo/methods/projection_settings)

Await a [`SteamStringResult`](/api/classes/SteamStringResult) with the 360-degree projection settings for the specified video AppID.

#### [`stream_url`](/api/classes/SteamVideo/methods/stream_url)

Await a [`SteamStringResult`](/api/classes/SteamStringResult) with the Steam-issued stream URL for an entitled video AppID.
