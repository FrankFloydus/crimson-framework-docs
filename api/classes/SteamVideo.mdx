**Inherits** `RefCounted`

## Description

Use `SteamClient.video()` after boot. Entitlement and a processed Steam Video AppID are required for playback. Identical lookups coalesce across client scopes. A pending observation times out after 15 seconds. Steam can still finish the native lookup after that.

## Methods

### `broadcast_status`

`broadcast_status() -> SteamBroadcastStatusResult`

Reads whether Steam is uploading a broadcast and how many viewers are watching.

### `projection_settings`

`projection_settings(video_app_id: int) -> Variant`

Await a [`SteamStringResult`](/api/classes/SteamStringResult) with the 360-degree projection settings for the specified video AppID. Concurrent lookups of the same AppID share a single Steam request.

### `stream_url`

`stream_url(video_app_id: int) -> Variant`

Await a [`SteamStringResult`](/api/classes/SteamStringResult) with the Steam-issued stream URL for an entitled video AppID. Treat this URL as temporary and keep it out of logs.

## Signals

### `broadcast_started`

`broadcast_started()`

Emitted when Steam reports a local broadcast upload started.

### `broadcast_stopped`

`broadcast_stopped(reason: int)`

Emitted with the SDK broadcast upload result code when the local upload stops.
