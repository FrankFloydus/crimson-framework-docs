A typed result from trusted Steam moderation.

Check `SteamResult.ok` for success. The approved action's audit receipt remains available when its remote outcome is unresolved or the backend's terminal audit write fails. An audit write failure returns `ERR_DATABASE_CANT_WRITE`. The receipt's acknowledgment field retains the observed Steam outcome.
