**Inherits** `RefCounted`

## Description

Get this service from `SteamClient.diagnostics()`. Start capture and drain snapshots from the main thread. One client scope can own the process-wide SDK warning hook at a time. The client releases capture automatically when it stops or exits the scene tree.

## Methods

### Instance methods

#### [`drain`](/api/classes/SteamDiagnostics/methods/drain)

Takes the current messages in capture order and resets the queue and overflow count.

#### [`start`](/api/classes/SteamDiagnostics/methods/start)

Claims the process-wide warning hook.

#### [`stop`](/api/classes/SteamDiagnostics/methods/stop)

Releases this service's hook and discards pending diagnostics on the main thread.
