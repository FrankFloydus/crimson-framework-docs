## Description

Get this service from `SteamClient.diagnostics()`. Start capture and drain snapshots from the main thread. One client scope can own the process-wide SDK warning hook at a time. The client releases capture automatically when it stops or exits the scene tree.

## Methods

### `drain`

`drain() -> SteamDiagnosticBatch`

Takes the current messages in capture order and resets the queue and overflow count. Returns an empty snapshot for an inactive scope, a caller without ownership, or a call from outside the main thread.

### `start`

`start() -> Error`

Claims the process-wide warning hook. Returns `OK` for a new capture or if this service already owns it. Returns `ERR_BUSY` when another scope owns it or a caller invokes this method outside the main thread. Returns `ERR_UNAVAILABLE` when the scope or SDK hook is unavailable.

### `stop`

`stop() -> void`

Releases this service's hook and discards pending diagnostics on the main thread. Repeated calls and calls by other scopes leave the hook state as it is.
