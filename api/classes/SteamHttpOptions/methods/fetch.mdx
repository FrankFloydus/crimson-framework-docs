## Signature

```text
fetch(url: String) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `url` | `String` | — |

## Return value

`Variant`

Await the call to receive [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult).

## Description

Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

## Example

```gdscript
extends Node

func run_fetch(
    steam_http_options: SteamHttpOptions,
    url: String,
    apply_fetch: Callable
) -> void:
    var result: SteamHttpResponseResult = await steam_http_options.fetch(url)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamHttpResponse = result.value
    if payload == null:
        return
    apply_fetch.call(payload)
```
