## Return value

[`SteamHttpOptions`](/api/classes/SteamHttpOptions)

## Description

Header names are case-insensitive, and a new value replaces the same header on that branch. Steam manages framing and connection headers.

## Example

```gdscript
extends Node

func run_with_header(
    steam_http_options: SteamHttpOptions,
    name: String,
    value: String,
    url: String,
    apply_response: Callable
) -> void:
    var result: SteamHttpOptions = steam_http_options.with_header(name, value)
    if result == null:
        return
    var response: SteamHttpResponseResult = await result.fetch(url)
    if response == null:
        return
    if not response.ok:
        push_warning(response.message)
        return
    var payload: SteamHttpResponse = response.value
    if payload == null:
        return
    apply_response.call(payload)
```
