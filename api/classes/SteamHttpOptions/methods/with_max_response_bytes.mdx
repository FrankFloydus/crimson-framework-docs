
## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `bytes` | `int` | — |

## Return value

[`SteamHttpOptions`](/api/classes/SteamHttpOptions)

## Description

The default is 1 MiB. Larger bodies return a limit error and expose no partial response.

## Example

```gdscript
extends Node

func run_with_max_response_bytes(
    steam_http_options: SteamHttpOptions,
    bytes: int,
    url: String,
    apply_response: Callable
) -> void:
    var result: SteamHttpOptions = steam_http_options.with_max_response_bytes(bytes)
    if result == null:
        return
    var response: SteamHttpResponseResult = await result.fetch(url)
    if response == null:
        return
    if not response.ok:
        push_warning(response.message)
        return
    var payload: SteamHttpResponse = response.value
    if payload == null:
        return
    apply_response.call(payload)
```
