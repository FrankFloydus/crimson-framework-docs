## Parameters

## Return value

[`SteamHttpOptions`](/api/classes/SteamHttpOptions)

## Description

Select up to 16 additional names. Matching ignores case, and Content-Type is captured when present. A selected field larger than 2,048 bytes returns a limit error.

## Example

```gdscript
extends Node

func run_with_response_headers(
    steam_http_options: SteamHttpOptions,
    names: PackedStringArray,
    url: String,
    apply_response: Callable
) -> void:
    var result: SteamHttpOptions = steam_http_options.with_response_headers(names)
    if result == null:
        return
    var response: SteamHttpResponseResult = await result.fetch(url)
    if response == null:
        return
    if not response.ok:
        push_warning(response.message)
        return
    var payload: SteamHttpResponse = response.value
    if payload == null:
        return
    apply_response.call(payload)
```
