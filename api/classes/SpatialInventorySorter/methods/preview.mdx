preview(inventory: SpatialInventory, pinned_ids: Array = [], allow_rotation: bool = true, placement_policy: Callable = Callable()) -> Dictionary

## Return value

`Dictionary`

## Description

Pinned items keep their positions and orientations. The optional policy receives `id`, `footprint`, `origin`, `rotated`, `source`, `destination`, `swap_id`, and `action`. Return an empty String to accept a candidate. The result reports `error`, plus `grid_size`, `placements`, and `changed_count` on success.
