## Signature

```text
cancel_load() -> Error
```

## Return value

`Error`

## Description

Returns `ERR\_DOES\_NOT\_EXIST` when idle, `ERR\_UNAUTHORIZED` on a client, or `ERR\_BUSY` if publication has begun.

## Example

extends Node

func run_cancel_load(scene_load_manager: SceneLoadManager, status_label: Label) -> void:
    var result: Error = scene_load_manager.cancel_load()
