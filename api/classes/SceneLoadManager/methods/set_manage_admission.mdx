## Signature

```text
set_manage_admission(enabled: bool) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `enabled` | `bool` | — |

## Return value

`Error`

## Description

The default is `true`. Set `false` when the orchestrator closes admission before a host transition and holds it through confirmation. Returns `ERR\_BUSY` while a transition is active or this loader holds a gate.
