## Signature

```text
request_load(scene_id: StringName) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `scene_id` | `StringName` | — |

## Return value

`Error`

## Description

Call offline or as host peer 1. A client receives `ERR\_UNAUTHORIZED`, an overlapping request receives `ERR\_BUSY`, and an unknown ID receives `ERR\_DOES\_NOT\_EXIST`. Signals report the outcome after admission.

## Example

```gdscript
const HARBOR_WORLD: StringName = &"harbor"

func queue_harbor_load(loader: SceneLoadManager) -> Error:
    # Set the world container and register this scene before requesting it.
    var error: Error = loader.request_load(HARBOR_WORLD)
    if error != OK:
        push_error(error_string(error))
    # Use load_completed or load_failed to report the final outcome.
    return error
```
