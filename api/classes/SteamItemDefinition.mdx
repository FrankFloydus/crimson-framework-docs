**Inherits** `RefCounted`

One published item definition copied from the Steam catalog.

`SteamInventory.definitions()` and `SteamInventory.definition()` copy the app's published definitions. The read-only dictionary contains Steam's available custom properties. The display name or type is empty if the corresponding property is absent.

| Property | Type | Default | Accessors | Description |
