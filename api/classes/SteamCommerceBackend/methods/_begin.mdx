## Description

On success, echo the checkout ID in the typed response.

## Example

```gdscript
extends SteamCommerceBackend

# Send the checkout to your authenticated game backend. It prices the cart
# and returns a typed result that echoes this checkout ID.
var begin_checkout: Callable

func _begin(cart: SteamPurchaseCart, checkout_id: String, request: SteamCommerceRequest) -> void:
    var result: SteamPurchaseOutcomeResult
    if begin_checkout.is_valid():
        result = await begin_checkout.call(cart, checkout_id) as SteamPurchaseOutcomeResult
    if result == null:
        result = SteamPurchaseOutcomeResult.create(ERR_UNAVAILABLE, null, checkout_id)
    request.complete_order(result)
```
