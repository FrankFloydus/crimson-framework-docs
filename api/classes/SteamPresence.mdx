**Inherits** `RefCounted`

Manages the localized Steam status and optional party grouping for one client scope.

Get this service from `SteamClient.presence()` or `SteamScope.presence()`. Only one attached scope owns the managed status at a time. Replacing or clearing status affects the keys that scope still owns. The Game provider owns the join route independently.

## Methods

### `clear`

`clear() -> Error`

Clears the keys still owned by this scope. A non-owning scope can call this without changing another scope's status. Explicit Friends overrides and unrelated presence keys are preserved. Stopping the owning scope also attempts to clear its keys.

### `clear_joinable`

`clear_joinable() -> Error`

Clears this Game's connect key and suppresses automatic publication for the current hosted lobby. Keeps the status label, party grouping, and any foreign connect key. Call `joinable()` to publish again. A newly hosted lobby uses its usual visibility policy. Returns `@GlobalScope.ERR_UNAVAILABLE` outside a live Steam Game scope, or `@GlobalScope.FAILED` if Steam declines the clear.

### `is_available`

`is_available() -> bool`

Returns whether the active main-thread Steam scope supports local status writes and cache reads.

### `joinable`

`joinable(listing: SteamListing) -> Error`

Publishes Steam Join Game for the exact Game's current friends-only or public lobby while admission is open and seats remain. Returns `@GlobalScope.OK` if Steam accepted the route or the Game already owns it. Returns `@GlobalScope.ERR_BUSY` when a foreign connect key exists, `@GlobalScope.ERR_UNAUTHORIZED` for an ineligible or stale lobby, and `@GlobalScope.ERR_UNAVAILABLE` outside a live Steam Game scope.

### `show`

`show(display_token: StringName, values: Dictionary[String, String] = {}, party_id: String = "", party_size: int = 0) -> Error`

Publishes a Steamworks localization token beginning with `#` and its optional replacements. To group players, provide both a nonempty `party_id` and a positive `party_size`. Use the defaults for no grouping. Replacement keys must fit Steam's byte and key limits and must avoid `connect`, `status`, and names beginning with `steam_`. Returns `@GlobalScope.ERR_BUSY` when another scope owns the status or unrelated keys leave insufficient capacity. Steam applies each key separately. `@GlobalScope.OK` acknowledges local acceptance. Configure the token in Steamworks to display the label for other players.
