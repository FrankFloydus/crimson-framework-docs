**Inherits** `RefCounted`

## Description

Get this service from `SteamClient.presence()` or `SteamScope.presence()`. Only one attached scope owns the managed status at a time. Replacing or clearing status affects the keys that scope still owns. The Game provider owns the join route independently.

## Methods

### Instance methods

#### [`clear`](/api/classes/SteamPresence/methods/clear)

Clears the keys still owned by this scope.

#### [`clear_joinable`](/api/classes/SteamPresence/methods/clear_joinable)

Clears this Game's connect key and suppresses automatic publication for the current hosted lobby.

#### [`is_available`](/api/classes/SteamPresence/methods/is_available)

Returns whether the active main-thread Steam scope supports local status writes and cache reads.

#### [`joinable`](/api/classes/SteamPresence/methods/joinable)

Publishes Steam Join Game for the exact Game's current friends-only or public lobby while admission is open and seats remain.

#### [`show`](/api/classes/SteamPresence/methods/show)

Publishes a Steamworks localization token beginning with `#` and its optional replacements.
