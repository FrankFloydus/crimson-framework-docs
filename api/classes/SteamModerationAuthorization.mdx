**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

A game policy's approval for one exact immutable moderation request.

Return an approval from `SteamModerationPolicy._authorize()` only after verifying the exact request. For a reviewed write, reserve a durable audit record before returning the approval. An approval for another request, an incorrect removal target, or a missing audit reference cannot authorize a sanction.

## Methods

### `approve`

`static approve(request: SteamModerationRequest, player_id: String = "", audit_id: String = "") -> SteamModerationAuthorization`

Returns an approval bound to this exact `request`. Use the reviewed `player_id` for a suspension or ban. An empty player ID keeps the request's explicit target. A sanction or removal requires a durable `audit_id`. Returns `null` for a missing request.

### `get_audit_id`

`get_audit_id() -> String`

Returns the trusted backend's durable audit reference for a reviewed action.

### `get_player_id`

`get_player_id() -> String`

Returns the policy's resolved target SteamID64 when the action addresses a player.
