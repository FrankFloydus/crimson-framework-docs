## Description

Accept with a SessionIdentity derived from verified evidence, or reject. You can settle the request during this call or later on the scene thread. The default implementation rejects the request.

## Example

```gdscript
extends SessionAuthenticator

# The verifier checks the provider, challenge, and session context, then returns a verified identity.
var verify_identity: Callable

func _verify(request: SessionAuthRequest) -> void:
    if not verify_identity.is_valid():
        request.reject()
        return
    var identity: SessionIdentity = verify_identity.call(request) as SessionIdentity
    if identity == null:
        request.reject()
        return
    request.accept(identity)
```
