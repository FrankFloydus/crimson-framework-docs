## Return value

`PackedByteArray`

## Description

The authority flag describes the local process. Return 1 to 4096 bytes for a proof, or an empty array to deny the connection.

## Example

```gdscript
extends SessionAuthenticator

const CHALLENGE_BYTES: int = 32
const MAX_PROOF_BYTES: int = 4096

# Set this to your credential provider's synchronous challenge signer.
var sign_challenge: Callable

func _make_proof(peer_id: int, authority: bool, challenge: PackedByteArray) -> PackedByteArray:
    if challenge.size() != CHALLENGE_BYTES or not sign_challenge.is_valid():
        return PackedByteArray()
    var proof: PackedByteArray = sign_challenge.call(peer_id, authority, challenge)
    if proof.is_empty() or proof.size() > MAX_PROOF_BYTES:
        return PackedByteArray()
    return proof
```
