### Method details

#### `authorize`

`authorize(ticket: PackedByteArray) -> Error`

Return a fresh signed Steam relay ticket of 1 to 4096 bytes for this exact client, AppID, authority, virtual port and registration. Crimson verifies the SDK-parsed fields and cache selection before opening any peer.

#### `fail`

`fail() -> Error`

Settle the pending request without a registration or authorization. A settled or unconfigured request returns `ERR_ALREADY_IN_USE`.

#### `get_app_id`

`get_app_id() -> int`

The Steam AppID selected and validated by the native SDK.

#### `get_kind`

`get_kind() -> SteamRelayRequest.Kind`

Return the native hosted step, registration or authorization.

#### `get_listing_id`

`get_listing_id() -> String`

The exact generation-scoped hosted locator. The coordinator must use this same value to register and withdraw.

#### `get_local_steam_id`

`get_local_steam_id() -> String`

The signed-in client's candidate SteamID64. The coordinator independently authenticates the caller before using this value. Empty during registration.

#### `get_login_blob`

`get_login_blob() -> PackedByteArray`

Copy the Steam-signed server login blob on the scene thread before dispatching backend work. Send it only to the authenticated coordinator backend. Empty off the scene thread, during client authorization, or after settlement.

#### `get_namespace`

`get_namespace() -> StringName`

The matching game's namespace, bound to the selected hosted locator.

#### `get_profile`

`get_profile() -> StringName`

The operator-defined hosted relay deployment profile.

#### `get_registration_id`

`get_registration_id() -> String`

The generation nonce as a decimal unsigned 64-bit string. The backend signs this value into the relay ticket's `crimson_registration` fixed64 extra field.

#### `get_server_steam_id`

`get_server_steam_id() -> String`

The expected certified Steam GameServer identity as a decimal SteamID64.

#### `get_virtual_port`

`get_virtual_port() -> int`

The exact Steam hosted virtual port, from zero through 65535.

#### `get_world_id`

`get_world_id() -> StringName`

The authority's mounted world during registration. Empty during client authorization.

#### `is_cancelled`

`is_cancelled() -> bool`

Return true once the owning Game abandoned this exact request.

#### `registered`

`registered() -> Error`

Acknowledge registration of the exact signed server login. If the Game cancelled, the request withdraws that same registration. `ERR_UNAVAILABLE` means the backend must compensate itself.

## Constants and enums

### `Kind`

| Name | Value | Description |
| --- | --- | --- |
| `AUTHORIZE` | `2` | Authenticate the current client independently and sign a ticket for the exact server registration. |
| `REGISTER` | `1` | Authenticate and register the exact server login with the trusted coordinator. |
| `UNCONFIGURED` | `0` | No native Game owns this request. |
