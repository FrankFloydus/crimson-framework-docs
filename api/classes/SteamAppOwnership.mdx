## Description

Use `owns_app` to check an active license. The other values describe the license where Valve supplies the corresponding fields.

## Properties

**[`acquired_at`](/api/classes/SteamAppOwnership/properties/acquired_at)**

Acquisition time text from Steam, or an empty string when unavailable.

**[`app_id`](/api/classes/SteamAppOwnership/properties/app_id)**

AppID requested by the trusted ownership check.

**[`expires_at`](/api/classes/SteamAppOwnership/properties/expires_at)**

Expiration time text or Steam's `never` sentinel.

**[`license_owner_steam_id`](/api/classes/SteamAppOwnership/properties/license_owner_steam_id)**

Full decimal SteamID64 of the owner, or an empty string when unavailable.

**[`owns_app`](/api/classes/SteamAppOwnership/properties/owns_app)**

Whether Steam reports an active license for the requested app.

**[`permanent`](/api/classes/SteamAppOwnership/properties/permanent)**

Whether Steam reports permanent ownership.

**[`site_license`](/api/classes/SteamAppOwnership/properties/site_license)**

Whether Steam reports a PC Café license.

**[`user_canceled`](/api/classes/SteamAppOwnership/properties/user_canceled)**

Whether Steam reports that the user cancelled the license.
