## Description

Read these fields from a successful `SteamController.analog()` result. Steam's mode determines whether the vector represents joystick axes, pointer deltas, or another configured source. Values for relative pointer motion can exceed the normalized joystick range.

## Properties

**[`active`](/api/classes/SteamAnalogInput/properties/active)**

Read-only active-set availability for this action.

**[`mode`](/api/classes/SteamAnalogInput/properties/mode)**

Read-only source mode that describes how to interpret the vector.

**[`value`](/api/classes/SteamAnalogInput/properties/value)**

Read-only horizontal and vertical values for the current source mode.
