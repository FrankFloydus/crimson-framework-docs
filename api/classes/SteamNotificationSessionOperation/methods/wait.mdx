## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamNotificationSessionResult`](/api/classes/SteamNotificationSessionResult).

## Example

```gdscript
extends Node

func run_wait(
    steam_notification_session_operation: SteamNotificationSessionOperation,
    apply_wait: Callable
) -> void:
    var result: SteamNotificationSessionResult = await steam_notification_session_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamNotificationSession = result.value
    if payload == null:
        return
    apply_wait.call(payload)
```
