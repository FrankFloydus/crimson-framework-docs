**Inherits** `RefCounted`

Scoped reference to one Workshop item by published file ID.

## Methods

### `edit`

`edit() -> SteamWorkshopPublishRequest`

Creates a branchable draft that edits this existing item. Unset fields keep their current values. Submission verifies that the item belongs to the active app.

### `fetch`

`fetch() -> Variant`

Use `await item.fetch()` to receive a [`SteamWorkshopItemResult`](/api/classes/SteamWorkshopItemResult) for this exact item in the active app. An unavailable or removed item can report `ERR_FILE_NOT_FOUND`.

### `install`

`install(high_priority: bool = false) -> Variant`

Use `await item.install()` to receive a [`SteamWorkshopInstallResult`](/api/classes/SteamWorkshopInstallResult). A same-app item with a current local directory resolves immediately after identity verification. Otherwise this waits for Steam's matching download. `high_priority` tells Steam to prioritize the transfer ahead of other downloads. An unsubscribed item may be cached temporarily. Inspect and validate the installed content before using it.

### `installed`

`installed() -> SteamWorkshopInstall`

Returns a current local content directory after this client verifies the item through a Workshop query or a matching install event. An unknown, pending, legacy, or out-of-date install returns `null`. Steam can record this inspection in the signed-in player's used items.

### `subscribe`

`subscribe() -> Variant`

Use `await item.subscribe()` to receive the [`SteamWorkshopSubscriptionResult`](/api/classes/SteamWorkshopSubscriptionResult) for an explicit subscription to this app's item. The result confirms the subscription. Use `install()` to wait for a current local directory.

### `unsubscribe`

`unsubscribe() -> Variant`

Use `await item.unsubscribe()` to receive the [`SteamWorkshopSubscriptionResult`](/api/classes/SteamWorkshopSubscriptionResult) for removing the subscription. Steam may remove the installed files after the game closes.

### `vote`

`vote(up: bool) -> Variant`

Use `await item.vote(up)` to receive the [`SteamWorkshopVoteResult`](/api/classes/SteamWorkshopVoteResult) after Steam acknowledges this app item's upvote or downvote for the signed-in account.
