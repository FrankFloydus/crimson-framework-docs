**Inherits** `RefCounted`

## Description

Resolve this facade with `SteamClient.screenshots()`. Call it on the main thread. Steam's overlay handles its normal screenshot hotkey. Submitted images go to the user's local Steam screenshot library.

## Methods

### Instance methods

#### [`capture`](/api/classes/SteamScreenshots/methods/capture)

Ask Steam to capture the current rendered frame.

#### [`from_image`](/api/classes/SteamScreenshots/methods/from_image)

Snapshot a nonempty, uncompressed image as RGB8 without mipmaps.

#### [`is_available`](/api/classes/SteamScreenshots/methods/is_available)

Return whether this scope has Steam's screenshot interface and ready-event routing.

## Signals

### `screenshot_ready`

`screenshot_ready(screenshot: SteamScreenshot)`

Emitted for a successful Steam save, including the normal screenshot hotkey. Only the scope that submitted an annotated image reports its annotation status. Use the draft's result for exact correlation.
