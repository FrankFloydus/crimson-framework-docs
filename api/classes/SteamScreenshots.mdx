**Inherits** `RefCounted`

Scoped access to Steam screenshot capture, annotated saves, and ready events.

Resolve this facade with `SteamClient.screenshots()`. Call it on the main thread. Steam's overlay handles its normal screenshot hotkey. Submitted images go to the user's local Steam screenshot library.

## Methods

### `capture`

`capture() -> Error`

Ask Steam to capture the current rendered frame. Return `OK` when the request was issued. Observe `screenshot_ready` after a successful save. Return `ERR_BUSY` while the overlay is unavailable for capture or another integration has hooked screenshots.

### `from_image`

`from_image(image: Image) -> SteamScreenshotRequest`

Snapshot a nonempty, uncompressed image as RGB8 without mipmaps. Each side is limited to 8192 pixels and the total to 16777216 pixels. Invalid input is reported when submitting the draft. Later edits to the original image do not affect the draft.

### `is_available`

`is_available() -> bool`

Return whether this scope has Steam's screenshot interface and ready-event routing. Capture has the additional overlay requirement.

## Signals

### `screenshot_ready`

`screenshot_ready(screenshot: SteamScreenshot)`

Emitted for a successful Steam save, including the normal screenshot hotkey. Only the scope that submitted an annotated image reports its annotation status. Use the draft's result for exact correlation.
