**Inherits** `RefCounted`

Reads Steam app and DLC metadata and issues optional DLC install requests.

Get this service from `SteamClient.apps()`. Call its methods on the main thread while its client scope is active. Store availability, local subscription, and installation are separate Steam queries. Local metadata is suitable for presentation. Multiplayer entitlement decisions use a verified server-side identity and ownership check.

## Methods

### `available_languages`

`available_languages() -> PackedStringArray`

Returns the app's configured Steam language codes in Steam's order, or an empty array when unavailable.

### `beta_branch`

`beta_branch() -> String`

Returns the selected named beta branch. An empty string indicates the default branch or unavailable data.

### `build_id`

`build_id() -> int`

Returns Steam's build ID for the current app. Returns `0` when Steam has no build ID for this process, including launches outside a Steam download or an inactive client scope.

### `current_language`

`current_language() -> String`

Returns the Steam language code selected for this game, or an empty string when unavailable. For the Steam client interface language, use `SteamUtils.ui_language()`.

### `dlc`

`dlc() -> SteamDlcListResult`

Returns a detached typed catalog for the current app with at most 256 entries in Steam's order. Steam may limit which entries it reports. Use known DLC AppIDs for required content. The `SteamDlcInfo.available` flag describes visibility on the Steam store.

### `download_progress`

`download_progress(dlc_app_id: int) -> SteamDlcProgressResult`

Reads a progress snapshot for the optional DLC identified by `dlc_app_id`. When Steam reports no active download, the query succeeds with an inactive [`SteamDlcProgress`](/api/classes/SteamDlcProgress). Returns an error for an invalid AppID, unavailable interface, or byte counts beyond the signed integer range.

### `install_dlc`

`install_dlc(dlc_app_id: int) -> Error`

Issues an installation request for an optional DLC AppID associated with this game. Steam's local subscription check must report ownership. `OK` confirms that the request was issued. Use `download_progress()`, `is_dlc_installed()`, or `dlc_installed` to observe installation.

### `is_available`

`is_available() -> bool`

Returns whether the active client exposes the Steam Apps interface on the main thread.

### `is_dlc_installed`

`is_dlc_installed(app_id: int) -> bool`

Returns whether the signed-in account owns and has installed the DLC identified by `app_id`. Returns `false` for invalid or unavailable queries.

### `is_subscribed_to_app`

`is_subscribed_to_app(app_id: int) -> bool`

Returns whether the signed-in account has a Steam subscription to the app identified by `app_id`. The AppID must be positive. Returns `false` when the query is invalid or unavailable.

### `notification_session_id`

`notification_session_id() -> String`

Returns the nonzero decimal session ID Steam supplied when opening a Game Notification. Returns an empty string when absent, invalid, or unavailable. Ask the game's backend to authorize the selected session for the authenticated player before loading it.

### `owns_dlc`

`owns_dlc(dlc_app_id: int) -> bool`

Returns Steam's local subscription state for the supplied DLC AppID. Use it as an ownership hint in the UI. Use `is_dlc_installed()` to check whether the local content is installed.

### `uninstall_dlc`

`uninstall_dlc(dlc_app_id: int) -> Error`

Issues a removal request for the selected optional DLC. Call after the player confirms removal. `OK` confirms that the request was issued. Use `is_dlc_installed()` to check the resulting state.

## Signals

### `dlc_installed`

`dlc_installed(dlc_app_id: int)`

Emitted when Steam reports installation of the specified DLC AppID to the active client scope. Refresh the local content catalog before presenting the DLC as playable.

### `notification_session_requested`

`notification_session_requested(session_id: String)`

Emitted when Steam supplies a valid Game Notification session ID while the game is running. Validate session membership before resuming it.
