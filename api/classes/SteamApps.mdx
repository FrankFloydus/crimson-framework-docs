## Description

Get this service from `SteamClient.apps()`. Call its methods on the main thread while its client scope is active. Store availability, local subscription, and installation are separate Steam queries. Local metadata is suitable for presentation. Multiplayer entitlement decisions use a verified server-side identity and ownership check.

## Methods

### Instance methods

#### [`available_languages`](/api/classes/SteamApps/methods/available_languages)

Returns the app's configured Steam language codes in Steam's order, or an empty array when unavailable.

#### [`beta_branch`](/api/classes/SteamApps/methods/beta_branch)

Returns the selected named beta branch.

#### [`build_id`](/api/classes/SteamApps/methods/build_id)

Returns Steam's build ID for the current app.

#### [`current_language`](/api/classes/SteamApps/methods/current_language)

Returns the Steam language code selected for this game, or an empty string when unavailable.

#### [`dlc`](/api/classes/SteamApps/methods/dlc)

Returns a detached typed catalog for the current app with at most 256 entries in Steam's order.

#### [`download_progress`](/api/classes/SteamApps/methods/download_progress)

Reads a progress snapshot for the optional DLC identified by `dlc_app_id`.

#### [`install_dlc`](/api/classes/SteamApps/methods/install_dlc)

Issues an installation request for an optional DLC AppID associated with this game.

#### [`is_available`](/api/classes/SteamApps/methods/is_available)

Returns whether the active client exposes the Steam Apps interface on the main thread.

#### [`is_dlc_installed`](/api/classes/SteamApps/methods/is_dlc_installed)

Returns whether the signed-in account owns and has installed the DLC identified by `app_id`.

#### [`is_subscribed_to_app`](/api/classes/SteamApps/methods/is_subscribed_to_app)

Returns whether the signed-in account has a Steam subscription to the app identified by `app_id`.

#### [`notification_session_id`](/api/classes/SteamApps/methods/notification_session_id)

Returns the nonzero decimal session ID Steam supplied when opening a Game Notification.

#### [`owns_dlc`](/api/classes/SteamApps/methods/owns_dlc)

Returns Steam's local subscription state for the supplied DLC AppID.

#### [`uninstall_dlc`](/api/classes/SteamApps/methods/uninstall_dlc)

Issues a removal request for the selected optional DLC.

## Signals

### `dlc_installed`

`dlc_installed(dlc_app_id: int)`

Emitted when Steam reports installation of the specified DLC AppID to the active client scope. Refresh the local content catalog before presenting the DLC as playable.

### `notification_session_requested`

`notification_session_requested(session_id: String)`

Emitted when Steam supplies a valid Game Notification session ID while the game is running. Validate session membership before resuming it.
