**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

## Description

The publisher passes this exact object to `SteamModerationPolicy._authorize()`. For a reviewed suspension or ban, resolve the report and its target in the game-owned review store. For a removal, check the supplied target. Persist the exact app, operation, report or target, reason, and duration before approving a reviewed write.
