## Description

Use `wait()` to await a terminal outcome and `cancel()` to stop a pending request.

## Methods

### Instance methods

#### [`cancel`](/api/classes/SteamHttpResponseOperation/methods/cancel)

Cancel the local request on the main thread.

#### [`is_finished`](/api/classes/SteamHttpResponseOperation/methods/is_finished)

Return whether the operation has settled.

#### [`result`](/api/classes/SteamHttpResponseOperation/methods/result)

Return the terminal result, or `null` while pending.

#### [`wait`](/api/classes/SteamHttpResponseOperation/methods/wait)

Return the completion signal while pending or the stored [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after settlement.

## Signals

### `completed`

`completed(result: SteamHttpResponseResult)`

Emitted once after the native request and its callback routing are retired. The result carries the transport outcome and any complete HTTP response.
