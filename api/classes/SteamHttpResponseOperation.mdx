**Inherits** `RefCounted`

Retained, cancellable operation for one submitted Steam HTTP request.

Use `wait()` to await a terminal outcome and `cancel()` to stop a pending request.

## Methods

### `cancel`

`cancel() -> Error`

Cancel the local request on the main thread. A successful cancellation settles the operation with `ERR_SKIP`. Return `ERR_DOES_NOT_EXIST` if the request is no longer pending.

### `is_finished`

`is_finished() -> bool`

Return whether the operation has settled.

### `result`

`result() -> SteamHttpResponseResult`

Return the terminal result, or `null` while pending.

### `wait`

`wait() -> Variant`

Return the completion signal while pending or the stored [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after settlement. Awaiting again returns the same result.

## Signals

### `completed`

`completed(result: SteamHttpResponseResult)`

Emitted once after the native request and its callback routing are retired. The result carries the transport outcome and any complete HTTP response.
