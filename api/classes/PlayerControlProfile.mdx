## Description

Set up input and default character movement on an existing body and its view. The profile starts a private driver that reads input before the mover advances physics. Settings UI can use the same `Controls` instance as the player.

## Properties

**[`capture_pointer_on_boot`](/api/classes/PlayerControlProfile/properties/capture_pointer_on_boot)**

Attempt desktop pointer capture after local control attaches.

**[`controller_style`](/api/classes/PlayerControlProfile/properties/controller_style)**

Choose how movement input turns and moves the body.

**[`forward_direction`](/api/classes/PlayerControlProfile/properties/forward_direction)**

Sets forward for FPS / Shoulder Aim.

**[`input_layout`](/api/classes/PlayerControlProfile/properties/input_layout)**

Defines actions and default bindings.

**[`jump_action`](/api/classes/PlayerControlProfile/properties/jump_action)**

Button action whose press requests grounded takeoff.

**[`mouse_look_action`](/api/classes/PlayerControlProfile/properties/mouse_look_action)**

Relative mouse motion action for rotating the view.

**[`mouse_sensitivity`](/api/classes/PlayerControlProfile/properties/mouse_sensitivity)**

View rotation in radians per unscaled pixel of mouse movement.

**[`move_action`](/api/classes/PlayerControlProfile/properties/move_action)**

Vector2 action from the input layout that supplies horizontal steering.

**[`move_relative_to`](/api/classes/PlayerControlProfile/properties/move_relative_to)**

Compatibility alias for `forward_direction`.

**[`move_speed`](/api/classes/PlayerControlProfile/properties/move_speed)**

Requested movement speed in metres per second at full input.

**[`movement_rule`](/api/classes/PlayerControlProfile/properties/movement_rule)**

Rule that resolves steering, gravity, and jump speed.

**[`predict_movement`](/api/classes/PlayerControlProfile/properties/predict_movement)**

Use immediate local movement and server reconciliation for compatible fixed-world games with an upright capsule and immutable static collision.

**[`stick_look_action`](/api/classes/PlayerControlProfile/properties/stick_look_action)**

Vector2 action that controls the view's rotation rate.

**[`stick_look_speed`](/api/classes/PlayerControlProfile/properties/stick_look_speed)**

View rotation in radians per second at full stick deflection.
