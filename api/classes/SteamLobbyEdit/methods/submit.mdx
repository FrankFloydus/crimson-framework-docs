## Signature

```text
submit() -> Error
```

## Return value

`Error`

## Description

`OK` means each write was accepted. Steam may accept earlier keys before a later write fails. Invalid or empty edits return `ERR_INVALID_PARAMETER`, closed membership returns `ERR_UNAVAILABLE`, and guests receive `ERR_UNAUTHORIZED`.

## Example

```gdscript
extends Node

func run_submit(steam_lobby: SteamLobby, status_label: Label) -> void:
    var steam_lobby_edit: SteamLobbyEdit = steam_lobby.edit()
    if steam_lobby_edit == null:
        return
    var result: Error = steam_lobby_edit.submit()
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Submit accepted."
```
