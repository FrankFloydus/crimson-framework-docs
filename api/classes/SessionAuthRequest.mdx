### Method details

#### `accept`

`accept(identity: SessionIdentity) -> Error`

Complete local verification with a non-null verified SessionIdentity. Returns ERR\_INVALID\_PARAMETER for an invalid identity, ERR\_BUSY off the scene thread, or ERR\_DOES\_NOT\_EXIST when the request has expired or already settled. The remote end must also finish verification before admission.

#### `get_challenge`

`get_challenge() -> PackedByteArray`

Return the 32-byte challenge issued to this connection for the remote proof to answer.

#### `get_peer_id`

`get_peer_id() -> int`

Return the engine-reported connection ID whose proof is being verified.

#### `get_proof`

`get_proof() -> PackedByteArray`

Return the remote proof bytes for verification. Keep proof bytes out of logs and persisted data.

#### `is_authority`

`is_authority() -> bool`

Return whether the local verifier is acting as the session authority.

#### `reject`

`reject() -> Error`

Deny the pending connection. Returns OK when recorded, ERR\_BUSY off the scene thread, or ERR\_DOES\_NOT\_EXIST when the request has expired or already settled.
