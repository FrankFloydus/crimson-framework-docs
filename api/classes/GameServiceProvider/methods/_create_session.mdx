## Signature

```text
_create_session() -> GameSession
```

## Return value

[`GameSession`](/api/classes/GameSession)

## Description

The game attaches and owns it. Omit the override to use the default session.

## Example

```gdscript
extends GameServiceProvider

func _create_session() -> GameSession:
    # Give this game its own detached session using the standard ENet transport.
    var session: GameSession = GameSession.new()
    var transport: ENetSessionTransport = ENetSessionTransport.new()
    var installed: Error = session.set_transport_adapter(transport)
    if installed != OK:
        push_error(error_string(installed))
    return session
```
