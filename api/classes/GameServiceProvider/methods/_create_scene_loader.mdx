## Signature

```text
_create_scene_loader() -> SceneLoadManager
```

## Return value

[`SceneLoadManager`](/api/classes/SceneLoadManager)

## Description

The game attaches and owns it. Omit the override to use the default loader.

## Example

```gdscript
extends GameServiceProvider

const SCENE_TIMEOUT_MSEC: int = 20_000

func _create_scene_loader() -> SceneLoadManager:
    var loader: SceneLoadManager = SceneLoadManager.new()
    loader.set_load_timeout_msec(SCENE_TIMEOUT_MSEC)
    return loader
```
