## Signature

```text
start(manifest_path: String = "") -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `manifest_path` | `String` | `""` |

## Return value

`Error`

## Description

Leave `manifest_path` empty to use Steam's app configuration or join the existing manifest. To override, pass an absolute path to a loose file Steam can read. A different explicit path while the lease is active returns `ERR_BUSY`. A missing file returns `ERR_FILE_NOT_FOUND`. Steam's parse rejection returns `ERR_PARSE_ERROR`. An invalid path returns `ERR_INVALID_PARAMETER`. A detached or unsupported scope returns `ERR_UNAVAILABLE`.

## Example

```gdscript
extends Node

func run_start(steam_client: SteamClient, manifest_path: String, status_label: Label) -> void:
    if not steam_client.is_ready():
        return
    var steam_input: SteamInput = steam_client.input()
    if steam_input == null:
        return
    var result: Error = steam_input.start(manifest_path)
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Start accepted."
```
