Resolve the Steam scope already attached to a game.

## Methods

### `current`

`static current() -> SteamScope`

Return Steam for the selected or sole active GameRuntime.

### `for_game`

`static for_game(game: GameRuntime) -> SteamScope`

Return the exact game's Steam scope. A failed setup exposes its diagnostic. Closed games and games without Steam return null.

### `server_for`

`static server_for(game: GameRuntime) -> SteamDedicatedServer`

Return the exact Steam dedicated attachment, including an unavailable attachment with a diagnostic. Return null for a client or non-Steam provider.
