## Return value

`Variant`

## Description

Supply one to 256 distinct unsigned decimal `instance_ids`. A missing selected instance returns `ERR_DOES_NOT_EXIST`. Proof bytes are limited to 1 MiB. Send them only to the authority that needs to verify this selection.
