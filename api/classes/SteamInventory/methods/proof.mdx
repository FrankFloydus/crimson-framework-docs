## Signature

```text
proof(instance_ids: PackedStringArray) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `instance_ids` | `PackedStringArray` | — |

## Return value

`Variant`

## Description

Supply one to 256 distinct unsigned decimal `instance_ids`. A missing selected instance returns `ERR_DOES_NOT_EXIST`. Proof bytes are limited to 1 MiB. Send them only to the authority that needs to verify this selection.

## Example

```gdscript
extends Node

func run_proof(
    steam_client: SteamClient,
    instance_ids: PackedStringArray,
    process_private_payload: Callable
) -> void:
    if not steam_client.is_ready():
        return
    var steam_inventory: SteamInventory = steam_client.inventory()
    if steam_inventory == null:
        return
    var result: SteamBytesResult = await steam_inventory.proof(instance_ids)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: PackedByteArray = result.value
    if payload.is_empty():
        return
    process_private_payload.call(payload)
```
