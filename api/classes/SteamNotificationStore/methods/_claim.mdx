## Description

Update and remove claims also reserve the exact owned target against competing keys until settlement. An unresolved sent operation remains reserved for trusted reconciliation.

## Example

```gdscript
extends SteamNotificationStore

# The callback authorizes and reserves the operation atomically in durable storage.
var reserve_operation: Callable

func _claim(app_id: int, key: String, fingerprint: String, action: SteamNotificationStore.Action, target_id: String) -> SteamNotificationClaim:
    if not reserve_operation.is_valid():
        return SteamNotificationClaim.create(SteamNotificationClaim.DENIED)
    return reserve_operation.call(app_id, key, fingerprint, action, target_id) as SteamNotificationClaim
```
