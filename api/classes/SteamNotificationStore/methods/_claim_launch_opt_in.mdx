## Return value

`Error`

## Description

Return `OK` only for a new durable claim, `ERR_ALREADY_IN_USE` when it is already claimed, or an error if authorization or storage fails. Keep the claim after dispatch even when Steam does not confirm the response.

## Example

```gdscript
extends SteamNotificationStore

# The callback verifies the launch and creates the one-time claim in durable storage.
var reserve_launch: Callable

func _claim_launch_opt_in(app_id: int, steam_id: String, launch_id: String) -> Error:
    if not reserve_launch.is_valid():
        return ERR_UNCONFIGURED
    return reserve_launch.call(app_id, steam_id, launch_id)
```
