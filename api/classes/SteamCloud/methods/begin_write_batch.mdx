## Signature

```text
begin_write_batch() -> SteamCloudWriteBatchResult
```

## Return value

[`SteamCloudWriteBatchResult`](/api/classes/SteamCloudWriteBatchResult)

## Description

Keep `SteamCloudWriteBatchResult.value` alive and await each submitted asynchronous write before closing it. `ERR_BUSY` indicates that a batch is already open. Each write keeps its own result and Steam controls synchronization.

## Example

```gdscript
const SETTINGS_FILE: String = "settings.json"

const PROFILE_FILE: String = "profile.json"
func store_profile_and_settings(
    cloud: SteamCloud, profile: PackedByteArray, settings: PackedByteArray
) -> void:
    var opened: SteamCloudWriteBatchResult = cloud.begin_write_batch()
    if not opened.ok:
        push_warning(opened.message)
        return
    var batch: SteamCloudWriteBatch = opened.value
    var profile_result: SteamResult = await cloud.write(PROFILE_FILE, profile)
    if profile_result.ok:
        var settings_result: SteamResult = await cloud.write(SETTINGS_FILE, settings)
        if not settings_result.ok:
            push_warning(settings_result.message)
    else:
        push_warning(profile_result.message)
    batch.close()
```
