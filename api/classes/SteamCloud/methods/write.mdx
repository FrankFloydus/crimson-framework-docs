```text
write(name: String, bytes: PackedByteArray) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |

| `bytes` | `PackedByteArray` | — |

## Return value

`Variant`

Await the call to receive [`SteamResult`](/api/classes/SteamResult).

## Description

Use `write_file()` to retain an operation for cancellation.

## Example

```gdscript
const PROFILE_FILE: String = "profile.json"

func store_cloud_profile(cloud: SteamCloud, profile: Dictionary) -> void:
    var bytes: PackedByteArray = JSON.stringify(profile).to_utf8_buffer()
    var result: SteamResult = await cloud.write(PROFILE_FILE, bytes)
    if not result.ok:
        push_warning(result.message)
```
