## Signature

```text
write_file(name: String, bytes: PackedByteArray) -> SteamOperation
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `name` | `String` | — |
| `bytes` | `PackedByteArray` | — |

## Return value

[`SteamOperation`](/api/classes/SteamOperation)

## Description

`bytes` must contain between 1 byte and `MAX_FILE_BYTES` bytes. The service copies the submitted bytes and holds the file name until Steam settles the transfer.

## Example

```gdscript
extends Node

func run_write_file(
    steam_client: SteamClient,
    name: String,
    bytes: PackedByteArray,
    status_label: Label
) -> void:
    if not steam_client.is_ready():
        return
    var steam_cloud: SteamCloud = steam_client.cloud()
    if steam_cloud == null:
        return
    var result: SteamOperation = steam_cloud.write_file(name, bytes)
    if result == null:
        return
    var result_value: SteamResult = await result.wait()
    if result_value == null:
        return
    if not result_value.ok:
        push_warning(result_value.message)
        return
    status_label.text = "Write file succeeded."
```
