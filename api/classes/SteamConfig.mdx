## Description

Pass this resource to `Steamworks.boot()` for standalone features, or to the game's code-first configuration for Steam multiplayer. Boot reads the settings before attaching the client. Lobby discovery settings apply to a game configured for Steam multiplayer.

- [Find an open Spacewar arena](/api/classes/SteamConfig/methods/public_games#example)

## Properties

**[`app_id`](/api/classes/SteamConfig/properties/app_id)**

Expected unsigned 32-bit AppID.

**[`discoverable`](/api/classes/SteamConfig/properties/discoverable)**

When true, a Steam multiplayer host publishes a publicly discoverable game.

**[`test_group`](/api/classes/SteamConfig/properties/test_group)**

Group shared by the host and guests in a Spacewar test.
