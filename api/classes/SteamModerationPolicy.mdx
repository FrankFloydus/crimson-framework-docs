**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

Authorizes moderation and records audited outcomes in the trusted game backend.

Implement this policy in a trusted publisher build and inject it through `SteamPublisherSettings.moderation_policy`. The game owns authentication, match evidence, moderator roles, review decisions, and durable audit storage. The publisher checks the exact request and target before dispatch.

## Methods

### `_authorize`

`_authorize(request: SteamModerationRequest) -> SteamModerationAuthorization`

**Virtual method.**

Return `null` to deny `request`. For a reviewed write, check moderator authorization and resolve the reviewed player for the configured app. Persist the exact action and reserve an audit reference before returning `SteamModerationAuthorization.approve()`.

### `_record_outcome`

`_record_outcome(receipt: SteamModerationReceipt, error: Error) -> bool`

**Virtual method.**

Durably record the publisher-observed terminal `error` and `receipt` in the matching audit record. Return `true` after persistence succeeds. A missing or failed write returns `ERR_DATABASE_CANT_WRITE` from the moderation action and preserves its receipt for reconciliation. This hook runs before the caller resumes.
