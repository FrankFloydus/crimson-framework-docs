## Description

Resolve this handle through `SteamDedicatedServer.stats()`. Use it on the scene thread from authoritative game code. Steamworks definitions must allow Game Server or Official GS writes. The handle expires on departure or retirement of the dedicated attachment, even when the same account reconnects.
