**Inherits** `RefCounted`

Steam GameServer progression for one currently authenticated player.

Resolve this handle through `SteamDedicatedServer.stats()`. Use it on the scene thread from authoritative game code. Steamworks definitions must allow Game Server or Official GS writes. The handle expires on departure or retirement of the dedicated attachment, even when the same account reconnects.

## Methods

### `achievement`

`achievement(name: StringName) -> SteamBoolResult`

Read whether `name` is unlocked in the loaded cache. A locked achievement is a successful false result. A missing definition returns `ERR_DOES_NOT_EXIST`, and an unloaded cache returns `ERR_UNCONFIGURED`.

### `edit`

`edit() -> SteamServerStatsEdit`

Create a new draft to set stats or achievements in this player's cache and submit them to Steam. Editing the draft has no immediate effect.

### `is_available`

`is_available() -> bool`

Return whether the dedicated interface is available and this exact admission remains active.

### `is_loaded`

`is_loaded() -> bool`

Return whether Steam successfully loaded the cache for this admission. Returns false before the first successful load and after Steam evicts the cache.

### `load`

`load() -> SteamServerStatsOperation`

Load stats and achievements for this admission, without changing any stats. An already loaded cache returns success immediately. Steam can refuse the request for an account or app without eligible stats. If another operation on the account is pending, this returns `ERR_BUSY`.

### `stat_float`

`stat_float(name: StringName) -> SteamFloatResult`

Read the finite single-precision value of the published stat `name` from the loaded cache. A missing definition or wrong type returns `ERR_DOES_NOT_EXIST`. An unloaded cache returns `ERR_UNCONFIGURED`.

### `stat_int`

`stat_int(name: StringName) -> SteamIntResult`

Read the signed 32-bit value of the published stat `name` from the loaded cache. A missing definition or wrong type returns `ERR_DOES_NOT_EXIST`. An unloaded cache returns `ERR_UNCONFIGURED`.

### `store`

`store() -> SteamServerStatsOperation`

Store previously accepted cache changes without repeating the setters. Use this after a partially applied batch or a drained failed store if the game intends to persist those accepted changes. An unloaded cache returns `ERR_UNCONFIGURED`. An undrained call returns `ERR_BUSY`. A loaded cache without pending changes returns success without issuing a Steam call.
