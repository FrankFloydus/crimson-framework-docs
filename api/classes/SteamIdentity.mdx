**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

A Steam identity verified by a trusted publisher scope.

Use the identity returned by `SteamPublisherAuth.verify()` when calling trusted services. A manually created value carries no verification and cannot authorize an action. The original publisher scope must remain active.
