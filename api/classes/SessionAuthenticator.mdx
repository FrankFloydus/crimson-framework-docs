## Methods

### `_make_proof`

`_make_proof(peer_id: int, authority: bool, challenge: PackedByteArray) -> PackedByteArray`

**Virtual method.**

Build a proof synchronously from prepared local credentials in response to the remote peer's 32-byte challenge. The authority flag describes the local process. Return 1 to 4096 bytes for a proof, or an empty array to deny the connection.

### `_verify`

`_verify(request: SessionAuthRequest) -> void`

**Virtual method.**

Verify the request's remote proof against the provider, challenge, and session context. Accept with a SessionIdentity derived from verified evidence, or reject. You can settle the request during this call or later on the scene thread. The default implementation rejects the request.
