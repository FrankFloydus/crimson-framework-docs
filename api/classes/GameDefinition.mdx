## Methods

### `boot`

`boot(owner: Node) -> GameRuntime`

Creates a configured GameRuntime and attaches it to a live owner. Returns null if attachment fails or the tree retires the owner or child during attachment.

### `configure`

`static configure() -> GameDefinition`

Create a new GameDefinition with its default fields. Set Inspector properties directly or branch from it with the fluent methods.

### `create`

`create() -> GameRuntime`

Create a detached GameRuntime named Game with a copy of this definition. Add it to a persistent scene before starting a session.

### `starting_in`

`starting_in(world_id: StringName) -> GameDefinition`

Return a copy that selects world\_id as the starting world. For coordinated play, use an ID from the world catalog.

### `with_multiplayer`

`with_multiplayer(rules: MultiplayerRules) -> GameDefinition`

Return a copy with a snapshot of the supplied MultiplayerRules for immediate listen and dedicated sessions. Pass null to clear the rules.

### `with_player`

`with_player(scene: PackedScene) -> GameDefinition`

Return a copy with the Node3D player scene to instantiate for participants in a fixed-world game.

### `with_provider`

`with_provider(provider: GameServiceProvider) -> GameDefinition`

Return a copy that uses provider when the game attaches to the scene tree. Pass null to use the default session and scene loader.

### `with_saves`

`with_saves(app_id: String, root: String = "user://crimson", schema_version: int = 1) -> GameDefinition`

Return a copy with the checkpoint application ID, storage directory, and positive schema version. Choose a stable project-specific app\_id and a writable path under user://.

### `with_starting_world`

`with_starting_world(world_id: StringName, scene: PackedScene) -> GameDefinition`

Return a copy with the starting world ID and the local Node3D scene for fixed-world play. Author PlayerSpawnPoint nodes inside the scene.

### `with_worlds`

`with_worlds(worlds: Dictionary) -> GameDefinition`

Return a copy with a detached catalog for coordinated startup and travel. Map each stable world ID to a dictionary containing scene\_id and a local res:// path to a .tscn or .scn file.
