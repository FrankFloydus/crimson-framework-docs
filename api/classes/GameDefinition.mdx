## Properties

**[`app_id`](/api/classes/GameDefinition/properties/app_id)**

Stable identifier stored in this game's checkpoints.

**[`multiplayer_rules`](/api/classes/GameDefinition/properties/multiplayer_rules)**

Capacity, UDP port, and late-join policy for Host Game and Join Game.

**[`player_scene`](/api/classes/GameDefinition/properties/player_scene)**

The player actor instantiated for each participant in a quick game.

**[`save_root`](/api/classes/GameDefinition/properties/save_root)**

Directory used for checkpoints in coordinated games.

**[`schema_version`](/api/classes/GameDefinition/properties/schema_version)**

Positive version number of the coordinated game's checkpoint schema.

**[`service_provider`](/api/classes/GameDefinition/properties/service_provider)**

Optional factories for this game's session and scene loader.

**[`starting_world`](/api/classes/GameDefinition/properties/starting_world)**

Stable identifier of the starting world.

**[`starting_world_scene`](/api/classes/GameDefinition/properties/starting_world_scene)**

The 3D scene mounted by Play Solo, Host Game, and Join Game.

**[`worlds`](/api/classes/GameDefinition/properties/worlds)**

Catalog for coordinated world loading and travel.
