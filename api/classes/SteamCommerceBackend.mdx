## Description

Implement the virtual hooks and complete the supplied request once, on the main thread. For asynchronous transport, retain the request until the game backend replies. Bind the adapter with `SteamProvider.with_commerce_backend()`.

`_observe_authorization(order_id: String, authorized: bool, request: SteamCommerceRequest) -> void`

**Virtual method.**
