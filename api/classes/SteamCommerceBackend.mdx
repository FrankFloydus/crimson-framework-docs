**Inherits** `RefCounted`

Script adapter for the game's authenticated purchasing service.

Implement the virtual hooks and complete the supplied request once, on the main thread. For asynchronous transport, retain the request until the game backend replies. Bind the adapter with `SteamProvider.with_commerce_backend()`.

## Methods

### `_begin`

`_begin(cart: SteamPurchaseCart, checkout_id: String, request: SteamCommerceRequest) -> void`

**Virtual method.**

Create or resume the persisted order for this checkout ID and authenticated account. On success, echo the checkout ID in the typed response.

### `_catalog`

`_catalog(request: SteamCommerceRequest) -> void`

**Virtual method.**

Fetch the current player's server-priced offers and call `SteamCommerceRequest.complete_catalog()`.

### `_observe_authorization`

`_observe_authorization(order_id: String, authorized: bool, request: SteamCommerceRequest) -> void`

**Virtual method.**

Use Steam's authorization hint to ask the game backend to query the known order. Return the verified backend state. The hint alone does not grant an entitlement.

### `_order`

`_order(order_id: String, request: SteamCommerceRequest) -> void`

**Virtual method.**

Refresh the current authenticated player's exact order from the game backend.
