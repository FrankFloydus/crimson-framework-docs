## Description

Implement the virtual hooks and complete the supplied request once, on the main thread. For asynchronous transport, retain the request until the game backend replies. Bind the adapter with `SteamProvider.with_commerce_backend()`.

## Methods

### Virtual methods

#### [`_begin`](/api/classes/SteamCommerceBackend/methods/_begin)

Create or resume the persisted order for this checkout ID and authenticated account.

#### [`_catalog`](/api/classes/SteamCommerceBackend/methods/_catalog)

Fetch the current player's server-priced offers and call `SteamCommerceRequest.complete_catalog()`.

#### [`_observe_authorization`](/api/classes/SteamCommerceBackend/methods/_observe_authorization)

Use Steam's authorization hint to ask the game backend to query the known order.

#### [`_order`](/api/classes/SteamCommerceBackend/methods/_order)

Refresh the current authenticated player's exact order from the game backend.
