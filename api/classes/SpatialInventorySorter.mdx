### Method details

#### `apply_preview`

`apply_preview() -> Error`

Commit the pending plan if the inventory baseline and placement policy still permit it. A successful sort with placement changes records the prior placements for undo. A rejected plan preserves the grid.

#### `can_undo`

`can_undo() -> bool`

Return whether the sorter retains a committed sort to undo. Intervening edits can still make undo fail.

#### `cancel_preview`

`cancel_preview() -> void`

Discard the pending preview without changing the inventory.

#### `has_preview`

`has_preview() -> bool`

Return whether an unapplied sort plan is available.

#### `preview`

`preview(inventory: SpatialInventory, pinned_ids: Array = [], allow_rotation: bool = true, placement_policy: Callable = Callable()) -> Dictionary`

Build a detached sort plan. Pinned items keep their positions and orientations. The optional policy receives `id`, `footprint`, `origin`, `rotated`, `source`, `destination`, `swap_id`, and `action`. Return an empty String to accept a candidate. The result reports `error`, plus `grid_size`, `placements`, and `changed_count` on success.

#### `undo`

`undo(placement_policy: Callable = Callable()) -> Error`

Restore the placements before the last applied sort, checking expected state and any supplied placement policy. A conflict preserves the grid and keeps undo available.
