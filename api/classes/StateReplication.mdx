### Method details

#### `advance_world`

`advance_world(world_epoch: int, committed_revision: int) -> Error`

Sets a strictly newer positive world epoch and a nonnegative committed revision on the authority. Existing peer bindings survive, and each peer must acknowledge a baseline for the new epoch.

#### `clear_projection`

`clear_projection() -> void`

Invalidates the client view and emits `projection\_cleared` when a view was ready. Keeps the stream identity so the orchestrator can clear the view after mounting a new world and before receiving its baseline.

#### `get_projection`

`get_projection() -> Dictionary`

Returns a detached copy of the client's ready view, or an empty dictionary when the view is unavailable.

#### `get_revision`

`get_revision() -> int`

Returns the authority's current committed revision or the client's last accepted revision. Returns zero when the transport is no longer current.

#### `get_world_epoch`

`get_world_epoch() -> int`

Returns the authority's current world epoch or the client's last accepted epoch. Returns zero when the transport is no longer current.

#### `is_client_ready`

`is_client_ready() -> bool`

Returns whether the client has a live, continuous view on the current transport.

#### `is_peer_ready`

`is_peer_ready(peer_id: int, binding_generation: int = 0) -> bool`

On the authority, returns whether a connected peer has acknowledged this epoch's baseline and completed catch-up. Pass its admitted `binding\_generation` when gating input. Zero accepts the current generation.

#### `publish_changes`

`publish_changes(committed_revision: int) -> Error`

Advances to a nondecreasing committed revision and sends changed or removed records to ready peers. Peers with a pending baseline catch up after acknowledgment. Hidden-only changes leave the recipient's delivery sequence unchanged. Returns the first delivery error and invalidates readiness for affected peers.

#### `register_peer`

`register_peer(peer_id: int, player_id: String, binding_generation: int) -> Error`

Registers a connected, admitted peer on the authority. Supply its stable player ID and a positive binding generation. A newer generation replaces the old stream. A repeated call with the same generation and player ID returns `OK`.

#### `remove_peer`

`remove_peer(peer_id: int, binding_generation: int = 0) -> void`

Removes the peer's replication stream. Supply the binding generation to guard against a delayed disconnect for an older binding. Zero removes the current stream.

#### `reset`

`reset() -> void`

Drops active streams, the current epoch, and the revision. Keeps the configured projector.

#### `send_baseline`

`send_baseline(peer_id: int) -> Error`

Sends a fresh snapshot from the authority to the registered peer after it has mounted the matching scene. Returns immediate errors. Wait for `peer\_ready` before admitting that peer's commands.

#### `set_projector`

`set_projector(callback: Callable) -> Error`

Sets a synchronous callback receiving `(peer\_id, player\_id, world\_epoch, committed\_revision)`. Return a dictionary with `ok` set to `true` and `view` set to a bounded dictionary of records visible to that player. Configure before registering peers and keep the callback free of side effects.

## Signals

### `peer_ready`

`peer_ready(peer_id: int, world_epoch: int, binding_generation: int)`

Emits on the authority after the matching baseline acknowledgment and successful catch-up for the given world epoch and binding generation.

### `peer_sync_failed`

`peer_sync_failed(peer_id: int, world_epoch: int, error: int)`

Emits on the authority if baseline acknowledgment times out or delivery fails. Readiness stays closed until the peer synchronizes successfully.

### `projection_cleared`

`projection_cleared()`

Emits on the client when its previously available view is invalidated.

### `projection_updated`

`projection_updated(world_epoch: int, committed_revision: int, baseline: bool)`

Emits on the client after applying a baseline or delta. The `baseline` argument is `true` for a baseline. Use `get\_projection()` to read the updated view.
