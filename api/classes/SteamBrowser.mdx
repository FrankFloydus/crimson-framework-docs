## Description

Get this service from `SteamClient.browser()`. Open pages on the scene thread in a rendered app. Crimson initializes the Steam HTML interface on first use and allows up to four live or pending browsers per process. Use URLs and content controlled by your game. Steam can fetch redirects before reporting the resulting URL, and its navigation callbacks do not intercept page subresources.
