## Description

Get this service from `SteamClient.browser()`. Open pages on the scene thread in a rendered app. Crimson initializes the Steam HTML interface on first use and allows up to four live or pending browsers per process. Use URLs and content controlled by your game. Steam can fetch redirects before reporting the resulting URL, and its navigation callbacks do not intercept page subresources.

## Methods

### `allow_origins`

`allow_origins(origins: PackedStringArray) -> SteamBrowserRequest`

Build a policy with up to sixteen additional exact origins. An origin contains the scheme, ASCII hostname, and optional port. An optional trailing slash is accepted. For controlled local fixtures, explicitly include a numeric loopback HTTP origin. Policy validation occurs when opening the request.

### `open`

`open(url: String, size: Vector2i = Vector2i(960, 540)) -> Variant`

Await a [`SteamBrowserPageResult`](/api/classes/SteamBrowserPageResult) after creating a browser and requesting initial HTTPS navigation. The URL must be absolute with an ASCII authority, no credentials, and percent-encoded non-ASCII URL text. It is limited to 2048 bytes. Use `SteamBrowserPage.page_finished` and `SteamBrowserPage.frame_updated` to confirm page content. The browser dimensions may each range from 1 to 4096 pixels with a combined limit of 4194304 pixels.
