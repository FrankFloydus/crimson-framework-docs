## Signature

```text
friends(board_name: String, count: int = 10) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `board_name` | `String` | — |
| `count` | `int` | `10` |

## Return value

`Variant`

Await the call to receive [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult).

## Description

The count must be between 1 and 100. Use `await` to receive a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult).

## Example

```gdscript
extends Node

func run_friends(
    steam_client: SteamClient,
    board_name: String,
    count: int,
    apply_friends: Callable
) -> void:
    if not steam_client.is_ready():
        return
    var steam_leaderboards: SteamLeaderboards = steam_client.leaderboards()
    if steam_leaderboards == null:
        return
    var result: SteamLeaderboardPageResult = await steam_leaderboards.friends(board_name, count)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamLeaderboardPage = result.value
    if payload == null:
        return
    apply_friends.call(payload)
```
