Standalone fixed-world session for existing integrations.

## Methods

### `configure`

`static configure() -> WorldSessionDefinition`

Create an empty WorldSessionDefinition for the standalone fixed-world session. Supply the world and player scenes before creating the session.

### `get_local_player`

`get_local_player() -> Node3D`

Return the local peer's spawned Node3D, or null until the session has placed that player. The session owns the node's lifetime.

### `get_player`

`get_player(peer_id: int) -> Node3D`

Return the live Node3D assigned to peer\_id, or null if the peer has no live actor in the current world.

### `get_port`

`get_port() -> int`

Return the active session's UDP port. While idle, return the definition's port or 7000 if no definition is assigned.

### `get_state`

`get_state() -> WorldSession.State`

Return the current WorldSession.State. Observe state\_changed to learn when a pending join reaches RUNNING.

### `get_world`

`get_world() -> Node3D`

Return the mounted Node3D world or null if the session has no mounted world. The node remains valid only while it belongs to the session.

### `host`

`host() -> Error`

Start a direct ENet listen session on the configured UDP port, mount the world, and place the local player. The host uses the first marker and leaves the remaining markers for guests. Return OK when running or an immediate Godot Error.

### `join`

`join(address: String) -> Error`

Begin a direct ENet connection to address on the configured UDP port. OK means the attempt started. Wait for RUNNING before accessing the local player.

### `leave`

`leave() -> Error`

Cancel a pending join or end an active session. Return OK when idle or when teardown starts, or ERR\_BUSY if the session is changing state. Use session\_ended to observe completed teardown.

### `start_offline`

`start_offline() -> Error`

Mount the configured world and place the local player at the first marker without opening a network listener. Return OK when running or an immediate Godot Error.

## Signals

### `session_ended`

`session_ended(reason: StringName)`

Emitted with the transport or startup failure reason after the world is cleared and the session returns to IDLE. Start another session from this signal.

### `state_changed`

`state_changed(state: int)`

Emitted when the session changes state. RUNNING means the world and local player are available.

## Constants and enums

### `State`

| Name | Value | Description |
| --- | --- | --- |
| `IDLE` | `0` | No active session. The definition can be set before the next start. |
| `RUNNING` | `2` | The session has finished startup and the world is available. |
| `STARTING` | `1` | The session is starting or a guest is waiting for its world and player. |
