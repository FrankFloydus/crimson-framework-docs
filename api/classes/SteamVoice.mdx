**Inherits** `RefCounted`

Steam voice decoding and opt-in microphone access for one client start.

## Methods

### `capture`

`capture() -> SteamVoiceCapture`

Returns the scope's microphone controls without starting capture. A new unattached service has no capture handle. A retained handle returns `ERR_UNAVAILABLE` after its scope stops.

### `decode`

`decode(bytes: PackedByteArray, sample_rate_hz: int = 0) -> SteamVoicePcmResult`

Decodes one complete Steam voice frame of 1 to 8192 bytes. Zero chooses Steam's recommended rate, or pass a rate from 11025 to 48000 Hz. The result contains up to 131072 bytes of signed 16-bit mono PCM. Unavailable codecs and invalid input return a typed error.
