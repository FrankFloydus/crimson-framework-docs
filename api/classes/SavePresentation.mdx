**Inherits** `RefCounted`

Static helpers for building, displaying, and decoding save slot metadata. Call them on the main thread. Preserve a generation's `sequence` and `id` separately so the UI can load the selected save.

## Methods

### `describe`

`static describe(entry: Dictionary, date_pattern: String = "%Y-%m-%d %H:%M UTC", utc_offset_minutes: int = 0) -> Dictionary`

Turn an inspection entry or its `meta` dictionary into display fields `label`, `time_text`, `context`, and `preview`. The preview is a texture when the metadata contains a valid image and null otherwise.

### `format_date`

`static format_date(unix_seconds: int, pattern: String, utc_offset_minutes: int = 0) -> String`

Format a Unix timestamp in seconds using the specified fixed offset in minutes. Supported tokens include `%Y`, `%m`, `%d`, `%H`, `%M`, `%S`, `%z`, and `%%`. An out-of-range date or offset returns an empty string.

### `make_metadata`

`static make_metadata(label: String, saved_at_utc: int, context: Dictionary, screenshot: Image = null) -> Dictionary`

Create bounded display metadata with the save label, Unix timestamp in seconds, and contextual fields. Pass an optional `Image` from your game to include a compact RGB565 preview when it fits the metadata budget. Pass the result to a [`SaveCoordinator`](/api/classes/SaveCoordinator) save request.
