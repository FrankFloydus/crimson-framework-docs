**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

The terminal audit details for one reviewed game sanction or removal.

A successful receipt acknowledges Steam's recognized reply for the request. Observe game admission or profile state separately when the game needs to confirm a later effect. When a submitted request times out or observation closes, the receipt remains available and the remote outcome can remain unresolved.
