**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

Submits authoritative leaderboard scores from a trusted backend.

Get this service from `SteamPublisher.leaderboards()` after the game has authorized the run and verified the player. The configured publisher must have write access to the board.

## Methods

### `submit_score`

`submit_score(player: SteamIdentity, board_id: int, score: int, details: PackedByteArray = PackedByteArray()) -> Variant`

Submits a signed 32-bit `score` using KeepBest for a verified player and a positive Valve board ID. Accepts up to 256 raw details bytes. Use `await` to receive [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult). Success acknowledges the HTTP submission. The publisher endpoint does not document rank or change fields, so the result carries the submitted score and no `SteamLeaderboardSubmission.upload` receipt.
