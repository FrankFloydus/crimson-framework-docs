## Methods

### `_disconnect_after_flush`

`_disconnect_after_flush(peer: MultiplayerPeer, peer_id: int) -> void`

**Virtual method.**

Disconnect an admitted guest after sending its queued reliable messages. If omitted, the adapter requests a regular Godot disconnect. Implement this hook when the guest needs to receive a final message before closure.

### `_open_client`

`_open_client(endpoint: SessionEndpoint) -> SessionTransportResult`

**Virtual method.**

Create an initialized, uninstalled client peer for the supplied endpoint. The peer may still be connecting, and must have an ID above 1 when it receives admission. Return SessionTransportResult.opened or SessionTransportResult.failed. If omitted, opening fails with ERR\_UNAVAILABLE.

### `_open_server`

`_open_server(port: int, remote_limit: int, bind_address: String) -> SessionTransportResult`

**Virtual method.**

Create an initialized, uninstalled server peer with ID 1 using the supplied port, remote client limit, and bind address. The session sets the admission flag before installation. Return SessionTransportResult.opened or SessionTransportResult.failed. If omitted, opening fails with ERR\_UNAVAILABLE.
