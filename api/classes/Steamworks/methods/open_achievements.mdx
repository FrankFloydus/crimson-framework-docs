## Signature

```text
open_achievements() -> SteamResult
```

## Return value

[`SteamResult`](/api/classes/SteamResult)

## Description

Success means the request was submitted. A busy result means the overlay is still loading, disabled, or inaccessible from this thread. A failed startup or detached scope returns its diagnostic. Observe the overlay to confirm display.

## Example

### Open achievements from the pause menu

Press Achievements to request the Steam overlay. This menu shares the Steam attachment of its owning game.

```gdscript
extends Control

@export var achievements_button: Button
@export var status: Label

var _steam: Steamworks

func _ready() -> void:
    var game: Game = Game.for_node(self)
    achievements_button.disabled = game == null
    if game == null:
        status.text = "No game is attached."
        return
    _steam = game.steam()
    achievements_button.pressed.connect(_open_achievements)

func _open_achievements() -> void:
    var requested: SteamResult = _steam.open_achievements()
    status.text = "" if requested.ok else requested.message
```
