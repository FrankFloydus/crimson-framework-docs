## Return value

[`SteamAchievements`](/api/classes/SteamAchievements)

## Description

Its unlock action submits storage and carries the original startup error when no stats service was attached.

## Example

### Award the training achievement

Call `training_completed()` from the training objective's completion signal. The results screen reports whether Steam accepted the unlock request. [Steam achievement setup](/steam/client-services#unlock-an-achievement)

```gdscript
extends Node

const TRAINING_ACHIEVEMENT: String = "TRAINING_COMPLETE"

@export var status: Label

var _steam: Steamworks

func _ready() -> void:
    _steam = Steamworks.boot(self)

func training_completed() -> void:
    var achievements: SteamAchievements = _steam.achievements()
    var submitted: SteamStatsSubmissionResult = achievements.unlock(TRAINING_ACHIEVEMENT)
    status.text = "Achievement sent to Steam." if submitted.ok else submitted.message
```
