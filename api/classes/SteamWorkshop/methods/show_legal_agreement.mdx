## Signature

```text
show_legal_agreement() -> Error
```

## Return value

`Error`

## Description

Call this in response to a player or author action. `OK` acknowledges the request. Query `legal_agreement_status()` after the user closes the overlay to read the current decision.

## Example

```gdscript
extends Node

func run_show_legal_agreement(steam_client: SteamClient, status_label: Label) -> void:
    if not steam_client.is_ready():
        return
    var steam_workshop: SteamWorkshop = steam_client.workshop()
    if steam_workshop == null:
        return
    var result: Error = steam_workshop.show_legal_agreement()
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Show legal agreement accepted."
```
