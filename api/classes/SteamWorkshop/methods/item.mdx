## Signature

```text
item(published_id: String) -> SteamWorkshopItemRef
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `published_id` | `String` | — |

## Return value

[`SteamWorkshopItemRef`](/api/classes/SteamWorkshopItemRef)

## Description

Pass the canonical unsigned decimal published file ID. `SteamWorkshopItemRef.fetch()` validates the ID before using Steam.

## Example

```gdscript
extends Node

func run_item(steam_client: SteamClient, published_id: String, apply_item: Callable) -> void:
    if not steam_client.is_ready():
        return
    var steam_workshop: SteamWorkshop = steam_client.workshop()
    if steam_workshop == null:
        return
    var result: SteamWorkshopItemRef = steam_workshop.item(published_id)
    if result == null:
        return
    apply_item.call(result)
```
