**Inherits** `Node`

A scene-tree node that coordinates checkpoint capture, storage, inspection, and staged restore. Configure it and submit requests on the main thread. Keep the host and participant adapters alive for the duration of their tickets. Capture, migration, and restore callbacks run on the main thread, and storage and codec work run on a worker using detached data. Save, load, and inspection requests return a positive ticket when admitted or 0 on rejection. Profile and slot IDs use 1 to 64 lowercase ASCII letters, digits, underscores, or hyphens, with a letter or digit first. App, scope, and participant IDs also allow periods after the first character. The first admitted ticket freezes app and storage configuration. The first admitted save or load also freezes the scope and schema registrations.

## Methods

### `activate_prepared_load`

`activate_prepared_load(ticket: int) -> bool`

Validate and publish the prepared candidate for the given ticket on the main thread. Returns true when publication succeeds. A valid prepared ticket queues a terminal `operation_finished` result.

### `bind_participant`

`bind_participant(id: String, adapter: Object) -> bool`

Attach or replace the live adapter for a declared participant. The adapter provides `save_capture()` and `save_stage(dto, candidate)`, with optional `save_default()` and `save_link(candidate)`. Returns false if the adapter is invalid, the ID is undeclared, or there is queued or active save or load work.

### `cancel`

`cancel(ticket: int) -> String`

Request cancellation of an admitted ticket. Returns `Cancelled` if cancellation won, `TooLate` after the commit gate, or `UnknownTicket` for an untracked ticket. Wait for the terminal signal before treating admitted work as finished.

### `capture_pending`

`capture_pending(revision: String = "") -> bool`

Capture the earliest admitted but uncaptured save at a committed gameplay boundary. The optional `revision` label is limited to 128 UTF-8 bytes. Returns true if the capture succeeds. Call once for each pending save you want to capture.

### `configure`

`configure(app_id: String, root: String = "user://godot-save-system") -> bool`

Set the stable app ID and initialize the default storage and codec. Pass a nonempty directory under `user://` as `root`. Returns false for invalid configuration or if the app and storage configuration has already been frozen by an admitted ticket.

### `configure_scope`

`configure_scope(scope_id: String, version: int) -> bool`

Set the single stable scope ID and its current positive schema version. The scope covers every registered participant. Configure it before the first admitted save or load.

### `declare_participant`

`declare_participant(id: String, version: int, required: bool = true) -> bool`

Declare a unique stable participant ID and positive schema version. During load, a missing required participant fails. An optional participant supplies a default through its adapter. Returns true if declared successfully.

### `get_last_admission_error`

`get_last_admission_error() -> String`

Read the error code from the most recent rejected request. Call immediately after a request returns 0. A rejected request produces no ticket events.

### `get_prepared_candidate`

`get_prepared_candidate(ticket: int) -> Variant`

Borrow the detached candidate held by a prepared load while its ticket is active. Returns null when the candidate is unavailable. Release borrowed references when the ticket finishes.

### `invalidate_world`

`invalidate_world() -> bool`

Invalidate work associated with the current world before you replace it outside the save system. If active work is past its cancellation gate, wait for it to finish and try again.

### `is_idle`

`is_idle() -> bool`

Return true when queued work, active work, and terminal results have drained. Check before reconfiguring or freeing the coordinator.

### `load_native_provider`

`load_native_provider(path: String, configuration: String = "") -> bool`

Load a trusted Windows x86-64 provider DLL after configuration and before the first admitted ticket. Pass an absolute DLL path or a Godot path resolving to an on-disk DLL. The provider-defined UTF-8 configuration is limited to 64 KiB. A provider can supply storage, a codec, or both.

### `register_migration`

`register_migration(id: String, from_version: int, migration: Callable) -> bool`

Register a participant migration from `from_version` to the next version. The synchronous callback accepts the old data and returns a dictionary with `ok` and, on success, `value` containing the upgraded data. Register every required step before the first admitted save or load.

### `register_participant`

`register_participant(id: String, version: int, adapter: Object, required: bool = true) -> bool`

Declare a participant schema and bind its live adapter in one call. Returns true if registration succeeds. Declare schemas before the first admitted save or load.

### `register_scope_migration`

`register_scope_migration(from_version: int, migration: Callable) -> bool`

Register one scope migration step from `from_version` to the next version. The callback receives an array of records with `id`, `version`, and `data` and returns the converted array in the result's `value` field on success. Scope migrations run before individual participant migrations.

### `request_autosave`

`request_autosave(profile: String, slot: String, metadata: Dictionary = {}) -> int`

Queue an autosave for the next host capture boundary. A newer intent can replace an uncaptured autosave for the same slot and world. Returns a ticket or 0 on rejection.

### `request_inspect_generation`

`request_inspect_generation(profile: String, slot: String, sequence: String, generation_id: String) -> int`

Inspect one committed generation by its exact `sequence` and `generation_id`. An absent generation reports `NotFound` in the terminal result. Use this after a save reports `CommitUnknown` to check the returned generation identity before retrying.

### `request_list`

`request_list(profile: String, slot: String, before_sequence: String = "", before_generation_id: String = "", limit: int = 16) -> int`

List committed generations newest first. The terminal result includes `value` for entries, `status` for the head, `truncated`, and `next`. For the next page, pass both identity strings from `next`. The limit must be positive. The coordinator caps the page size at 16.

### `request_load`

`request_load(profile: String, slot: String, sequence: String = "", generation_id: String = "") -> int`

Queue a load of the current slot head when both selection strings are empty. To load a specific generation, pass both `sequence` and `generation_id` from inspection. Returns a ticket or 0 on rejection.

### `request_prepare_load`

`request_prepare_load(profile: String, slot: String, sequence: String = "", generation_id: String = "") -> int`

Select a generation like `request_load()`, then read, migrate, stage, and link it. Wait for `load_prepared` and call `activate_prepared_load()` when the host is ready to publish the candidate.

### `request_save`

`request_save(profile: String, slot: String, metadata: Dictionary = {}) -> int`

Queue a manual save for the next host capture boundary. Pass optional data-only metadata up to 8 KiB. After admission, call `capture_pending()` at a committed gameplay boundary.

### `set_host`

`set_host(host: Object) -> bool`

Bind the live object that builds and publishes restore candidates. It provides `save_create_candidate()` and `save_publish(candidate)` and may also validate or discard candidates. Replace the host only when there is no active or queued save or load.

### `validate_prepared_load_for_save`

`validate_prepared_load_for_save(ticket: int) -> bool`

Validate and discard a prepared candidate selected by exact generation identity, leaving the active world in place. The selected generation must still be the head when checked. Wait for the terminal success result before retrying a save over that head.

## Signals

### `load_prepared`

`load_prepared(ticket: int, generation: Dictionary)`

Emitted on the main thread after an explicit prepare request finishes staging and linking. The generation dictionary contains `sequence` and `id`. The ticket remains active until you activate or cancel it.

### `operation_finished`

`operation_finished(ticket: int, result: Dictionary)`

Emitted on the main thread when a ticket reaches a terminal result. The dictionary includes `ok` and `code` and can include `message`, `warning`, or `value`. Successful saves and loads return the generation's `sequence` and `id` in `value`.

### `operation_progress`

`operation_progress(ticket: int, phase: String)`

Emitted on the main thread when a ticket changes phase. Several transitions can arrive in one frame. A `Verifying` update during load gives listeners a chance to cancel before main-thread restore work.
