## Return value

`bool`

## Description

Capture has the additional overlay requirement.

## Example

```gdscript
extends Node

func run_is_available(steam_client: SteamClient, action_button: Button) -> void:
    if not steam_client.is_ready():
        return
    var steam_screenshots: SteamScreenshots = steam_client.screenshots()
    if steam_screenshots == null:
        return
    var result: bool = steam_screenshots.is_available()
    action_button.disabled = not result
```
