## Description

Get this service from `SteamPublisher.moderation()` in an explicitly enabled trusted publisher build. Configure the app for Valve's anti-cheat Web API and inject [`SteamModerationPolicy`](/api/classes/SteamModerationPolicy). Await the actions on the main thread. Report submission creates evidence for review. Steam's game sanctions require a separate reviewed request. A missing policy returns `ERR_UNCONFIGURED`, and a denied or mismatched authorization returns `ERR_UNAUTHORIZED`.

## Methods

### Instance methods

#### [`ban`](/api/classes/SteamPublisherModeration/methods/ban)

Requests a permanent game ban for the policy-resolved player associated with `report_id`.

#### [`remove_ban`](/api/classes/SteamPublisherModeration/methods/remove_ban)

Requests removal of the game ban for `player_id` on the configured AppID.

#### [`report`](/api/classes/SteamPublisherModeration/methods/report)

Submits `evidence` about `player_id` after policy approval.

#### [`reports`](/api/classes/SteamPublisherModeration/methods/reports)

Lists reports from `from_unix` to `to_unix`, in UTC Unix seconds, with a maximum span of seven days.

#### [`suspend`](/api/classes/SteamPublisherModeration/methods/suspend)

Requests a suspension for the policy-resolved player associated with `report_id`. `seconds` must be from 1 through 31535999.
