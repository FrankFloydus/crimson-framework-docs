**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

Reports, reviews, and requests app-scoped Steam game sanctions.

Get this service from `SteamPublisher.moderation()` in an explicitly enabled trusted publisher build. Configure the app for Valve's anti-cheat Web API and inject [`SteamModerationPolicy`](/api/classes/SteamModerationPolicy). Await the actions on the main thread. Report submission creates evidence for review. Steam's game sanctions require a separate reviewed request. A missing policy returns `ERR_UNCONFIGURED`, and a denied or mismatched authorization returns `ERR_UNAUTHORIZED`.

## Methods

### `ban`

`ban(report_id: String, reason: String) -> Variant`

Requests a permanent game ban for the policy-resolved player associated with `report_id`. Supply the reviewed `reason`. Returns [`SteamModerationReceiptResult`](/api/classes/SteamModerationReceiptResult). The exact game policy must authorize the request and reserve the audit record before Steam receives it. An expired or closed observation can leave the remote outcome unresolved.

### `remove_ban`

`remove_ban(player_id: String, reason: String) -> Variant`

Requests removal of the game ban for `player_id` on the configured AppID. The `reason` stays in the trusted audit record. Returns [`SteamModerationReceiptResult`](/api/classes/SteamModerationReceiptResult). The exact game policy must authorize the request and reserve the audit record before Steam receives it. An expired or closed observation can leave the remote outcome unresolved.

### `report`

`report(player_id: String, evidence: SteamCheatEvidence) -> Variant`

Submits `evidence` about `player_id` after policy approval. The player ID is an individual SteamID64 in decimal form. A player reporter must be verified by the same publisher. Returns [`SteamCheatReportResult`](/api/classes/SteamCheatReportResult) with the full unsigned Valve report ID.

### `reports`

`reports(from_unix: int, to_unix: int, after_report_id: String = "0") -> Variant`

Lists reports from `from_unix` to `to_unix`, in UTC Unix seconds, with a maximum span of seven days. Use the exclusive decimal `after_report_id` cursor from the previous page or `"0"` for the first page. Returns [`SteamCheatReportPageResult`](/api/classes/SteamCheatReportPageResult).

### `suspend`

`suspend(report_id: String, seconds: int, reason: String) -> Variant`

Requests a suspension for the policy-resolved player associated with `report_id`. `seconds` must be from 1 through 31535999. Valve treats durations under one year as suspensions hidden from the player's public profile. Supply the reviewed `reason`. Returns [`SteamModerationReceiptResult`](/api/classes/SteamModerationReceiptResult). An invalid duration returns `ERR_INVALID_PARAMETER` before invoking the policy. The exact game policy must authorize the request and reserve the audit record before Steam receives it. An expired or closed observation can leave the remote outcome unresolved.
