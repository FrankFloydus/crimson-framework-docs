## Methods

### `_authorize_client`

`_authorize_client(request: SteamRelayRequest) -> void`

**Virtual method.**

Authenticate the client independently, authorize only the selected live registration, and sign a fresh Steam relay ticket on the backend. Complete the exact request with `SteamRelayRequest.authorize()` or `SteamRelayRequest.fail()`. Keep signing credentials off client and game-server builds.

`_register_server(request: SteamRelayRequest) -> void`

**Virtual method.**
