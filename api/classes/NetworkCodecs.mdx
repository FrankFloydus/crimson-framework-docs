## Description

Use `Game.codecs()` for a catalog tied to a game attachment or create an independent catalog with `NetworkCodecs.new()`. Register the same game codec in each participant and select its identifier and version explicitly. The catalog neither sends packets nor adds a schema header to the payload. Encode and decode on the scene thread. When a game scope retires, its catalog releases the callbacks and further operations return `ERR_UNAVAILABLE`.
