## Description

Each edit returns a new draft. Steam receives the image only when an explicit submission starts. Location and tags are submitted after the exact save is confirmed.

## Methods

### Instance methods

#### [`at`](/api/classes/SteamScreenshotRequest/methods/at)

Return a copy with the optional location label.

#### [`send`](/api/classes/SteamScreenshotRequest/methods/send)

Submit the draft once and return a retained operation.

#### [`submit`](/api/classes/SteamScreenshotRequest/methods/submit)

Submit the draft once.

#### [`tag`](/api/classes/SteamScreenshotRequest/methods/tag)

Return a copy with an individual decimal SteamID64 tag.

#### [`tag_item`](/api/classes/SteamScreenshotRequest/methods/tag_item)

Return a copy with a nonzero decimal Workshop published-file ID.
