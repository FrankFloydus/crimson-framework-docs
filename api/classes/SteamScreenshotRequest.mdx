## Description

Each edit returns a new draft. Steam receives the image only when an explicit submission starts. Location and tags are submitted after the exact save is confirmed.

### Method details

#### `at`

`at(location: String) -> SteamScreenshotRequest`

Return a copy with the optional location label. Pass empty text to omit it. Steam accepts at most 255 UTF-8 bytes without embedded NUL characters.

#### `send`

`send() -> SteamScreenshotOperation`

Submit the draft once and return a retained operation. The scope validates all input before writing, waits up to 15 seconds for the exact save confirmation, and then applies requested metadata. A timeout does not cancel the Steam write.

#### `submit`

`submit() -> Variant`

Submit the draft once. Await this call for a [`SteamScreenshotResult`](/api/classes/SteamScreenshotResult), including immediate validation or availability failures.

#### `tag`

`tag(steam_id: String) -> SteamScreenshotRequest`

Return a copy with an individual decimal SteamID64 tag. Submission rejects a malformed ID or more than 32 user tag requests. Duplicate IDs are submitted once.

#### `tag_item`

`tag_item(published_id: String) -> SteamScreenshotRequest`

Return a copy with a nonzero decimal Workshop published-file ID. Submission rejects a malformed ID or more than 32 item tag requests. Duplicate IDs are submitted once.
