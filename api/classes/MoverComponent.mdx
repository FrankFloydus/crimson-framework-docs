**Inherits** `Node`

## Description

Add one MoverComponent directly under the player scene's `CharacterBody3D`. Edit Ground Movement, Air Movement, and Jumping in the Inspector before boot. Fixed-world [`Game`](/api/classes/Game) sessions and standalone [`PlayerControlProfile`](/api/classes/PlayerControlProfile) controllers copy the effective settings when configuring movement. The component does not start a physics driver by itself. An attached runtime [`Mover`](/api/classes/Mover) can be read using `mover()`.

## Properties

**[`acceleration`](/api/classes/MoverComponent/properties/acceleration)**

How quickly steering adds speed or changes direction on the ground, in metres per second squared.

**[`air_control`](/api/classes/MoverComponent/properties/air_control)**

Fraction of steering acceleration available while airborne, including on takeoff.

**[`controller_style`](/api/classes/MoverComponent/properties/controller_style)**

Choose how movement input turns and moves the body.

**[`deceleration`](/api/classes/MoverComponent/properties/deceleration)**

Base ground braking rate in metres per second squared when input requests a lower speed or stops.

**[`forward_direction`](/api/classes/MoverComponent/properties/forward_direction)**

Sets forward for FPS / Shoulder Aim.

**[`gravity_scale`](/api/classes/MoverComponent/properties/gravity_scale)**

Multiplier on gravity along the body's up axis.

**[`ground_friction`](/api/classes/MoverComponent/properties/ground_friction)**

Ground turning and braking coefficient in inverse seconds, from 0 to 100.

**[`jump_speed`](/api/classes/MoverComponent/properties/jump_speed)**

Upward speed at takeoff in metres per second, from 0 to 1000.

**[`move_relative_to`](/api/classes/MoverComponent/properties/move_relative_to)**

Compatibility alias for `forward_direction`.

**[`move_speed`](/api/classes/MoverComponent/properties/move_speed)**

Requested speed at full movement input, in metres per second.

**[`predict_movement`](/api/classes/MoverComponent/properties/predict_movement)**

Use client prediction and server reconciliation in fixed-world sessions with matching upright capsules and static level collision.

## Constants and enums

### `ControllerStyle`

| Name | Value | Description |
| --- | --- | --- |
| `FORWARD_ONLY` | `2` | Forward-Only Third Person. Press Left to turn the body toward the camera's left and walk forward into the turn instead of strafing. Steering asks for less speed while the body lines up. Turns at up to 540 degrees per second. |
| `FPS_AIM` | `0` | FPS / Shoulder Aim. With View Heading, the body turns with the camera even while standing still. Press Left to strafe without turning. Standalone Character Heading leaves body rotation to the game. |
| `FREE_ORBIT` | `1` | Free-Orbit Third Person. Looking around while idle leaves the body facing the same way. Press Left to move toward the camera's left while the body turns toward that direction. Turns at up to 540 degrees per second. |
| `LOCK_ON` | `3` | Lock-On. The body faces a target selected with `PlayerControl.lock_on()`. Press Left to move sideways relative to the target and Back to move away. With no target, the body and movement follow the view. |

### `MoveReference`

| Name | Value | Description |
| --- | --- | --- |
| `CHARACTER` | `1` | Character Heading. Forward follows the body's current heading in standalone Player Control and its spawn heading in Game sessions. |
| `VIEW` | `0` | View Heading. Forward follows the camera or view pivot's horizontal heading. |
| `WORLD` | `2` | World Axes. Forward always follows the world's negative Z direction. |
