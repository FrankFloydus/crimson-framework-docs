**Inherits** `RefCounted`

Steam dedicated server discovery for one exact signed-in client scope.

## Methods

### `inspect`

`inspect(listing: SteamListing, timeout_ms: int = 3000) -> SteamServerDetailsOperation`

Refresh one selected server using its native Steam query port. The response must match the selected AppID, namespace, server identity and address. Timeout accepts 100 to 15000 milliseconds.

### `is_available`

`is_available() -> bool`

Return whether the owning Steam client start supports the server browser.

### `query`

`query(source: SteamServer.Advertisement = 2, namespace: StringName = &"") -> SteamServerQuery`

Return detached options for Steam Internet or LAN discovery. Omit the namespace to use the owning game's namespace or `crimson` on a standalone client. A Game scope cannot override its namespace.
