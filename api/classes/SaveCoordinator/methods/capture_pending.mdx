## Signature

```text
capture_pending(revision: String = "") -> bool
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `revision` | `String` | `""` |

## Return value

`bool`

## Description

The optional `revision` label is limited to 128 UTF-8 bytes. Returns true if the capture succeeds. Call once for each pending save you want to capture.
