## Signature

```text
query(namespace: StringName = &"") -> SteamLobbyQuery
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `namespace` | `StringName` | `&""` |

## Return value

[`SteamLobbyQuery`](/api/classes/SteamLobbyQuery)

## Description

The namespace defaults to the configured Game namespace or `crimson` for standalone clients. A standalone query can opt into social lobbies with `SteamLobbyQuery.social()`.

## Example

```gdscript
extends Node

func run_query(
    steam_client: SteamClient,
    namespace_value: StringName,
    results_list: ItemList
) -> void:
    if not steam_client.is_ready():
        return
    var steam_lobbies: SteamLobbies = steam_client.lobbies()
    if steam_lobbies == null:
        return
    var result: SteamLobbyQuery = steam_lobbies.query(namespace_value)
    if result == null:
        return
    var search_result: SteamListingsResult = await result.fetch()
    if search_result == null:
        return
    if not search_result.ok:
        push_warning(search_result.message)
        return
    var payload: Array[SteamListing] = search_result.value
    results_list.clear()
    for entry: SteamListing in payload:
        results_list.add_item(str(entry.name))
```
