
## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `options` | [`SteamLobbyOptions`](/api/classes/SteamLobbyOptions) | `null` |

## Return value

[`SteamLobbyOperation`](/api/classes/SteamLobbyOperation)

## Description

Null options use the private default. An existing membership or pending native acquisition in this account returns `ERR_BUSY`. A Game scope returns `ERR_UNAUTHORIZED`.

## Example

```gdscript
func create_invite_only_lobby(lobbies: SteamLobbies) -> SteamLobby:
    # Use a standalone Steam client. The default lobby is private.
    var result: SteamLobbyResult = await lobbies.create().wait()
    if not result.ok:
        push_warning(result.message)
        return null
    return result.value
```
