**Inherits** `RefCounted`

Branchable edits to one player's published Steam GameServer progression.

Each edit returns a new branch. Stage at most 32 changes with nonempty Steam API names of at most 127 UTF-8 bytes. `submit()` loads the cache if necessary and validates all names and readable types before calling setters. Steam applies setters individually. If a later setter fails, the receipt reports the accepted count and rejected index. Accepted cache changes can remain in Steam. An explicit `SteamServerPlayerStats.store()` can persist them without replaying the setters.

## Methods

### `clear_achievement`

`clear_achievement(name: StringName) -> SteamServerStatsEdit`

Stage clearing the published server-writable achievement `name`. Submit only for a deliberate reset.

### `set_float`

`set_float(name: StringName, value: float) -> SteamServerStatsEdit`

Stage an absolute finite value representable as a Steam single-precision float for `name`.

### `set_int`

`set_int(name: StringName, value: int) -> SteamServerStatsEdit`

Stage an absolute signed 32-bit value for the published integer stat `name`.

### `submit`

`submit() -> SteamServerStatsOperation`

Submit this exact draft once and return its retained observation. Repeated calls return the same operation, including after failure or cancellation. A successful edit receipt confirms Steam's native StoreUserStats response. An invalid draft settles with `ERR_INVALID_PARAMETER` before issuing Steam work. Use a new draft for a different game action.

### `unlock`

`unlock(name: StringName) -> SteamServerStatsEdit`

Stage an unlock for the published server-writable achievement `name`.

### `update_average_rate`

`update_average_rate(name: StringName, count: float, seconds: float) -> SteamServerStatsEdit`

Stage a finite accumulated `count` over a finite, positive elapsed duration in `seconds` for the published AVGRATE stat `name`.
