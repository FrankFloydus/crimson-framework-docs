## Description

Each edit returns a new branch. Stage at most 32 changes with nonempty Steam API names of at most 127 UTF-8 bytes. `submit()` loads the cache if necessary and validates all names and readable types before calling setters. Steam applies setters individually. If a later setter fails, the receipt reports the accepted count and rejected index. Accepted cache changes can remain in Steam. An explicit `SteamServerPlayerStats.store()` can persist them without replaying the setters.
