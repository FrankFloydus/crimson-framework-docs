**Inherits** `RefCounted`

## Description

Attach to an existing body on the main thread, then give it a world-space velocity with `move()`. The body owns the attachment and advances it every physics tick. You can steer from game input, AI, or any other script. Issue steering before physics processing priority 100 within the same main-thread processing group to affect the current tick. The attachment uses `CharacterBody3D.move_and_slide()` for character collision or updates the world position directly for a plain `Node3D`. Keep pose and velocity writes in the mover while it is attached. Leaving the scene tree clears pending steering and motion state.

## Methods

### Static methods

#### [`attach`](/api/classes/Mover/methods/attach)

Attach to a `CharacterBody3D` or a `Node3D` without its own collision body.

#### [`for_node`](/api/classes/Mover/methods/for_node)

Get the attachment for this exact body without creating one.

### Instance methods

#### [`jump`](/api/classes/Mover/methods/jump)

Queue one grounded jump attempt for the next live physics step.

#### [`move`](/api/classes/Mover/methods/move)

Set the world-space steering target in metres per second.

#### [`stop`](/api/classes/Mover/methods/stop)

Clear steering.

#### [`use_rule`](/api/classes/Mover/methods/use_rule)

Use a snapshot of `rule` from the next step, or pass `null` to restore neutral steering.
