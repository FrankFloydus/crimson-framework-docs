## Description

A complete HTTP response can carry an unsuccessful HTTP status. The enclosing [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) reports transport and completion errors.

#### `header`

`header(name: String) -> String`

Return a captured response header by case-insensitive name. An absent, empty, or unselected field returns an empty string.

#### `is_successful`

`is_successful() -> bool`

Return true when the HTTP status is in the 2xx range.

#### `json`

`json() -> SteamJsonResult`

Parse the body as UTF-8 JSON and return its separate decoding result. Check the parsing outcome independently of the response status.
