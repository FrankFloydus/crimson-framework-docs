Keep a persistent manager at the same relative path on every peer and register the same scene IDs locally. The manager prepares each scene asynchronously and owns the child named `World` in its configured container."

### Method details

#### `cancel_load`

`cancel_load() -> Error`

Cancels the pending offline or host transition before its commit decision and reports it through `load\_failed`. Returns `ERR\_DOES\_NOT\_EXIST` when idle, `ERR\_UNAUTHORIZED` on a client, or `ERR\_BUSY` if publication has begun.

#### `clear_world`

`clear_world() -> Error`

Unmounts the local world and releases the admission gate held by this loader. Returns `ERR\_BUSY` during an active transition. Call on each participant during network teardown.

#### `get_current_scene`

`get_current_scene() -> Node`

Returns the managed world root while it belongs to the configured container, or `null`.

#### `get_current_scene_id`

`get_current_scene_id() -> StringName`

Returns the registered ID of the mounted world, or an empty `StringName` when no managed world is mounted.

#### `get_load_timeout_msec`

`get_load_timeout_msec() -> int`

Returns the configured preparation and activation confirmation timeout in milliseconds per phase.

#### `get_manage_admission`

`get_manage_admission() -> bool`

Returns whether the loader owns the host admission gate during and after a multiplayer transition.

#### `get_world_container`

`get_world_container() -> Node`

Returns the configured world container while it remains in the same scene tree, or `null`.

#### `is_loading`

`is_loading() -> bool`

Returns whether a transition is pending, including the wait for multiplayer activation confirmation.

#### `register_scene`

`register_scene(scene_id: StringName, scene_path: String) -> Error`

Adds a case-sensitive ID and canonical local `res://` path to a `.tscn` or `.scn` scene. IDs are 1 to 64 ASCII characters, begin with a letter or digit, and can contain letters, digits, dots, hyphens, and underscores. Duplicate IDs return `ERR\_ALREADY\_EXISTS`.

#### `request_coordinated_load`

`request_coordinated_load(scene_id: StringName, publish_state: Callable) -> Error`

Requests an asynchronous transition with a zero-argument callback that returns a Godot `Error`. The authority calls it once after the candidate and mount are validated and all captured peers are prepared. Return `OK` to publish state before the new world enters the tree. On rejection, keep the current state intact. A return of `OK` from this method means admission. Signals report the outcome.

#### `request_load`

`request_load(scene_id: StringName) -> Error`

Starts an asynchronous transition for a registered scene. Call offline or as host peer 1. A client receives `ERR\_UNAUTHORIZED`, an overlapping request receives `ERR\_BUSY`, and an unknown ID receives `ERR\_DOES\_NOT\_EXIST`. Signals report the outcome after admission.

#### `set_load_timeout_msec`

`set_load_timeout_msec(timeout: int) -> Error`

Sets the timeout for future preparation and activation confirmation phases. Accepts 1 through 120,000 milliseconds and defaults to 15,000. Returns `ERR\_BUSY` during a transition or `ERR\_INVALID\_PARAMETER` for an out-of-range timeout.

#### `set_manage_admission`

`set_manage_admission(enabled: bool) -> Error`

Selects who manages the host admission gate. The default is `true`. Set `false` when the orchestrator closes admission before a host transition and holds it through confirmation. Returns `ERR\_BUSY` while a transition is active or this loader holds a gate.

#### `set_world_container`

`set_world_container(container: Node) -> Error`

Assigns a live container in the manager's scene tree. Reserve the child name `World` for the loader. Keep the current container while a managed world is mounted.

## Signals

### `load_completed`

`load_completed(scene_id: StringName)`

Emits after the offline scene mounts or the multiplayer host confirms activation by all participants. An orchestrator can wait for a separate gameplay baseline before opening input.

### `load_failed`

`load_failed(scene_id: StringName, error: int, message: String)`

Emits for cancellation or failure before commit, including a rejected publisher or peer membership changes. The existing world stays mounted.

### `load_started`

`load_started(scene_id: StringName)`

Emits when the transition has been admitted. Use it to gate gameplay and show loading feedback.

### `load_sync_failed`

`load_sync_failed(scene_id: StringName, error: int, message: String)`

Emits if the transition fails after the multiplayer commit decision or after coordinated authority state publication. Keep gameplay gated until the game recovers or ends the session.
