---
title: "SceneLoadManager"
description: "Replaces a managed world offline or across the connected peers in its Godot multiplayer scope. Keep a persistent manager at the same relative path on every peer and register the same scene IDs locally. The manager prepares each scene asynchronously and owns the child named `World` in its configured container."

## Methods

### Instance methods

#### [`cancel_load`](/api/classes/SceneLoadManager/methods/cancel_load)

Cancels the pending offline or host transition before its commit decision and reports it through `load\_failed`.

#### [`clear_world`](/api/classes/SceneLoadManager/methods/clear_world)

Unmounts the local world and releases the admission gate held by this loader.

#### [`get_current_scene`](/api/classes/SceneLoadManager/methods/get_current_scene)

Returns the managed world root while it belongs to the configured container, or `null`.

#### [`get_current_scene_id`](/api/classes/SceneLoadManager/methods/get_current_scene_id)

Returns the registered ID of the mounted world, or an empty `StringName` when no managed world is mounted.

#### [`get_load_timeout_msec`](/api/classes/SceneLoadManager/methods/get_load_timeout_msec)

Returns the configured preparation and activation confirmation timeout in milliseconds per phase.

#### [`get_manage_admission`](/api/classes/SceneLoadManager/methods/get_manage_admission)

Returns whether the loader owns the host admission gate during and after a multiplayer transition.

#### [`get_world_container`](/api/classes/SceneLoadManager/methods/get_world_container)

Returns the configured world container while it remains in the same scene tree, or `null`.

#### [`is_loading`](/api/classes/SceneLoadManager/methods/is_loading)

Returns whether a transition is pending, including the wait for multiplayer activation confirmation.

#### [`register_scene`](/api/classes/SceneLoadManager/methods/register_scene)

Adds a case-sensitive ID and canonical local `res://` path to a `.tscn` or `.scn` scene.

#### [`request_coordinated_load`](/api/classes/SceneLoadManager/methods/request_coordinated_load)

Requests an asynchronous transition with a zero-argument callback that returns a Godot `Error`.

#### [`request_load`](/api/classes/SceneLoadManager/methods/request_load)

Starts an asynchronous transition for a registered scene.

#### [`set_load_timeout_msec`](/api/classes/SceneLoadManager/methods/set_load_timeout_msec)

Sets the timeout for future preparation and activation confirmation phases.

#### [`set_manage_admission`](/api/classes/SceneLoadManager/methods/set_manage_admission)

Selects who manages the host admission gate.

#### [`set_world_container`](/api/classes/SceneLoadManager/methods/set_world_container)

Assigns a live container in the manager's scene tree.

## Signals

### `load_completed`

`load_completed(scene_id: StringName)`

Emits after the offline scene mounts or the multiplayer host confirms activation by all participants. An orchestrator can wait for a separate gameplay baseline before opening input.

### `load_failed`

`load_failed(scene_id: StringName, error: int, message: String)`

Emits for cancellation or failure before commit, including a rejected publisher or peer membership changes. The existing world stays mounted.

### `load_started`

`load_started(scene_id: StringName)`

Emits when the transition has been admitted. Use it to gate gameplay and show loading feedback.

### `load_sync_failed`

`load_sync_failed(scene_id: StringName, error: int, message: String)`

Emits if the transition fails after the multiplayer commit decision or after coordinated authority state publication. Keep gameplay gated until the game recovers or ends the session.
