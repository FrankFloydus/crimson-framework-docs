**Inherits** `RefCounted`

Retained result of one Steam GameServer stats operation.

Local observation is bounded to 15 seconds. Steam may still complete an issued store after local cancellation, departure, or timeout. The same account stays fenced while its earlier Steam call drains, preventing accidental replay of a pending update.

## Methods

### `cancel`

`cancel() -> Error`

Settle a pending observer with `ERR_SKIP` and stop any edit still waiting on a load. A store already issued to Steam can still persist. Returns `ERR_DOES_NOT_EXIST` once the observer is settled.

### `is_finished`

`is_finished() -> bool`

Report whether the observation has a terminal result.

### `result`

`result() -> SteamServerStatsResult`

Return the settled result, or null while pending.

### `wait`

`wait() -> Variant`

Return the terminal [`SteamServerStatsResult`](/api/classes/SteamServerStatsResult) or a signal to await for that result.

## Signals

### `completed`

`completed(result: SteamServerStatsResult)`

Emitted once the terminal result is stored on this operation.
