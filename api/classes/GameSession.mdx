## Description

Network sessions use ENet by default. A host and its guests use matching session node paths within their multiplayer scopes. Use the scene tree's normal multiplayer polling, or poll the configured `MultiplayerAPI` yourself when automatic polling is disabled. A guest becomes active once the host confirms admission.

## Signals

### `peer_joined`

`peer_joined(peer_id: int)`

Emitted when an admitted remote peer enters this scope's roster. The peer ID identifies a connection.

### `peer_left`

`peer_left(peer_id: int)`

Emitted when a remote peer leaves the active roster. Ending the entire session clears the roster together.

### `session_ended`

`session_ended(reason: StringName)`

Emitted when a session ends or a pending connection fails. Reasons include `left`, `connection_failed`, `connection_timeout`, `protocol_mismatch`, `server_disconnected`, `transport_replaced`, and `transport_disconnected`. Verified sessions can also report `authentication_failed` or `authentication_replaced`. Removing the session node closes it silently.

### `session_started`

`session_started(state: int, local_peer_id: int)`

Emitted after an offline or host session starts, or after the host admits this guest. The peer ID identifies the active connection.

### `state_changed`

`state_changed(state: int)`

Emitted when the session enters a new `State`, including while waiting for admission.

## Constants and enums

### `State`

| Name | Value | Description |
| --- | --- | --- |
| `CLIENT` | `4` | The host has admitted the local guest. |
| `CONNECTING` | `3` | The guest is connecting or waiting for the host to confirm admission. |
| `HOSTING` | `2` | The local process listens as the network authority. |
| `IDLE` | `0` | The session owns no transport. |
| `OFFLINE` | `1` | The local process owns an offline session and acts as authority. |
