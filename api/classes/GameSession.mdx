### Method details

#### `get_authenticator`

`get_authenticator() -> SessionAuthenticator`

Return the authenticator selected for network starts, or null when the scope uses its existing authentication policy.

#### `get_connected_peer_ids`

`get_connected_peer_ids() -> PackedInt32Array`

Return the current admitted remote connection IDs in ascending order. The scope's relay configuration determines which other guests a client sees.

#### `get_local_peer_id`

`get_local_peer_id() -> int`

Return the active local connection ID. Offline and host sessions use ID 1. Returns 0 while idle or waiting for admission.

#### `get_peer_identity`

`get_peer_identity(peer_id: int) -> SessionIdentity`

Return the identity verified by this session for an admitted direct peer, or null when it has no such identity. A host can read verified guests and a guest can read its verified host.

#### `get_state`

`get_state() -> GameSession.State`

Return the current session role. CONNECTING lasts until the host confirms admission, even if the underlying transport has connected.

#### `host`

`host(port: int, max_clients: int = 32, bind_address: String = "*") -> Error`

Start a listening session as peer 1 with admission open. Provide a port from 1 to 65535, a remote client limit from 1 to 4095, and `\*` or a literal bind IP. Returns OK when the host is installed, ERR\_INVALID\_PARAMETER for invalid settings, or the scope or transport setup error.

#### `is_accepting_connections`

`is_accepting_connections() -> bool`

Return true when the active host peer allows new connections. Returns false outside the host role.

#### `is_authority`

`is_authority() -> bool`

Return true in an active offline or host session. Authority assignments for individual Godot nodes still follow the project's multiplayer configuration.

#### `join`

`join(address: String, port: int, timeout_seconds: float = 10.0) -> Error`

Begin connecting to a host by IP address or hostname and port using the selected adapter. The timeout is in seconds and must be greater than 0 and at most 120. OK means the attempt started. Wait for session\_started before sending gameplay RPCs.

#### `join_endpoint`

`join_endpoint(endpoint: SessionEndpoint, timeout_seconds: float = 10.0) -> Error`

Begin connecting through the selected adapter to a SessionEndpoint. The timeout is in seconds and must be greater than 0 and at most 120. A null endpoint or invalid timeout returns ERR\_INVALID\_PARAMETER. OK means the attempt started. Wait for session\_started to confirm admission.

#### `leave`

`leave() -> void`

End an active session or pending connection and clear the remote roster. Restore the previous multiplayer peer if this session still owns the slot. Calling while idle has no effect.

#### `set_accepting_connections`

`set_accepting_connections(enabled: bool) -> Error`

Open or close admission on the active host without removing admitted guests. Returns ERR\_UNAUTHORIZED outside the host role, ERR\_BUSY if ownership changes during the call, or ERR\_UNAVAILABLE when the peer cannot apply the requested flag.

#### `set_authenticator`

`set_authenticator(authenticator: SessionAuthenticator) -> Error`

Select a SessionAuthenticator for future network sessions. Pass null to retain the multiplayer scope's own authentication policy. Returns ERR\_BUSY unless the session is idle and no start or teardown is in progress.

#### `set_transport_adapter`

`set_transport_adapter(adapter: SessionTransport) -> Error`

Select a SessionTransport for future network sessions. Pass null to use ENet. Offline startup always uses Godot's offline peer. Returns ERR\_BUSY unless the session is idle and no start or teardown is in progress.

#### `start_offline`

`start_offline() -> Error`

Install a Godot offline peer and make the local process authoritative with peer ID 1. Returns OK on success or an error if the node cannot claim the multiplayer scope.

## Signals

### `peer_joined`

`peer_joined(peer_id: int)`

Emitted after a remote connection enters the admitted roster. On a verified host, get\_peer\_identity can read that guest's identity at this point.

### `peer_left`

`peer_left(peer_id: int)`

Emitted after a remote connection leaves the admitted roster during an active session. Session teardown clears the roster together.

### `session_ended`

`session_ended(reason: StringName)`

Emitted when the active session or a pending connection ends. Reasons include `left`, `connection\_failed`, `connection\_timeout`, `protocol\_mismatch`, `server\_disconnected`, `transport\_replaced`, and `transport\_disconnected`. Verified sessions can also end with `authentication\_failed` or `authentication\_replaced`. Removing the node from the tree closes it silently.

### `session_started`

`session_started(state: int, local_peer_id: int)`

Emitted when an offline session, host, or admitted client becomes active, with its state and local peer ID.

### `state_changed`

`state_changed(state: int)`

Emitted when the session changes roles, including entering CONNECTING during a join attempt.

## Constants and enums

### `State`

| Name | Value | Description |
| --- | --- | --- |
| `CLIENT` | `4` | The host has admitted the local client. |
| `CONNECTING` | `3` | The client is waiting for the host to confirm admission. |
| `HOSTING` | `2` | The local process is listening as the network authority. |
| `IDLE` | `0` | The session owns no transport. |
| `OFFLINE` | `1` | The local process is the authority for an offline game. |
