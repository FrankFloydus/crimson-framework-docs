## Return value

`Error`

## Description

Verify expected amounts, stage all updates, invoke the supplied commit callable synchronously when present, and restore the previous balances if it returns an error.

## Example

```gdscript
extends SpatialInventoryWallet

# This transaction checks expected amounts, stages the balances, runs commit,
# and restores the old balances if commit fails.
var apply_wallet_transaction: Callable

func _apply_balance_changes(changes: Array[Dictionary], commit: Callable) -> Error:
    if not apply_wallet_transaction.is_valid():
        return ERR_UNCONFIGURED
    return apply_wallet_transaction.call(changes, commit)
```
