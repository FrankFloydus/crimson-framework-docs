## Parameters

| Parameter | Type | Default |

| `changes` | `Array` | — |
| `commit` | `Callable` | `Callable()` |

## Return value

`Error`

## Description

A stale expected balance returns `ERR_BUSY`. Stage the full batch before the optional no-argument commit callback. A callback error rolls all balances back.
