[`SteamLeaderboardSubmission`](/api/classes/SteamLeaderboardSubmission)

## Description

Returns `null` if Steam never reported an accepted upload.

```gdscript

func run_get_value(
    steam_leaderboard_submission_result: SteamLeaderboardSubmissionResult,
    apply_value: Callable
```
