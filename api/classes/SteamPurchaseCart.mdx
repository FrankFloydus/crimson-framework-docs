**Inherits** `RefCounted`

Branchable purchase selection containing game SKUs and quantities.

Build a cart with `with_item()`. Crimson assigns its stable checkout ID on first submission. Save it with the original cart to recover a lost response. A different item or quantity creates a different checkout.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `checkout_id` | `String` | — | `get_checkout_id()` | Stable checkout retry ID. Empty until first checkout assigns it. Read on the main thread. |

## Methods

### `lines`

`lines() -> SteamPurchaseLine[]`

Returns a read-only copy of the typed SKU selections.

### `with_checkout_id`

`with_checkout_id(checkout_id: String) -> SteamPurchaseCart`

Returns the same selection with a previously assigned 32-character lowercase hexadecimal retry ID. Returns null if the ID is invalid.

### `with_item`

`with_item(sku: StringName, quantity: int) -> SteamPurchaseCart`

Returns an independent branch with the quantity for this SKU replaced. A SKU uses 1 to 64 letters, digits, dots, dashes, or underscores. A cart holds up to 32 SKUs. Quantities range from 1 through 1000. Invalid selections return null.
