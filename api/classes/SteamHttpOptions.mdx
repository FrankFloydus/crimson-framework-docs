**Inherits** `RefCounted`

Branchable HTTP options and actions for one Steam client scope.

Each modifier returns a new branch. The same HTTP terminal can be called on [`SteamHttp`](/api/classes/SteamHttp) with defaults or on a configured branch.

## Methods

### `accept_json`

`accept_json() -> SteamHttpOptions`

Return a branch with the request's Accept header set to `application/json`.

### `delete`

`delete(url: String) -> Variant`

Send DELETE using the selected options. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `fetch`

`fetch(url: String) -> Variant`

Send an absolute HTTP or HTTPS URL using GET. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `head`

`head(url: String) -> Variant`

Send HEAD and return status and captured headers with an empty body. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `options`

`options(url: String) -> Variant`

Send OPTIONS using the selected options. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `patch`

`patch(url: String, data: Dictionary) -> Variant`

Send the supplied dictionary as a JSON PATCH body. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `post`

`post(url: String, data: Dictionary) -> Variant`

Send the supplied dictionary as a JSON POST body. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `put`

`put(url: String, data: Dictionary) -> Variant`

Send the supplied dictionary as a JSON PUT body. Returns a [`SteamHttpResponseResult`](/api/classes/SteamHttpResponseResult) after `await`.

### `request`

`request(url: String, method: SteamHttpOptions.Method = 1) -> SteamHttpRequest`

Create an unsent request draft with the selected options. The default method is GET.

### `with_header`

`with_header(name: String, value: String) -> SteamHttpOptions`

Return a branch with a request header. Header names are case-insensitive, and a new value replaces the same header on that branch. Steam manages framing and connection headers.

### `with_max_response_bytes`

`with_max_response_bytes(bytes: int) -> SteamHttpOptions`

Return a branch with a response body limit from 1 byte to 4 MiB. The default is 1 MiB. Larger bodies return a limit error and expose no partial response.

### `with_response_headers`

`with_response_headers(names: PackedStringArray) -> SteamHttpOptions`

Return a branch that replaces the selected response header names. Select up to 16 additional names. Matching ignores case, and Content-Type is captured when present. A selected field larger than 2,048 bytes returns a limit error.

### `with_timeout`

`with_timeout(milliseconds: int) -> SteamHttpOptions`

Return a branch with an absolute deadline from 100 to 120,000 milliseconds. The default is 15,000 milliseconds.
