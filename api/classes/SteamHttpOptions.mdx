## Description

Each modifier returns a new branch. The same HTTP terminal can be called on [`SteamHttp`](/api/classes/SteamHttp) with defaults or on a configured branch.

## Methods

### Instance methods

#### [`accept_json`](/api/classes/SteamHttpOptions/methods/accept_json)

Return a branch with the request's Accept header set to `application/json`.

#### [`delete`](/api/classes/SteamHttpOptions/methods/delete)

Send DELETE using the selected options.

#### [`fetch`](/api/classes/SteamHttpOptions/methods/fetch)

Send an absolute HTTP or HTTPS URL using GET.

#### [`head`](/api/classes/SteamHttpOptions/methods/head)

Send HEAD and return status and captured headers with an empty body.

#### [`options`](/api/classes/SteamHttpOptions/methods/options)

Send OPTIONS using the selected options.

#### [`patch`](/api/classes/SteamHttpOptions/methods/patch)

Send the supplied dictionary as a JSON PATCH body.

#### [`post`](/api/classes/SteamHttpOptions/methods/post)

Send the supplied dictionary as a JSON POST body.

#### [`put`](/api/classes/SteamHttpOptions/methods/put)

Send the supplied dictionary as a JSON PUT body.

#### [`request`](/api/classes/SteamHttpOptions/methods/request)

Create an unsent request draft with the selected options.

#### [`with_header`](/api/classes/SteamHttpOptions/methods/with_header)

Return a branch with a request header.

#### [`with_max_response_bytes`](/api/classes/SteamHttpOptions/methods/with_max_response_bytes)

Return a branch with a response body limit from 1 byte to 4 MiB.

#### [`with_response_headers`](/api/classes/SteamHttpOptions/methods/with_response_headers)

Return a branch that replaces the selected response header names.

#### [`with_timeout`](/api/classes/SteamHttpOptions/methods/with_timeout)

Return a branch with an absolute deadline from 100 to 120,000 milliseconds.
