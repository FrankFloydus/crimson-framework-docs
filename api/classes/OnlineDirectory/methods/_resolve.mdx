## Description

Call fail when the listing cannot be resolved.

## Example

```gdscript
extends OnlineDirectory

# Set this to the backend lookup for this directory's listings.
var find_route: Callable

func _resolve(listing_id: String, request: OnlineDirectoryRequest) -> void:
    if not find_route.is_valid():
        request.fail()
        return
    var endpoint: SessionEndpoint = find_route.call(listing_id) as SessionEndpoint
    if endpoint == null:
        request.fail()
        return
    request.resolve(endpoint)
```
