## Description

Use endpoint as the advertised route when supplied, or obtain the route from the provider's transport. Complete request with publish or fail.

## Example

```gdscript
extends OnlineDirectory

# Set this to the backend function that publishes a route and returns its ID.
var publish_route: Callable

func _publish(endpoint: SessionEndpoint, world_id: StringName, request: OnlineDirectoryRequest) -> void:
    if endpoint == null or not publish_route.is_valid():
        request.fail()
        return
    var listing_id: String = publish_route.call(endpoint, world_id)
    if listing_id.is_empty():
        request.fail()
        return
    request.publish(listing_id)
```
