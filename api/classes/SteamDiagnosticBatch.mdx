**Inherits** `RefCounted`

A read-only snapshot of Steam SDK diagnostics.

`SteamDiagnostics.drain()` returns an independent snapshot of the current capture queue. Later drains or capture stops leave earlier snapshots usable.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `dropped_count` | `int` | — | `get_dropped_count()` | Read-only overflow count for this snapshot. |
| `messages` | `SteamDiagnosticMessage[]` | — | `get_messages()` | Read-only typed array of diagnostics in capture order. |

## Methods

### `get_dropped_count`

`get_dropped_count() -> int`

Returns the number of additional callbacks discarded after the queue reached capacity, since capture started or since the previous drain.

### `get_messages`

`get_messages() -> SteamDiagnosticMessage[]`

Returns the read-only array of up to 32 messages in capture order. An empty snapshot returns an empty typed array.
