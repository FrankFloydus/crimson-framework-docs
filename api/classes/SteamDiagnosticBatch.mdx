**Inherits** `RefCounted`

## Description

`SteamDiagnostics.drain()` returns an independent snapshot of the current capture queue. Later drains or capture stops leave earlier snapshots usable.

## Properties

**[`dropped_count`](/api/classes/SteamDiagnosticBatch/properties/dropped_count)**

Read-only overflow count for this snapshot.

**[`messages`](/api/classes/SteamDiagnosticBatch/properties/messages)**

Read-only typed array of diagnostics in capture order.

## Methods

### Property accessors

#### [`get_dropped_count`](/api/classes/SteamDiagnosticBatch/methods/get_dropped_count)

Returns the number of additional callbacks discarded after the queue reached capacity, since capture started or since the previous drain.

#### [`get_messages`](/api/classes/SteamDiagnosticBatch/methods/get_messages)

Returns the read-only array of up to 32 messages in capture order.
