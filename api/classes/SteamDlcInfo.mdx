**Inherits** `RefCounted`

Detached metadata for a DLC entry in Steam's app catalog.

Get these records from a successful `SteamApps.dlc()` query. They describe the catalog at the time of the query.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `app_id` | `int` | — | `get_app_id()` | Positive Steam DLC AppID for a catalog entry. An uninitialized record has AppID `0`. |
| `available` | `bool` | — | `is_available()` | Read-only Steam store visibility flag. Use `SteamApps.owns_dlc()` to query local ownership. |
| `display_name` | `String` | — | `get_display_name()` | Read-only name copied from Steam's catalog. Steam can supply an empty name. |

## Methods

### `get_app_id`

`get_app_id() -> int`

Returns the Steam DLC AppID for this record.

### `get_display_name`

`get_display_name() -> String`

Returns the display name copied from Steam.

### `is_available`

`is_available() -> bool`
