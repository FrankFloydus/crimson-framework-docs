## Description

Get these records from a successful `SteamApps.dlc()` query. They describe the catalog at the time of the query.

## Properties

**[`app_id`](/api/classes/SteamDlcInfo/properties/app_id)**

Positive Steam DLC AppID for a catalog entry.

**[`available`](/api/classes/SteamDlcInfo/properties/available)**

Read-only Steam store visibility flag.

**[`display_name`](/api/classes/SteamDlcInfo/properties/display_name)**

Read-only name copied from Steam's catalog.
