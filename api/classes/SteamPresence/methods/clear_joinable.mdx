## Signature

```text
clear_joinable() -> Error
```

## Return value

`Error`

## Description

Keeps the status label, party grouping, and any foreign connect key. Call `joinable()` to publish again. A newly hosted lobby uses its usual visibility policy. Returns `@GlobalScope.ERR_UNAVAILABLE` outside a live Steam Game scope, or `@GlobalScope.FAILED` if Steam declines the clear.
