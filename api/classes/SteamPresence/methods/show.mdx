## Description

To group players, provide both a nonempty `party_id` and a positive `party_size`. Use the defaults for no grouping. Replacement keys must fit Steam's byte and key limits and must avoid `connect`, `status`, and names beginning with `steam_`. Returns `@GlobalScope.ERR_BUSY` when another scope owns the status or unrelated keys leave insufficient capacity. Steam applies each key separately. `@GlobalScope.OK` acknowledges local acceptance. Configure the token in Steamworks to display the label for other players.
