## Description

Keeps the current steering request. Returns `OK` on success, `ERR_INVALID_PARAMETER` for a grounded rule on an incompatible body, `ERR_UNAVAILABLE` when the attachment has retired, or `ERR_BUSY` when called off the main thread.
