## Signature

```text
move(world_velocity: Vector3) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `world_velocity` | `Vector3` | — |

## Return value

`Error`

## Description

The target persists until replaced, stopped, or cleared by scene exit. A grounded rule projects steering onto the plane perpendicular to the body's up direction and uses its acceleration, braking, and air control to approach the target. Neutral movement applies the requested velocity directly. Returns `OK` on success, `ERR_INVALID_PARAMETER` for a nonfinite velocity, `ERR_UNAVAILABLE` when the attachment has retired, or `ERR_BUSY` when called off the main thread.

## Example

### Send a supply drone across the room

Run a room with a supply drone. It flies four metres to the right, then stops. [Set up the drone](/scripted-movement)

```gdscript
extends Node3D

const SPEED: float = 2.0
const PASS_TIME: float = 2.0


func _ready() -> void:
    var mover: Mover = Mover.attach(self)
    if mover == null:
        push_error("Could not attach the supply drone's mover.")
        return

    var start: Vector3 = global_position
    var started: Error = mover.move(Vector3.RIGHT * SPEED)
    if started != OK:
        push_error(error_string(started))
        return

    await get_tree().create_timer(PASS_TIME, false, true).timeout
    var stopped: Error = mover.stop()
    if stopped != OK:
        push_error(error_string(stopped))
        return

    print("Supply drone stopped after %.1f m." % start.distance_to(global_position))
```
