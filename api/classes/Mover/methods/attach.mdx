## Description

Use a main-thread process group. Omit `rule` for unconstrained steering in three dimensions without gravity. A grounded rule requires a `CharacterBody3D` in grounded motion mode. Returns the existing attachment for a body that already has one, without changing its rule. Use `use_rule()` to replace the rule. Returns `null` if the target or initial rule is invalid, or if the target cannot accept the attachment. A body outside the scene tree begins stepping when it enters a supported process group.
