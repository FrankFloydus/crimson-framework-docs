## Signature

```text
configure(coordinator: TransactionCoordinator, players_store: String, characters_store: String, eligibility: Callable = Callable()) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `coordinator` | [`TransactionCoordinator`](/api/classes/TransactionCoordinator) | — |
| `players_store` | `String` | — |
| `characters_store` | `String` | — |
| `eligibility` | `Callable` | `Callable()` |

## Return value

`Error`

## Description

Supply two distinct, already registered stores containing dictionaries keyed by player and character ID. The optional `eligibility(player\_id, old\_id, new\_id, context)` callback returns whether the proposed change is allowed.

## Example

```gdscript
extends Node

func run_configure(
    game_runtime: GameRuntime,
    coordinator: TransactionCoordinator,
    players_store: String,
    characters_store: String,
    eligibility: Callable,
    status_label: Label
) -> void:
    var player_possession: PlayerPossession = game_runtime.get_possession()
    if player_possession == null:
        return
    var result: Error = player_possession.configure(
        coordinator,
        players_store,
        characters_store,
        eligibility,
    )
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Configure accepted."
```
