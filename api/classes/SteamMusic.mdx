**Inherits** `RefCounted`

## Description

Use `SteamClient.music()` after boot. `OK` on a control acknowledges submission. Controls return `ERR_UNAVAILABLE` when Steam Music is disabled.

## Methods

### Instance methods

#### [`next`](/api/classes/SteamMusic/methods/next)

Requests the next track in the current Steam queue.

#### [`pause`](/api/classes/SteamMusic/methods/pause)

Requests a pause of the current Steam queue.

#### [`play`](/api/classes/SteamMusic/methods/play)

Requests resume or playback of the current Steam queue.

#### [`previous`](/api/classes/SteamMusic/methods/previous)

Requests the previous track in the current Steam queue.

#### [`set_volume`](/api/classes/SteamMusic/methods/set_volume)

Requests the normalized volume `level` from 0 through 1.

#### [`status`](/api/classes/SteamMusic/methods/status)

Reads the player's enabled state, playback state, and volume.

## Signals

### `playback_changed`

`playback_changed()`

Emitted after Steam reports a playback change. Read the new state with `status()`.

### `volume_changed`

`volume_changed(level: float)`

Emitted with the normalized volume reported by Steam.
