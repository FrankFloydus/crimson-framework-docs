## Signature

```text
leave() -> Error
```

## Return value

`Error`

## Description

Return OK when idle or when teardown starts, or ERR\_BUSY if the session is changing state. Use session\_ended to observe completed teardown.

## Example

extends Node

func run_leave(world_session: WorldSession, status_label: Label) -> void:
    var result: Error = world_session.leave()
    if result != OK:
        status_label.text = error_string(result)
        return
