**Inherits** `Resource`

Admission and transport settings for listen and dedicated co-op games.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `join_in_progress` | `bool` | `true` | `get_join_in_progress()`, `set_join_in_progress(value)` | Allow guests to join an active world. Keep this enabled for immediate listen and dedicated sessions. Use coordinated lobbies for games that close admission before play. |
| `max_players` | `int` | `4` | `get_max_players()`, `set_max_players(value)` | Total player capacity. Listen hosting uses one seat for the host and requires at least two seats. Dedicated hosting makes every seat available to guests. Spawn points supply placements separately. |
| `port` | `int` | `7000` | `get_port()`, `set_port(value)` | UDP port used to listen for guests and connect to a host. Host and guest must use the same port, from 1 to 65535. |

## Methods

### `allow_join_in_progress`

`allow_join_in_progress(enabled: bool = true) -> MultiplayerRules`

Return a copy with late admission enabled or disabled. Immediate listen and dedicated games require it to be enabled.

### `listen_coop`

`static listen_coop() -> MultiplayerRules`

Create rules with four total seats, late joins enabled, and UDP port 7000.

### `on_port`

`on_port(port: int) -> MultiplayerRules`

Return a copy with the UDP port for hosting and joining. Use the same port on each peer, from 1 through 65535.

### `with_max_players`

`with_max_players(count: int) -> MultiplayerRules`

Return a copy with the total seat count. Listen hosting supports 2 through 64 players, including the host. Dedicated hosting supports 1 through 64 guests.
