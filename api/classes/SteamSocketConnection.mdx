**Inherits** `RefCounted`

An owned standalone connection for authenticated Steam packets.

An incoming connection becomes ready after `connected`. A successful outgoing operation returns an already connected handle. Use `steam_id` to authorize game data and apply your own protocol bounds.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `steam_id` | `String` | `""` | `get_steam_id()` | Canonical certified remote SteamID64 while connected. Empty before connection and after retirement. |

## Methods

### `close`

`close() -> Error`

Closes this exact socket, including a pending incoming handshake.

### `get_steam_id`

`get_steam_id() -> String`

Returns the certified account of the live peer.

### `is_connected`

`is_connected() -> bool`

Returns whether the exact live connection passed Steam identity and encryption checks.

### `path`

`path() -> SteamConnectionPath`

Returns metrics from the current live socket or `null` without a verified path.

### `send`

`send(bytes: PackedByteArray, delivery: SteamDelivery.Mode = 0) -> Error`

Queues one message from 1 byte to 32 KiB after authentication. Both directions allow up to 128 frames and 256 KiB per second. `ERR_BUSY` reports SDK backpressure or an exhausted outbound budget.

## Signals

### `closed`

`closed(reason: Error)`

Emitted after the socket has been retired. `OK` indicates a local close, `ERR_SKIP` indicates scope retirement, and other values report a transport or policy failure.

### `connected`

`connected()`

Emitted once an accepted incoming connection is encrypted and has a certified account.

### `received`

`received(bytes: PackedByteArray, delivery: SteamDelivery.Mode)`

Emitted with a copied packet from the live authenticated socket. Reliable receive overload closes the connection. Unreliable overload can drop packets.
