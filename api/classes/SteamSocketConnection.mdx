## Description

An incoming connection becomes ready after `connected`. A successful outgoing operation returns an already connected handle. Use `steam_id` to authorize game data and apply your own protocol bounds.

## Signals

### `closed`

`closed(reason: Error)`

Emitted after the socket has been retired. `OK` indicates a local close, `ERR_SKIP` indicates scope retirement, and other values report a transport or policy failure.

### `connected`

`connected()`

Emitted once an accepted incoming connection is encrypted and has a certified account.

### `received`

`received(bytes: PackedByteArray, delivery: SteamDelivery.Mode)`

Emitted with a copied packet from the live authenticated socket. Reliable receive overload closes the connection. Unreliable overload can drop packets.
