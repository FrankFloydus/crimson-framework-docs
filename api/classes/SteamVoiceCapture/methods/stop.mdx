## Signature

```text
stop() -> Error
```

## Return value

`Error`

## Description

The exact owner may read final frames for up to 300 milliseconds. Scope teardown discards those frames immediately. A detached or inactive owner returns `ERR_UNAVAILABLE`.

## Example
