## Signature

```text
read_frame() -> SteamVoiceFrameResult
```

## Return value

[`SteamVoiceFrameResult`](/api/classes/SteamVoiceFrameResult)

## Description

Call once per process frame during capture. An empty poll, exhausted tail, or detached owner returns `ERR_UNAVAILABLE`.

## Example

```gdscript
extends Node

func run_read_frame(steam_voice_capture: SteamVoiceCapture, apply_read_frame: Callable) -> void:
    var result: SteamVoiceFrameResult = steam_voice_capture.read_frame()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamVoiceFrame = result.value
    if payload == null:
        return
    apply_read_frame.call(payload)
```
