## Signature

```text
dismiss_keyboard() -> Error
```

## Return value

`Error`

## Description

`OK` means the request was accepted. The keyboard remains reserved until Steam reports it closed. Returns `ERR_DOES_NOT_EXIST` when there is no keyboard and `ERR_BUSY` when another scope owns it or a prior owner is closing.

## Example

```gdscript
extends Node

func run_dismiss_keyboard(steam_client: SteamClient, status_label: Label) -> void:
    if not steam_client.is_ready():
        return
    var steam_device: SteamDevice = steam_client.device()
    if steam_device == null:
        return
    var result: Error = steam_device.dismiss_keyboard()
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Dismiss keyboard accepted."
```
