## Return value

`bool`

## Description

Returns `false` if the query is unavailable.

## Example

```gdscript
extends Node

func run_is_proton(steam_client: SteamClient, status_label: Label) -> void:
    if not steam_client.is_ready():
        return
    var steam_device: SteamDevice = steam_client.device()
    if steam_device == null:
        return
    var result: bool = steam_device.is_proton()
    status_label.text = "Proton: yes" if result else "Proton: no"
```
