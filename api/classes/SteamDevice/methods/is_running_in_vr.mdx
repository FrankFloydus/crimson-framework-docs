## Signature

```text
is_running_in_vr() -> bool
```

## Return value

`bool`

## Description

Returns `false` if the query is unavailable. Query the OpenXR interface for the game's own XR session state.

## Example

```gdscript
extends Node

func run_is_running_in_vr(steam_client: SteamClient, status_label: Label) -> void:
    if not steam_client.is_ready():
        return
    var steam_device: SteamDevice = steam_client.device()
    if steam_device == null:
        return
    var result: bool = steam_device.is_running_in_vr()
    status_label.text = "Running in vr: yes" if result else "Running in vr: no"
```
