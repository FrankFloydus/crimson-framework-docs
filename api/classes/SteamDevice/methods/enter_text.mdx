## Return value

`Variant`

Await the call to receive [`SteamTextEntryResult`](/api/classes/SteamTextEntryResult).

## Description

Await a [`SteamTextEntryResult`](/api/classes/SteamTextEntryResult). The optional prompt is limited to 1024 UTF-8 bytes and `max_chars` to 1 through 4096 Unicode characters. Initial text must fit the requested length. Hidden mode masks characters during entry. A user dismissal succeeds with an empty, unsubmitted entry. Return an unavailable result if Steam cannot open the dialog or the owning scope stops, or `ERR_BUSY` if a keyboard is already active or closing.

## Example

```gdscript
extends Node

func run_enter_text(
    steam_client: SteamClient,
    prompt: String,
    initial: String,
    max_chars: int,
    multiline: bool,
    hidden: bool,
    apply_enter_text: Callable
) -> void:
    if not steam_client.is_ready():
        return
    var steam_device: SteamDevice = steam_client.device()
    if steam_device == null:
        return
    var result: SteamTextEntryResult = await steam_device.enter_text(prompt, initial, max_chars, multiline, hidden)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamTextEntry = result.value
    if payload == null:
        return
    apply_enter_text.call(payload)
```
