**Inherits** `Marker3D`

An authored player placement in a 3D world.

Place and rotate this node in the world to set the player's initial position and facing direction. Direct Marker3D children can supply additional placements. The authority chooses a vacant placement when a player enters. Session capacity is set in [`MultiplayerRules`](/api/classes/MultiplayerRules).
