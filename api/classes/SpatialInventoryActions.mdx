**Inherits** `RefCounted`

Implements checked moves, swaps, quick transfers, and quantity edits across inventory grids. Use a [`SpatialInventoryStackAdapter`](/api/classes/SpatialInventoryStackAdapter) for host-owned stack records. Action results report a Godot `error`, `reason`, how much moved and remains, a `selection` identifying an inventory and item, and `changes` identifying items whose views need refreshing.

### `merge_stacks`

`merge_stacks(source: SpatialInventory, id: StringName, destination: SpatialInventory, target_id: StringName, limit: int = 0) -> Dictionary`

Move compatible units from the placed source stack to the placed target stack up to its capacity. A positive `limit` caps the transfer. A zero limit uses the available capacity. The source placement is removed if its stack is depleted.

### `move_item`

`move_item(source: SpatialInventory, id: StringName, destination: SpatialInventory, origin: Vector2i, rotated: bool = false, swap_id: StringName = &"", expected_source: Dictionary = {}, expected_swap: Dictionary = {}) -> Dictionary`

Move a placed item to the requested origin and rotation. Supply `swap_id` to exchange with the expected occupant, and optionally pass exact `expected_source` and `expected_swap` placement dictionaries to guard against stale UI state. A failed validation preserves the affected placements.

### `quick_transfer`

`quick_transfer(source: SpatialInventory, id: StringName, destinations: Array = []) -> Dictionary`

Try the provided destination grids in order, or use the destination provider if the array is empty. Merge compatible stacks first when an adapter is available, then try to place the remaining item. Inspect `completed` and `remaining` because a partial transfer can return `OK`.

### `quick_transfer_matching`

`quick_transfer_matching(source: SpatialInventory, id: StringName, destinations: Array = []) -> Dictionary`

Transfer the selected stack and other source stacks with the same compatibility key. The result includes per-item `transfers` and the number of completed source stacks. Transfers commit separately, so some items can stay in the source even when the batch reports `OK`.

### `set_allow_rotation`

`set_allow_rotation(value: bool) -> void`

Allow or disallow rotation during automatic placement searches. Explicit placement arguments still control explicit moves.

### `set_destination_policy`

`set_destination_policy(value: Callable) -> void`

Set the callback that filters each candidate destination for a quick transfer. Return an empty String to accept that destination, or a reason to skip it.

### `set_destination_provider`

`set_destination_provider(value: Callable) -> void`

Set the callback that supplies ordered destination grids when a quick transfer receives an empty destination array.

### `set_drop_policy`

`set_drop_policy(value: Callable) -> void`

Set the callback that evaluates a proposed destination edit. Return an empty String to allow it or a denial reason to reject it.

### `set_operation_guard`

`set_operation_guard(value: Callable) -> void`

Set a callback taking the source and destination grids. It must return true for the operation to proceed.

### `set_pickup_policy`

`set_pickup_policy(value: Callable) -> void`

Set the callback that checks whether the source item may be lifted. Return an empty String to allow it or a denial reason to reject it.

### `set_stack_adapter`

`set_stack_adapter(value: SpatialInventoryStackAdapter) -> void`

Attach the adapter that reads and commits your stack records. Pass null to clear it.

### `split_stack`

`split_stack(source: SpatialInventory, id: StringName, amount: int, new_id: StringName, destination: SpatialInventory, origin: Vector2i, rotated: bool = false) -> Dictionary`

Move a positive quantity smaller than the source stack into a new item ID and place it at the requested destination. The source record, new record, and destination placement commit through the stack adapter.
