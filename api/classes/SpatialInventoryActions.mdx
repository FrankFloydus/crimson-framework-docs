**Inherits** `RefCounted`

## Description

Set callbacks to apply game rules when an item leaves or enters a grid. Attach a stack adapter when the game owns stack quantities separately from placements.

## Properties

**[`allow_rotation`](/api/classes/SpatialInventoryActions/properties/allow_rotation)**

Whether automatic placement may try a rotated footprint when looking for a fit.

**[`destination_policy`](/api/classes/SpatialInventoryActions/properties/destination_policy)**

Optional callback that checks each candidate grid during a quick transfer.

**[`destination_provider`](/api/classes/SpatialInventoryActions/properties/destination_provider)**

Optional callback used when a quick transfer receives an empty destination list.

**[`drop_policy`](/api/classes/SpatialInventoryActions/properties/drop_policy)**

Optional callback that receives the item and proposed destination placement, including the action and any swap target.

**[`operation_guard`](/api/classes/SpatialInventoryActions/properties/operation_guard)**

Optional callback that receives the source grid and the destination grid, which can be `null`.

**[`pickup_policy`](/api/classes/SpatialInventoryActions/properties/pickup_policy)**

Optional callback that receives the item ID, unrotated footprint, rotation, origin, and source grid before a pickup.

**[`stack_adapter`](/api/classes/SpatialInventoryActions/properties/stack_adapter)**

Optional adapter that describes stack quantities and commits their changes together with grid placements.
