### Method details

#### `configure`

`configure(coordinator: TransactionCoordinator, store_id: String, initial_snapshot: Dictionary) -> Error`

Validate the initial SpatialInventory snapshot and register it under store\_id in the supplied coordinator. Returns a Godot Error.

#### `get_snapshot`

`get_snapshot() -> Dictionary`

Return the currently committed snapshot in SpatialInventory format, or an empty dictionary before configuration.

#### `queue_move`

`queue_move(transaction: GameTransaction, item_id: String, origin: Vector2i, rotated: bool = false) -> Error`

Queue an existing item's new grid origin and rotation in a transaction owned by the configured coordinator. Returns a Godot Error. The inventory changes on a successful commit.

#### `queue_place`

`queue_place(transaction: GameTransaction, item_id: String, footprint: Vector2i, origin: Vector2i, rotated: bool = false) -> Error`

Queue placement of a new item with the given footprint, grid origin, and rotation. Returns a Godot Error. The authority validates the placement when the transaction commits.

#### `queue_remove`

`queue_remove(transaction: GameTransaction, item_id: String) -> Error`

Queue removal of item\_id in a transaction owned by the configured coordinator. Returns a Godot Error. The inventory changes on a successful commit.
