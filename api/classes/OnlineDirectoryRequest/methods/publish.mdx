## Signature

```text
publish(listing_id: String) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `listing_id` | `String` | — |

## Return value

`Error`

## Description

If completion arrives after cancellation, the request attempts to retire the listing. If it returns ERR\_UNAVAILABLE, the provider must remove the external listing itself.
