## Description

Get this facade from `SteamClient.overlay()` after starting the client. Call it on the main thread. A retained facade becomes unavailable when its owning client stops. The SDK overlay must be enabled and loaded for the running game. For a direct development launch, pass `--crimson-steam-overlay=<AppID>` after Godot's `--` separator and launch with the matching Steam AppID. An open method returns `@GlobalScope.OK` once it issues the request to Steam. Observe the rendered pane to confirm its contents. `@GlobalScope.ERR_BUSY` means the overlay is not ready or the method was called off the main thread. `@GlobalScope.ERR_UNAVAILABLE` means the facade or required SDK interface is unavailable. `@GlobalScope.ERR_INVALID_PARAMETER` means a live facade rejected a target.

## Signals

### `activation_changed`

`activation_changed(active: bool)`

Emitted when Steam reports that the overlay gained or lost focus. Applies to both a Steam hotkey and an in-game request. `is_active()` already reflects the new state when the signal is delivered.
