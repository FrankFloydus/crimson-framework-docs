**Inherits** `RefCounted`

Opens Steam overlay panes and observes when the overlay has focus.

Get this facade from `SteamClient.overlay()` after starting the client. Call it on the main thread. A retained facade becomes unavailable when its owning client stops. The SDK overlay must be enabled and loaded for the running game. For a direct development launch, pass `--crimson-steam-overlay=<AppID>` after Godot's `--` separator and launch with the matching Steam AppID. An open method returns `@GlobalScope.OK` once it issues the request to Steam. Observe the rendered pane to confirm its contents. `@GlobalScope.ERR_BUSY` means the overlay is not ready or the method was called off the main thread. `@GlobalScope.ERR_UNAVAILABLE` means the facade or required SDK interface is unavailable. `@GlobalScope.ERR_INVALID_PARAMETER` means a live facade rejected a target.

## Methods

### `is_active`

`is_active() -> bool`

Returns the latest activation state observed for the running AppID. The initial state is false until the current Steam runtime receives an activation event. A detached facade returns false.

### `is_ready`

`is_ready() -> bool`

Returns true when the running Steam client reports that the overlay is loaded and accessible. It may remain false during graphics startup, with the overlay disabled, or in a headless process.

### `open_achievements`

`open_achievements() -> Error`

Requests the current game's Steam Achievements pane.

### `open_profile`

`open_profile(steam_id: String) -> Error`

Requests the Steam Community profile of an individual account identified by its decimal SteamID64.

### `open_store`

`open_store(app_id: int = 0) -> Error`

Requests the Steam Store page in browse mode. Zero selects the running AppID. A positive unsigned 32-bit AppID selects another product.

### `open_trade`

`open_trade(partner_steam_id: String) -> Error`

Requests the Steam Trading pane for the supplied partner's decimal SteamID64. Call it after the game's authorized backend has started an existing Steam trading session with that individual account.

### `open_web`

`open_web(url: String) -> Error`

Requests a page in Steam's overlay browser. Supply an absolute HTTP or HTTPS URL without embedded credentials and at most 2048 UTF-8 bytes.

## Signals

### `activation_changed`

`activation_changed(active: bool)`

Emitted when Steam reports that the overlay gained or lost focus. Applies to both a Steam hotkey and an in-game request. `is_active()` already reflects the new state when the signal is delivered.
