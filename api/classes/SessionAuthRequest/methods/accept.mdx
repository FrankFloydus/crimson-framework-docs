## Parameters

## Return value

`Error`

## Description

Returns ERR\_INVALID\_PARAMETER for an invalid identity, ERR\_BUSY off the scene thread, or ERR\_DOES\_NOT\_EXIST when the request has expired or already settled. The remote end must also finish verification before admission.
