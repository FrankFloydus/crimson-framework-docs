### Method details

#### `direct`

`static direct(address: String, port: int) -> SessionEndpoint`

Create an ENet endpoint for the address and port. Trims surrounding whitespace from the address. Returns null for an empty address or a port outside 1 to 65535.

#### `get_address`

`get_address() -> String`

Return the direct host address, or an empty string for an opaque endpoint.

#### `get_port`

`get_port() -> int`

Return the direct UDP port, or 0 for an opaque endpoint.

#### `get_route`

`get_route() -> PackedByteArray`

Return a copy of the opaque route bytes, or an empty array for a direct endpoint.

#### `get_transport`

`get_transport() -> StringName`

Return the adapter name that handles the endpoint. Direct endpoints use `enet`.

#### `opaque`

`static opaque(transport: StringName, route: PackedByteArray) -> SessionEndpoint`

Create an endpoint from 1 to 512 route bytes. The adapter name must begin with a lowercase ASCII letter, contain at most 32 lowercase ASCII letters, digits, or underscores, and differ from `enet`. Invalid input returns null. Keep authentication credentials separate from the route.
