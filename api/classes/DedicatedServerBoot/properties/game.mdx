## Description

Assign a game with a starting world and multiplayer rules. The server starts when the process receives the explicit server role.

## Example

```gdscript
extends Node

func update_game(
    dedicated_server_boot: DedicatedServerBoot,
    new_game: GameRuntime,
    apply_game: Callable
) -> void:
    dedicated_server_boot.game = new_game
    var active_game: GameRuntime = dedicated_server_boot.game
    if active_game == null:
        return
    apply_game.call(active_game)
```
