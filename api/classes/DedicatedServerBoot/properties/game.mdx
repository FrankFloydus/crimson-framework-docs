## Description

Assign a game with a starting world and multiplayer rules. The server starts when the process receives the explicit server role.

## Example

### Run the cargo yard as a headless server

Launch a configured cargo yard scene with `--headless` and pass `--crimson-role=server` after `--`. The server logs the mounted map and port so a direct-address guest can connect.

```gdscript
extends Node

@export var server_game: GameRuntime
@export var dedicated_boot: DedicatedServerBoot


func _ready() -> void:
    dedicated_boot.game = server_game
    server_game.world_ready.connect(_on_world_ready)


func _on_world_ready(world_id: StringName, _world_epoch: int) -> void:
    print("Dedicated cargo yard loaded: ", world_id)
```
