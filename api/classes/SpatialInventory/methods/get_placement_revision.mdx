## Signature

```text
get_placement_revision() -> int
```

## Return value

`int`

## Description

Actual changes to its placements or dimensions advance the counter before change signals run. Compare revisions on the same grid to detect edits. The counter is independent of snapshots.

## Example

extends Node

func run_get_placement_revision(
