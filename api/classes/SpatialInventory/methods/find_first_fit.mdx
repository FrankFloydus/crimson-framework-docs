## Signature

```text
find_first_fit(footprint: Vector2i, rotated: bool = false, start: Vector2i = Vector2i(0, 0)) -> Vector2i
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `footprint` | `Vector2i` | — |
| `rotated` | `bool` | `false` |
| `start` | `Vector2i` | `Vector2i(0, 0)` |

## Return value

`Vector2i`

## Description

If `start` is past the last possible origin on its row, the search continues on the next row. Returns `Vector2i(-1, -1)` for invalid geometry, a negative start, or no fit.

## Example

```gdscript
const MEDKIT_SIZE: Vector2i = Vector2i(2, 1)
const NO_FIT: Vector2i = Vector2i(-1, -1)

func find_medkit_cell(inventory: SpatialInventory) -> void:
    var cell: Vector2i = inventory.find_first_fit(MEDKIT_SIZE)
    if cell == NO_FIT:
        print("No space for a medkit.")
    else:
        print("The medkit fits at ", cell)
```
