## Return value

`Error`

## Description

Each row is a dictionary containing `inventory`, `id`, `before`, and `after`. Use placement dictionaries from `get_placement()` or an empty dictionary for absence. A stale expected placement returns `ERR_BUSY`. If any row fails validation, every grid keeps its previous state.
