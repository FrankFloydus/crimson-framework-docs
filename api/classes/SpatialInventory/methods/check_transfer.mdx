## Return value

`Error`

## Description

The destination needs room for the footprint and an unused instance ID. A transfer to this grid uses `check_move()`.

## Example

```gdscript
extends Node

func run_check_transfer(
    spatial_inventory: SpatialInventory,
    id: StringName,
    destination: SpatialInventory,
    origin: Vector2i,
```
