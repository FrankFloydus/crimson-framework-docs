## Signature

```text
configure(size: Vector2i) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `size` | `Vector2i` | — |

## Return value

`Error`

## Description

Both dimensions must be positive and the grid can hold up to 1,048,576 cells. Changing the dimensions of a populated grid returns `ERR_BUSY`.

## Example

```gdscript
extends Node

const BACKPACK_SIZE: Vector2i = Vector2i(6, 4)

var backpack: SpatialInventory

func _ready() -> void:
    backpack = SpatialInventory.new()
    var configured: Error = backpack.configure(BACKPACK_SIZE)
    if configured != OK:
        backpack = null
        push_error(error_string(configured))
        return
    var size: Vector2i = backpack.get_grid_size()
    print("Backpack ready: %d columns and %d rows." % [size.x, size.y])
```
