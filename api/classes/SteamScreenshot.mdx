**Inherits** `RefCounted`

A confirmed saved Steam screenshot and its annotation status.

The native handle stays internal. This snapshot describes metadata submissions observed by this scope. An ordinary screenshot or another scope's save has no local annotation requests.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `annotation_errors` | `int[]` | `[]` | `get_annotation_errors()` | Read-only `Error` codes for failed annotation requests, in location, user, and Workshop item order. Steam's rejection maps to `FAILED`. A missing native action maps to `ERR_UNAVAILABLE`. A saved image stays available even when metadata fails. |
| `annotations_accepted` | `bool` | `true` | `get_annotations_accepted()` | Whether Steam accepted every annotation requested by this scope. Ordinary screenshots and saves from other scopes have no local annotations to reject. |
