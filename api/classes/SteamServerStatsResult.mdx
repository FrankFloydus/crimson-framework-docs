## Description

For a submitted edit, success confirms the exact Steam StoreUserStats response. Failed results preserve the number of accepted setters and whether the store was issued. A timeout or cancellation with `store_submitted` true leaves persistence unknown to the local observer.

## Properties

**[`applied`](/api/classes/SteamServerStatsResult/properties/applied)**

Number of setters accepted into Steam's cache for this action.

**[`failed_at`](/api/classes/SteamServerStatsResult/properties/failed_at)**

Zero-based index of a rejected edit.

**[`steam_result`](/api/classes/SteamServerStatsResult/properties/steam_result)**

Observed Steam EResult, or 0 if unavailable.

**[`store_submitted`](/api/classes/SteamServerStatsResult/properties/store_submitted)**

Whether Steam accepted a native store request for processing.

## Methods

### Property accessors

#### [`get_applied`](/api/classes/SteamServerStatsResult/methods/get_applied)

#### [`get_failed_at`](/api/classes/SteamServerStatsResult/methods/get_failed_at)
