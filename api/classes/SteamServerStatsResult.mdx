**Inherits** [`SteamResult`](/api/classes/SteamResult)

Outcome and native evidence for a dedicated Steam progression action.

For a submitted edit, success confirms the exact Steam StoreUserStats response. Failed results preserve the number of accepted setters and whether the store was issued. A timeout or cancellation with `store_submitted` true leaves persistence unknown to the local observer.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `applied` | `int` | `0` | `get_applied()` | Number of setters accepted into Steam's cache for this action. |
| `failed_at` | `int` | `-1` | `get_failed_at()` | Zero-based index of a rejected edit. Defaults to -1. |
| `steam_result` | `int` | `0` | `get_steam_result()` | Observed Steam EResult, or 0 if unavailable. |
| `store_submitted` | `bool` | `false` | `was_store_submitted()` | Whether Steam accepted a native store request for processing. |

## Methods

### `get_applied`

`get_applied() -> int`

Return the number of setters accepted into the native cache for this action.

### `get_failed_at`

`get_failed_at() -> int`

Return the zero-based index of a rejected edit, or -1 when no individual edit failed.

### `get_steam_result`

`get_steam_result() -> int`

Return the exact observed Steam EResult, or 0 when there is no matched native result.

### `was_store_submitted`

`was_store_submitted() -> bool`

Return whether Steam assigned a native call handle to the store.
