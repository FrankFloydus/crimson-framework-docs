## Methods

### Instance methods

#### [`fetch`](/api/classes/SteamLobbyQuery/methods/fetch)

Start the search and await its typed result directly.

#### [`fetch_operation`](/api/classes/SteamLobbyQuery/methods/fetch_operation)

Start the same search and retain an operation for cancellation or repeated reads.

#### [`limit`](/api/classes/SteamLobbyQuery/methods/limit)

Return a branch capped at one to 50 results.

#### [`on_map`](/api/classes/SteamLobbyQuery/methods/on_map)

Return a branch for the supplied world identifier.

#### [`social`](/api/classes/SteamLobbyQuery/methods/social)

Return a branch searching standalone social lobbies.

#### [`with_room_for`](/api/classes/SteamLobbyQuery/methods/with_room_for)

Return a branch requiring one to 64 available lobby seats.

#### [`within`](/api/classes/SteamLobbyQuery/methods/within)

Return a branch with the selected Steam region preference.

| `FAR` | `2` | Extend the search across more regions. |
