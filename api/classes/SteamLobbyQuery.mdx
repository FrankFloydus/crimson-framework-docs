**Inherits** `RefCounted`

Branchable options for a search within this game's Steam AppID and namespace.

## Methods

### `fetch`

`fetch() -> Variant`

Start the search and await its typed result directly.

### `fetch_operation`

`fetch_operation() -> SteamListingsOperation`

Start the same search and retain an operation for cancellation or repeated reads. An overlapping SDK search returns busy.

### `limit`

`limit(count: int) -> SteamLobbyQuery`

Return a branch capped at one to 50 results. The default is 20.

### `on_map`

`on_map(world_id: StringName) -> SteamLobbyQuery`

Return a branch for the supplied world identifier. Steam discovery accepts up to 128 characters and 512 UTF-8 bytes without control characters.

### `social`

`social() -> SteamLobbyQuery`

Return a branch searching standalone social lobbies. Use a standalone [`SteamLobbies`](/api/classes/SteamLobbies) scope. Gameplay map filters do not apply to social searches.

### `with_room_for`

`with_room_for(players: int) -> SteamLobbyQuery`

Return a branch requiring one to 64 available lobby seats. The default is one.

### `within`

`within(distance: SteamLobbyQuery.Distance) -> SteamLobbyQuery`

Return a branch with the selected Steam region preference. The default is nearby.

## Constants and enums

### `Distance`

| Name | Value | Description |
| --- | --- | --- |
| `CLOSE` | `0` | Prefer lobbies in the immediate region. |
| `FAR` | `2` | Extend the search across more regions. |
| `NEARBY` | `1` | Search this region and nearby regions. |
| `WORLDWIDE` | `3` | Search every Steam region. |
