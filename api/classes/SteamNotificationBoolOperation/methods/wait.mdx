## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamBoolResult`](/api/classes/SteamBoolResult).

## Example

```gdscript
extends Node

func run_wait(
    steam_notification_bool_operation: SteamNotificationBoolOperation,
    apply_wait: Callable
) -> void:
    var result: SteamBoolResult = await steam_notification_bool_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: bool = result.value
    apply_wait.call(payload)
```
