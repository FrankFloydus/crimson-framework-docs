## Return value

[`SteamModerationAuthorization`](/api/classes/SteamModerationAuthorization)

## Description

For a reviewed write, check moderator authorization and resolve the reviewed player for the configured app. Persist the exact action and reserve an audit reference before returning `SteamModerationAuthorization.approve()`.

func _authorize(request: SteamModerationRequest) -> SteamModerationAuthorization:

        return null
    return reserve_audit.call(request) as SteamModerationAuthorization
