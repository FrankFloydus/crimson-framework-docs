## Description

Get this service from `SteamPublisher.inventory()` in a trusted publisher build with Economy permissions for the configured AppID. Use identities verified by that exact publisher. Foreign identities return `ERR_UNAUTHORIZED`, invalid arguments return `ERR_INVALID_PARAMETER`, and unavailable scopes return `ERR_UNAVAILABLE`. Before calling a write, have the game authorize the action and durably bind its unique request ID to the complete award or consumption intent. After a timeout, a closed observation, or an unrecognized reply, reconcile Steam inventory before retrying with the same request ID and arguments. A Valve replay reports the current state of the affected items.

### Method details

#### `consume`

`consume(player: SteamIdentity, instance_id: String, quantity: int, request_id: String) -> Variant`

Awaits a [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult) for the permanent consumption of a positive unsigned 32-bit `quantity` from `player`'s `instance_id`. Supply the same nonzero unsigned decimal `request_id` for a retry of the same authorized operation. A recognized confirmation includes exactly one changed or removed row for the requested stack.

#### `grant`

`grant(player: SteamIdentity, definition_ids: PackedInt32Array, request_id: String) -> Variant`

Awaits a [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult) for a game-authorized award to `player`. Supply 1 to 256 published `definition_ids` and a nonzero unsigned decimal `request_id`. The result contains the actual item rows Steam reports after bundle and generator expansion. Repeat the same request ID and definitions for a retry of this award.

#### `items`

`items(player: SteamIdentity) -> Variant`

Awaits a [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the configured app and verified `player`. The typed rows are detached and read-only. The publisher endpoint supplies no snapshot freshness evidence.

#### `start_trade`

`start_trade(player: SteamIdentity, partner: SteamIdentity) -> Variant`

Awaits a [`SteamTradeSessionResult`](/api/classes/SteamTradeSessionResult) for a Steam trade request in an eligible Economy app. Verify the distinct `player` and `partner` in the same publisher and confirm their consent in the game before calling. A recognized Steam acknowledgment identifies both accounts. The participants confirm any transfer through Steam.
