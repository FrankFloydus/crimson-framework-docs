## Description

Get this service from `SteamPublisher.inventory()` in a trusted publisher build with Economy permissions for the configured AppID. Use identities verified by that exact publisher. Foreign identities return `ERR_UNAUTHORIZED`, invalid arguments return `ERR_INVALID_PARAMETER`, and unavailable scopes return `ERR_UNAVAILABLE`. Before calling a write, have the game authorize the action and durably bind its unique request ID to the complete award or consumption intent. After a timeout, a closed observation, or an unrecognized reply, reconcile Steam inventory before retrying with the same request ID and arguments. A Valve replay reports the current state of the affected items.

## Methods

### Instance methods

#### [`consume`](/api/classes/SteamPublisherInventory/methods/consume)

Awaits a [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult) for the permanent consumption of a positive unsigned 32-bit `quantity` from `player`'s `instance_id`.

#### [`grant`](/api/classes/SteamPublisherInventory/methods/grant)

Awaits a [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult) for a game-authorized award to `player`.

#### [`items`](/api/classes/SteamPublisherInventory/methods/items)

Awaits a [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the configured app and verified `player`.

#### [`start_trade`](/api/classes/SteamPublisherInventory/methods/start_trade)

Awaits a [`SteamTradeSessionResult`](/api/classes/SteamTradeSessionResult) for a Steam trade request in an eligible Economy app.
