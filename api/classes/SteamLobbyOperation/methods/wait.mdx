## Return value

`Variant`

Await the call to receive [`SteamLobbyResult`](/api/classes/SteamLobbyResult).

## Example

```gdscript
extends Node

func run_wait(steam_lobby_operation: SteamLobbyOperation, apply_wait: Callable) -> void:
    var result: SteamLobbyResult = await steam_lobby_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamLobby = result.value

        return
```
