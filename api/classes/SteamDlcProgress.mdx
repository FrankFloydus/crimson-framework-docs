## Description

Get a fresh record from `SteamApps.download_progress()` when updating a progress display.

## Properties

**[`active`](/api/classes/SteamDlcProgress/properties/active)**

Whether Steam was downloading the DLC when queried.

**[`downloaded_bytes`](/api/classes/SteamDlcProgress/properties/downloaded_bytes)**

Number of bytes downloaded for the active transfer.
