Detached download progress for one optional DLC.

Get a fresh record from `SteamApps.download_progress()` when updating a progress display.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `active` | `bool` | — | `is_active()` | Whether Steam was downloading the DLC when queried. Both byte counts are zero for an inactive transfer. |
| `downloaded_bytes` | `int` | — | `get_downloaded_bytes()` | Number of bytes downloaded for the active transfer. Zero while inactive. |
| `total_bytes` | `int` | — | `get_total_bytes()` | Total download size in bytes. Zero indicates an inactive transfer or an unknown total. |

## Methods

### `get_downloaded_bytes`

`get_downloaded_bytes() -> int`

### `get_total_bytes`

`get_total_bytes() -> int`
