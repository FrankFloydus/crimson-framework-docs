**Inherits** `RefCounted`

Retained operation for one annotated Steam screenshot.

Use `wait()` to await the result, or poll `is_finished()`. Cancelling observation cannot undo a native screenshot write already submitted to Steam.

## Methods

### `cancel`

`cancel() -> Error`

Stop local observation and skip its pending annotations. Settle the result with `ERR_SKIP`. Return `ERR_DOES_NOT_EXIST` when already settled.

### `is_finished`

`is_finished() -> bool`

Return whether the callback, local deadline, cancellation, or scope stop settled the result.

### `result`

`result() -> SteamScreenshotResult`

Return the stored outcome, or `null` while observation is pending.

### `wait`

`wait() -> Variant`

Return the completion signal while pending, or the same terminal result on every call after settlement.

## Signals

### `completed`

`completed(result: SteamScreenshotResult)`

Emitted once with the terminal save observation after the handle has been removed from the scope's pending operations.
