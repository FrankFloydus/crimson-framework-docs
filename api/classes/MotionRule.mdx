**Inherits** `Resource`

## Description

A mover takes a snapshot when you attach or call `Mover.use_rule()`. Multiple bodies can share a resource and retain independent runtime state. Use `Locomotion.ground()` to start with grounded movement.

- [Make a practice target hop on a timer](/api/classes/MotionRule/properties/jump_speed#example)

## Properties

**[`acceleration`](/api/classes/MotionRule/properties/acceleration)**

Ground steering acceleration in metres per second squared, from 0 to 1000.

**[`air_control`](/api/classes/MotionRule/properties/air_control)**

Fraction of steering acceleration available while airborne, from 0 to 1.

**[`deceleration`](/api/classes/MotionRule/properties/deceleration)**

Base ground braking rate in metres per second squared when input requests a lower speed or stops.

**[`gravity_scale`](/api/classes/MotionRule/properties/gravity_scale)**

Multiplier for the body's gravity projected onto its up axis.

**[`ground_friction`](/api/classes/MotionRule/properties/ground_friction)**

Ground turning and braking coefficient in inverse seconds, from 0 to 100.

**[`grounded`](/api/classes/MotionRule/properties/grounded)**

Constrain steering to the plane perpendicular to the body's up axis and apply gravity along that axis.

**[`jump_speed`](/api/classes/MotionRule/properties/jump_speed)**

Upward takeoff speed in metres per second.
