## Description

Applies to a grounded jump on floor contact. Set to zero to disable jumps.

## Example

### Make a practice target hop on a timer

Attach this script to a visible CharacterBody3D with a CollisionShape3D on a floor with static collision. During target practice the body hops at regular intervals once it has floor contact.

```gdscript
extends CharacterBody3D

const TAKEOFF_SPEED: float = 4.0
const HOP_INTERVAL: float = 2.0

var _mover: Mover


func _ready() -> void:
    var rule: MotionRule = Locomotion.ground()
    rule.jump_speed = TAKEOFF_SPEED
    _mover = Mover.attach(self, rule)
    if _mover == null:
        push_error("Could not attach the practice target's mover.")
        return

    var timer: Timer = Timer.new()
    add_child(timer)
    timer.timeout.connect(_hop)
    timer.start(HOP_INTERVAL)


func _hop() -> void:
    if not is_on_floor():
        return
    var result: Error = _mover.jump()
    if result != OK:
        push_warning("Could not queue the target's hop: %s" % error_string(result))
```
