## Signature

```text
open_overlay() -> Error
```

## Return value

`Error`

## Description

`OK` means Steam accepted the request, and `ERR_BUSY` means the overlay is loading.

## Example

```gdscript
extends Node

func run_open_overlay(game_runtime: GameRuntime, status_label: Label) -> void:
    var game_invites: GameInvites = game_runtime.invites()
    if game_invites == null:
        return
    var result: Error = game_invites.open_overlay()
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Open overlay accepted."
```
