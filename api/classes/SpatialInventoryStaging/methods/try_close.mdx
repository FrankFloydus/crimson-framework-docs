## Signature

```text
try_close(restore: bool = false) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `restore` | `bool` | `false` |

## Return value

`Error`

## Description

If `restore` is true, attempt to restore everything first. Otherwise an occupied tray returns `ERR_BUSY`.

## Example

```gdscript
extends Node

    spatial_inventory_staging: SpatialInventoryStaging,

) -> void:
    var result: Error = spatial_inventory_staging.try_close(restore)

        return
    status_label.text = "Try close accepted."
```
