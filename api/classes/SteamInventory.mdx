## Description

Get this service from `SteamClient.inventory()` after starting the Steam client. Enable Steam Inventory Service and publish the relevant item definitions for your AppID. Await the methods on the main thread. An inactive or unsupported scope returns `ERR_UNAVAILABLE`, invalid arguments return `ERR_INVALID_PARAMETER`, and a full request queue returns `ERR_BUSY`. A pending request times out after 15 seconds. A submitted mutation may still apply after local observation ends. Stop or restart the owning client to retire its service and pending reads.

## Methods

### Instance methods

#### [`claim_playtime_drop`](/api/classes/SteamInventory/methods/claim_playtime_drop)

Evaluates the published playtime generator `generator_id`.

#### [`claim_promotion`](/api/classes/SteamInventory/methods/claim_promotion)

Asks Steam to apply the published promotion `definition_id` if the signed-in player is eligible.

#### [`claim_promotions`](/api/classes/SteamInventory/methods/claim_promotions)

Asks Steam to apply all eligible configured promotions.

#### [`consume`](/api/classes/SteamInventory/methods/consume)

Permanently consumes `quantity` units from `instance_id`.

#### [`craft`](/api/classes/SteamInventory/methods/craft)

Atomically exchanges the distinct owned `ingredients` for one unit of `output_definition_id` when a published Steam recipe matches.

#### [`definition`](/api/classes/SteamInventory/methods/definition)

Loads the catalog as needed and returns [`SteamItemDefinitionResult`](/api/classes/SteamItemDefinitionResult) for the published `definition_id`.

#### [`definitions`](/api/classes/SteamInventory/methods/definitions)

Loads the app's published catalog on demand and returns [`SteamItemDefinitionsResult`](/api/classes/SteamItemDefinitionsResult).

#### [`items`](/api/classes/SteamInventory/methods/items)

Returns [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the signed-in player's full inventory.

#### [`items_by_id`](/api/classes/SteamInventory/methods/items_by_id)

Returns [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the available owned instances in `instance_ids`.

#### [`merge`](/api/classes/SteamInventory/methods/merge)

Moves `quantity` units from `from_instance_id` into the distinct `into_instance_id` stack.

#### [`proof`](/api/classes/SteamInventory/methods/proof)

Returns [`SteamBytesResult`](/api/classes/SteamBytesResult) with a signed Steam result containing exactly the available owned selection.

#### [`split`](/api/classes/SteamInventory/methods/split)

Moves `quantity` units from `instance_id` into a new instance of the same definition.

## Signals

### `definitions_changed`

`definitions_changed()`

Emitted after Steam announces a catalog update. An open catalog can call `definitions()` again to read the new revision.

### `items_changed`

`items_changed(snapshot: SteamInventorySnapshot)`

Emitted after this scope accepts a newer full inventory response to `items()`. The snapshot is detached and read-only. Mutations return their own changes.
