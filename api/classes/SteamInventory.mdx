**Inherits** `RefCounted`

Reads and changes the signed-in player's Steam inventory.

Get this service from `SteamClient.inventory()` after starting the Steam client. Enable Steam Inventory Service and publish the relevant item definitions for your AppID. Await the methods on the main thread. An inactive or unsupported scope returns `ERR_UNAVAILABLE`, invalid arguments return `ERR_INVALID_PARAMETER`, and a full request queue returns `ERR_BUSY`. A pending request times out after 15 seconds. A submitted mutation may still apply after local observation ends. Stop or restart the owning client to retire its service and pending reads.

## Methods

### `claim_playtime_drop`

`claim_playtime_drop(generator_id: int) -> Variant`

Evaluates the published playtime generator `generator_id`. A successful evaluation can grant no items. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `claim_promotion`

`claim_promotion(definition_id: int) -> Variant`

Asks Steam to apply the published promotion `definition_id` if the signed-in player is eligible. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `claim_promotions`

`claim_promotions() -> Variant`

Asks Steam to apply all eligible configured promotions. A successful result can contain no grants. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `consume`

`consume(instance_id: String, quantity: int = 1) -> Variant`

Permanently consumes `quantity` units from `instance_id`. Use a confirmation step in the game UI before submitting this action. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `craft`

`craft(output_definition_id: int, ingredients: SteamItemQuantity[]) -> Variant`

Atomically exchanges the distinct owned `ingredients` for one unit of `output_definition_id` when a published Steam recipe matches. Steam validates the recipe and quantities before changing either side. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `definition`

`definition(definition_id: int) -> Variant`

Loads the catalog as needed and returns [`SteamItemDefinitionResult`](/api/classes/SteamItemDefinitionResult) for the published `definition_id`. A valid ID absent from the catalog returns `ERR_DOES_NOT_EXIST`.

### `definitions`

`definitions() -> Variant`

Loads the app's published catalog on demand and returns [`SteamItemDefinitionsResult`](/api/classes/SteamItemDefinitionsResult). Requests in the same scope share an in-flight load. A successful catalog may be empty.

### `items`

`items() -> Variant`

Returns [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the signed-in player's full inventory. Call when a view needs refresh. Steam can rate-limit full reads and return cached results. Inspect the snapshot's freshness before making decisions that require current inventory.

### `items_by_id`

`items_by_id(instance_ids: PackedStringArray) -> Variant`

Returns [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) for the available owned instances in `instance_ids`. Steam may omit instances that are no longer present. Supply one to 256 distinct unsigned decimal IDs.

### `merge`

`merge(from_instance_id: String, into_instance_id: String, quantity: int) -> Variant`

Moves `quantity` units from `from_instance_id` into the distinct `into_instance_id` stack. Steam enforces the matching definition and trade restrictions. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

### `proof`

`proof(instance_ids: PackedStringArray) -> Variant`

Returns [`SteamBytesResult`](/api/classes/SteamBytesResult) with a signed Steam result containing exactly the available owned selection. Supply one to 256 distinct unsigned decimal `instance_ids`. A missing selected instance returns `ERR_DOES_NOT_EXIST`. Proof bytes are limited to 1 MiB. Send them only to the authority that needs to verify this selection.

### `split`

`split(instance_id: String, quantity: int) -> Variant`

Moves `quantity` units from `instance_id` into a new instance of the same definition. The result carries the changed or removed source and the new stack. Returns [`SteamInventoryChangeResult`](/api/classes/SteamInventoryChangeResult). Refresh inventory before retrying after a timeout.

## Signals

### `definitions_changed`

`definitions_changed()`

Emitted after Steam announces a catalog update. An open catalog can call `definitions()` again to read the new revision.

### `items_changed`

`items_changed(snapshot: SteamInventorySnapshot)`

Emitted after this scope accepts a newer full inventory response to `items()`. The snapshot is detached and read-only. Mutations return their own changes.
