**Inherits** `RefCounted`

## Description

Read a snapshot through `Game.network_diagnostics()` for a developer panel or test. The properties describe the session at the time of the call. They do not control the transport or movement simulation. Only ENet provides a round-trip estimate in this snapshot.

## Examples

- [Watch movement corrections on a LAN guest](/api/classes/GameNetworkDiagnostics/properties/authority_position#example)

## Properties

**[`acknowledged_input`](/api/classes/GameNetworkDiagnostics/properties/acknowledged_input)**

The last local guest input sequence accounted for by server state, or zero when unavailable.

**[`authority_position`](/api/classes/GameNetworkDiagnostics/properties/authority_position)**

The latest authoritative local actor position.

**[`connected_peers`](/api/classes/GameNetworkDiagnostics/properties/connected_peers)**

The number of admitted remote peers visible to the local game session.

**[`correction_distance`](/api/classes/GameNetworkDiagnostics/properties/correction_distance)**

The most recent owner correction in metres, or zero before a correction.

**[`corrections`](/api/classes/GameNetworkDiagnostics/properties/corrections)**

The number of owner corrections above the simulation's visible-error threshold during the current session.

**[`movement_mode`](/api/classes/GameNetworkDiagnostics/properties/movement_mode)**

The local fixed-world movement pipeline.

**[`peer_id`](/api/classes/GameNetworkDiagnostics/properties/peer_id)**

The local session peer ID, or zero before admission.

**[`pending_inputs`](/api/classes/GameNetworkDiagnostics/properties/pending_inputs)**

The number of local guest commands awaiting confirmation.

**[`phase`](/api/classes/GameNetworkDiagnostics/properties/phase)**

The game's readiness when sampled.

**[`player_number`](/api/classes/GameNetworkDiagnostics/properties/player_number)**

The local actor's one-based fixed-world spawn slot.

**[`predicted_position`](/api/classes/GameNetworkDiagnostics/properties/predicted_position)**

The current predicted local actor position when `movement_mode` is `GUEST_PREDICTED`.

**[`replayed_inputs`](/api/classes/GameNetworkDiagnostics/properties/replayed_inputs)**

The number of inputs replayed during the most recent owner reconciliation.

**[`role`](/api/classes/GameNetworkDiagnostics/properties/role)**

The local session role when sampled.

**[`round_trip_ms`](/api/classes/GameNetworkDiagnostics/properties/round_trip_ms)**

The ENet round-trip estimate in milliseconds.

**[`simulation_tick`](/api/classes/GameNetworkDiagnostics/properties/simulation_tick)**

The last known completed server physics tick, or zero when unavailable.

**[`state_age_ms`](/api/classes/GameNetworkDiagnostics/properties/state_age_ms)**

Local elapsed milliseconds since the most recent authoritative guest state arrived, or -1 when unavailable.

**[`transport`](/api/classes/GameNetworkDiagnostics/properties/transport)**

`enet` for ENet, `custom` for other multiplayer peers, or empty when idle or offline.

## Constants and enums

### `MovementMode`

| Name | Value | Description |
| --- | --- | --- |
| `AUTHORITY_LIVE` | `1` | The authority uses the live Godot movement driver. |
| `AUTHORITY_PREDICTIVE` | `2` | The authority uses the grounded driver shared by prediction. |
| `GUEST_INTERPOLATED` | `3` | The owning guest follows authoritative position updates. |
| `GUEST_PREDICTED` | `4` | The owning guest predicts and reconciles local movement. |
| `MOVEMENT_DISABLED` | `0` | No fixed-world movement diagnostics are available. |

### `Role`

| Name | Value | Description |
| --- | --- | --- |
| `CONNECTING` | `3` | A guest connection is awaiting admission. |
| `DEDICATED` | `5` | The fixed-world game is running as a dedicated server. |
| `GUEST` | `4` | The local client has been admitted by the authority. |
| `HOST` | `2` | The game is running as a listen authority or coordinated server. |
| `IDLE` | `0` | The game owns no active connection. |
| `OFFLINE` | `1` | The local player runs an offline session. |
