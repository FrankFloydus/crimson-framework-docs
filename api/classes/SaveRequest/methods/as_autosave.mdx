## Signature

```text
as_autosave() -> SaveRequest
```

## Return value

[`SaveRequest`](/api/classes/SaveRequest)

## Description

A newer autosave for the same slot and world epoch can supersede an earlier request before capture.

## Example

```gdscript
extends Node

func run_as_autosave(save_request: SaveRequest, confirmed: bool, status_label: Label) -> void:
    var result: SaveRequest = save_request.as_autosave()
    if result == null:
        return
    if not confirmed:
        return
    var completion: GameOperation = result.submit()
    if completion == null:
        return
    var result_value: Dictionary = await completion.wait()
    if not result_value.get("ok", false):
        status_label.text = str(result_value.get("message", "Operation failed."))
        return
    status_label.text = "Submit completed."
```
