## Signature

```text
submit() -> GameOperation
```

## Return value

[`GameOperation`](/api/classes/GameOperation)

## Description

The game must be a running authority. On success, the operation's value contains the sequence and ID of the published generation.

## Example

```gdscript
func publish_checkpoint(slot: SaveSlot) -> void:
    var request: SaveRequest = slot.save().named("Before entering the ruins")
    var result: Dictionary = await request.submit().wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Checkpoint: ", result.value)
```
