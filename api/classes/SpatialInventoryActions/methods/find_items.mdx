## Signature

```text
static find_items(inventory: SpatialInventory, predicate: Callable = Callable()) -> StringName[]
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `inventory` | [`SpatialInventory`](/api/classes/SpatialInventory) | — |
| `predicate` | `Callable` | `Callable()` |

## Return value

`StringName[]`

## Description

The predicate receives one placement dictionary and must return true to include its ID. Without a predicate, every placement is included.

## Example

    var result: Array[StringName] = SpatialInventoryActions.find_items(inventory, predicate)
