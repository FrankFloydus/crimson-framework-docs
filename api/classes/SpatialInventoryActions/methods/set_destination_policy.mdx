## Description

Return an empty String to accept that destination, or a reason to skip it.

## Example

func skip_locked_grid(actions: SpatialInventoryActions, locked_grid: SpatialInventory) -> void:
    actions.set_destination_policy(func(context: Dictionary) -> String:

            return "Storage is locked."
        return ""
