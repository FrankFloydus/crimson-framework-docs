## Return value

[`SteamVoicePcmResult`](/api/classes/SteamVoicePcmResult)

## Description

Zero chooses Steam's recommended rate, or pass a rate from 11025 to 48000 Hz. The result contains up to 131072 bytes of signed 16-bit mono PCM. Unavailable codecs and invalid input return a typed error.
