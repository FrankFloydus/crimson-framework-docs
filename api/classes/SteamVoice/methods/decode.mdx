## Signature

```text
decode(bytes: PackedByteArray, sample_rate_hz: int = 0) -> SteamVoicePcmResult
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `bytes` | `PackedByteArray` | — |
| `sample_rate_hz` | `int` | `0` |

## Return value

[`SteamVoicePcmResult`](/api/classes/SteamVoicePcmResult)

## Description

Zero chooses Steam's recommended rate, or pass a rate from 11025 to 48000 Hz. The result contains up to 131072 bytes of signed 16-bit mono PCM. Unavailable codecs and invalid input return a typed error.

## Example

```gdscript
extends Node

func run_decode(
    steam_client: SteamClient,
    bytes: PackedByteArray,
    sample_rate_hz: int,
    apply_decode: Callable
) -> void:
    if not steam_client.is_ready():
        return
    var steam_voice: SteamVoice = steam_client.voice()
    if steam_voice == null:
        return
    var result: SteamVoicePcmResult = steam_voice.decode(bytes, sample_rate_hz)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamVoicePcm = result.value
    if payload == null:
        return
    apply_decode.call(payload)
```
