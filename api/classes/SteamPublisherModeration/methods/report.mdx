## Parameters

| --- | --- | --- |

## Return value

`Variant`

## Description

The player ID is an individual SteamID64 in decimal form. A player reporter must be verified by the same publisher. Returns [`SteamCheatReportResult`](/api/classes/SteamCheatReportResult) with the full unsigned Valve report ID.

## Example

```gdscript
extends Node

func run_report(
    steam_publisher: SteamPublisher,
    player_id: String,
    evidence: SteamCheatEvidence,
    apply_report: Callable
) -> void:
    if not steam_publisher.is_ready():
        return
    var steam_publisher_moderation: SteamPublisherModeration = steam_publisher.moderation()
    if steam_publisher_moderation == null:
        return
    var result: SteamCheatReportResult = await steam_publisher_moderation.report(player_id, evidence)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamCheatReport = result.value
    if payload == null:
        return
    apply_report.call(payload)
```
