## Description

`seconds` must be from 1 through 31535999. Valve treats durations under one year as suspensions hidden from the player's public profile. Supply the reviewed `reason`. Returns [`SteamModerationReceiptResult`](/api/classes/SteamModerationReceiptResult). An invalid duration returns `ERR_INVALID_PARAMETER` before invoking the policy. The exact game policy must authorize the request and reserve the audit record before Steam receives it. An expired or closed observation can leave the remote outcome unresolved.
