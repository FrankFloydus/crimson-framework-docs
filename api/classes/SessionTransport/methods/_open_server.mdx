## Return value

[`SessionTransportResult`](/api/classes/SessionTransportResult)

## Description

The session sets the admission flag before installation. Return SessionTransportResult.opened or SessionTransportResult.failed. If omitted, opening fails with ERR\_UNAVAILABLE.

## Example

```gdscript
extends SessionTransport

func _open_server(port: int, remote_limit: int, bind_address: String) -> SessionTransportResult:
    var peer: ENetMultiplayerPeer = ENetMultiplayerPeer.new()
    peer.set_bind_ip(bind_address)
    var error: Error = peer.create_server(port, remote_limit)
    if error != OK:
        return SessionTransportResult.failed(error)
    return SessionTransportResult.opened(peer)
```
