## Description

If omitted, the adapter requests a regular Godot disconnect. Implement this hook when the guest needs to receive a final message before closure.

## Example

```gdscript
extends SessionTransport

# Set this to your transport's reliable drain operation.
var disconnect_when_drained: Callable

func _disconnect_after_flush(peer: MultiplayerPeer, peer_id: int) -> void:
    if disconnect_when_drained.is_valid():
        disconnect_when_drained.call(peer, peer_id)
    else:
        peer.disconnect_peer(peer_id)
```
