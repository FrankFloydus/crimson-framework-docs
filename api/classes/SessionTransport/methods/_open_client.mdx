## Signature

```text
_open_client(endpoint: SessionEndpoint) -> SessionTransportResult
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `endpoint` | [`SessionEndpoint`](/api/classes/SessionEndpoint) | — |

## Return value

[`SessionTransportResult`](/api/classes/SessionTransportResult)

## Description

The peer may still be connecting, and must have an ID above 1 when it receives admission. Return SessionTransportResult.opened or SessionTransportResult.failed. If omitted, opening fails with ERR\_UNAVAILABLE.

## Example

```gdscript
extends SessionTransport

func _open_client(endpoint: SessionEndpoint) -> SessionTransportResult:
    var peer: ENetMultiplayerPeer = ENetMultiplayerPeer.new()
    var error: Error = peer.create_client(endpoint.get_address(), endpoint.get_port())
    if error != OK:
        return SessionTransportResult.failed(error)
    return SessionTransportResult.opened(peer)
```
