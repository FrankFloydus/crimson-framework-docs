## Signature

```text
register_handler(command_type: String, handler: Callable, requires_primary: bool = false) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `command_type` | `String` | — |
| `handler` | `Callable` | — |
| `requires_primary` | `bool` | `false` |

## Return value

`Error`

## Description

Set `requires\_primary` when the intent must contain the matching character ID and possession revision. The handler returns plain dictionary data with boolean `ok` and optional string `code` and `message`.
