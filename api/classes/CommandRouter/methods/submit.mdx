## Return value

`Dictionary`

## Description

The dictionary contains `match\_id`, `world\_epoch`, `sequence`, `type`, and a `payload` dictionary. Supply `character\_id` and `possession\_revision` together when asserting primary control. Returns a result with `ok`, `code`, and `message`. The sequence is consumed once the handler runs, even if it rejects the intent.
