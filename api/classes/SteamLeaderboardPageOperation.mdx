**Inherits** `RefCounted`

Observes a cancellable leaderboard read.

A request started from `SteamLeaderboardQuery.fetch_operation()` can first resolve the board and then download the page. A request from an existing [`SteamLeaderboard`](/api/classes/SteamLeaderboard) starts at the download. Stopping the owning scope settles pending reads with `@GlobalScope.ERR_SKIP`.

## Methods

### `cancel`

`cancel() -> Error`

Ends local observation of the current stage. Returns `@GlobalScope.OK` when the cancellation was applied. The operation settles with `@GlobalScope.ERR_SKIP`. Steam can still finish an already submitted download.

### `is_finished`

`is_finished() -> bool`

Returns whether this operation has a terminal outcome.

### `result`

`result() -> SteamLeaderboardPageResult`

Returns the same typed terminal result delivered by `completed`, or `null` while pending.

### `wait`

`wait() -> Variant`

Use `await` to get a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult). A settled operation returns its result immediately.
