## Description

Listen games use a Steam individual account and virtual port. A Steam dedicated game uses the certificate-pinned direct IPv4 `steam_server` or hosted relay `steam_hosted` endpoint. The hosted endpoint also requires a fresh one-shot coordinator grant from the Game provider.

## Methods

### Static methods

#### [`route`](/api/classes/SteamSessionTransport/methods/route)

Construct a versioned P2P endpoint for a valid individual SteamID64 and virtual port from 0 to 65535.

### Instance methods

#### [`get_host_endpoint`](/api/classes/SteamSessionTransport/methods/get_host_endpoint)

#### [`get_host_remote_limit`](/api/classes/SteamSessionTransport/methods/get_host_remote_limit)

Return the active authority's remote seat limit, or zero without a live listener.

#### [`get_remote_steam_id`](/api/classes/SteamSessionTransport/methods/get_remote_steam_id)

#### [`open_server`](/api/classes/SteamSessionTransport/methods/open_server)
