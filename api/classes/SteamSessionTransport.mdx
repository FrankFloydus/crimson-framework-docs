**Inherits** [`SessionTransport`](/api/classes/SessionTransport)

The Steam Networking Sockets adapter selected by the native Steam game provider.

Listen games use a Steam individual account and virtual port. A Steam dedicated game uses the certificate-pinned direct IPv4 `steam_server` or hosted relay `steam_hosted` endpoint. The hosted endpoint also requires a fresh one-shot coordinator grant from the Game provider.

## Methods

### `get_host_endpoint`

`get_host_endpoint() -> SessionEndpoint`

Return the typed route for the current authenticated authority when the listener and Steam identity are available.

### `get_host_remote_limit`

`get_host_remote_limit() -> int`

Return the active authority's remote seat limit, or zero without a live listener.

### `get_remote_steam_id`

`get_remote_steam_id(peer_id: int) -> int`

Return the certified Steam identity for the exact ready physical Godot peer, or zero when it is unavailable. Gameplay admission also validates its Session identity.

### `open_client`

`open_client(endpoint: SessionEndpoint) -> SessionTransportResult`

Connect on the configured signed-in Steam pipe. The adapter accepts its versioned Steam P2P, dedicated direct, or coordinator-authorized hosted endpoint and checks the remote identity against the expected certificate.

### `open_server`

`open_server(port: int, remote_limit: int, bind_address: String) -> SessionTransportResult`

Open a listener on the configured Steam virtual port or dedicated gameplay port. The bound peer count is 1 to 64. Listen Steam accepts the wildcard bind. A dedicated adapter accepts its configured IPv4 address or the wildcard selection of its configured interface.

### `route`

`static route(owner_id: int, virtual_port: int = 0) -> SessionEndpoint`

Construct a versioned P2P endpoint for a valid individual SteamID64 and virtual port from 0 to 65535. Return null when unavailable or invalid. Dedicated locators are resolved by the Steam game provider instead.
