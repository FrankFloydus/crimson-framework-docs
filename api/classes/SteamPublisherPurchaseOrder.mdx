**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

Immutable priced order and its durable progress.

Trusted stores persist and rehydrate this value for the exact AppID, environment, Steam account and checkout. Use `with_progress()` to restore a stored revision. The publisher verifies every applicable Steam receipt before using it to grant or reverse entitlement.

## Constants and enums

### `Phase`

| Name | Value | Description |
| --- | --- | --- |
| `APPROVED` | `3` | Steam verified that the player authorized this exact order. |
| `AWAITING` | `2` | Steam created the order and is waiting for the player's authorization. |
| `DECLINED` | `5` | Steam confirmed denial or failure. |
| `FINALIZING` | `4` | The durable charge claim exists and Steam's response may be uncertain. |
| `FULFILLED` | `6` | Steam confirmed payment and the durable grant was committed. |
| `INITIALIZING` | `1` | The durable authorization claim exists and Steam's response may be uncertain. |
| `PARTIALLY_REVERSED` | `8` | Steam confirmed item-level reversals and some entitlements remain. |
| `REFUNDING` | `7` | The authorized full refund claim exists and Steam's response may be uncertain. |
| `RESERVED` | `0` | The original quote is persisted and no authorization request was queued. |
| `REVERSED` | `9` | Steam confirmed a full reversal and the store persisted it. |

### `TaxBasis`

| Name | Value | Description |
| --- | --- | --- |
| `GROSS` | `1` | Compare the quote with Steam's reported amount plus VAT after checked addition. |
| `NET` | `0` | Compare the quote with Steam's reported amount excluding VAT. |
