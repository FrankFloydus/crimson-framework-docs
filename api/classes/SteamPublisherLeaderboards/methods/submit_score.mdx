## Description

Accepts up to 256 raw details bytes. Use `await` to receive [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult). Success acknowledges the HTTP submission. The publisher endpoint does not document rank or change fields, so the result carries the submitted score and no `SteamLeaderboardSubmission.upload` receipt.
