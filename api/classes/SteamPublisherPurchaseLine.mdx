## Description

The trusted store maps one unpriced cart SKU to a positive Steam item ID and localized description. `total` covers the entire quantity.

## Properties

**[`description`](/api/classes/SteamPublisherPurchaseLine/properties/description)**

Trusted localized Steam checkout text, up to 128 characters.

**[`item_id`](/api/classes/SteamPublisherPurchaseLine/properties/item_id)**

Positive unsigned 32-bit Steam item ID configured by the game.

**[`quantity`](/api/classes/SteamPublisherPurchaseLine/properties/quantity)**

Positive count of units, up to 32767.

**[`sku`](/api/classes/SteamPublisherPurchaseLine/properties/sku)**

Game catalog SKU, up to 96 characters.

**[`total`](/api/classes/SteamPublisherPurchaseLine/properties/total)**

Total for the whole line in the original quote's Steam currency units.
