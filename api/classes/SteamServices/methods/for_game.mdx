[`SteamScope`](/api/classes/SteamScope)

## Description

A failed setup exposes its diagnostic. Closed games and games without Steam return null.

## Example

```gdscript
func show_game_steam_language(game: GameRuntime) -> void:
    var scope: SteamScope = SteamServices.for_game(game)
    if scope == null or not scope.is_ready():
        return
    var apps: SteamApps = scope.apps()
    if apps != null:
        print("Steam language: ", apps.current_language())
```
