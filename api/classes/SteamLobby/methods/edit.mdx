## Signature

```text
edit() -> SteamLobbyEdit
```

## Return value

[`SteamLobbyEdit`](/api/classes/SteamLobbyEdit)

## Description

Call `SteamLobbyEdit.submit()` to check live ownership and write.

## Example

```gdscript
extends Node

func run_edit(
    steam_lobby: SteamLobby,
    display_name: String,
    confirmed: bool,
    status_label: Label
) -> void:
    var result: SteamLobbyEdit = steam_lobby.edit()
    if result == null:
        return
    var named_draft: SteamLobbyEdit = result.named(display_name)
    if named_draft == null:
        return
    if not confirmed:
        return
    var completion: Error = named_draft.submit()
    if completion != OK:
        status_label.text = error_string(completion)
        return
    status_label.text = "Completion accepted."
```
