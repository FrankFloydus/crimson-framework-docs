## Return value

[`SteamServer`](/api/classes/SteamServer)

## Description

Version and description are limited to 63 UTF-8 bytes. The folder name is limited to 31 UTF-8 bytes and must be one folder component. All values are nonempty and exclude controls. Invalid settings prevent dedicated startup. Defaults are 1.0.0.0, Crimson, and crimson for compatibility. Set metadata before boot for a published app.

## Example

```gdscript
extends Node

func run_with_product_metadata(
    steam_server: SteamServer,
    version: String,
    description: String,
    install_dir: String,
    provider: SteamProvider,
    definition: GameDefinition,
    game: GameRuntime
) -> void:
    var result: SteamServer = steam_server.with_product_metadata(version, description, install_dir)
    if result == null:
        return
    # Set the dedicated provider before adding GameRuntime to the tree.
    if game.is_inside_tree():
        return
    game.definition = definition.with_provider(provider.dedicated(result))
```
