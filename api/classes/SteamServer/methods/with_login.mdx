## Parameters

| Parameter | Type | Default |

| `secret_ref` | `StringName` | — |

## Return value

[`SteamServer`](/api/classes/SteamServer)

## Description

Use up to 64 uppercase ASCII letters, digits or underscores. An empty key uses Steam's anonymous game server logon.

## Example

```gdscript
extends Node

func run_with_login(
    steam_server: SteamServer,
    secret_ref: StringName,
    provider: SteamProvider,
    definition: GameDefinition,
    game: GameRuntime
) -> void:
    var result: SteamServer = steam_server.with_login(secret_ref)
    if result == null:
        return
    # Set the dedicated provider before adding GameRuntime to the tree.
    if game.is_inside_tree():
        return
    game.definition = definition.with_provider(provider.dedicated(result))
```
