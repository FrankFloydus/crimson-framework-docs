## Signature

```text
static configure(name: String = "Crimson Server", game_port: int = 27015, query_port: int = 27016) -> SteamServer
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `name` | `String` | `"Crimson Server"` |
| `game_port` | `int` | `27015` |
| `query_port` | `int` | `27016` |

## Return value

[`SteamServer`](/api/classes/SteamServer)

## Description

The display name allows up to 63 UTF-8 bytes. Gameplay accepts ports 1 to 65535. Query ports 1 to 65534 are available. The default binds all IPv4 interfaces and starts in authenticated, unlisted direct mode.

## Example

extends Node

func run_configure(
    name: String,
    game_port: int,
    query_port: int,
    provider: SteamProvider,
    definition: GameDefinition,
    game: GameRuntime
) -> void:
    var result: SteamServer = SteamServer.configure(name, game_port, query_port)
    if result == null:
        return
    # Set the dedicated provider before adding GameRuntime to the tree.
    if game.is_inside_tree():
        return
    game.definition = definition.with_provider(provider.dedicated(result))
