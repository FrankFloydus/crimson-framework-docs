## Return value

[`SteamServer`](/api/classes/SteamServer)

## Description

An empty profile selects direct transport. A hosted profile requires Valve-provisioned server settings and a trusted game coordinator.

## Example

```gdscript
extends Node

func run_via_sdr(
    steam_server: SteamServer,
    profile: StringName,
    provider: SteamProvider,
    definition: GameDefinition,
    game: GameRuntime
) -> void:
    var result: SteamServer = steam_server.via_sdr(profile)
    if result == null:
        return
    # Set the dedicated provider before adding GameRuntime to the tree.
    if game.is_inside_tree():
        return
    game.definition = definition.with_provider(provider.dedicated(result))
```
