## Description

Standalone bodies with a [`MoverComponent`](/api/classes/MoverComponent) use its movement settings. Fixed-world sessions use the settings captured by `GameConfig.player_controls()`. Supply existing live controls for the same input layout and tree to retain bindings across bodies. With no handle supplied, boots body-scoped controls. Returns a handle with an error and message if validation fails. Optional desktop capture is attempted after attachment and depends on window focus and pointer availability.
