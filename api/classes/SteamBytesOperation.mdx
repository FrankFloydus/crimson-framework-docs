**Inherits** `RefCounted`

Retained observation of a Steam action with a typed byte result.

## Methods

### `cancel`

`cancel() -> Error`

Ends local observation and completes it with `ERR_SKIP`. Steam drains the submitted call and holds any file reservation until then. Returns `ERR_DOES_NOT_EXIST` when observation has already ended.

### `is_finished`

`is_finished() -> bool`

Returns whether the operation has a terminal result.

### `result`

`result() -> SteamBytesResult`

Returns the same terminal result as `completed`, or `null` while observation is pending.

### `wait`

`wait() -> Variant`

Use `await operation.wait()` to receive a [`SteamBytesResult`](/api/classes/SteamBytesResult) before or after observation ends.

## Signals

### `completed`

`completed(result: SteamBytesResult)`

Emitted once after a pending action settles, including after cancellation or client shutdown. `result()` already returns this result during the signal.
