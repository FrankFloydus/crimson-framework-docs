## Return value

Await the call to receive [`SteamServerStatsResult`](/api/classes/SteamServerStatsResult).

## Example

```gdscript
extends Node

func run_wait(
    steam_server_stats_operation: SteamServerStatsOperation,
    status_label: Label

    var result: SteamServerStatsResult = await steam_server_stats_operation.wait()
    if result == null:
        return

        push_warning(result.message)
        return
```
