### Method details

#### `item`

`item(published_id: String) -> SteamWorkshopItemRef`

Creates a reference to one item. Pass the canonical unsigned decimal published file ID. `SteamWorkshopItemRef.fetch()` validates the ID before using Steam.

#### `legal_agreement_status`

`legal_agreement_status() -> Variant`

Use `await workshop.legal_agreement_status()` for a [`SteamWorkshopLegalAgreementStatusResult`](/api/classes/SteamWorkshopLegalAgreementStatusResult) for the exact active app. Check `SteamWorkshopLegalAgreementStatus.needs_action` and offer `show_legal_agreement()` as an explicit player action when needed.

#### `new_item`

`new_item() -> SteamWorkshopPublishRequest`

Creates a branchable draft for a new item. The draft remains local until `SteamWorkshopPublishRequest.submit()`. New items default to private visibility.

#### `query`

`query() -> SteamWorkshopQuery`

Creates a fresh query starting at the first page. Use the query methods to branch filters before calling `SteamWorkshopQuery.fetch()`.

#### `show_legal_agreement`

`show_legal_agreement() -> Error`

Asks Steam to open the active app's Workshop legal agreement in its overlay. Call this in response to a player or author action. `OK` acknowledges the request. Query `legal_agreement_status()` after the user closes the overlay to read the current decision.

#### `subscriptions`

`subscriptions(limit: int = 128, include_locally_disabled: bool = false) -> SteamWorkshopSubscriptionsResult`

Copies up to `limit` Workshop subscriptions for the signed-in user and current app in Steam's subscription order. Set `include_locally_disabled` to include subscriptions disabled in the Steam client. The limit ranges from 1 to `MAX_SUBSCRIPTIONS`. Use a returned decimal ID with `item()` to inspect or install that item.

## Signals

### `install_changed`

`install_changed(published_id: String, install: SteamWorkshopInstall)`

Emitted for Steam's matching same-app installation or update event. `published_id` identifies the item. Passive events provide a `null` `install`. Call `SteamWorkshopItemRef.installed()` to inspect its current directory when needed.
