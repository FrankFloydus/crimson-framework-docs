## Signals

### `install_changed`

`install_changed(published_id: String, install: SteamWorkshopInstall)`

Emitted for Steam's matching same-app installation or update event. `published_id` identifies the item. Passive events provide a `null` `install`. Call `SteamWorkshopItemRef.installed()` to inspect its current directory when needed.
