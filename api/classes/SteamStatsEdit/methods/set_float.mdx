[`SteamStatsEdit`](/api/classes/SteamStatsEdit)

## Description

The value must be finite and fit Steam's single-precision range.

## Example

```gdscript
extends Node

func run_set_float(
    steam_stats: SteamStats,
    name: String,
    value: float,
    confirmed: bool,
    apply_completion: Callable
) -> void:
    var steam_stats_edit: SteamStatsEdit = steam_stats.edit()
    if steam_stats_edit == null:
        return
    var result: SteamStatsEdit = steam_stats_edit.set_float(name, value)
    if result == null:
        return
    if not confirmed:
        return
    var completion: SteamStatsSubmissionResult = result.submit()
    if completion == null:
        return
    if not completion.ok:
        push_warning(completion.message)
        return
    var payload: SteamStatsSubmission = completion.value
    if payload == null:
        return
    apply_completion.call(payload)
```
