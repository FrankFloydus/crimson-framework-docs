## Description

Observe `connection_requested` and apply a local allowlist or equivalent session policy. Pending offers expire after 1.5 seconds and count against this listener's remote limit.

## Methods

### `accept`

`accept(offer: SteamSocketOffer) -> SteamSocketConnectionResult`

Accepts the exact live offer on its original listener. Successful acceptance issues a handle that can be closed immediately. Wait for `SteamSocketConnection.connected` before using its authenticated identity or sending.

### `close`

`close() -> Error`

Closes this listener and retires its pending offers and accepted connections.

### `reject`

`reject(offer: SteamSocketOffer) -> Error`

Rejects and retires the exact pending offer.

## Signals

### `connection_requested`

`connection_requested(offer: SteamSocketOffer)`

Emitted for a new pending offer. Handle it within its monotonic deadline.
