## Example

### Watch movement corrections on a LAN guest

Put the label under the persistent game owner and move around as a predicting LAN guest. It shows outstanding inputs and the most recent correction in metres. [Synchronize player movement](/networked-movement)

```gdscript
extends Label

func _process(_delta: float) -> void:
    var game: Game = Game.for_node(self)
    if game == null:
        text = "Waiting for the game."
        return

    var sample: GameNetworkDiagnostics = game.network_diagnostics()
    if sample.player_number == 0:
        text = "Waiting for a local player."
        return

    if sample.movement_mode != GameNetworkDiagnostics.GUEST_PREDICTED:
        text = "Player %d: %s" % [sample.player_number, sample.authority_position]
        return

    text = "Player %d: %d pending inputs, last correction %.2f m." % [
        sample.player_number, sample.pending_inputs, sample.correction_distance
    ]
```
