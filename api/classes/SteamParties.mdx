**Inherits** `RefCounted`

Steam Party discovery, reservations and exact Game-owned publication.

## Methods

### `beacons`

`beacons() -> SteamPartyListingsResult`

Reads visible beacons with compatible bounded Game lobby metadata. Snapshots remain readable after the SDK changes its visible list.

### `locations`

`locations() -> SteamPartyLocationsResult`

Reads up to 128 eligible Steam Chat locations as typed snapshots. Empty eligible lists are valid.

### `publish`

`publish(listing: SteamListing, location: SteamPartyLocation, open_slots: int) -> Variant`

Await a [`SteamPartyBeaconResult`](/api/classes/SteamPartyBeaconResult). The listing must be this Game scope's live owned non-private Steam lobby. Choose a currently eligible location and one to 64 unreserved seats within authority capacity. A process can publish one beacon at a time.

### `reserve`

`reserve(beacon: SteamPartyListing) -> Variant`

Await a [`SteamListingResult`](/api/classes/SteamListingResult). Steam reserves a seat and returns an owner-bound locator for `GameRuntime.join_listing()`. Game admission still verifies the live lobby owner and rules. An abandoned reservation expires on the host.

## Signals

### `beacons_changed`

`beacons_changed()`

Emitted when Steam says the visible beacons or eligible locations changed. Read a fresh snapshot when handling it.
