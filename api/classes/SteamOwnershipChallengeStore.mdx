**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher addon](/steam/publisher).

Trusted durable store for one-time encrypted ownership challenges.

Inject this adapter through `SteamPublisherSettings.ownership_challenge_store`. The backend issues a cryptographically random challenge for a specific outstanding request and persists its app, expiry, and any expected account binding. Pass that outstanding challenge to `SteamPublisherAuth.verify_ownership()`. A shared store must serialize the same challenge across all backend workers.

## Methods

### `_consume`

`_consume(app_id: int, challenge: PackedByteArray, steam_id: String, issued_at_unix: int, now_unix: int) -> bool`

**Virtual method.**

Atomically matches the exact backend-issued challenge and AppID, verifies the record is unexpired and unused, checks its request and expected-account bindings, and retires it before returning `true`. `steam_id` is the verified ticket account. Times use Unix seconds. Return `false` when any check fails. Keep challenge bytes and account identifiers out of logs.
