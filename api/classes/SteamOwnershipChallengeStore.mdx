## Description

Inject this adapter through `SteamPublisherSettings.ownership_challenge_store`. The backend issues a cryptographically random challenge for a specific outstanding request and persists its app, expiry, and any expected account binding. Pass that outstanding challenge to `SteamPublisherAuth.verify_ownership()`. A shared store must serialize the same challenge across all backend workers.

## Methods

### Virtual methods

#### [`_consume`](/api/classes/SteamOwnershipChallengeStore/methods/_consume)

Atomically matches the exact backend-issued challenge and AppID, verifies the record is unexpired and unused, checks its request and expected-account bindings, and retires it before returning `true`. `steam_id` is the verified ticket account.
