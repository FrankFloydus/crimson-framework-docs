**Inherits** `RefCounted`

Supplies the completion signal for a directly awaited score submission.

Use `SteamLeaderboards.submit_score()` or `SteamScoreOptions.submit_score()` to start a submission.

## Signals

### `completed`

`completed(result: SteamLeaderboardSubmissionResult)`

Emitted once when score submission and its optional replay stage settle.
