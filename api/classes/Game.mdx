## Signals

### `invite_changed`

`invite_changed(invite: SteamInvite)`

Emitted when the pending offer changes. Null clears the offer.

### `peer_joined`

`peer_joined(peer_id: int)`

Emitted when a peer is admitted.

### `phase_changed`

`phase_changed(phase: int)`

Emitted after the runtime publishes the new phase.

### `session_ended`

`session_ended(reason: StringName)`

Emitted after session retirement.

### `world_ready`

`world_ready(world: StringName, epoch: int)`

Emitted when the runtime publishes a playable world.

## Constants and enums

### `Phase`

| Name | Value | Description |
| --- | --- | --- |
| `IDLE` | `0` | No active gameplay session. |
| `LOBBY` | `1` | Coordinated admission or identity binding. |
| `RECOVERING` | `4` | A post-commit synchronization failure needs recovery. |
| `RUNNING` | `3` | The game world is ready. |
| `TRANSITIONING` | `2` | A world transition is pending. |
