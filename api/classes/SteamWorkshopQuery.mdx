**Inherits** `RefCounted`

Branchable filters and paging for the active app's ready-to-use Workshop items.

## Methods

### `after`

`after(cursor: String) -> SteamWorkshopQuery`

Returns a branch using the exact `SteamWorkshopPage.next_cursor` from the same filters and sort. An empty cursor starts from the first page. `cursor` supports up to 255 UTF-8 bytes.

### `fetch`

`fetch() -> Variant`

Use `await query.fetch()` to receive a [`SteamWorkshopPageResult`](/api/classes/SteamWorkshopPageResult). Requests up to 50 items for the active app. A stopped client settles pending observation with `ERR_SKIP`.

### `search`

`search(text: String) -> SteamWorkshopQuery`

Returns a branch that matches text in item titles or descriptions and starts at the first page. An empty string clears the text filter. `text` supports up to 255 UTF-8 bytes.

### `sort_by`

`sort_by(sort: SteamWorkshopQuery.Sort) -> SteamWorkshopQuery`

Returns a branch with explicit sorting and starts at the first page. Browsing defaults to `RATING`, and a text search defaults to `RELEVANCE`.

### `tagged`

`tagged(tag: String) -> SteamWorkshopQuery`

Returns a branch requiring the additional tag and starts at the first page. A branch supports up to 16 tags, each between 1 and 255 UTF-8 bytes.

## Constants and enums

### `Sort`

| Name | Value | Description |
| --- | --- | --- |
| `NEWEST` | `2` | Sorts items from newest to oldest publication. |
| `RATING` | `1` | Ranks ready-to-use items by Steam vote popularity. |
| `RELEVANCE` | `0` | Ranks matches by text relevance. A search term is required. |
