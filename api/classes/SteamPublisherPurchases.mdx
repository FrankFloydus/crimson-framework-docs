## Description

Resolve with `SteamPublisher.purchases()` and inject `SteamPublisherSettings.purchase_store`. Await each action for its typed result. All order-changing calls operate only on trusted persisted quotes and exact Steam receipts. The backend must authorize caller access to known order IDs before exposing these functions to a client.

### Method details

#### `begin`

`begin(player: SteamIdentity, cart: SteamPurchaseCart, checkout_id: String) -> Variant`

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult). Requires a [`SteamIdentity`](/api/classes/SteamIdentity) verified by the same publisher. Atomically prices and reserves the cart under `checkout_id`, then starts Steam authorization. An uncertain previous initialization is queried without automatically repeating the write.

#### `buyer_info`

`buyer_info(player: SteamIdentity) -> Variant`

Await a [`SteamPurchaseBuyerInfoResult`](/api/classes/SteamPurchaseBuyerInfoResult) with the Steam Wallet country, currency, optional region, and reported account status for `player`. The identity must come from this exact publisher. Uses the configured live or sandbox environment. Read this before quoting a localized price. The game keeps ownership of its catalog, pricing, and eligibility policy.

#### `finalize`

`finalize(order_id: String) -> Variant`

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult). Requires an exact Steam query to verify approval before claiming and capturing the charge. Durable fulfillment follows a verified success. An uncertain earlier finalization remains in reconciliation and is never blindly repeated.

#### `query`

`query(order_id: String) -> Variant`

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult) for a known order. Verifies exact Steam payer, transaction, currency and line amounts and persists applicable state changes. An unknown order or invalid receipt returns a typed error.

#### `reconcile`

`reconcile(since_unix: int, max_results: int = 1000) -> Variant`

Await a [`SteamPurchaseReconciliationResult`](/api/classes/SteamPurchaseReconciliationResult) for one bounded settlement page from the inclusive Unix UTC cursor. `max_results` must be from 1 to 1000 and defaults to 1000. A reply larger than 4 MiB fails validation. Applies known receipts and exact item reversals in order. A failing event leaves the original cursor available for replay. A full page whose last timestamp equals the input cursor returns `ERR_BUSY`.

#### `refund`

`refund(order_id: String) -> Variant`

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult). Queries and requests a full refund only for a known fulfilled order and an explicit store policy approval. Reversal requires a confirmed receipt and durable update. Partial Steam-originated reversals are handled by `reconcile()`.
