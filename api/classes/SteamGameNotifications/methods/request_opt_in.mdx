## Return value

[`SteamNotificationBoolOperation`](/api/classes/SteamNotificationBoolOperation)

## Description

Reuse `launch_id` across authentication refreshes within a launch and issue a fresh ID on the next game launch. Use 1 to 128 ASCII letters, digits, hyphens, underscores, periods, or colons. A missing ID returns `ERR_INVALID_PARAMETER`. A claimed launch returns `ERR_ALREADY_IN_USE`, including after an ambiguous Steam reply. Implement the launch claim hooks in [`SteamNotificationStore`](/api/classes/SteamNotificationStore). A true receipt means Steam accepted registration. Steam controls the opt-in prompt and decision.
