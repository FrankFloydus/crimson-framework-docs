**Inherits** `RefCounted`

Stores nonnegative integer amounts for positive actor IDs and nonempty StringName currency IDs. Its batch operation can pair balance updates with a synchronous commit. Implement both virtual methods if your game stores balances elsewhere.

## Methods

### `_apply_balance_changes`

`_apply_balance_changes(changes: Dictionary[], commit: Callable) -> Error`

**Virtual method.**

Override to commit balances in a game-owned store. Verify expected amounts, stage all updates, invoke the supplied commit callable synchronously when present, and restore the previous balances if it returns an error.

### `_get_balance`

`_get_balance(actor: int, currency: StringName) -> int`

**Virtual method.**

Override to read the authoritative integer amount for the actor and currency. Return 0 when no balance is recorded.

### `apply_balance_changes`

`apply_balance_changes(changes: Array, commit: Callable = Callable()) -> Error`

Compare and update a batch of dictionaries with `actor`, `currency`, `before`, and `after`. A stale expected balance returns `ERR_BUSY`. Stage the full batch before the optional no-argument commit callback. A callback error rolls all balances back.

### `get_balance`

`get_balance(actor: int, currency: StringName) -> int`

Return the current integer amount for the actor and currency, or 0 when no balance is recorded by the default store.

### `set_balance`

`set_balance(actor: int, currency: StringName, amount: int) -> Error`

Set a single balance through the expected-value batch operation. Amounts must be nonnegative, and setting 0 clears the stored amount in the default wallet.
