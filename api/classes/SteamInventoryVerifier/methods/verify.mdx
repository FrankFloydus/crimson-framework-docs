## Description

A successful snapshot contains up to 256 selected items at the signed timestamp and uses `SteamInventorySnapshot.FRESHNESS_VERIFIED_PROOF`. Invalid arguments return `ERR_INVALID_PARAMETER`. An unavailable game server returns `ERR_UNAVAILABLE`. A rejected signature or malformed result returns `ERR_INVALID_DATA`. An expired proof or verification deadline returns `ERR_TIMEOUT`. An owner or admission mismatch returns `ERR_UNAUTHORIZED`. A retired observation returns `ERR_SKIP`.
