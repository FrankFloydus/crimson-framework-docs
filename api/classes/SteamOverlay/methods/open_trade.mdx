## Parameters

| Parameter | Type | Default |

| `partner_steam_id` | `String` | — |

## Return value

`Error`

## Description

Call it after the game's authorized backend has started an existing Steam trading session with that individual account.

## Example

```gdscript
extends Node

func run_open_trade(
    steam_client: SteamClient,
    partner_steam_id: String,
    status_label: Label
) -> void:
    if not steam_client.is_ready():
        return
    var steam_overlay: SteamOverlay = steam_client.overlay()
    if steam_overlay == null:
        return
    var result: Error = steam_overlay.open_trade(partner_steam_id)
    if result != OK:
        status_label.text = error_string(result)
        return
    status_label.text = "Open trade accepted."
```
