## Signature

```text
is_ready() -> bool
```

## Return value

`bool`

## Description

It may remain false during graphics startup, with the overlay disabled, or in a headless process.

## Example

```gdscript
extends Node

func run_is_ready(steam_client: SteamClient, action_button: Button) -> void:
    if not steam_client.is_ready():
        return
    var steam_overlay: SteamOverlay = steam_client.overlay()
    if steam_overlay == null:
        return
    var result: bool = steam_overlay.is_ready()
    action_button.disabled = not result
```
