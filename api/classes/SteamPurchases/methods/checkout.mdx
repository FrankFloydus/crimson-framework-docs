## Parameters

| Parameter | Type | Default |
| --- | --- | --- |

## Return value

`Variant`

Await the call to receive [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult).

## Description

A pending receipt can be refreshed later by order ID. A failed local observation retains the checkout ID.

## Example

```gdscript
extends Node

func run_checkout(
    steam_scope: SteamScope,
    cart: SteamPurchaseCart,
    apply_checkout: Callable
) -> void:
    if not steam_scope.is_ready():
        return
    var steam_purchases: SteamPurchases = steam_scope.purchases()
    if steam_purchases == null:
        return
    var result: SteamPurchaseOutcomeResult = await steam_purchases.checkout(cart)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamPurchaseOutcome = result.value
    if payload == null:
        return
    apply_checkout.call(payload)
```
