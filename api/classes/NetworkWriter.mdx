## Description

Create a writer with `create()`, write fields in schema order, then seal the payload with `finish()`. Integers and floats use fixed widths and little-endian byte order. A string or byte array starts with an unsigned 32-bit byte length. The first error prevents later writes. This class writes payload bytes for a game-selected transport or storage path.
