**Inherits** `RefCounted`

Reads platform and overlay state from Steam.

Get this service from `SteamClient.utils()`. Hardware, language, and overlay queries read Steam's current client state.

## Methods

### `hardware_default_config`

`hardware_default_config() -> SteamUtils.HardwareDefaultConfig`

Returns Steam's suggested starting preset for this game and device. Use it when choosing initial settings and let players retain their own settings. Returns `CONFIG_UNAVAILABLE` when Steam cannot supply the query.

### `hardware_type`

`hardware_type() -> SteamUtils.HardwareType`

Returns the Steam-reported hardware type. Returns `HARDWARE_UNAVAILABLE` when Steam cannot supply the query.

### `is_available`

`is_available() -> bool`

Returns whether the active client exposes the Steam Utils interface on the main thread.

### `is_overlay_ready`

`is_overlay_ready() -> bool`

Returns whether the Steam overlay is available to this process now. Check again before requesting an overlay action after startup.

### `is_running_in_vr`

`is_running_in_vr() -> bool`

Returns whether Steam reports that the Steam client is running in VR mode. Returns `false` when the query is unavailable.

### `is_running_under_proton`

`is_running_under_proton() -> bool`

Returns whether Steam reports that the game process is running under Proton. Returns `false` when the query is unavailable.

### `ui_language`

`ui_language() -> String`

Returns the Steam client's interface language code, or an empty string when unavailable. For the selected game language, use `SteamApps.current_language()`.
