**Inherits** `RefCounted`

## Description

Open a payload with `open()`, read fields in the order the writer used, and check `finish()` before accepting the decoded values. Integers and floats use fixed widths and little-endian byte order. Each failed read records an error and later reads return neutral values. A field value of zero or an empty string can be valid.

## Methods

### Static methods

#### [`open`](/api/classes/NetworkReader/methods/open)

Open bytes with a payload budget from 0 through 1,048,576 bytes.

### Instance methods

#### [`fail`](/api/classes/NetworkReader/methods/fail)

Record a schema validation error when the fields are readable but the decoded values are invalid for the game.

#### [`finish`](/api/classes/NetworkReader/methods/finish)

Return `OK` when every byte was consumed without errors.

#### [`get_error`](/api/classes/NetworkReader/methods/get_error)

Return the first reader error, or `OK` without checking for trailing bytes.

#### [`get_remaining`](/api/classes/NetworkReader/methods/get_remaining)

Return the number of payload bytes that have not been consumed.

#### [`read_bool`](/api/classes/NetworkReader/methods/read_bool)

Read one byte, with 0 for false and 1 for true.

#### [`read_bytes`](/api/classes/NetworkReader/methods/read_bytes)

Read a byte array preceded by its unsigned 32-bit length.

#### [`read_f32`](/api/classes/NetworkReader/methods/read_f32)

#### [`read_f64`](/api/classes/NetworkReader/methods/read_f64)
