## Methods

### Instance methods

#### [`configure`](/api/classes/SpatialInventoryEquipment/methods/configure)

Associate a configured backpack with an ordered list of 1 to 64 unique, nonempty slot IDs.

#### [`equip`](/api/classes/SpatialInventoryEquipment/methods/equip)

Equip a backpack item in the requested slot and return displaced equipment to the backpack in the same commit.

#### [`export_snapshot`](/api/classes/SpatialInventoryEquipment/methods/export_snapshot)

Return a version 1 snapshot with `version` and `items`.

#### [`get_equipped`](/api/classes/SpatialInventoryEquipment/methods/get_equipped)

Return a detached record for an equipped item ID, or an empty dictionary for an unknown ID.

#### [`get_equipped_items`](/api/classes/SpatialInventoryEquipment/methods/get_equipped_items)

Return detached equipped records in primary-slot order.

#### [`get_slot_ids`](/api/classes/SpatialInventoryEquipment/methods/get_slot_ids)

Return the configured slot IDs in their display order.

#### [`get_slot_item`](/api/classes/SpatialInventoryEquipment/methods/get_slot_item)

Return the ID occupying the requested slot, or an empty StringName for an empty or unknown slot.

#### [`import_snapshot`](/api/classes/SpatialInventoryEquipment/methods/import_snapshot)

Validate and restore equipped records into an empty equipment model with its backpack and slot rules already configured.

#### [`preview_equip`](/api/classes/SpatialInventoryEquipment/methods/preview_equip)

Plan equipping the item and returning any displaced equipment without mutating the models.

#### [`preview_unequip`](/api/classes/SpatialInventoryEquipment/methods/preview_unequip)

Plan a backpack placement for the item occupying the slot. `Vector2i(-1, -1)` selects first fit, and null rotation keeps the item's stored orientation.

#### [`unequip`](/api/classes/SpatialInventoryEquipment/methods/unequip)

Return the item occupying the requested slot to the backpack.
