**Inherits** `RefCounted`

Equipment slots backed by a [`SpatialInventory`](/api/classes/SpatialInventory) backpack. An item can occupy several slots while keeping a single equipped record. Preview an action before committing it when the player needs to review the displaced gear or destination.

## Methods

### `configure`

`configure(source: SpatialInventory, slot_ids: Array) -> Error`

Associate a configured backpack with an ordered list of 1 to 64 unique, nonempty slot IDs. Reconfiguration with different slots or a different backpack returns `ERR_BUSY` while items are equipped.

### `equip`

`equip(id: StringName, slot: StringName, expected: Dictionary = {}) -> Dictionary`

Equip a backpack item in the requested slot and return displaced equipment to the backpack in the same commit. Supply a preview as `expected` to reject a stale result with `ERR_BUSY`. Inspect `error` and `committed` in the result.

### `export_snapshot`

`export_snapshot() -> Dictionary`

Return a version 1 snapshot with `version` and `items`. Persist it alongside the backpack and your item records.

### `get_backpack`

`get_backpack() -> SpatialInventory`

Return the configured backpack, or null before configuration.

### `get_equipped`

`get_equipped(id: StringName) -> Dictionary`

Return a detached record for an equipped item ID, or an empty dictionary for an unknown ID.

### `get_equipped_items`

`get_equipped_items() -> Dictionary[]`

Return detached equipped records in primary-slot order. An item occupying multiple slots appears once.

### `get_move_policy`

`get_move_policy() -> Callable`

Return the optional rule for equips, unequips, and returns of displaced items.

### `get_revision`

`get_revision() -> int`

Return the current revision of committed equipment state.

### `get_slot_ids`

`get_slot_ids() -> StringName[]`

Return the configured slot IDs in their display order.

### `get_slot_item`

`get_slot_item(slot: StringName) -> StringName`

Return the ID occupying the requested slot, or an empty StringName for an empty or unknown slot.

### `get_slot_requirements`

`get_slot_requirements() -> Callable`

Return the callback that supplies all occupied slots for the requested equip.

### `import_snapshot`

`import_snapshot(snapshot: Dictionary) -> Error`

Validate and restore equipped records into an empty equipment model with its backpack and slot rules already configured. Invalid data leaves the model unchanged.

### `preview_equip`

`preview_equip(id: StringName, slot: StringName) -> Dictionary`

Plan equipping the item and returning any displaced equipment without mutating the models. The result includes `error`, `reason`, `slots`, `displaced`, placement `changes`, and both model revisions.

### `preview_unequip`

`preview_unequip(slot: StringName, origin: Vector2i = Vector2i(-1, -1), rotated: Variant = null) -> Dictionary`

Plan a backpack placement for the item occupying the slot. `Vector2i(-1, -1)` selects first fit, and null rotation keeps the item's stored orientation.

### `set_move_policy`

`set_move_policy(value: Callable) -> void`

Set a callback that can deny equipment moves, including returns for displaced items. Return an empty string to allow the move or a reason to deny it.

### `set_slot_requirements`

`set_slot_requirements(value: Callable) -> void`

Set a callback taking the item ID and requested slot. Return the full array of occupied slots, including the requested slot, or a denial string.

### `unequip`

`unequip(slot: StringName, origin: Vector2i = Vector2i(-1, -1), rotated: Variant = null, expected: Dictionary = {}) -> Dictionary`

Return the item occupying the requested slot to the backpack. Pass the preview in `expected` to require that the reviewed placement still matches before commit.
