## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `beacon` | [`SteamPartyListing`](/api/classes/SteamPartyListing) | — |

## Return value

`Variant`

Await the call to receive [`SteamListingResult`](/api/classes/SteamListingResult).

## Description

Steam reserves a seat and returns an owner-bound locator for `GameRuntime.join_listing()`. Game admission still verifies the live lobby owner and rules. An abandoned reservation expires on the host.

## Example

```gdscript
extends Node

func run_reserve(
    steam_client: SteamClient,
    beacon: SteamPartyListing,
    name_label: Label
) -> void:
    if not steam_client.is_ready():
        return
    var steam_parties: SteamParties = steam_client.parties()
    if steam_parties == null:
        return
    var result: SteamListingResult = await steam_parties.reserve(beacon)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamListing = result.value
    if payload == null:
        return
    var name: String = payload.name
    name_label.text = "Name: %s" % str(name)
```
