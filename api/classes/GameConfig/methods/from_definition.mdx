## Example

### Start a world from an existing game definition

Boot from your existing definition and start its saved world offline. [Move an existing project to code-first actions](/migration#keep-a-saved-game-definition)

```gdscript
extends Node

@export var previous_definition: GameDefinition


func _ready() -> void:
    if previous_definition == null:
        push_error("Assign the existing game definition before starting.")
        return

    var game: Game = GameConfig.from_definition(previous_definition).boot(self)
    var started: GameResult = await game.play()
    if not started.ok:
        push_error(started.message)
        return

    print("The saved starting world is ready.")
```
