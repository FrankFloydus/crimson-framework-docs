## Return value

[`GameConfig`](/api/classes/GameConfig)

## Description

Omit `profile` to read movement settings from one [`MoverComponent`](/api/classes/MoverComponent) directly under the player scene's `CharacterBody3D` root. Boot reports invalid or missing scene setup through `Game.boot_result()`. Supply an explicit profile to use its movement settings instead. Enable prediction on compatible grounded capsules for client prediction and server reconciliation against immutable static collision. Use compatible player scenes and the same movement protocol on each peer. The authority captures movement rules and speed at boot. Attach local input through a [`ControlsComponent`](/api/classes/ControlsComponent) or [`PlayerControlProfile`](/api/classes/PlayerControlProfile) when the world is ready.
