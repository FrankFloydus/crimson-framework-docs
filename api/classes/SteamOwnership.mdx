## Description

The trusted publisher issues this receipt after decryption, ownership checks, and atomic consumption of the exact outstanding backend challenge. Verification accepts tickets up to five minutes old with up to 30 seconds of forward clock skew. The challenge store also enforces the backend's challenge expiry. The receipt represents the ticket's entitlement snapshot.
