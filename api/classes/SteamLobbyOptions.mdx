## Methods

### Static methods

#### [`configure`](/api/classes/SteamLobbyOptions/methods/configure)

### Instance methods

#### [`for_players`](/api/classes/SteamLobbyOptions/methods/for_players)

Return a branch with 1 to 65 member seats, including the creator.

#### [`in_namespace`](/api/classes/SteamLobbyOptions/methods/in_namespace)

Return a branch with a matchmaking namespace of 1 to 64 ASCII letters, numbers, underscores or hyphens.

#### [`with_visibility`](/api/classes/SteamLobbyOptions/methods/with_visibility)

Return a branch with the selected Steam lobby visibility.

## Constants and enums

### `Visibility`

| Name | Value | Description |
| --- | --- | --- |
| `FRIENDS_ONLY` | `1` | Steam friends and invitees can join. |
| `INVISIBLE` | `3` | Compatible searches can find the lobby without Steam friends visibility. |
| `PRIVATE` | `0` | Steam invitees can join. |
| `PUBLIC` | `2` | Steam clients can find the lobby in compatible searches. |
