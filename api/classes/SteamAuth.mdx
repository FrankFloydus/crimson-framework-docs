## Description

Use `SteamClient.auth()` after boot. Local observation expires after 15 seconds. The client cancels Web API handles at scope shutdown. The native encrypted ticket reservation stays active until Steam delivers its result.

## Methods

### `ownership_ticket`

`ownership_ticket(challenge: PackedByteArray) -> Variant`

Await a [`SteamOwnershipTicketResult`](/api/classes/SteamOwnershipTicketResult) containing an encrypted app ticket for the backend's 1-to-1024-byte challenge. Steam allows one pending request across client scopes and enforces its own rate limit.

### `web_ticket`

`web_ticket(audience: String) -> Variant`

Await a [`SteamWebTicketResult`](/api/classes/SteamWebTicketResult) for the named service. Use a nonempty audience of at most 255 UTF-8 bytes without ASCII control characters. The backend must verify the same audience and AppID.
