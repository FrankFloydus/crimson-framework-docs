## Return value

[`GameTransaction`](/api/classes/GameTransaction)

## Description

Returns `null` if called from another thread, during protected mutation, or with an unsupported context.

## Example

```gdscript
extends Node

func run_begin(game_runtime: GameRuntime, context: Dictionary, apply_begin: Callable) -> void:
    var transaction_coordinator: TransactionCoordinator = game_runtime.get_transactions()
    if transaction_coordinator == null:
        return
    var result: GameTransaction = transaction_coordinator.begin(context)
    if result == null:
        return
    apply_begin.call(result)
```
