## Description

Returns an empty dictionary for an unknown store or when called from another thread.

## Example

```gdscript
extends Node

func run_read_store(
    game_runtime: GameRuntime,
    store_id: String,
    apply_read_store: Callable
) -> void:
    var transaction_coordinator: TransactionCoordinator = game_runtime.get_transactions()
    if transaction_coordinator == null:
        return
    var result: Dictionary = transaction_coordinator.read_store(store_id)
    if result.is_empty():
        return
    apply_read_store.call(result)
```
