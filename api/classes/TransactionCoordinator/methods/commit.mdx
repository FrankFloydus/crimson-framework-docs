## Parameters

| Parameter | Type | Default |
| --- | --- | --- |

## Return value

`Dictionary`

## Description

Checks each expected store revision, prepares candidates, validates them, and publishes every changed store before notification. Returns `ok`, `code`, `message`, and `revision`. A failed evaluation consumes the submitted transaction and leaves all committed states and revisions intact.

## Example

```gdscript
extends Node

func run_commit(
    game_runtime: GameRuntime,
    transaction: GameTransaction,
    apply_commit: Callable
) -> void:
    var transaction_coordinator: TransactionCoordinator = game_runtime.get_transactions()
    if transaction_coordinator == null:
        return
    var result: Dictionary = transaction_coordinator.commit(transaction)
    if result.is_empty():
        return
    apply_commit.call(result)
```
