**Inherits** `RefCounted`

## Description

Get a board from a successful `SteamLeaderboards.find()` or `SteamLeaderboards.find_or_create()` result. Read operations settle through [`SteamLeaderboardPageOperation`](/api/classes/SteamLeaderboardPageOperation). Score upload and attachment share a process-local write reservation. The board expires with the scope that found it.

## Methods

### Instance methods

#### [`around_user`](/api/classes/SteamLeaderboard/methods/around_user)

Fetches a range around the signed-in user's score. `before` and `after` are nonnegative counts and the requested page, including the center, is at most 100 entries.

#### [`attach_ugc`](/api/classes/SteamLeaderboard/methods/attach_ugc)

Attaches an existing Steam Remote Storage shared-file handle to the signed-in user's score.

#### [`entries`](/api/classes/SteamLeaderboard/methods/entries)

Fetches a page starting at the one-based global `first_rank`. `count` must be between 1 and 100.

#### [`friends`](/api/classes/SteamLeaderboard/methods/friends)

Fetches up to `limit` entries from Steam's friends view for the signed-in account.

#### [`is_available`](/api/classes/SteamLeaderboard/methods/is_available)

Returns whether this handle still belongs to an active client scope with leaderboard access.

#### [`metadata`](/api/classes/SteamLeaderboard/methods/metadata)

Returns the detached [`SteamLeaderboardInfo`](/api/classes/SteamLeaderboardInfo) when the read succeeds.

#### [`upload`](/api/classes/SteamLeaderboard/methods/upload)

Uploads the signed-in user's signed 32-bit score with up to 64 optional signed 32-bit details.
