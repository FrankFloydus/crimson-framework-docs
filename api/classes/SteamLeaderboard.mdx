**Inherits** `RefCounted`

Reads or updates one leaderboard in an active Steam client scope.

Get a board from a successful `SteamLeaderboards.find()` or `SteamLeaderboards.find_or_create()` result. Read operations settle through [`SteamLeaderboardPageOperation`](/api/classes/SteamLeaderboardPageOperation). Score upload and attachment share a process-local write reservation. The board expires with the scope that found it.

## Methods

### `around_user`

`around_user(before: int, after: int) -> SteamLeaderboardPageOperation`

Fetches a range around the signed-in user's score. `before` and `after` are nonnegative counts and the requested page, including the center, is at most 100 entries. Results use the same page format as `entries()`.

### `attach_ugc`

`attach_ugc(shared_file_handle: String) -> SteamOperation`

Attaches an existing Steam Remote Storage shared-file handle to the signed-in user's score. Pass the handle as a decimal string. Await the operation to receive a [`SteamResult`](/api/classes/SteamResult). An overlapping score write or attachment returns `@GlobalScope.ERR_BUSY`.

### `entries`

`entries(first_rank: int, count: int) -> SteamLeaderboardPageOperation`

Fetches a page starting at the one-based global `first_rank`. `count` must be between 1 and 100. Await the operation to receive a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult) containing a [`SteamLeaderboardPage`](/api/classes/SteamLeaderboardPage) on success.

### `friends`

`friends(limit: int = 100) -> SteamLeaderboardPageOperation`

Fetches up to `limit` entries from Steam's friends view for the signed-in account. The limit is between 1 and 100. Results use the same page format as `entries()`.

### `is_available`

`is_available() -> bool`

Returns whether this handle still belongs to an active client scope with leaderboard access.

### `metadata`

`metadata() -> SteamLeaderboardInfoResult`

Returns the detached [`SteamLeaderboardInfo`](/api/classes/SteamLeaderboardInfo) when the read succeeds. The result reports `@GlobalScope.ERR_UNAVAILABLE` after the board scope stops.

### `upload`

`upload(score: int, details: PackedInt32Array = PackedInt32Array(), force_update: bool = false) -> SteamScoreUploadOperation`

Uploads the signed-in user's signed 32-bit score with up to 64 optional signed 32-bit details. Steam keeps the best score by default. Set `force_update` to replace it. Await a [`SteamScoreUploadResult`](/api/classes/SteamScoreUploadResult) for the typed score receipt. An overlapping write returns `@GlobalScope.ERR_BUSY`.
