## Return value

`Error`

## Description

Defaults to reliable ordered delivery. `OK` confirms local queue acceptance. Pending binding proof can queue up to eight reliable frames and 16 KiB. A remote binding change drops queued packets from the previous binding. Unreliable sends return `ERR_BUSY` until the exact binding is proven. An unconfigured channel returns `ERR_UNAUTHORIZED`.
