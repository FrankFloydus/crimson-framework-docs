## Description

Read through `SteamPublisherPurchases.buyer_info()` before preparing a localized quote. The purchasing status is advisory. The backend must apply its own eligibility and pricing policy.

## Properties

**[`account_status`](/api/classes/SteamPurchaseBuyerInfo/properties/account_status)**

Purchasing status reported by Steam.

**[`country`](/api/classes/SteamPurchaseBuyerInfo/properties/country)**

Two-letter uppercase ISO 3166-1 country code used to choose a local price.

**[`currency`](/api/classes/SteamPurchaseBuyerInfo/properties/currency)**

Three-letter uppercase ISO 4217 Steam Wallet currency code used to quote a purchase.

**[`region`](/api/classes/SteamPurchaseBuyerInfo/properties/region)**

State or region Steam supplied, or an empty string when unavailable.
