## Description

Get this service from `SteamClient.leaderboards()`. Board handles and pending operations belong to this client scope.

## Methods

### Instance methods

#### [`find`](/api/classes/SteamLeaderboards/methods/find)

Looks up an existing leaderboard by its Steam API `name`.

#### [`find_or_create`](/api/classes/SteamLeaderboards/methods/find_or_create)

Looks up a board by its Steam API `name`, or creates it using `sort` and `display`.

#### [`friends`](/api/classes/SteamLeaderboards/methods/friends)

Looks up the existing board and fetches up to `count` rows from the signed-in account's friends view.

#### [`is_available`](/api/classes/SteamLeaderboards/methods/is_available)

Returns whether the active scope exposes Steam leaderboards on the main thread.

#### [`query`](/api/classes/SteamLeaderboards/methods/query)

Returns a branchable read for the existing Steam board named `board_name`.

#### [`submit_score`](/api/classes/SteamLeaderboards/methods/submit_score)

Submits the signed 32-bit score to an existing board using keep-best.

#### [`top`](/api/classes/SteamLeaderboards/methods/top)

Looks up `board_name` and fetches the first `count` global ranks.

#### [`with_details`](/api/classes/SteamLeaderboards/methods/with_details)

Starts score options with these game-defined details.

#### [`with_replay`](/api/classes/SteamLeaderboards/methods/with_replay)

Starts score options with a requested replay attachment.

## Constants and enums

### `Display`

| Name | Value | Description |
| --- | --- | --- |
| `MILLISECONDS` | `3` | Displays scores as durations in milliseconds. |
| `NUMERIC` | `1` | Displays scores as plain signed numbers. |
| `SECONDS` | `2` | Displays scores as durations in seconds. |

### `Sort`

| Name | Value | Description |
| --- | --- | --- |
| `ASCENDING` | `1` | Lower scores rank first. |
| `DESCENDING` | `2` | Higher scores rank first. |
