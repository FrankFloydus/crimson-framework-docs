**Inherits** `RefCounted`

Finds and reads leaderboards for the current Steam app.

Get this service from `SteamClient.leaderboards()`. Board handles and pending operations belong to this client scope.

## Methods

### `find`

`find(name: String) -> SteamLeaderboardOperation`

Looks up an existing leaderboard by its Steam API `name`. On success, the typed result contains a [`SteamLeaderboard`](/api/classes/SteamLeaderboard). An unknown board returns `@GlobalScope.ERR_DOES_NOT_EXIST`.

### `find_or_create`

`find_or_create(name: String, sort: SteamLeaderboards.Sort = 2, display: SteamLeaderboards.Display = 1) -> SteamLeaderboardOperation`

Looks up a board by its Steam API `name`, or creates it using `sort` and `display`. An existing board keeps its configured settings. On success, the typed result contains the board.

### `friends`

`friends(board_name: String, count: int = 10) -> Variant`

Looks up the existing board and fetches up to `count` rows from the signed-in account's friends view. The count must be between 1 and 100. Use `await` to receive a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult).

### `is_available`

`is_available() -> bool`

Returns whether the active scope exposes Steam leaderboards on the main thread.

### `query`

`query(board_name: String) -> SteamLeaderboardQuery`

Returns a branchable read for the existing Steam board named `board_name`. Defaults to the first ten global ranks. Use `SteamLeaderboardQuery.fetch()` or `SteamLeaderboardQuery.fetch_operation()` to start the read.

### `submit_score`

`submit_score(board_name: String, score: int) -> Variant`

Submits the signed 32-bit score to an existing board using keep-best. Use `await` to receive a [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult). To supply details or a replay, start with `with_details()` or `with_replay()`.

### `top`

`top(board_name: String, count: int = 10) -> Variant`

Looks up `board_name` and fetches the first `count` global ranks. The count must be between 1 and 100. Use `await` to receive a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult). See `query()` for other rank ranges and cancellable queries.

### `with_details`

`with_details(details: PackedInt32Array) -> SteamScoreOptions`

Starts score options with these game-defined details. A submission accepts at most 64 signed 32-bit integers.

### `with_replay`

`with_replay(shared_file_handle: String) -> SteamScoreOptions`

Starts score options with a requested replay attachment. Pass a nonzero decimal Steam Remote Storage handle belonging to the active app.

## Constants and enums

### `Display`

| Name | Value | Description |
| --- | --- | --- |
| `MILLISECONDS` | `3` | Displays scores as durations in milliseconds. |
| `NUMERIC` | `1` | Displays scores as plain signed numbers. |
| `SECONDS` | `2` | Displays scores as durations in seconds. |

### `Sort`

| Name | Value | Description |
| --- | --- | --- |
| `ASCENDING` | `1` | Lower scores rank first. |
| `DESCENDING` | `2` | Higher scores rank first. |
