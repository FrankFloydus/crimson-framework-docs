## Description

Available from `SteamPublisher.game_notifications()` in trusted backend builds. Keep one canonical verified [`SteamIdentity`](/api/classes/SteamIdentity) per authenticated game launch and coordinate launch deduplication across workers. Writes require a [`SteamNotificationStore`](/api/classes/SteamNotificationStore). Operation keys use up to 128 ASCII letters, digits, hyphens, underscores, periods, or colons. The service accepts up to 16 recipients per session and 8 KiB of encoded request JSON. Steam controls notification delivery.
