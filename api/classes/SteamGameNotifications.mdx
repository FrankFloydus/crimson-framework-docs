**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

Trusted app-scoped Steam asynchronous notifications.

Available from `SteamPublisher.game_notifications()` in trusted backend builds. Keep one canonical verified [`SteamIdentity`](/api/classes/SteamIdentity) per authenticated game launch and coordinate launch deduplication across workers. Writes require a [`SteamNotificationStore`](/api/classes/SteamNotificationStore). Operation keys use up to 128 ASCII letters, digits, hyphens, underscores, periods, or colons. The service accepts up to 16 recipients per session and 8 KiB of encoded request JSON. Steam controls notification delivery.

## Methods

### `create`

`create(spec: SteamNotificationSessionSpec, operation_key: String) -> SteamNotificationSessionOperation`

Creates an app-owned session from verified participants. Reuse the same immutable operation key to replay an accepted, committed response.

### `details`

`details(session_id: String) -> SteamNotificationSessionOperation`

Requests one exact session owned by this app in the trusted store.

### `remove`

`remove(session_id: String, operation_key: String) -> SteamNotificationBoolOperation`

Removes an owned session and its notifications through a durable operation. A repeated committed key returns the original acknowledgment.

### `request_opt_in`

`request_opt_in(user: SteamIdentity, launch_id: String = "") -> SteamNotificationBoolOperation`

Requests Steam registration once per verified account and authoritative backend launch ID. Reuse `launch_id` across authentication refreshes within a launch and issue a fresh ID on the next game launch. Use 1 to 128 ASCII letters, digits, hyphens, underscores, periods, or colons. A missing ID returns `ERR_INVALID_PARAMETER`. A claimed launch returns `ERR_ALREADY_IN_USE`, including after an ambiguous Steam reply. Implement the launch claim hooks in [`SteamNotificationStore`](/api/classes/SteamNotificationStore). A true receipt means Steam accepted registration. Steam controls the opt-in prompt and decision.

### `sessions_for`

`sessions_for(user: SteamIdentity) -> SteamNotificationSessionsOperation`

Reads up to 128 sessions returned for a user verified by this exact publisher and app.

### `update`

`update(session_id: String, spec: SteamNotificationSessionSpec, operation_key: String) -> SteamNotificationSessionOperation`

Replaces the full participant state of an owned session. Supply all users who should remain in the session and a stable operation key. The creation context remains as it was.
