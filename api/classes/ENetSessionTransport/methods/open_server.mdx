## Description

Provide a UDP port from 1 to 65535, a remote client limit from 1 to 4095, and either `\*` for all interfaces or a literal bind IP. Invalid input produces ERR\_INVALID\_PARAMETER. Otherwise the result carries the new peer or the ENet startup error.
