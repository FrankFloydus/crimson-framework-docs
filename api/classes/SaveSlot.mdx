**Inherits** `RefCounted`

A handle for one checkpoint slot in a named profile. Obtain it from GameRuntime.save\_slot. The originating GameRuntime must remain in the scene tree for storage operations.

## Methods

### `history`

`history(before_sequence: String = "", before_id: String = "", limit: int = 16) -> GameOperation`

Read a page of committed generations in newest-first order. Leave both cursor values empty for the first page or pass both values from the previous result's next cursor. The page limit is positive and capped at 16. On success, the operation reports the rows in value and the slot status.

### `restore`

`restore(sequence: String, id: String) -> GameOperation`

Load a specific generation from this slot. Pass both the sequence and ID returned by save or history. Await the operation to observe whether the saved scene and stores became active.

### `restore_latest`

`restore_latest() -> GameOperation`

Load the current head of the slot. Await the operation to observe whether the saved scene and stores became active.

### `save`

`save() -> SaveRequest`

Create a SaveRequest for this slot with the slot ID as its default display label. Call submit on the request to queue the save.
