**Inherits** `Node`

Opt-in push-to-talk and authority-routed voice for one Steam game.

Resolve the persistent service with `GameRuntime.voice()`. The game owns input, user consent and playback. Voice uses an unreliable ordered lane for the current mounted world and accepts only authenticated, world-ready participants. The authority filters recipients and limits sender and relay bandwidth. Local mute removes queued playback without changing the sender's access.

## Methods

### `set_channel`

`set_channel(channel: GameVoice.Channel) -> Error`

Selects the requested channel for future local frames. The game authority evaluates the channel and recipient policy before any remote delivery.

### `set_muted`

`set_muted(peer_id: int, muted: bool = true) -> Error`

Mutes or unmutes one remote session-local peer on this client. Muting removes queued frames and ends its displayed speaking state.

### `set_recipient_policy`

`set_recipient_policy(policy: Callable) -> Error`

Configures trusted authority code accepting sender peer ID, recipient peer ID and channel and returning a boolean. An empty callable enables group delivery to eligible peers only. Supply authority-owned team or proximity state when filtering those channels.

### `start_talking`

`start_talking() -> Error`

Requests local microphone capture after explicit opt-in. Requires a ready Steam participant in an online world. An occupied process microphone returns `ERR_BUSY`.

### `stop_talking`

`stop_talking() -> Error`

Stops transmitting immediately and requests native capture stop. Any final native audio is discarded by the capture scope.

## Signals

### `frame_received`

`frame_received(peer_id: int, pcm: SteamVoicePcm)`

Emitted with authorized decoded signed 16-bit mono samples for one remote peer. Feed them to the game's playback queue at the reported rate.

### `talking_changed`

`talking_changed(peer_id: int, talking: bool)`

Emitted when explicit local capture changes or decoded remote audio begins, goes idle, is muted, or leaves the current world.
