**Inherits** `RefCounted`

Steam Remote Play sessions, Together invitations, and optional per-stream input.

Resolve this facade with `SteamClient.remote_play()`. Use it on the main thread. A Remote Play Together host runs the game locally and the game owns seat assignment. Steam merges remote keyboard and mouse input by default. Controller handling stays in the game's local input flow.

## Methods

### `is_available`

`is_available() -> bool`

Return whether this live scope has the Steam Remote Play interface and stream callback routing. The Steam app must enable Together features for invites and separate input.

### `open_together_overlay`

`open_together_overlay() -> Error`

Request Steam's Remote Play Together overlay. Return `OK` if Steam accepts, `ERR_BUSY` if its overlay is still unavailable for display, or `ERR_UNAVAILABLE` if the feature or live scope is unavailable. Use the session signals to observe actual streams.

### `poll_input`

`poll_input(limit: int = 64) -> SteamRemotePlayInputEvent[]`

Return a read-only batch of newly available keyboard and mouse samples. The owner that enabled separate input can consume up to the requested limit, capped at 256. A nonpositive limit or unavailable scope yields an empty batch. Unknown SDK events are skipped.

### `send_invite`

`send_invite(steam_id: String) -> Error`

Submit a Together invitation to an individual friend's decimal SteamID64. A malformed or local ID returns `ERR_INVALID_PARAMETER`. Return `FAILED` when Steam declines the invitation. Successful submission does not indicate that the guest connected.

### `sessions`

`sessions() -> SteamRemotePlaySession[]`

Return a read-only snapshot of currently connected Remote Play streams. An empty list is valid when nobody is connected. Use `is_available()` to distinguish unavailable observation.

### `set_separate_input`

`set_separate_input(enabled: bool) -> Error`

Enable separate Together keyboard and mouse input for this scope, or restore Steam's merged input. Return `ERR_BUSY` while another scope owns the process input mode. Stopping the owner also restores merged input.

## Signals

### `session_connected`

`session_connected(session: SteamRemotePlaySession)`

Emitted when Steam reports a connected stream. Use its session ID to assign or restore a local seat.

### `session_disconnected`

`session_disconnected(session_id: int)`

Emitted when Steam reports a disconnected stream. Release that seat and clear any held input.
