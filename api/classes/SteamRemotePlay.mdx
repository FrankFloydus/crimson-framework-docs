## Description

Resolve this facade with `SteamClient.remote_play()`. Use it on the main thread. A Remote Play Together host runs the game locally and the game owns seat assignment. Steam merges remote keyboard and mouse input by default. Controller handling stays in the game's local input flow.

## Methods

### Instance methods

#### [`is_available`](/api/classes/SteamRemotePlay/methods/is_available)

#### [`set_separate_input`](/api/classes/SteamRemotePlay/methods/set_separate_input)

Enable separate Together keyboard and mouse input for this scope, or restore Steam's merged input.

## Signals

### `session_connected`

`session_connected(session: SteamRemotePlaySession)`

Emitted when Steam reports a connected stream. Use its session ID to assign or restore a local seat.

### `session_disconnected`

`session_disconnected(session_id: int)`

Emitted when Steam reports a disconnected stream. Release that seat and clear any held input.
