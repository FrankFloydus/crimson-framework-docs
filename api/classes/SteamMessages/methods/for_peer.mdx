
## Parameters

| Parameter | Type | Default |

## Return value

[`SteamMessagePeerResult`](/api/classes/SteamMessagePeerResult)

## Description

A guest resolves its authority. An authority resolves its admitted world-ready peers. The binding expires when the participant or current epoch retires.

## Example

```gdscript
extends Node

func run_for_peer(steam_scope: SteamScope, peer_id: int, apply_for_peer: Callable) -> void:
    if not steam_scope.is_ready():
        return
    var steam_messages: SteamMessages = steam_scope.messages()
    if steam_messages == null:
        return
    var result: SteamMessagePeerResult = steam_messages.for_peer(peer_id)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamMessagePeer = result.value
    if payload == null:
        return
    apply_for_peer.call(payload)
```
