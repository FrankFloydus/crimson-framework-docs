**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

Verifies Steam Web API tickets and current ownership on the trusted backend.

Get this scoped service from `SteamPublisher.auth()`. The backend supplies its expected service audience and keeps ticket bytes out of logs and saved data.

## Methods

### `owns_app`

`owns_app(identity: SteamIdentity, app_id: int) -> Variant`

Checks Steam's current license for an identity minted by this exact publisher. Use `await` to receive [`SteamAppOwnershipResult`](/api/classes/SteamAppOwnershipResult). A negative license is a successful query with `SteamAppOwnership.owns_app` false.

### `verify`

`verify(ticket_bytes: PackedByteArray, audience: String) -> Variant`

Sends the configured AppID, exact `audience`, and hex-encoded ticket to Valve. Use `await` to receive [`SteamIdentityResult`](/api/classes/SteamIdentityResult). Only an accepted ticket with a valid individual SteamID issues an identity.

### `verify_ownership`

`verify_ownership(ticket: PackedByteArray, expected_challenge: PackedByteArray, dlc_ids: PackedInt64Array = PackedInt64Array()) -> SteamOwnershipResult`

Verifies an encrypted app ticket locally against the configured AppID, exact `expected_challenge`, and optional DLC AppIDs. Checks the fresh ticket and consumes the one-time challenge through the trusted store before issuing an identity. Returns a typed error for invalid tickets, replay, or unavailable configuration.
