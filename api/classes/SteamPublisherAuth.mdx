## Description

Get this scoped service from `SteamPublisher.auth()`. The backend supplies its expected service audience and keeps ticket bytes out of logs and saved data.

## Methods

### Instance methods

#### [`owns_app`](/api/classes/SteamPublisherAuth/methods/owns_app)

Checks Steam's current license for an identity minted by this exact publisher.

#### [`verify`](/api/classes/SteamPublisherAuth/methods/verify)

Sends the configured AppID, exact `audience`, and hex-encoded ticket to Valve.

#### [`verify_ownership`](/api/classes/SteamPublisherAuth/methods/verify_ownership)

Verifies an encrypted app ticket locally against the configured AppID, exact `expected_challenge`, and optional DLC AppIDs.
