## Signature

```text
dlc() -> SteamDlcListResult
```

## Return value

[`SteamDlcListResult`](/api/classes/SteamDlcListResult)

## Description

Steam may limit which entries it reports. Use known DLC AppIDs for required content. The `SteamDlcInfo.available` flag describes visibility on the Steam store.

## Example

```gdscript
extends Node

func run_dlc(steam_client: SteamClient, results_list: ItemList) -> void:
    if not steam_client.is_ready():
        return
    var steam_apps: SteamApps = steam_client.apps()
    if steam_apps == null:
        return
    var result: SteamDlcListResult = steam_apps.dlc()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: Array[SteamDlcInfo] = result.value
    results_list.clear()
    for entry: SteamDlcInfo in payload:
        results_list.add_item(str(entry.display_name))
```
