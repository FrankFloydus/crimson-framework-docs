## Description

Use the session ID to associate a stream with a game-owned local player seat. Take a fresh snapshot when current device information is needed.

## Properties

**[`client_size`](/api/classes/SteamRemotePlaySession/properties/client_size)**

Reported streaming client's display resolution in pixels, or zero in both dimensions when Steam has no resolution.

**[`session_id`](/api/classes/SteamRemotePlaySession/properties/session_id)**

Steam's transient stream ID.

**[`steam_id`](/api/classes/SteamRemotePlaySession/properties/steam_id)**

Decimal SteamID64, or an empty string when Steam has no individual account ID for the guest.

**[`together`](/api/classes/SteamRemotePlaySession/properties/together)**

Whether the stream was created using a Remote Play Together invitation.
