## Parameters

| Parameter | Type | Default |
| --- | --- | --- |

| `bind_address` | `String` | `"*"` |

## Return value

[`GameOperation`](/api/classes/GameOperation)

## Description

Supply the advertised address, or an empty string for a provider that supplies a route. The operation completes after the world is ready and the provider publishes its listing.

## Example

```gdscript
func host_steam_game(game: GameRuntime) -> void:
    # Attach the game with multiplayer rules, world spawn points, and a ready Steam provider.
    var result: Dictionary = await game.host_online().wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Lobby listing: ", game.get_online_listing())
```
