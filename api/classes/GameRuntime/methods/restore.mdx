## Description

Leave sequence and generation\_id empty to restore the latest generation, or supply both for an exact restore.

## Example

```gdscript
const PLAYER_PROFILE: String = "player-1"
const CAMPAIGN_SLOT: String = "campaign"

func continue_campaign(game: GameRuntime) -> void:
    # Request this on the authority with the saved world's definition registered.
    var result: Dictionary = await game.restore(PLAYER_PROFILE, CAMPAIGN_SLOT).wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Restored world: ", game.get_world_id())
```
