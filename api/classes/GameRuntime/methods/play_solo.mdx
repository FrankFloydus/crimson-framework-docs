## Description

Await the operation before accessing the mounted world or player.

## Example

```gdscript
func enter_solo_game(game: GameRuntime) -> void:
    var result: Dictionary = await game.play_solo().wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Player ready: ", game.get_local_player().name)
```
