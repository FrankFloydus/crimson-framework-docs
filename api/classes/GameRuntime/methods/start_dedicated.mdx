## Description

All configured player seats are available to guests. Await the operation for world and admission readiness.

## Example

```gdscript
const LOCAL_ADDRESS: String = "127.0.0.1"

func start_local_dedicated_server(game: GameRuntime) -> void:
    # The game definition must be configured for multiplayer.
    var result: Dictionary = await game.start_dedicated(LOCAL_ADDRESS).wait()
    if not result.ok:
        push_error(result.message)
        return
    print("The dedicated server can accept guests.")
```
