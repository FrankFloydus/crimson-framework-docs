## Signature

```text
host(port: int, max_clients: int = 32, bind_address: String = "*") -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `port` | `int` | — |
| `max_clients` | `int` | `32` |
| `bind_address` | `String` | `"*"` |

## Return value

`Error`

## Description

With ENet, port is the UDP port and \* binds all interfaces. A successful return opens the lobby for admission and player binding before start\_match.

## Example

```gdscript
extends Node
```
