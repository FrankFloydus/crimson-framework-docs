## Description

The operation succeeds after the world and local player are ready and the host can admit guests. Use \* to bind all interfaces.

## Example

```gdscript
const LOCAL_ADDRESS: String = "127.0.0.1"

# Attach the game with multiplayer rules and the required world spawn points first.
func host_for_local_testing(game: GameRuntime) -> void:
    var result: Dictionary = await game.host_game(LOCAL_ADDRESS).wait()
    if not result.ok:
        push_error(result.message)
        return
    print("The local host is ready.")
```
