## Return value

`Error`

## Description

The callback receives the peer ID, player ID, world epoch, and committed revision. Return a Dictionary with `ok` set to `true` and a `view` Dictionary on success. A rejected projection can include a `message` for the local console. Returns `ERR_BUSY` outside setup phases.
