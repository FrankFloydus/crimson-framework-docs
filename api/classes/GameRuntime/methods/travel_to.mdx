## Return value

[`GameOperation`](/api/classes/GameOperation)

## Description

Await the operation before using the replacement world. A preparation failure leaves the prior world available.

## Example

```gdscript
const MARKET_WORLD: StringName = &"market"

func enter_market(game: GameRuntime) -> void:
    # Run on the coordinated authority. Register this world in the game definition.
    var result: Dictionary = await game.travel_to(MARKET_WORLD).wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Active world: ", game.get_world_id())
```
