## Return value

[`GameOperation`](/api/classes/GameOperation)

## Description

Pass display metadata as a dictionary and set autosave to use autosave admission. A successful operation returns the generation sequence and ID in value.

## Example

```gdscript
const PLAYER_PROFILE: String = "player-1"
const CAMPAIGN_SLOT: String = "campaign"

func save_at_the_harbor(game: GameRuntime) -> void:
    # Run this on the authority after committed gameplay has started.
    var result: Dictionary = await game.save(PLAYER_PROFILE, CAMPAIGN_SLOT, {"label": "Harbor"}).wait()
    if not result.ok:
        push_error(result.message)
        return
    print("Published generation: ", result.value)
```
