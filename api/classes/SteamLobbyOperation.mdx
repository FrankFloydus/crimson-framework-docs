Cancellable observation of one standalone Steam lobby create or join.

## Methods

### `cancel`

`cancel() -> Error`

Settle the pending observation with `ERR_SKIP`. An acquired membership is cleaned up once the pending native Steam call completes. An already settled operation returns `ERR_DOES_NOT_EXIST`.

### `is_finished`

`is_finished() -> bool`

Return whether this operation has a terminal result.

### `result`

`result() -> SteamLobbyResult`

Return the terminal result, or null while pending.

### `wait`

`wait() -> Variant`

Await `completed` or return its existing [`SteamLobbyResult`](/api/classes/SteamLobbyResult) if already finished.

## Signals

### `completed`

`completed(result: SteamLobbyResult)`

Emitted once when the lobby is available or the observation fails, is cancelled, or reaches its 30-second deadline.
