**Inherits** `RefCounted`

Branchable draft for one URL and HTTP method.

Use `send()` to submit the draft and retain a cancellable operation. Each option returns an independent draft.

## Methods

### `accept_json`

`accept_json() -> SteamHttpRequest`

Return a branch with the request's Accept header set to `application/json`.

### `send`

`send() -> SteamHttpResponseOperation`

Submit this draft on its original Steam client scope. Invalid drafts and stopped scopes return already-settled failures.

### `with_body`

`with_body(bytes: PackedByteArray, content_type: String) -> SteamHttpRequest`

Return a branch that owns raw bytes and their media type for POST, PUT, or PATCH. The body limit is 1 MiB. This media type supplies the request's Content-Type header.

### `with_header`

`with_header(name: String, value: String) -> SteamHttpRequest`

Return a branch with a request header. Header names are case-insensitive, and a new value replaces the same header on that branch. Steam manages framing and connection headers.

### `with_max_response_bytes`

`with_max_response_bytes(bytes: int) -> SteamHttpRequest`

Return a branch with a response body limit from 1 byte to 4 MiB. The default is 1 MiB. Larger bodies return a limit error and expose no partial response.

### `with_response_headers`

`with_response_headers(names: PackedStringArray) -> SteamHttpRequest`

Return a branch that replaces the selected response header names. Select up to 16 additional names. Matching ignores case, and Content-Type is captured when present. A selected field larger than 2,048 bytes returns a limit error.

### `with_timeout`

`with_timeout(milliseconds: int) -> SteamHttpRequest`

Return a branch with an absolute deadline from 100 to 120,000 milliseconds. The default is 15,000 milliseconds.
