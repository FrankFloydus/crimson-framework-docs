## Description

Use `send()` to submit the draft and retain a cancellable operation. Each option returns an independent draft.

## Methods

### Instance methods

#### [`accept_json`](/api/classes/SteamHttpRequest/methods/accept_json)

Return a branch with the request's Accept header set to `application/json`.

#### [`send`](/api/classes/SteamHttpRequest/methods/send)

Submit this draft on its original Steam client scope.

#### [`with_body`](/api/classes/SteamHttpRequest/methods/with_body)

Return a branch that owns raw bytes and their media type for POST, PUT, or PATCH.

#### [`with_header`](/api/classes/SteamHttpRequest/methods/with_header)

Return a branch with a request header.

#### [`with_max_response_bytes`](/api/classes/SteamHttpRequest/methods/with_max_response_bytes)

Return a branch with a response body limit from 1 byte to 4 MiB.

#### [`with_response_headers`](/api/classes/SteamHttpRequest/methods/with_response_headers)

Return a branch that replaces the selected response header names.

#### [`with_timeout`](/api/classes/SteamHttpRequest/methods/with_timeout)

Return a branch with an absolute deadline from 100 to 120,000 milliseconds.
