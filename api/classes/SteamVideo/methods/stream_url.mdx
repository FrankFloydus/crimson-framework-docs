## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `video_app_id` | `int` | — |

## Return value

`Variant`

Await the call to receive [`SteamStringResult`](/api/classes/SteamStringResult).

## Description

Treat this URL as temporary and keep it out of logs.

## Example

```gdscript
extends Node

func run_stream_url(
    steam_client: SteamClient,
    video_app_id: int,
    stream_url_label: Label
) -> void:
    if not steam_client.is_ready():
        return
    var steam_video: SteamVideo = steam_client.video()
    if steam_video == null:
        return
    var result: SteamStringResult = await steam_video.stream_url(video_app_id)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: String = result.value
    stream_url_label.text = "Stream url: %s" % str(payload)
```
