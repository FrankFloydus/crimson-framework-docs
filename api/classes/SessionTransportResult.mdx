**Inherits** `RefCounted`

An immutable result from opening a transport. A successful result supplies a fresh Godot multiplayer peer to the session. A failed result carries the setup error.

## Methods

### `failed`

`static failed(error: Error) -> SessionTransportResult`

Wrap a transport setup error. Passing OK produces ERR\_INVALID\_PARAMETER.

### `get_error`

`get_error() -> Error`

Return OK for an opened peer or the stored setup error. A result created without either factory reports ERR\_UNCONFIGURED.

### `get_peer`

`get_peer() -> MultiplayerPeer`

Return the initialized peer supplied by a successful transport open, or null on failure.

### `opened`

`static opened(peer: MultiplayerPeer) -> SessionTransportResult`

Wrap an initialized peer in a successful result. A null peer produces a result with ERR\_INVALID\_PARAMETER.
