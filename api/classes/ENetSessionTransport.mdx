## Methods

### `disconnect_after_flush`

`disconnect_after_flush(peer: MultiplayerPeer, peer_id: int) -> void`

Schedule the specified guest's ENet connection to close after outgoing reliable packets have been sent. Does nothing when the peer is not an ENet peer or the guest is absent.

### `open_client`

`open_client(endpoint: SessionEndpoint) -> SessionTransportResult`

Create a fresh ENet client peer and begin connecting to a direct SessionEndpoint. An absent, opaque, or invalid endpoint produces ERR\_INVALID\_PARAMETER. A successful open starts the attempt, while GameSession confirms admission later.

### `open_server`

`open_server(port: int, remote_limit: int, bind_address: String) -> SessionTransportResult`

Create a fresh listening ENet peer. Provide a UDP port from 1 to 65535, a remote client limit from 1 to 4095, and either `\*` for all interfaces or a literal bind IP. Invalid input produces ERR\_INVALID\_PARAMETER. Otherwise the result carries the new peer or the ENet startup error.
