**Inherits** `RefCounted`

Read Steam relay readiness and inspect an admitted Game peer's transport path.

Access from `SteamClient.networking()` or `SteamScope.networking()`. The Game scope resolves `peer_path()` from current Steam-verified participants and their exact live gameplay sockets. Standalone sockets expose their own `SteamSocketConnection.path()`.

## Methods

### `peer_path`

`peer_path(peer_id: int) -> SteamConnectionPathResult`

Samples the exact current remote Steam-verified Game peer. Returns `ERR_INVALID_PARAMETER` for an invalid ID, `ERR_UNAVAILABLE` without a live Game sampler, or `ERR_DOES_NOT_EXIST` when the peer has no matching admitted live socket.

### `relay_status`

`relay_status() -> SteamRelayStatus`

Returns Steam's latest relay readiness. An inactive or unsupported scope returns an unknown snapshot.

### `warm_relay`

`warm_relay() -> Error`

Starts Steam relay preparation. `OK` means preparation was requested. Observe `relay_status_changed` or query `relay_status()` for readiness.

## Signals

### `relay_status_changed`

`relay_status_changed(status: SteamRelayStatus)`

Emitted when Steam reports a relay availability update. The argument is a detached snapshot.
