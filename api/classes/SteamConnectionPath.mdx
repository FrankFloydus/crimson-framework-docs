## Description

Read this snapshot from `SteamSocketConnection.path()` or `SteamNetworking.peer_path()`. Steam reports measurements for the current connection. Sample again for updates.

## Properties

**[`kind`](/api/classes/SteamConnectionPath/properties/kind)**

Steam's observed route kind.

**[`packet_loss`](/api/classes/SteamConnectionPath/properties/packet_loss)**

A value from `0.0` to `1.0` estimated as one minus Steam's local in-order delivery quality.

**[`ping_ms`](/api/classes/SteamConnectionPath/properties/ping_ms)**

Steam's latency measurement in milliseconds, or `-1` before a measurement.
