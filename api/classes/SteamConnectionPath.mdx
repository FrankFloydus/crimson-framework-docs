**Inherits** `RefCounted`

A snapshot of an authenticated Steam connection's route and quality.

Read this snapshot from `SteamSocketConnection.path()` or `SteamNetworking.peer_path()`. Steam reports measurements for the current connection. Sample again for updates.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `kind` | `SteamConnectionPath.RouteKind` | `0` | `get_kind()` | Steam's observed route kind. |
| `packet_loss` | `float` | `-1.0` | `get_packet_loss()` | A value from `0.0` to `1.0` estimated as one minus Steam's local in-order delivery quality. Steam can count reordered packets in this metric. `-1.0` means unavailable. |
| `ping_ms` | `int` | `-1` | `get_ping_ms()` | Steam's latency measurement in milliseconds, or `-1` before a measurement. |
