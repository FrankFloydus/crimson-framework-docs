### Method details

#### `as_autosave`

`as_autosave() -> SaveRequest`

Return a copy marked as an autosave. A newer autosave for the same slot and world epoch can supersede an earlier request before capture.

#### `named`

`named(label: String) -> SaveRequest`

Return a copy with the requested display label. Submission sanitizes and bounds the label stored in the generation.

#### `submit`

`submit() -> GameOperation`

Timestamp the metadata and queue a checkpoint on the originating game. The game must be a running authority. On success, the operation's value contains the sequence and ID of the published generation.

#### `with_context`

`with_context(context: Dictionary) -> SaveRequest`

Return a copy with sanitized, bounded display context. Use small fields such as a location or chapter label. Persist gameplay state in the match stores.

#### `with_preview`

`with_preview(image: Image) -> SaveRequest`

Return a copy with a snapshot of an uncompressed, nonempty Image. Pass null to clear it. Submission includes a preview when it fits the metadata budget.
