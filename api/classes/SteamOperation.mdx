## Methods

### Instance methods

#### [`cancel`](/api/classes/SteamOperation/methods/cancel)

Ends local observation and completes it with `ERR_SKIP`.

#### [`is_finished`](/api/classes/SteamOperation/methods/is_finished)

Returns whether the operation has a terminal result.

#### [`result`](/api/classes/SteamOperation/methods/result)

Returns the same terminal result as `completed`, or `null` while observation is pending.

#### [`wait`](/api/classes/SteamOperation/methods/wait)

Use `await operation.wait()` to receive a [`SteamResult`](/api/classes/SteamResult) before or after observation ends.

## Signals

### `completed`

`completed(result: SteamResult)`

Emitted once after a pending action settles, including after cancellation or client shutdown. `result()` already returns this result during the signal.
