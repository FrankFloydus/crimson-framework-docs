## Signature

```text
register_inventory(inventory: SpatialInventory, container_id: StringName = &"") -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `inventory` | [`SpatialInventory`](/api/classes/SpatialInventory) | — |
| `container_id` | `StringName` | `&""` |

## Return value

`Error`

## Description

Use an empty `container_id` for a standalone grid or pass the owning item ID for a container's contents. Returns an error if the registration introduces duplicate ownership or invalid nesting.
