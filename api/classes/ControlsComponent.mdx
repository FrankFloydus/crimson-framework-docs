**Inherits** `Node`

## Description

Add one ControlsComponent directly under a `CharacterBody3D`. Choose Edit Input Actions in the Inspector to open the layout editor. Player Setup contains action assignments, look rates, and pointer capture for this character. Boot the component once the body is mounted and assigned to this local player. This lets the game activate local input at the same point it selects the player's view. Use a [`MoverComponent`](/api/classes/MoverComponent) on the same body to author movement settings.

## Properties

**[`capture_pointer_on_boot`](/api/classes/ControlsComponent/properties/capture_pointer_on_boot)**

Attempt desktop pointer capture after local control attaches.

**[`input_layout`](/api/classes/ControlsComponent/properties/input_layout)**

Edit actions and their default keyboard, mouse, and controller bindings here.

**[`jump_action`](/api/classes/ControlsComponent/properties/jump_action)**

Button action whose press requests grounded takeoff.

**[`mouse_look_action`](/api/classes/ControlsComponent/properties/mouse_look_action)**

Relative mouse motion action for rotating the view.

**[`mouse_sensitivity`](/api/classes/ControlsComponent/properties/mouse_sensitivity)**

View rotation in radians per unscaled pixel of mouse movement.

**[`move_action`](/api/classes/ControlsComponent/properties/move_action)**

Vector2 action that supplies steering.

**[`stick_look_action`](/api/classes/ControlsComponent/properties/stick_look_action)**

Vector2 action that controls the view's rotation rate.

**[`stick_look_speed`](/api/classes/ControlsComponent/properties/stick_look_speed)**

View rotation in radians per second at full stick deflection.
