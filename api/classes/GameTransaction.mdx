## Methods

### `add_change`

`add_change(store_id: String, operation: Dictionary, expected_revision: int) -> Error`

Queues a detached copy of `operation` for `store\_id` with the caller's observed store revision. The coordinator checks that revision during commit. Returns `ERR\_UNAVAILABLE` for an unowned, consumed, restore-only, or wrong-thread handle, and `ERR\_INVALID\_DATA` if the operation exceeds the data limits or contains unsupported values.
