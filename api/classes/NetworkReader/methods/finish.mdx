## Signature

```text
finish() -> Error
```

## Return value

`Error`

## Description

Record `ERR_INVALID_DATA` for trailing bytes and preserve an existing error.

## Example

### Read a fixed-size practice target measurement

Attach the script to a plain Node and run the scene. Output shows the decoded target ID and distance from the six-byte reading. [Practice target setup](/binary-messages#read-and-write-fields-directly)

```gdscript
extends Node

const PAYLOAD_BYTES: int = 6
const TARGET_ID: int = 12
const TARGET_DISTANCE: float = 42.5


func _ready() -> void:
    var writer: NetworkWriter = NetworkWriter.create(PAYLOAD_BYTES)
    writer.write_u16(TARGET_ID)
    writer.write_f32(TARGET_DISTANCE)
    var bytes: PackedByteArray = writer.finish()
    if writer.get_error() != OK:
        push_error("Could not encode the target reading.")
        return

    var reader: NetworkReader = NetworkReader.open(bytes, PAYLOAD_BYTES)
    var target_id: int = reader.read_u16()
    var distance: float = reader.read_f32()
    if reader.finish() != OK:
        push_error("Invalid target reading.")
        return

    print("Target %d at %.1f m (%d bytes)." % [target_id, distance, bytes.size()])
```
