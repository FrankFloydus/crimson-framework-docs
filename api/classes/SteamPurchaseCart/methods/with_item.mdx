[`SteamPurchaseCart`](/api/classes/SteamPurchaseCart)

## Description

A SKU uses 1 to 64 letters, digits, dots, dashes, or underscores. A cart holds up to 32 SKUs. Quantities range from 1 through 1000. Invalid selections return null.
