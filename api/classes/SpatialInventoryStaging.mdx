**Inherits** `RefCounted`

## Description

A tray can return all its staged items as one checked operation. If the return fails, the tray retains the items.

## Properties

**[`batch_policy`](/api/classes/SpatialInventoryStaging/properties/batch_policy)**

Optional callback that receives all proposed placement changes before the tray restores its contents.

**[`drop_policy`](/api/classes/SpatialInventoryStaging/properties/drop_policy)**

Optional callback that receives the item and proposed destination placement, including a placement in its original grid during restoration.

**[`inventory`](/api/classes/SpatialInventoryStaging/properties/inventory)**

The tray's own grid.

**[`last_reason`](/api/classes/SpatialInventoryStaging/properties/last_reason)**

Reason reported by the most recent failed staging operation.

**[`pickup_policy`](/api/classes/SpatialInventoryStaging/properties/pickup_policy)**

Optional callback that receives the item and source placement before an item is picked up.
