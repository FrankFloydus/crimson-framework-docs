### Method details

#### `configure`

`configure(size: Vector2i) -> Error`

Set the staging grid dimensions in cells. Return `ERR_BUSY` when trying to resize a tray with recorded items.

#### `get_batch_policy`

`get_batch_policy() -> Callable`

Return the optional policy that checks the complete restoration batch.

#### `get_drop_policy`

`get_drop_policy() -> Callable`

Return the policy for proposed destination placements.

#### `get_inventory`

`get_inventory() -> SpatialInventory`

Return the live staging grid for display and placement queries. Use the staging model to edit it.

#### `get_last_reason`

`get_last_reason() -> String`

Return the last operation's explanatory message, or an empty string if there is no reason to report.

#### `get_pickup_policy`

`get_pickup_policy() -> Callable`

Return the policy for picking an item up from its source grid.

#### `is_empty`

`is_empty() -> bool`

Return true when the tray has no placements and no recorded original placements.

#### `place_item`

`place_item(id: StringName, destination: SpatialInventory, origin: Vector2i, rotated: bool = false) -> Error`

Transfer a staged item to the requested external grid, origin, and rotation. On success the item leaves the tray and its original placement record is cleared.

#### `restore_all`

`restore_all() -> Error`

Try to restore every staged item to its original inventory, origin, and rotation in a single checked batch. If a placement or policy rejects the restore, read `last_reason`.

#### `set_batch_policy`

`set_batch_policy(value: Callable) -> void`

Set a callback that evaluates all before-and-after placement rows for a restore. Return an empty String to allow the batch or a reason to reject it.

#### `set_drop_policy`

`set_drop_policy(value: Callable) -> void`

Set a callback that checks a proposed destination placement. Return an empty String to allow the move or a reason to reject it.

#### `set_pickup_policy`

`set_pickup_policy(value: Callable) -> void`

Set a callback that checks whether the source item can be lifted. Return an empty String to allow pickup or a reason to reject it.

#### `stage_from`

`stage_from(source: SpatialInventory, id: StringName, origin: Vector2i, rotated: bool = false) -> Error`

Move a complete item from another grid into the tray and remember the original placement. Returns an error if the item is missing, already tracked, blocked by a policy, or does not fit.

#### `try_close`

`try_close(restore: bool = false) -> Error`

Return `OK` when the tray is empty. If `restore` is true, attempt to restore everything first. Otherwise an occupied tray returns `ERR_BUSY`.
