**Inherits** `RefCounted`

One Steam SDK diagnostic from a capture batch.

Each message records the SDK severity and a fixed description suitable for a developer console or log. The description is selected by severity, so the original SDK payload stays private.

## Properties

| Property | Type | Default | Accessors | Description |
| --- | --- | --- | --- | --- |
| `severity` | `int` | — | `get_severity()` | Read-only Steam SDK severity number. Use it to select how a developer console presents the message. |
| `text` | `String` | — | `get_text()` | Read-only description suitable for displaying or logging the diagnostic. |

## Methods

### `get_severity`

`get_severity() -> int`

Returns the Steam SDK severity number. Steam uses `0` for an informational message and `1` for a warning.

### `get_text`

`get_text() -> String`

Returns the fixed framework description for the severity. Future SDK severity codes use a generic diagnostic description.
