## Description

Each message records the SDK severity and a fixed description suitable for a developer console or log. The description is selected by severity, so the original SDK payload stays private.

## Properties

**[`severity`](/api/classes/SteamDiagnosticMessage/properties/severity)**

Read-only Steam SDK severity number.

**[`text`](/api/classes/SteamDiagnosticMessage/properties/text)**

Read-only description suitable for displaying or logging the diagnostic.
