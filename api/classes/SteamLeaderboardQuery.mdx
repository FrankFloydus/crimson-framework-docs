**Inherits** `RefCounted`

## Description

Start with `SteamLeaderboards.query()` and choose a selection. Each modifier returns an independent branch. The default selection is the first ten global ranks. A stopped scope leaves its queries unavailable.

## Methods

### Instance methods

#### [`around_me`](/api/classes/SteamLeaderboardQuery/methods/around_me)

Returns a branch centered on the signed-in player's score.

#### [`fetch`](/api/classes/SteamLeaderboardQuery/methods/fetch)

Looks up the existing board and fetches the selected page.

#### [`fetch_operation`](/api/classes/SteamLeaderboardQuery/methods/fetch_operation)

Starts the same query as `fetch()` and returns a retained operation for cancellation, completion, or typed result inspection.

#### [`friends`](/api/classes/SteamLeaderboardQuery/methods/friends)

Returns a branch that reads the signed-in player's friends view with a display cap from 1 to 100 rows.

#### [`global_ranks`](/api/classes/SteamLeaderboardQuery/methods/global_ranks)

Returns a branch that reads `count` global ranks from the one-based `first_rank`.

#### [`users`](/api/classes/SteamLeaderboardQuery/methods/users)

Returns a branch for 1 to 100 distinct individual SteamID64 values in decimal.
