**Inherits** `RefCounted`

A branchable leaderboard read bound to one Steam client scope.

Start with `SteamLeaderboards.query()` and choose a selection. Each modifier returns an independent branch. The default selection is the first ten global ranks. A stopped scope leaves its queries unavailable.

## Methods

### `around_me`

`around_me(before: int = 4, after: int = 5) -> SteamLeaderboardQuery`

Returns a branch centered on the signed-in player's score. The nonnegative counts before and after the center plus the center row must total at most 100.

### `fetch`

`fetch() -> Variant`

Looks up the existing board and fetches the selected page. Use `await` to receive a [`SteamLeaderboardPageResult`](/api/classes/SteamLeaderboardPageResult). Immediate errors return the same result type.

### `fetch_operation`

`fetch_operation() -> SteamLeaderboardPageOperation`

Starts the same query as `fetch()` and returns a retained operation for cancellation, completion, or typed result inspection.

### `friends`

`friends(count: int = 10) -> SteamLeaderboardQuery`

Returns a branch that reads the signed-in player's friends view with a display cap from 1 to 100 rows.

### `global_ranks`

`global_ranks(first_rank: int = 1, count: int = 10) -> SteamLeaderboardQuery`

Returns a branch that reads `count` global ranks from the one-based `first_rank`. The count must be between 1 and 100.

### `users`

`users(steam_ids: PackedStringArray) -> SteamLeaderboardQuery`

Returns a branch for 1 to 100 distinct individual SteamID64 values in decimal. Only players with scores appear in the page. Steam accepts one selected-user download at a time across the shared runtime. An overlapping download returns `@GlobalScope.ERR_BUSY`.
