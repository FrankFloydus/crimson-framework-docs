## Signature

```text
set_transport_adapter(adapter: SessionTransport) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `adapter` | [`SessionTransport`](/api/classes/SessionTransport) | — |

## Return value

`Error`

## Description

Pass null to use ENet. Offline startup always uses Godot's offline peer. Returns ERR\_BUSY unless the session is idle and no start or teardown is in progress.
