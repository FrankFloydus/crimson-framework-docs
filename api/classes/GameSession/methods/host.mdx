## Signature

```text
host(port: int, max_clients: int = 32, bind_address: String = "*") -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `port` | `int` | — |
| `max_clients` | `int` | `32` |
| `bind_address` | `String` | `"*"` |

## Return value

`Error`

## Description

Provide a port from 1 to 65535, a remote client limit from 1 to 4095, and `\*` or a literal bind IP. Returns OK when the host is installed, ERR\_INVALID\_PARAMETER for invalid settings, or the scope or transport setup error.
