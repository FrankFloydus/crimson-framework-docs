## Signature

```text
join_endpoint(endpoint: SessionEndpoint, timeout_seconds: float = 10.0) -> Error
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `endpoint` | [`SessionEndpoint`](/api/classes/SessionEndpoint) | — |
| `timeout_seconds` | `float` | `10.0` |

## Return value

`Error`

## Description

The timeout is in seconds and must be greater than 0 and at most 120. A null endpoint or invalid timeout returns ERR\_INVALID\_PARAMETER. OK means the attempt started. Wait for session\_started to confirm admission.
