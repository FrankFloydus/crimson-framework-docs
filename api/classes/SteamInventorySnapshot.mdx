## Description

A snapshot remains readable after the Steam client stops. Steam can return cached inventory when an application refreshes rapidly. An unchanged result may also lack freshness evidence. Inspect `freshness` before relying on this snapshot as a current view.

## Properties

**[`freshness`](/api/classes/SteamInventorySnapshot/properties/freshness)**

## Constants and enums

### `Freshness`

| Name | Value | Description |
| --- | --- | --- |
| `FRESHNESS_CACHED` | `2` | Steam returned readable data with an expired result status. |
| `FRESHNESS_FRESH` | `1` | Steam announced a newer full view for this exact request. |
| `FRESHNESS_UNCONFIRMED` | `0` | Steam supplied no freshness evidence. This includes selected reads and full results that Steam may have served from cache or found unchanged. |
| `FRESHNESS_VERIFIED_PROOF` | `3` | A dedicated server verified the signed selection and its age for a currently authenticated owner. The snapshot describes the selected instances at the proof timestamp. |
