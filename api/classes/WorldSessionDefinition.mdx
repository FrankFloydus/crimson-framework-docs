### Method details

#### `create`

`create() -> WorldSession`

Create a detached WorldSession named WorldSession with a copy of this definition. Add it to the scene tree before starting it.

#### `on_port`

`on_port(port: int) -> WorldSessionDefinition`

Return a copy with the UDP port used by the host and guest. The valid range is 1 through 65535.

#### `with_local_view`

`with_local_view(camera_path: NodePath, hidden_path: NodePath = NodePath("")) -> WorldSessionDefinition`

Return a copy with player-relative NodePaths for the Camera3D to activate and the visual Node3D to hide on the local actor. Leave either path empty to skip that action.

#### `with_players`

`with_players(scene: PackedScene, spawn_points_path: NodePath = NodePath("SpawnPoints")) -> WorldSessionDefinition`

Return a copy with a Node3D player scene and a world-relative path to the spawn container. Its ordered direct Marker3D children define the spawn slots.

#### `with_world`

`with_world(scene: PackedScene) -> WorldSessionDefinition`

Return a copy with the Node3D scene that the session mounts. Use the same scene and marker order on the host and guests.
