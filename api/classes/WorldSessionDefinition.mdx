## Properties

**[`local_camera_path`](/api/classes/WorldSessionDefinition/properties/local_camera_path)**

**[`local_hidden_path`](/api/classes/WorldSessionDefinition/properties/local_hidden_path)**

Optional path relative to the assigned player scene root.

**[`player_scene`](/api/classes/WorldSessionDefinition/properties/player_scene)**

Node3D scene instantiated for each occupied slot in a standalone World Session.

**[`port`](/api/classes/WorldSessionDefinition/properties/port)**

UDP port used to host or join the standalone session.

**[`spawn_points_path`](/api/classes/WorldSessionDefinition/properties/spawn_points_path)**

Path relative to the assigned world scene root.

**[`world_scene`](/api/classes/WorldSessionDefinition/properties/world_scene)**

The Node3D world mounted from the same local asset on each participant.

## Methods

### Instance methods

#### [`create`](/api/classes/WorldSessionDefinition/methods/create)

Create a detached WorldSession named WorldSession with a copy of this definition.

#### [`on_port`](/api/classes/WorldSessionDefinition/methods/on_port)

Return a copy with the UDP port used by the host and guest.

#### [`with_local_view`](/api/classes/WorldSessionDefinition/methods/with_local_view)

Return a copy with player-relative NodePaths for the Camera3D to activate and the visual Node3D to hide on the local actor.

#### [`with_players`](/api/classes/WorldSessionDefinition/methods/with_players)

Return a copy with a Node3D player scene and a world-relative path to the spawn container.

#### [`with_world`](/api/classes/WorldSessionDefinition/methods/with_world)

Return a copy with the Node3D scene that the session mounts.
