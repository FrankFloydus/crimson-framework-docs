**Inherits** `RefCounted`

Create standalone Steam listeners and connections through the owning Steam client.

Access from `SteamClient.sockets()` or `SteamScope.sockets()`. Each facade owns up to eight listeners and 64 connections. The process owns up to 16 listeners and 128 connections across standalone facades. These connections have their own admission and packet API, separate from Game session transport.

## Methods

### `connect_to`

`connect_to(endpoint: SteamSocketEndpoint, timeout_ms: int = 10000) -> SteamSocketConnectOperation`

Starts one authenticated outgoing handshake. Specify a timeout from 1000 to 30000 milliseconds. For direct routes requiring a specific Steam account, pass the endpoint returned by `SteamSocketEndpoint.expect_peer()`.

### `listen`

`listen(endpoint: SteamSocketEndpoint, remote_limit: int = 8) -> SteamSocketListenerResult`

Listens on a direct endpoint or a P2P endpoint addressed to the current Steam user. Set `remote_limit` from 1 to 64 to cap pending and accepted connections together. A direct listener cannot have an outgoing peer pin.
