
## Parameters

## Return value

`Error`

## Description

Pass zero for both to clear the request. `OK` acknowledges the SDK submission. A disconnected controller or missing vibration capability returns `ERR_UNAVAILABLE`. Nonfinite or out-of-range values return `ERR_INVALID_PARAMETER`.

```gdscript
extends Node

    if result != OK:
```
