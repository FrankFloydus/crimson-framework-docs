## Description

Inactive input returns an inactive zero vector. Unknown actions return `ERR_DOES_NOT_EXIST`. An empty or oversized action name returns `ERR_INVALID_PARAMETER`. A retired view or unavailable Steam interface returns `ERR_UNAVAILABLE`.
