## Signature

```text
glyphs(action: StringName, size: SteamController.GlyphSize = 1) -> SteamTexturesResult
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `action` | `StringName` | — |
| `size` | `SteamController.GlyphSize` | `1` |

## Return value

[`SteamTexturesResult`](/api/classes/SteamTexturesResult)

## Description

The highest active layer that supplies origins takes precedence over the base set. An unbound action, unavailable glyph, or retired view returns `ERR_UNAVAILABLE`. An invalid size or action name returns `ERR_INVALID_PARAMETER`.

## Example

```gdscript
extends Node

func run_glyphs(
    steam_controller: SteamController,
    action: StringName,
    size: SteamController.GlyphSize,
    add_glyphs_entry: Callable
) -> void:
    var result: SteamTexturesResult = steam_controller.glyphs(action, size)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: Array[Texture2D] = result.value
    for entry: Texture2D in payload:
        add_glyphs_entry.call(entry)
```
