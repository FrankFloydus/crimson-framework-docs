## Parameters

| Parameter | Type | Default |

| `name` | `StringName` | — |

## Return value

`Error`

## Description

Returns `ERR_DOES_NOT_EXIST` if the published name is unknown, `ERR_INVALID_PARAMETER` if it is empty or exceeds 128 UTF-8 bytes, or `ERR_UNAVAILABLE` when this view or native capability is unavailable.
