**Inherits** `RefCounted`

An immutable provider namespace and stable account identifier for a connection verified by a trusted authenticator. Keep persistent player bindings separate from Godot peer IDs, which identify individual connections.

## Methods

### `get_provider`

`get_provider() -> StringName`

Return the provider namespace used to interpret the account identifier.

### `get_subject`

`get_subject() -> String`

Return the stable account identifier in that provider's namespace.

### `verified`

`static verified(provider: StringName, subject: String) -> SessionIdentity`

Construct an identity from a provider and subject that the authenticator has already verified. Returns null for a blank field, a provider longer than 64 characters, or a subject longer than 256 characters.
