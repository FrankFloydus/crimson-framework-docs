## Signature

```text
inspect(listing: SteamListing, timeout_ms: int = 3000) -> SteamServerDetailsOperation
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `listing` | [`SteamListing`](/api/classes/SteamListing) | — |
| `timeout_ms` | `int` | `3000` |

## Return value

[`SteamServerDetailsOperation`](/api/classes/SteamServerDetailsOperation)

## Description

The response must match the selected AppID, namespace, server identity and address. Timeout accepts 100 to 15000 milliseconds.

## Example

```gdscript
extends Node

func run_inspect(
    steam_client: SteamClient,
    listing: SteamListing,
    timeout_ms: int,
    apply_inspect: Callable
) -> void:
    if not steam_client.is_ready():
        return
    var steam_server_browser: SteamServerBrowser = steam_client.server_browser()
    if steam_server_browser == null:
        return
    var result: SteamServerDetailsOperation = steam_server_browser.inspect(listing, timeout_ms)
    if result == null:
        return
    var result_value: SteamServerDetailsResult = await result.wait()
    if result_value == null:
        return
    if not result_value.ok:
        push_warning(result_value.message)
        return
    var payload: SteamServerDetails = result_value.value
    if payload == null:
        return
    apply_inspect.call(payload)
```
