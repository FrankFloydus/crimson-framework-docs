## Signature

```text
query(source: SteamServer.Advertisement = 2, namespace: StringName = &"") -> SteamServerQuery
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `source` | `SteamServer.Advertisement` | `2` |
| `namespace` | `StringName` | `&""` |

## Return value

[`SteamServerQuery`](/api/classes/SteamServerQuery)

## Description

Omit the namespace to use the owning game's namespace or `crimson` on a standalone client. A Game scope cannot override its namespace.

## Example

```gdscript
extends Node

func run_query(
    steam_client: SteamClient,
    source: SteamServer.Advertisement,
    namespace_value: StringName,
    results_list: ItemList
) -> void:
    if not steam_client.is_ready():
        return
    var steam_server_browser: SteamServerBrowser = steam_client.server_browser()
    if steam_server_browser == null:
        return
    var result: SteamServerQuery = steam_server_browser.query(source, namespace_value)
    if result == null:
        return
    var search_result: SteamListingsResult = await result.fetch()
    if search_result == null:
        return
    if not search_result.ok:
        push_warning(search_result.message)
        return
    var payload: Array[SteamListing] = search_result.value
    results_list.clear()
    for entry: SteamListing in payload:
        results_list.add_item(str(entry.name))
```
