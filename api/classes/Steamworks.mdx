**Inherits** `RefCounted`

## Description

Call `boot()` on the main thread to use Steam features independently of the game runtime. The existing scene-tree owner controls the lifetime of the internal Steam callback client. The facade and its typed services belong to that attachment and retire when it exits or loses its native client generation. Boot returns a facade even if startup fails. Read `boot_result()` for the startup diagnostic. Direct actions report their own availability. Typed accessors may return null when the client or requested service is unavailable.

## Signals

### `runtime_lost`

`runtime_lost()`

Emitted after an IPC failure retires the exact native client generation and invalidates its retained services. To recover a standalone scope, defer a fresh `boot()` until the callback returns.
