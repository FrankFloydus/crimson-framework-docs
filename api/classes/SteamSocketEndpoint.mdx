**Inherits** `RefCounted`

An immutable direct or Steam P2P route for a standalone socket.

Use `direct()` for numeric IP routes and `p2p()` for a Steam individual account and virtual port. For direct outgoing connections that must reach a specific account, add `expect_peer()`. Direct connections without a pin still require the connected endpoint to have a Steam-certified identity and encrypted transport.

## Methods

### `direct`

`static direct(address: String, port: int) -> SteamSocketEndpoint`

Returns a numeric IPv4 or IPv6 route with a physical UDP port from 1 to 65535. Returns `null` for invalid input. Wildcard addresses are for listeners.

### `expect_peer`

`expect_peer(steam_id: String) -> SteamSocketEndpoint`

Branches a direct route with a pinned certified individual or game server identity. Returns `null` for an invalid account or P2P route. Apply the returned route to `SteamSockets.connect_to()`.

### `get_address`

`get_address() -> String`

Returns the specified address or an empty string for P2P.

### `get_kind`

`get_kind() -> SteamSocketEndpoint.Kind`

Returns the route kind.

### `get_port`

`get_port() -> int`

Returns the configured physical or virtual port.

### `get_steam_id`

`get_steam_id() -> String`

Returns the P2P identity or optional direct identity pin.

### `p2p`

`static p2p(steam_id: String, virtual_port: int = 0) -> SteamSocketEndpoint`

Returns a route to a canonical decimal SteamID64 for an individual Steam account. Use your own ID for a listener and the remote account for a connection. The virtual port is from 0 to 65535. Returns `null` for invalid input.
