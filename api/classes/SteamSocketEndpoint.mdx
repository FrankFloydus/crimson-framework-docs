## Description

Use `direct()` for numeric IP routes and `p2p()` for a Steam individual account and virtual port. For direct outgoing connections that must reach a specific account, add `expect_peer()`. Direct connections without a pin still require the connected endpoint to have a Steam-certified identity and encrypted transport.

## Methods

### Static methods

#### [`direct`](/api/classes/SteamSocketEndpoint/methods/direct)

Returns a numeric IPv4 or IPv6 route with a physical UDP port from 1 to 65535.

#### [`p2p`](/api/classes/SteamSocketEndpoint/methods/p2p)

Returns a route to a canonical decimal SteamID64 for an individual Steam account.

### Instance methods

#### [`expect_peer`](/api/classes/SteamSocketEndpoint/methods/expect_peer)
