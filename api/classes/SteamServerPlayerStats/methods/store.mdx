## Signature

```text
store() -> SteamServerStatsOperation
```

## Return value

[`SteamServerStatsOperation`](/api/classes/SteamServerStatsOperation)

## Description

Use this after a partially applied batch or a drained failed store if the game intends to persist those accepted changes. An unloaded cache returns `ERR_UNCONFIGURED`. An undrained call returns `ERR_BUSY`. A loaded cache without pending changes returns success without issuing a Steam call.
