**Inherits** `RefCounted`

Verifies a signed inventory selection for a currently authenticated Steam player.

Get this service from `SteamDedicatedServer.inventory_verifier()` on the dedicated Steam authority. Pass the current admitted player's authenticated SteamID64. The server verifies the signature and matching account through its GameServer interface, checks the exact admission before and after verification, and accepts proofs at most five minutes old by Steam's server clock.

## Methods

### `verify`

`verify(proof: PackedByteArray, expected_steam_id: String) -> Variant`

Awaits a [`SteamInventorySnapshotResult`](/api/classes/SteamInventorySnapshotResult) after validating the `proof` of up to 1 MiB against the currently admitted `expected_steam_id` in canonical decimal form. A successful snapshot contains up to 256 selected items at the signed timestamp and uses `SteamInventorySnapshot.FRESHNESS_VERIFIED_PROOF`. Invalid arguments return `ERR_INVALID_PARAMETER`. An unavailable game server returns `ERR_UNAVAILABLE`. A rejected signature or malformed result returns `ERR_INVALID_DATA`. An expired proof or verification deadline returns `ERR_TIMEOUT`. An owner or admission mismatch returns `ERR_UNAUTHORIZED`. A retired observation returns `ERR_SKIP`.
