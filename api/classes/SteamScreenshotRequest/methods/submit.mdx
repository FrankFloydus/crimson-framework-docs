## Signature

```text
submit() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamScreenshotResult`](/api/classes/SteamScreenshotResult).

## Description

Await this call for a [`SteamScreenshotResult`](/api/classes/SteamScreenshotResult), including immediate validation or availability failures.

## Example

```gdscript
extends Node

func run_submit(
    steam_screenshot_request: SteamScreenshotRequest,
    apply_submit: Callable
) -> void:
    var result: SteamScreenshotResult = await steam_screenshot_request.submit()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamScreenshot = result.value
    if payload == null:
        return
    apply_submit.call(payload)
```
