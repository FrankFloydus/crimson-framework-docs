### Method details

#### `cancel`

`cancel(reservation: SteamPartyReservation) -> Error`

Returns the exact pending reservation to Steam. A guest already in flight still follows the ordinary Game admission rules.

#### `change_open_slots`

`change_open_slots(slots: int) -> SteamPartySlotsOperation`

Requests a new count of zero to 64 unreserved seats. The count cannot exceed current authority capacity after outstanding reservations. Await the operation to observe Steam's response.

#### `close`

`close() -> Error`

Withdraws the exact beacon and retires its reservations and local slot observer.

#### `complete`

`complete(reservation: SteamPartyReservation) -> Error`

Acknowledges the exact reserved account after the authority confirms that it reached the current world. The Game also performs this acknowledgment automatically.
