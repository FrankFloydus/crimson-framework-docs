**Inherits** `RefCounted`

**Availability** [Trusted Steam publisher build](/steam/publisher).

Owns one trusted Steam Web API scope.

Available only in an explicit publisher build for a server or operator tool. Keep this scope alive while its services or verified identities are in use.

## Methods

### `auth`

`auth() -> SteamPublisherAuth`

Returns the trusted authentication and ownership service, or null if the scope has closed.

### `boot`

`static boot(settings: SteamPublisherSettings) -> SteamPublisherResult`

Validates and snapshots settings and the attached trusted host. Resolves the credential on the first request.

### `close`

`close() -> void`

Invalidates the issuer and its services. Pending local observations settle on the next host tick.

### `game_notifications`

`game_notifications() -> SteamGameNotifications`

Returns the scoped game notification service, or null if the scope has closed. Durable mutations require an injected `SteamPublisherSettings.notification_store`.

### `inventory`

`inventory() -> SteamPublisherInventory`

Returns the trusted Steam Inventory service for this app, or null if the scope has closed.

### `is_ready`

`is_ready() -> bool`

Returns whether the publisher still belongs to its original attached host generation.

### `leaderboards`

`leaderboards() -> SteamPublisherLeaderboards`

Returns the trusted leaderboard service, or null if the scope has closed.

### `moderation`

`moderation() -> SteamPublisherModeration`

Returns the scoped publisher moderation service, or null if the scope has closed. Actions require an injected `SteamPublisherSettings.moderation_policy`.

### `purchases`

`purchases() -> SteamPublisherPurchases`

Returns the scoped trusted Steam Wallet service, or null if the scope has closed. Actions require an injected `SteamPublisherSettings.purchase_store`.
