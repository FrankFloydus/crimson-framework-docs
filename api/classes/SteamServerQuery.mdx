### Method details

#### `fetch`

`fetch(timeout_ms: int = 5000) -> Variant`

Run the search and await its typed [`SteamListingsResult`](/api/classes/SteamListingsResult). The deadline accepts 100 to 15000 milliseconds. Eligible rows already copied by the deadline are returned when available.

#### `fetch_operation`

`fetch_operation(timeout_ms: int = 5000) -> SteamListingsOperation`

Run the same bounded search with an explicit cancellable operation. A scope permits one active search.

#### `limit`

`limit(count: int) -> SteamServerQuery`

Return a branch with a 1 to 50 result cap. The default is 50.

#### `on_map`

`on_map(world_id: StringName) -> SteamServerQuery`

Return a branch matching the exact world tag. The default accepts every compatible world.

#### `under_latency`

`under_latency(milliseconds: int) -> SteamServerQuery`

Return a branch capping latency at 1 to 60000 milliseconds. The default applies no additional latency cutoff.

#### `with_room_for`

`with_room_for(players: int) -> SteamServerQuery`

Return a branch requiring 1 to 64 free seats. The default requires one seat.
