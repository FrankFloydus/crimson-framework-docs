## Signature

```text
cancel() -> Error
```

## Return value

`Error`

## Description

Returns `@GlobalScope.OK` when the cancellation was applied. The operation settles with `@GlobalScope.ERR_SKIP`. Steam can still finish an already submitted download.

    var result: Error = steam_leaderboard_page_operation.cancel()
