**Inherits** `RefCounted`

## Description

Use `SteamScope.purchases()` after binding a [`SteamCommerceBackend`](/api/classes/SteamCommerceBackend). A local observer times out after 20 seconds. On timeout, retry the same cart and checkout ID so the backend can reconcile the existing order.

## Methods

### Instance methods

#### [`catalog`](/api/classes/SteamPurchases/methods/catalog)

Await a [`SteamPurchaseCatalogResult`](/api/classes/SteamPurchaseCatalogResult) for the signed-in player's offers.

#### [`checkout`](/api/classes/SteamPurchases/methods/checkout)

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult) for this cart.

#### [`order`](/api/classes/SteamPurchases/methods/order)

Await a [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult) for the authenticated player's exact previously created order.
