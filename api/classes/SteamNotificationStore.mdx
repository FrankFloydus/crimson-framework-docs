### Method details

#### `_claim`

`_claim(app_id: int, key: String, fingerprint: String, action: SteamNotificationStore.Action, target_id: String) -> SteamNotificationClaim`

**Virtual method.**

Atomically compare the app-scoped key and fingerprint, replay completed receipts, and claim a new write only when authorized. Update and remove claims also reserve the exact owned target against competing keys until settlement. An unresolved sent operation remains reserved for trusted reconciliation.

#### `_claim_launch_opt_in`

`_claim_launch_opt_in(app_id: int, steam_id: String, launch_id: String) -> Error`

**Virtual method.**

Atomically reserve notification registration for the exact verified app, account, and authoritative launch ID across backend workers. Return `OK` only for a new durable claim, `ERR_ALREADY_IN_USE` when it is already claimed, or an error if authorization or storage fails. Keep the claim after dispatch even when Steam does not confirm the response.

#### `_commit`

`_commit(app_id: int, key: String, fingerprint: String, action: SteamNotificationStore.Action, provider_id: String) -> bool`

**Virtual method.**

Atomically commit the exact claim and its provider ID. Record ownership on create, preserve it on update, and retire it on remove. Release the target reservation in the same transaction.

#### `_owns_session`

`_owns_session(app_id: int, session_id: String) -> bool`

**Virtual method.**

Returns whether the trusted backend currently owns this provider session for the configured app.

#### `_release_unsent`

`_release_unsent(app_id: int, key: String, fingerprint: String, action: SteamNotificationStore.Action) -> bool`

**Virtual method.**

Atomically releases the exact claim and its target reservation when Crimson reports that transport scheduling failed.

#### `_release_unsent_launch_opt_in`

`_release_unsent_launch_opt_in(app_id: int, steam_id: String, launch_id: String) -> bool`

**Virtual method.**

Release the exact launch claim when Crimson confirms no Steam request was scheduled. Return true only after releasing the claim durably.
