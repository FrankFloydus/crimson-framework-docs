**Inherits** `RefCounted`

Stages display metadata for one exact Steam lobby membership.

## Methods

### `named`

`named(name: String) -> SteamLobbyEdit`

Return a branch staging a display name of up to 127 UTF-8 bytes. An empty name clears the current name.

### `submit`

`submit() -> Error`

Recheck Steam's current owner and submit up to 16 distinct staged keys. `OK` means each write was accepted. Steam may accept earlier keys before a later write fails. Invalid or empty edits return `ERR_INVALID_PARAMETER`, closed membership returns `ERR_UNAVAILABLE`, and guests receive `ERR_UNAUTHORIZED`.

### `tag`

`tag(key: StringName, value: String) -> SteamLobbyEdit`

Return a branch staging a key of 1 to 32 ASCII letters, numbers, underscores or hyphens and a value up to 255 UTF-8 bytes. Keys starting with `crimson_`, including case variants, are reserved. An empty value clears the tag.
