**Inherits** `RefCounted`

The signed-in user's Workshop legal agreement status for the exact AppID.

Use `needs_action` to determine whether Steam needs the user to accept the latest version. The user may have accepted an older version. Open the agreement explicitly with `SteamWorkshop.show_legal_agreement()`.
