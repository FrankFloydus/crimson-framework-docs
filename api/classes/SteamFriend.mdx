## Description

Get snapshots from `SteamFriends.list()`. They remain readable after the Steam client stops.

## Properties

**[`display_name`](/api/classes/SteamFriend/properties/display_name)**

Cached Steam persona name.

**[`online`](/api/classes/SteamFriend/properties/online)**

Whether Steam presented the friend as online when this snapshot was taken.

**[`steam_id`](/api/classes/SteamFriend/properties/steam_id)**

Full decimal SteamID64 used by Steam friend actions.
