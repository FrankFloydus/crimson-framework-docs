## Signature

```text
install(high_priority: bool = false) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `high_priority` | `bool` | `false` |

## Return value

`Variant`

Await the call to receive [`SteamWorkshopInstallResult`](/api/classes/SteamWorkshopInstallResult).

## Description

A same-app item with a current local directory resolves immediately after identity verification. Otherwise this waits for Steam's matching download. `high_priority` tells Steam to prioritize the transfer ahead of other downloads. An unsubscribed item may be cached temporarily. Inspect and validate the installed content before using it.
