## Signature

```text
fetch() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamWorkshopItemResult`](/api/classes/SteamWorkshopItemResult).

## Description

An unavailable or removed item can report `ERR_FILE_NOT_FOUND`.

## Example

```gdscript
extends Node

func run_fetch(steam_workshop_item_ref: SteamWorkshopItemRef, title_label: Label) -> void:
    var result: SteamWorkshopItemResult = await steam_workshop_item_ref.fetch()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamWorkshopItem = result.value
    if payload == null:
        return
    var title: String = payload.title
    title_label.text = "Title: %s" % str(title)
```
