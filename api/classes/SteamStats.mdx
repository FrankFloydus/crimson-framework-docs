**Inherits** `RefCounted`

## Description

Get this service from `SteamClient.stats()` after Steam starts. It reads Steam's local cache for the current app. Use `edit()` to collect changes and `SteamStatsEdit.submit()` to request persistence once.

## Examples

- [Update Steam progression after a match victory](/api/classes/SteamStats/methods/edit#example)

## Methods

### Instance methods

#### [`achievement`](/api/classes/SteamStats/methods/achievement)

Returns a detached snapshot of the named achievement, or `null` if the name or cache cannot be read.

#### [`achievements`](/api/classes/SteamStats/methods/achievements)

Returns a typed array of readable achievement snapshots.

#### [`clear_achievement`](/api/classes/SteamStats/methods/clear_achievement)

Clears an unlock in the signed-in player's local cache.

#### [`edit`](/api/classes/SteamStats/methods/edit)

Returns an empty draft.

#### [`indicate_achievement_progress`](/api/classes/SteamStats/methods/indicate_achievement_progress)

Alias for `show_progress()`.

#### [`is_available`](/api/classes/SteamStats/methods/is_available)

Returns whether the active client scope exposes the Steam User Stats interface on the main thread.

#### [`set_stat_float`](/api/classes/SteamStats/methods/set_stat_float)

Sets an absolute finite float in the local cache within Steam's single-precision range.

#### [`set_stat_int`](/api/classes/SteamStats/methods/set_stat_int)

Sets an absolute signed 32-bit integer in the local cache.

#### [`show_progress`](/api/classes/SteamStats/methods/show_progress)

Requests a Steam overlay progress popup for a locked achievement.

#### [`stat_float`](/api/classes/SteamStats/methods/stat_float)

Reads a cached float or average-rate stat.

#### [`stat_int`](/api/classes/SteamStats/methods/stat_int)

Reads a cached signed 32-bit stat.

#### [`store`](/api/classes/SteamStats/methods/store)

Requests persistence of changed stats and achievements. `@GlobalScope.OK` means Steam accepted the local request.

#### [`unlock_achievement`](/api/classes/SteamStats/methods/unlock_achievement)

Marks the named achievement unlocked in the signed-in player's local cache.

#### [`update_average_rate`](/api/classes/SteamStats/methods/update_average_rate)

Updates an average-rate stat in the local cache.

## Signals

### `achievement_stored`

`achievement_stored(name: String, current: int, maximum: int)`

Emitted when Steam reports an achievement unlock or a progress popup for the active app. Both progress counts are zero for a complete unlock.

### `stats_stored`

`stats_stored(steam_result: int)`

Emitted with Steam's native result for a store or achievement progress event. This is an app-wide event shared by matching Steam scopes.
