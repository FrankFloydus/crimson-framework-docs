## Description

Get this service from `SteamClient.stats()` after Steam starts. It reads Steam's local cache for the current app. Use `edit()` to collect changes and `SteamStatsEdit.submit()` to request persistence once.

### Method details

#### `achievement`

`achievement(name: StringName) -> SteamAchievement`

Returns a detached snapshot of the named achievement, or `null` if the name or cache cannot be read.

#### `achievements`

`achievements() -> SteamAchievement[]`

Returns a typed array of readable achievement snapshots. Returns an empty array if the Steam stats cache is unavailable or there are no entries.

#### `clear_achievement`

`clear_achievement(name: String) -> Error`

Clears an unlock in the signed-in player's local cache. Use on controlled test data or as part of a game reset. Call `store()` to request persistence.

#### `edit`

`edit() -> SteamStatsEdit`

Returns an empty draft. This call has no effect on the Steam cache.

#### `indicate_achievement_progress`

`indicate_achievement_progress(name: String, current: int, maximum: int) -> Error`

**Deprecated. Use \[method show\_progress\] instead.**

Alias for `show_progress()`.

#### `is_available`

`is_available() -> bool`

Returns whether the active client scope exposes the Steam User Stats interface on the main thread.

#### `set_stat_float`

`set_stat_float(name: String, value: float) -> Error`

Sets an absolute finite float in the local cache within Steam's single-precision range. Call `store()` to request persistence.

#### `set_stat_int`

`set_stat_int(name: String, value: int) -> Error`

Sets an absolute signed 32-bit integer in the local cache. Call `store()` to request persistence.

#### `show_progress`

`show_progress(name: String, current: int, maximum: int) -> Error`

Requests a Steam overlay progress popup for a locked achievement. The current count must be positive and below the maximum, which fits an unsigned 32-bit integer. The popup leaves the cached unlock state unchanged.

#### `stat_float`

`stat_float(name: String) -> SteamFloatResult`

Reads a cached float or average-rate stat. Check `SteamResult.ok` before using its value. The result reports an invalid name, an unavailable interface, or a missing stat of the requested type.

#### `stat_int`

`stat_int(name: String) -> SteamIntResult`

Reads a cached signed 32-bit stat. Check `SteamResult.ok` before using its value. The result reports an invalid name, an unavailable interface, or a missing stat of the requested type.

#### `store`

`store() -> Error`

Requests persistence of changed stats and achievements. `@GlobalScope.OK` means Steam accepted the local request. Use `stats_stored` to observe the app-wide backend response.

#### `unlock_achievement`

`unlock_achievement(name: String) -> Error`

Marks the named achievement unlocked in the signed-in player's local cache. Call `store()` to request persistence and the unlock notification.

#### `update_average_rate`

`update_average_rate(name: String, count: float, seconds: float) -> Error`

Updates an average-rate stat in the local cache. The accumulated count must be finite within Steam's float range and the duration must be finite and positive. Call `store()` to request persistence.

## Signals

### `achievement_stored`

`achievement_stored(name: String, current: int, maximum: int)`

Emitted when Steam reports an achievement unlock or a progress popup for the active app. Both progress counts are zero for a complete unlock.

### `stats_stored`

`stats_stored(steam_result: int)`

Emitted with Steam's native result for a store or achievement progress event. This is an app-wide event shared by matching Steam scopes.
