#### [`secure`](/api/classes/SteamServer/methods/secure)

Return a branch retaining the default requirement for certified Steam identities and valid Steam authentication tickets.

#### [`via_sdr`](/api/classes/SteamServer/methods/via_sdr)

Return a branch selecting a hosted Steam Datagram Relay deployment with a profile name of up to 32 ASCII letters, digits, underscores or hyphens.

#### [`with_login`](/api/classes/SteamServer/methods/with_login)

Return a branch reading a server login token from an operator-owned environment key.

#### [`with_product_metadata`](/api/classes/SteamServer/methods/with_product_metadata)

Returns a branch with the game's configured Steam master-server version, game description, and install folder name.

## Constants and enums

### `Advertisement`

| Name | Value | Description |
| --- | --- | --- |
| `DIRECT` | `0` | Authenticated direct play with no Steam browser advertisement. |
| `INTERNET` | `2` | Request Valve's joint server-browser and LAN advertisement after the listener, certificate, and world are ready. |
| `LAN` | `1` | Request LAN-only publication. Startup reports unavailable while the SDK lacks an independent secure LAN-only switch. |
