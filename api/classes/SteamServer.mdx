**Inherits** `RefCounted`

Fluent settings for a certified playerless Steam dedicated Game.

## Methods

### `advertise_on`

`advertise_on(scope: SteamServer.Advertisement) -> SteamServer`

Return a branch with the selected advertisement policy. LAN-only Steam advertisement is unavailable in the current SDK. Only `INTERNET` explicitly enables Steam discovery.

### `bind_to`

`bind_to(address: String) -> SteamServer`

Return a branch bound to a literal IPv4 interface. An asterisk uses every local IPv4 interface.

### `configure`

`static configure(name: String = "Crimson Server", game_port: int = 27015, query_port: int = 27016) -> SteamServer`

Configure the server name and two distinct UDP ports. The display name allows up to 63 UTF-8 bytes. Gameplay accepts ports 1 to 65535. Query ports 1 to 65534 are available. The default binds all IPv4 interfaces and starts in authenticated, unlisted direct mode.

### `get_game_description`

`get_game_description() -> String`

Returns the title's browser game description.

### `get_install_dir`

`get_install_dir() -> String`

Returns the title's Steam install folder name, without the parent path.

### `get_product_version`

`get_product_version() -> String`

Returns the version sent to Steam's GameServer initialization and master-server checks.

### `is_valid`

`is_valid() -> bool`

Returns whether all detached settings passed validation. An invalid branch cannot start a Steam dedicated Game.

### `secure`

`secure() -> SteamServer`

Return a branch retaining the default requirement for certified Steam identities and valid Steam authentication tickets.

### `via_sdr`

`via_sdr(profile: StringName) -> SteamServer`

Return a branch selecting a hosted Steam Datagram Relay deployment with a profile name of up to 32 ASCII letters, digits, underscores or hyphens. An empty profile selects direct transport. A hosted profile requires Valve-provisioned server settings and a trusted game coordinator.

### `with_login`

`with_login(secret_ref: StringName) -> SteamServer`

Return a branch reading a server login token from an operator-owned environment key. Use up to 64 uppercase ASCII letters, digits or underscores. An empty key uses Steam's anonymous game server logon.

### `with_product_metadata`

`with_product_metadata(version: String, description: String, install_dir: String) -> SteamServer`

Returns a branch with the game's configured Steam master-server version, game description, and install folder name. Version and description are limited to 63 UTF-8 bytes. The folder name is limited to 31 UTF-8 bytes and must be one folder component. All values are nonempty and exclude controls. Invalid settings prevent dedicated startup. Defaults are 1.0.0.0, Crimson, and crimson for compatibility. Set metadata before boot for a published app.

## Constants and enums

### `Advertisement`

| Name | Value | Description |
| --- | --- | --- |
| `DIRECT` | `0` | Authenticated direct play with no Steam browser advertisement. |
| `INTERNET` | `2` | Request Valve's joint server-browser and LAN advertisement after the listener, certificate, and world are ready. |
| `LAN` | `1` | Request LAN-only publication. Startup reports unavailable while the SDK lacks an independent secure LAN-only switch. |
