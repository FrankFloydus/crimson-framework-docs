## Return value

`Variant`

Await the call to receive [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult).

## Description

If Steam reports that the score became the entry, attaches the requested replay. Use `await` to receive a [`SteamLeaderboardSubmissionResult`](/api/classes/SteamLeaderboardSubmissionResult). The accepted receipt remains available if attachment fails.

## Example

```gdscript
extends Node

func run_submit_score(
    steam_score_options: SteamScoreOptions,
    board_name: String,
    score: int,
    apply_submit_score: Callable
) -> void:
    var result: SteamLeaderboardSubmissionResult = await steam_score_options.submit_score(board_name, score)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamLeaderboardSubmission = result.value
    if payload == null:
        return
    apply_submit_score.call(payload)
```
