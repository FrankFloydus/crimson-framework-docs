## Signature

```text
wait() -> Variant
```

## Return value

`Variant`

Await the call to receive [`SteamLeaderboardResult`](/api/classes/SteamLeaderboardResult).

## Description

A settled operation returns the same result immediately.

## Example

```gdscript
extends Node

func run_wait(
    steam_leaderboard_operation: SteamLeaderboardOperation,
    apply_wait: Callable
) -> void:
    var result: SteamLeaderboardResult = await steam_leaderboard_operation.wait()
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamLeaderboard = result.value
    if payload == null:
        return
    apply_wait.call(payload)
```
