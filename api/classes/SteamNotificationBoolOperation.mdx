Retained observation of one boolean notification acknowledgment.

## Methods

### `cancel`

`cancel() -> Error`

Settles local observation with `ERR_SKIP`. An already submitted request can still reach Steam and commit its durable receipt. Returns `ERR_DOES_NOT_EXIST` if observation has ended.

### `is_finished`

`is_finished() -> bool`

Returns whether this observation has a terminal result.

### `result`

`result() -> SteamBoolResult`

Returns the terminal result, or `null` while pending.

### `wait`

`wait() -> Variant`

Use `await operation.wait()` to receive a [`SteamBoolResult`](/api/classes/SteamBoolResult) before or after settlement.

## Signals

### `completed`

`completed(result: SteamBoolResult)`
