## Description

Submits gameplay markers and phases to Steam Game Recording. Get the service from `SteamClient.timeline()`. Markers belong to the issuing facade. The process can have one open phase. A submitted marker does not guarantee footage. Use the recording queries to check for footage.

### Method details

#### `add_phase_tag`

Adds a tag to the current phase owned by this facade. An empty group leaves the tag out of group filtering. Priority ranges from 0 through 1000.

#### `end_range`

#### `is_available`

`is_available() -> bool`

Returns whether the active main-thread scope can use Steam Timeline.

#### `mark`

`mark(title: String, options: TimelineMarkerOptions = null) -> SteamTimelineEventResult`

Adds an instantaneous marker. A null options object selects the default icon, priority, clip policy, and start time.

#### `mark_range`

`mark_range(title: String, duration_seconds: float, options: TimelineMarkerOptions = null) -> SteamTimelineEventResult`

Marks a fixed duration greater than zero and at most 600 seconds.

#### `open_in_overlay`

`open_in_overlay(event: SteamTimelineEvent) -> Error`

Requests the overlay view of an event owned by this facade. Returns `ERR_BUSY` if the overlay is disabled or still starting.

#### `open_phase_in_overlay`

`open_phase_in_overlay(phase_id: String) -> Error`

Requests that an enabled Steam overlay open the phase associated with this game ID.

#### `phase_recording`

`phase_recording(phase_id: String) -> Variant`

Await to receive a [`SteamTimelinePhaseResult`](/api/classes/SteamTimelinePhaseResult) for the exact stable phase ID.

#### `recording_exists`

`recording_exists(event: SteamTimelineEvent) -> Variant`

Await to receive a [`SteamBoolResult`](/api/classes/SteamBoolResult) with whether Steam has video for the completed event.

#### `recording_operation`

`recording_operation(event: SteamTimelineEvent) -> SteamTimelineOperation`

Starts the same lookup as `recording_exists()` and returns a retained, cancellable operation.

#### `remove_event`

`remove_event(event: SteamTimelineEvent) -> Error`

Removes a completed event or discards an open range owned by this service. Invalidates the handle.

#### `set_game_mode`

`set_game_mode(mode: SteamTimeline.GameMode) -> Error`

Sets the activity mode for the process timeline.

#### `set_phase_attribute`

`set_phase_attribute(group: String, value: String, priority: int = 0) -> Error`

Replaces an attribute on the current phase owned by this facade. Group and value are nonempty. Priority ranges from 0 through 1000.

#### `set_tooltip`

`set_tooltip(description: String, offset_seconds: float = 0.0) -> Error`

Sets a nonempty localized tooltip of up to 1024 UTF-8 bytes at a relative time in seconds.

#### `start_phase`

`start_phase(phase_id: String) -> Error`

Starts the process phase using a stable, nonempty game ID of up to 63 UTF-8 bytes with no ASCII control characters. An already-open phase returns `ERR_BUSY`.

#### `start_range`

`start_range(title: String, options: TimelineMarkerOptions = null) -> SteamTimelineEventResult`

Starts an open range. End it with `end_range()` or discard it with `remove_event()`.

#### `update_range`

`update_range(event: SteamTimelineEvent, title: String, presentation: TimelineMarkerPresentation = null) -> Error`

Replaces the display details of an open range owned by this service. Null presentation selects the default details.

## Constants and enums

### `ClipPriority`

| Name | Value | Description |
| --- | --- | --- |
| `FEATURED` | `3` | Steam may feature the clip suggestion. |
| `NONE` | `1` | The marker carries no clip suggestion. |
| `STANDARD` | `2` | Steam may offer a clip suggestion. |

### `GameMode`

| Name | Value | Description |
| --- | --- | --- |
| `LOADING_SCREEN` | `4` | The game is displaying a loading screen. |
| `MENUS` | `3` | The player is navigating menus. |
| `PLAYING` | `1` | The player is actively playing. |
| `STAGING` | `2` | The player is preparing to play, for example in a lobby. |
