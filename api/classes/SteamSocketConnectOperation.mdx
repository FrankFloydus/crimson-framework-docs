**Inherits** `RefCounted`

A retained operation for one outgoing Steam handshake.

Await `wait()` or observe `completed`. The terminal result is retained for later reads.

## Methods

### `cancel`

`cancel() -> Error`

Cancels the exact pending handshake and settles it with `ERR_SKIP`. A completed operation has no pending handshake to cancel.

### `is_finished`

`is_finished() -> bool`

Returns whether the operation has reached a terminal result.

### `result`

`result() -> SteamSocketConnectionResult`

Returns the terminal typed result, or `null` while pending.

### `wait`

`wait() -> Variant`

Use `var result: SteamSocketConnectionResult = await operation.wait()`. Returns the existing result immediately or a signal that settles with the typed result.

## Signals

### `completed`

`completed(result: SteamSocketConnectionResult)`

Emitted once when the operation settles.
