## Signals

### `peer_joined`

`peer_joined(peer_id: int)`

Emitted when a peer joins the coordinated session roster. The authority can then bind the admitted connection to a verified player ID.

### `peer_left`

`peer_left(peer_id: int)`

Emitted when a peer leaves the coordinated session roster. The departed peer's binding and readiness are retired.

### `phase_changed`

`phase_changed(phase: int)`

Emitted when the game changes Phase. The argument is the new phase.

### `projection_updated`

`projection_updated(revision: int, baseline: bool)`

Emitted after a guest applies a visible projection at revision. baseline is true when the update establishes a new baseline. Read get\_projection to obtain the applied view.

### `session_ended`

`session_ended(reason: StringName)`

Emitted after the game releases session resources. The reason identifies what ended the session.

### `world_ready`

`world_ready(world_id: StringName, world_epoch: int)`

Emitted when a world with the given ID and epoch is ready for play. Coordinated network games wait for required scene and baseline acknowledgments.

## Constants and enums

### `Phase`

| Name | Value | Description |
| --- | --- | --- |
| `IDLE` | `0` | No active game session. An online listing lookup may still be pending. |
| `LOBBY` | `1` | A coordinated session is open and the first world is pending. |
| `RECOVERING` | `4` | A failure after publication closed command admission. Leave the game before starting a new session. |
| `RUNNING` | `3` | The published world is ready for play. |
| `TRANSITIONING` | `2` | A world startup, travel, or restore is in progress. |
