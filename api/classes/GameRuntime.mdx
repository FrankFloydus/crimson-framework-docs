### Method details

#### `bind_player`

`bind_player(peer: int, player_id: String) -> Error`

Assign a stable, game-owned player ID to an admitted peer in the authority lobby. The caller supplies the verified identity. Returns a Godot Error.

#### `configure`

`static configure() -> GameDefinition`

Create a new GameDefinition with the same defaults as a definition created in the Inspector.

#### `declare_command`

`declare_command(name: String, requires_primary: bool = false) -> Error`

Declare a command name on a guest. Match the authority's requires\_primary setting. Returns a Godot Error.

#### `get_local_character_id`

`get_local_character_id() -> String`

Return the local player's current primary character ID, or an empty string when no primary is available.

#### `get_local_player`

`get_local_player() -> Node3D`

Return the spawned player node for this peer in an immediate-play game, or null when there is no local player.

#### `get_local_player_id`

`get_local_player_id() -> String`

Return the game-owned player ID for this peer, or an empty string when no local binding is available.

#### `get_online_listing`

`get_online_listing() -> String`

Return the current provider listing ID, or an empty string when the game has no active listing.

#### `get_phase`

`get_phase() -> GameRuntime.Phase`

Return the current Phase value. Listen to phase\_changed to observe transitions.

#### `get_player`

`get_player(peer_id: int) -> Node3D`

Return the spawned player node for peer\_id in an immediate-play game, or null when that peer has no mounted player.

#### `get_projection`

`get_projection() -> Dictionary`

Return a detached copy of this guest's visible replicated records. Read it after projection\_updated. The authority's internal command context is omitted.

#### `get_world`

`get_world() -> Node`

Return the currently mounted world root, or null when no world is mounted. Reacquire the node after travel, restore, or teardown.

#### `get_world_epoch`

`get_world_epoch() -> int`

Return the epoch of the published world. Epochs distinguish successive activations, including visits to the same world ID.

#### `get_world_id`

`get_world_id() -> StringName`

Return the last published world ID. Wait for world\_ready before using it as the active playable destination.

#### `host`

`host(port: int, max_clients: int = 32, bind_address: String = "*") -> Error`

Open a coordinated lobby on the session's selected transport, ENet by default. max\_clients counts guests. With ENet, port is the UDP port and \* binds all interfaces. A successful return opens the lobby for admission and player binding before start\_match.

#### `host_game`

`host_game(bind_address: String = "*") -> GameOperation`

Start a direct-address listen game with the configured starting scene and player. The operation succeeds after the world and local player are ready and the host can admit guests. Use \* to bind all interfaces.

#### `host_online`

`host_online(public_address: String = "", bind_address: String = "*") -> GameOperation`

Start a listen game using the configured provider. Supply the advertised address, or an empty string for a provider that supplies a route. The operation completes after the world is ready and the provider publishes its listing.

#### `invites`

`invites() -> GameInvites`

Return this attachment's invite gateway if its provider supplies one. A failed Steam attachment has an unavailable gateway.

#### `is_authority`

`is_authority() -> bool`

Return whether this game instance currently owns session authority, including when playing offline.

#### `join`

`join(address: String, port: int, timeout_seconds: float = 10.0) -> Error`

Begin joining a coordinated lobby through the session's selected transport. With ENet, supply the host address and UDP port. timeout\_seconds bounds connection time. OK means the attempt started. Observe phase\_changed and session\_ended for the outcome.

#### `join_game`

`join_game(address: String) -> GameOperation`

Connect to a direct-address game using the configured UDP port. Await the operation for scene and roster readiness and placement of the local player.

#### `join_listing`

`join_listing(listing: OnlineListing) -> GameOperation`

Join a provider-owned discovery or invite snapshot through the normal online game lifecycle. The provider resolves the current lobby, and the operation succeeds after authenticated world and player readiness.

#### `join_online`

`join_online(listing_id: String) -> GameOperation`

Resolve listing\_id through the configured provider and join the resulting game. The operation succeeds after admission, world synchronization, and local player readiness.

#### `leave`

`leave() -> Error`

Cancel pending startup or begin releasing the active transport, match, and mounted world. Observe session\_ended after leaving an active session. If cancelling an online lookup before the session starts, observe the startup operation. Returns a Godot Error.

#### `open_offline`

`open_offline() -> Error`

Open a local authority lobby. Use it before restore to continue from a menu without loading the default world first. Returns a Godot Error.

#### `play_solo`

`play_solo() -> GameOperation`

Mount the configured starting scene and spawn the local player in an offline game. Await the operation before accessing the mounted world or player.

#### `register_command`

`register_command(name: String, handler: Callable, requires_primary: bool = false) -> Error`

Register an authority-side handler for a command name. The handler receives the trusted player ID and the intent dictionary. Set requires\_primary to require a current primary character assignment. Returns a Godot Error.

#### `restore`

`restore(profile: String, slot: String, sequence: String = "", generation_id: String = "") -> GameOperation`

Read a checkpoint for profile and slot and activate its saved world and stores through the authority transition pipeline. Leave sequence and generation\_id empty to restore the latest generation, or supply both for an exact restore.

#### `save`

`save(profile: String, slot: String, metadata: Dictionary = {}, autosave: bool = false) -> GameOperation`

Capture the running authority's committed state and publish a checkpoint generation. Pass display metadata as a dictionary and set autosave to use autosave admission. A successful operation returns the generation sequence and ID in value.

#### `save_history`

`save_history(profile: String, slot: String, before_sequence: String = "", before_id: String = "", limit: int = 16) -> GameOperation`

Read up to limit generations from a known profile and slot, newest first. Supply both before\_sequence and before\_id to continue from an exclusive cursor. A successful result includes rows in value, the slot status, a truncated flag, and a next cursor when more rows exist.

#### `save_slot`

`save_slot(profile: String, slot: String) -> SaveSlot`

Create a handle for save, history, and restore actions on the specified profile and slot of this game.

#### `set_projector`

`set_projector(projector: Callable) -> Error`

Set the authority's visibility callback. It receives peer ID, player ID, world epoch, and committed revision, and returns a dictionary with ok and view. Its per-recipient view takes precedence over the shared-store list. Returns a Godot Error.

#### `set_shared_stores`

`set_shared_stores(store_ids: PackedStringArray) -> Error`

Set the store IDs whose complete records can be published to every bound guest. The default view exposes no shared stores. A custom projector takes precedence. Returns a Godot Error.

#### `start_dedicated`

`start_dedicated(bind_address: String = "*") -> GameOperation`

Mount the starting world as a dedicated direct-address authority. All configured player seats are available to guests. Await the operation for world and admission readiness.

#### `start_dedicated_online`

`start_dedicated_online(public_address: String = "", bind_address: String = "*") -> GameOperation`

Mount a playerless authority world and publish it through the configured online provider. Supply the advertised address, or an empty string for a provider-managed route. Await the operation for listing and world readiness.

#### `start_match`

`start_match(world: StringName = &"") -> GameOperation`

Start a registered world from the coordinated authority lobby. An empty world uses the definition's starting world. Bind all admitted peers before calling it and await world readiness.

#### `start_offline`

`start_offline() -> GameOperation`

Open a coordinated offline session, bind the local player, and start the configured world. Await the operation for world readiness.

#### `submit`

`submit(name: String, payload: Dictionary = {}) -> GameOperation`

Submit a declared gameplay command and a plain dictionary payload from a ready participant. The returned operation reports the authority's command result. Observe projection\_updated separately for visible state changes.

#### `travel_to`

`travel_to(world: StringName) -> GameOperation`

Activate a registered destination on the coordinated authority while preserving committed match stores. Await the operation before using the replacement world. A preparation failure leaves the prior world available.

#### `voice`

`voice() -> GameVoice`

Returns the persistent voice service for this exact Steam game attachment. Returns null when no Steam client or dedicated Steam service is configured.

## Signals

### `peer_joined`

`peer_joined(peer_id: int)`

Emitted when a peer joins the coordinated session roster. The authority can then bind the admitted connection to a verified player ID.

### `peer_left`

`peer_left(peer_id: int)`

Emitted when a peer leaves the coordinated session roster. The departed peer's binding and readiness are retired.

### `phase_changed`

`phase_changed(phase: int)`

Emitted when the game changes Phase. The argument is the new phase.

### `projection_updated`

`projection_updated(revision: int, baseline: bool)`

Emitted after a guest applies a visible projection at revision. baseline is true when the update establishes a new baseline. Read get\_projection to obtain the applied view.

### `session_ended`

`session_ended(reason: StringName)`

Emitted after the game releases session resources. The reason identifies what ended the session.

### `world_ready`

`world_ready(world_id: StringName, world_epoch: int)`

Emitted when a world with the given ID and epoch is ready for play. Coordinated network games wait for required scene and baseline acknowledgments.

## Constants and enums

### `Phase`

| Name | Value | Description |
| --- | --- | --- |
| `IDLE` | `0` | No active game session. An online listing lookup may still be pending. |
| `LOBBY` | `1` | A coordinated session is open and the first world is pending. |
| `RECOVERING` | `4` | A failure after publication closed command admission. Leave the game before starting a new session. |
| `RUNNING` | `3` | The published world is ready for play. |
| `TRANSITIONING` | `2` | A world startup, travel, or restore is in progress. |
