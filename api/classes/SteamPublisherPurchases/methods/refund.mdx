## Parameters

| Parameter | Type | Default |

## Return value

`Variant`

Await the call to receive [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult).

## Description

Queries and requests a full refund only for a known fulfilled order and an explicit store policy approval. Reversal requires a confirmed receipt and durable update. Partial Steam-originated reversals are handled by `reconcile()`.

## Example

```gdscript
extends Node

func run_refund(
    steam_publisher: SteamPublisher,
    order_id: String,
    apply_refund: Callable
) -> void:
    if not steam_publisher.is_ready():
        return
    var steam_publisher_purchases: SteamPublisherPurchases = steam_publisher.purchases()
    if steam_publisher_purchases == null:
        return
    var result: SteamPurchaseOutcomeResult = await steam_publisher_purchases.refund(order_id)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamPurchaseOutcome = result.value
    if payload == null:
        return
    apply_refund.call(payload)
```
