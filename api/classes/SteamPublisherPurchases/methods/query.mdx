## Signature

```text
query(order_id: String) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `order_id` | `String` | — |

## Return value

`Variant`

Await the call to receive [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult).

## Description

Verifies exact Steam payer, transaction, currency and line amounts and persists applicable state changes. An unknown order or invalid receipt returns a typed error.

## Example

```gdscript
extends Node

func run_query(
    steam_publisher: SteamPublisher,
    order_id: String,
    apply_query: Callable
) -> void:
    if not steam_publisher.is_ready():
        return
    var steam_publisher_purchases: SteamPublisherPurchases = steam_publisher.purchases()
    if steam_publisher_purchases == null:
        return
    var result: SteamPurchaseOutcomeResult = await steam_publisher_purchases.query(order_id)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamPurchaseOutcome = result.value
    if payload == null:
        return
    apply_query.call(payload)
```
