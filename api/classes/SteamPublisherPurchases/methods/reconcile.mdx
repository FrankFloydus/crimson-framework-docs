## Return value

`Variant`

Await the call to receive [`SteamPurchaseReconciliationResult`](/api/classes/SteamPurchaseReconciliationResult).

## Description

`max_results` must be from 1 to 1000 and defaults to 1000. A reply larger than 4 MiB fails validation. Applies known receipts and exact item reversals in order. A failing event leaves the original cursor available for replay. A full page whose last timestamp equals the input cursor returns `ERR_BUSY`.
