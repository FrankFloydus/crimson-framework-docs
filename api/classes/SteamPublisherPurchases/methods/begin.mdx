## Signature

```text
begin(player: SteamIdentity, cart: SteamPurchaseCart, checkout_id: String) -> Variant
```

## Parameters

| Parameter | Type | Default |
| --- | --- | --- |
| `player` | [`SteamIdentity`](/api/classes/SteamIdentity) | — |
| `cart` | [`SteamPurchaseCart`](/api/classes/SteamPurchaseCart) | — |
| `checkout_id` | `String` | — |

## Return value

`Variant`

Await the call to receive [`SteamPurchaseOutcomeResult`](/api/classes/SteamPurchaseOutcomeResult).

## Description

Requires a [`SteamIdentity`](/api/classes/SteamIdentity) verified by the same publisher. Atomically prices and reserves the cart under `checkout_id`, then starts Steam authorization. An uncertain previous initialization is queried without automatically repeating the write.

## Example

```gdscript
extends Node

func run_begin(
    steam_publisher: SteamPublisher,
    player: SteamIdentity,
    cart: SteamPurchaseCart,
    checkout_id: String,
    apply_begin: Callable
) -> void:
    if not steam_publisher.is_ready():
        return
    var steam_publisher_purchases: SteamPublisherPurchases = steam_publisher.purchases()
    if steam_publisher_purchases == null:
        return
    var result: SteamPurchaseOutcomeResult = await steam_publisher_purchases.begin(player, cart, checkout_id)
    if result == null:
        return
    if not result.ok:
        push_warning(result.message)
        return
    var payload: SteamPurchaseOutcome = result.value
    if payload == null:
        return
    apply_begin.call(payload)
```
