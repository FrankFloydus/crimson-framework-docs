## Description

Build independent policies using `SteamBrowser.allow_origins()`. Each opening binds the resulting page to its own fixed policy and original client scope.

## Methods

### `open`

`open(url: String, size: Vector2i = Vector2i(960, 540)) -> Variant`

Await a [`SteamBrowserPageResult`](/api/classes/SteamBrowserPageResult) after submitting creation and initial navigation under this policy. HTTPS permits its initial origin. HTTP is available only for an explicitly included numeric loopback origin at the same port.
