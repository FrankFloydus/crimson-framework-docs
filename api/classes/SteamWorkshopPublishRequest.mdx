## Description

Get a draft from `SteamWorkshop.new_item()` or `SteamWorkshopItemRef.edit()`. Modifiers return independent branches. New items require a title and existing local content directory and default to private visibility. An edit preserves every field left unset.

## Constants and enums

### `Visibility`

| Name | Value | Description |
| --- | --- | --- |
| `FRIENDS_ONLY` | `1` | Shares the item with the author's Steam friends. |
| `PRIVATE` | `0` | Restricts visibility to the item's author. |
| `PUBLIC` | `2` | Publishes the item publicly in Steam Workshop. |
| `UNLISTED` | `3` | Allows viewing through the item's link while keeping it out of global Workshop query results. |
