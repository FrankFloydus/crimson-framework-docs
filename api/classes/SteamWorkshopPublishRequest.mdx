## Description

Get a draft from `SteamWorkshop.new_item()` or `SteamWorkshopItemRef.edit()`. Modifiers return independent branches. New items require a title and existing local content directory and default to private visibility. An edit preserves every field left unset.

### Method details

#### `described_as`

`described_as(description: String) -> SteamWorkshopPublishRequest`

Returns a branch with a replacement item description. An empty description clears this field. Supports up to 7,999 UTF-8 bytes.

#### `named`

`named(title: String) -> SteamWorkshopPublishRequest`

Returns a branch with a replacement title of 1 to 128 UTF-8 bytes.

#### `submit`

`submit(change_notes: String = "") -> Variant`

Use `await request.submit()` to receive a [`SteamWorkshopPublicationResult`](/api/classes/SteamWorkshopPublicationResult). Steam uploads the chosen content and preview. Keep those paths available while Steam may still complete a submitted update. `change_notes` supports up to 7,999 UTF-8 bytes. If Steam has already created an item, an interrupted upload can return its published ID even when `SteamResult.ok` is false. When `SteamWorkshopPublication.needs_legal_agreement` is true, offer `SteamWorkshop.show_legal_agreement()` and check `SteamWorkshop.legal_agreement_status()` after the author closes the overlay. Continue a known item through `SteamWorkshopItemRef.edit()` using the original published ID.

#### `tagged`

`tagged(tag: String) -> SteamWorkshopPublishRequest`

Returns a branch that includes this tag in the replacement set. Supply up to 16 distinct tags using printable characters other than commas. A tag supports up to 255 UTF-8 bytes, and Steam also bounds the combined set. Leaving tags unset on an edit preserves the existing set.

#### `visibility`

`visibility(visibility: SteamWorkshopPublishRequest.Visibility) -> SteamWorkshopPublishRequest`

Returns a branch with the selected Steam Workshop audience. Leaving visibility unset keeps a new item private and preserves an existing item's audience.

#### `with_content`

`with_content(directory: String) -> SteamWorkshopPublishRequest`

Returns a branch that uploads the selected content directory. Use an existing absolute local directory or a Godot path that resolves to one. Steam uploads the directory's contents.

#### `with_preview`

`with_preview(image_file: String) -> SteamWorkshopPublishRequest`

Returns a branch with a replacement local preview image. The file must contain at least 16 bytes and be smaller than 1 MiB. Steam uses the active app's Cloud settings to store the preview.

## Constants and enums

### `Visibility`

| Name | Value | Description |
| --- | --- | --- |
| `FRIENDS_ONLY` | `1` | Shares the item with the author's Steam friends. |
| `PRIVATE` | `0` | Restricts visibility to the item's author. |
| `PUBLIC` | `2` | Publishes the item publicly in Steam Workshop. |
| `UNLISTED` | `3` | Allows viewing through the item's link while keeping it out of global Workshop query results. |
