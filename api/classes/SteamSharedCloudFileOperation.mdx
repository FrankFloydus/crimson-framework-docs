**Inherits** `RefCounted`

Retained observation of one shared Steam Cloud download.

## Methods

### `cancel`

`cancel() -> Error`

Ends local observation and completes it with `ERR_SKIP`. Steam finishes the native download and closes any resulting cache entry. Returns `ERR_DOES_NOT_EXIST` when observation has already ended.

### `is_finished`

`is_finished() -> bool`

Returns whether the operation has a terminal result.

### `result`

`result() -> SteamSharedCloudFileResult`

Returns the same terminal result as `completed`, or `null` while observation is pending.

### `wait`

`wait() -> Variant`

Use `await operation.wait()` to receive a [`SteamSharedCloudFileResult`](/api/classes/SteamSharedCloudFileResult) before or after observation ends.

## Signals

### `completed`

`completed(result: SteamSharedCloudFileResult)`

Emitted once after a pending download settles, including after cancellation or client shutdown. `result()` already returns this result during the signal.
