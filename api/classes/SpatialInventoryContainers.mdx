### Method details

#### `get_contents`

#### `get_host_placement_policy`

#### `get_owner_inventory`

`get_owner_inventory(item_id: StringName) -> SpatialInventory`

Return the grid that uniquely owns the given item ID, or null if there is no unique owner.

#### `placement_policy`

`placement_policy(context: Dictionary) -> String`

Validate a proposed action using its `id`, `source`, `destination`, and action-specific fields. Rejects duplicate ownership, nesting cycles, and container splits or merges. Returns an empty String to allow the action, or a reason to deny it.

#### `register_inventory`

`register_inventory(inventory: SpatialInventory, container_id: StringName = &"") -> Error`

Register an inventory grid. Use an empty `container_id` for a standalone grid or pass the owning item ID for a container's contents. Returns an error if the registration introduces duplicate ownership or invalid nesting.

#### `set_host_placement_policy`

`set_host_placement_policy(value: Callable) -> void`

Set an optional game rule that receives the placement context after built-in validation. The callback returns an empty String to accept the placement or a reason to deny it.

#### `unregister_inventory`

`unregister_inventory(inventory: SpatialInventory) -> Error`

Remove a grid from ownership tracking without editing the grid. Returns `ERR_DOES_NOT_EXIST` if it was not registered.

#### `validate_changes`

`validate_changes(changes: Array) -> String`

Check the projected ownership graph after applying the given `SpatialInventory.apply_placement_changes()` rows. Returns an empty String if the proposed batch preserves unique owners and acyclic nesting. Apply the batch separately to check geometry and commit.
