## Description

Associate container items with their contents grids to enforce unique item IDs and prevent a container from moving into its own contents or descendants.

## Properties

**[`host_placement_policy`](/api/classes/SpatialInventoryContainers/properties/host_placement_policy)**

Optional game rule called with the placement context after the container ownership checks pass.
