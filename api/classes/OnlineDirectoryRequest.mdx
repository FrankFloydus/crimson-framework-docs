### Method details

#### `fail`

`fail() -> Error`

Finish a pending directory request with no listing or endpoint. Returns a Godot Error if the request can no longer accept completion.

#### `is_cancelled`

`is_cancelled() -> bool`

Return true after the game cancels or abandons this request. Use it to release provider resources.

#### `publish`

`publish(listing_id: String) -> Error`

Complete a publication with a unique listing ID. If completion arrives after cancellation, the request attempts to retire the listing. If it returns ERR\_UNAVAILABLE, the provider must remove the external listing itself.

#### `resolve`

`resolve(target: SessionEndpoint) -> Error`

Complete a lookup with a non-null endpoint for the selected transport. Returns a Godot Error when the request is invalid or no longer pending.
