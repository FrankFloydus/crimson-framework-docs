**Inherits** `RefCounted`

Observes a Steam leaderboard lookup or creation.

Use `SteamLeaderboards.find()` to read an existing board and `SteamLeaderboards.find_or_create()` to allow creation. Cancellation cannot undo a creation Steam already accepted.
