## Description

Returned by `SteamPublisherModeration.report()` or within [`SteamCheatReportPage`](/api/classes/SteamCheatReportPage). A report is evidence for review. The trusted game retains the match and reviewer context.

## Properties

**[`app_id`](/api/classes/SteamCheatReport/properties/app_id)**

The publisher AppID that scoped the report.

**[`match_id`](/api/classes/SteamCheatReport/properties/match_id)**

The game-owned match reference when available from local submission.

**[`player_id`](/api/classes/SteamCheatReport/properties/player_id)**

The reported player's SteamID64.

**[`reason_code`](/api/classes/SteamCheatReport/properties/reason_code)**

The game-defined report reason code, or zero when unavailable.

**[`report_id`](/api/classes/SteamCheatReport/properties/report_id)**

Valve's report ID in unsigned decimal form.

**[`reported_at_unix`](/api/classes/SteamCheatReport/properties/reported_at_unix)**

The Valve report timestamp in Unix seconds, or zero when unavailable.
