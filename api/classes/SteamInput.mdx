**Inherits** `RefCounted`

Starts Steam Input and exposes connected controllers.

Get this service from `SteamClient.input()`. Start it on the main thread of the persistent client. Steam Input uses app settings by default and accepts an absolute path to a loose development manifest. Client scopes share the active native lease, manifest, and frame update. The game assigns each [`SteamController`](/api/classes/SteamController) to a player independently of Godot joypad indices.

## Methods

### `controllers`

`controllers() -> SteamController[]`

Returns a read-only snapshot of the connected controller views owned by this lease. Before start and after stop, returns an empty array.

### `start`

`start(manifest_path: String = "") -> Error`

Starts Steam Input. Leave `manifest_path` empty to use Steam's app configuration or join the existing manifest. To override, pass an absolute path to a loose file Steam can read. A different explicit path while the lease is active returns `ERR_BUSY`. A missing file returns `ERR_FILE_NOT_FOUND`. Steam's parse rejection returns `ERR_PARSE_ERROR`. An invalid path returns `ERR_INVALID_PARAMETER`. A detached or unsupported scope returns `ERR_UNAVAILABLE`.

### `stop`

`stop() -> void`

Releases this lease and invalidates the views already returned by `controllers()`. The last active lease shuts down Steam Input. Stopping again is safe.

## Signals

### `bindings_changed`

`bindings_changed(controller: SteamController)`

Emitted when Steam reloads the configuration for a connected controller. Refresh cached HUD prompts.

### `controller_connected`

`controller_connected(controller: SteamController)`

Emitted after a new controller view appears in `controllers()`. A reconnect may produce a new view for the same hardware.

### `controller_disconnected`

`controller_disconnected(controller: SteamController)`

Emitted after a controller view is removed and invalidated. Use the supplied view to clear the local player assignment.
