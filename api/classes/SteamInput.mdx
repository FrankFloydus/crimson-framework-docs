## Description

Get this service from `SteamClient.input()`. Start it on the main thread of the persistent client. Steam Input uses app settings by default and accepts an absolute path to a loose development manifest. Client scopes share the active native lease, manifest, and frame update. The game assigns each [`SteamController`](/api/classes/SteamController) to a player independently of Godot joypad indices.

## Methods

### Instance methods

#### [`controllers`](/api/classes/SteamInput/methods/controllers)

Returns a read-only snapshot of the connected controller views owned by this lease.

#### [`start`](/api/classes/SteamInput/methods/start)

Starts Steam Input.

#### [`stop`](/api/classes/SteamInput/methods/stop)

Releases this lease and invalidates the views already returned by `controllers()`.

## Signals

### `bindings_changed`

`bindings_changed(controller: SteamController)`

Emitted when Steam reloads the configuration for a connected controller. Refresh cached HUD prompts.

### `controller_connected`

`controller_connected(controller: SteamController)`

Emitted after a new controller view appears in `controllers()`. A reconnect may produce a new view for the same hardware.

### `controller_disconnected`

`controller_disconnected(controller: SteamController)`

Emitted after a controller view is removed and invalidated. Use the supplied view to clear the local player assignment.
