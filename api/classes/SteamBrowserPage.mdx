**Inherits** `RefCounted`

A scoped Steam browser texture with explicit game-owned input focus.

Display `texture()` in a UI and forward local keyboard and pointer events only while the panel owns focus. Close the page when removing the panel. The game owns control focus and panel lifetime. Steam dialog, popup, and file chooser requests are dismissed without opening another game UI. This facade exposes no downloads or native script bridge.

## Methods

### `close`

`close() -> void`

Release this browser handle. Repeated calls have no effect. Ending the original Steam client scope also closes the page.

### `navigate`

`navigate(url: String) -> Error`

Submit navigation to an absolute URL covered by this page's original origin policy. Return `ERR_UNAUTHORIZED` and emit `navigation_blocked` for a rejected URL. Steam callbacks check later requests and the final document. An unexpected document closes the browser before displaying its frame.

### `resize`

`resize(size: Vector2i) -> Error`

Request a new width and height in browser pixels. Both sides must be in the range 1 to 4096 with at most 4194304 total pixels. The texture updates after Steam provides a frame at the new size.

### `send_input`

`send_input(event: InputEvent) -> Error`

Forward supported keyboard, mouse motion, button and vertical wheel input. Convert pointer coordinates to browser-local pixels first. Out-of-bounds input returns `ERR_INVALID_PARAMETER`, except release of a previously pressed button. Return `ERR_UNAUTHORIZED` until the game gives this page input focus.

### `set_focused`

`set_focused(focused: bool) -> Error`

Enable forwarding while the game UI owns focus. Passing false stops new forwarded events and releases keys and buttons held by the page.

### `texture`

`texture() -> Texture2D`

Return the page's owned texture, which becomes displayable on the first `frame_updated`. Returns null after the page or its client scope closes.

## Signals

### `frame_updated`

`frame_updated()`

Emitted after the page texture receives the newest accepted browser frame for this Godot process frame.

### `navigation_blocked`

`navigation_blocked(url: String)`

Emitted when a direct request, native navigation, redirect, or attempted new window is rejected. The URL may be empty if Steam supplied an invalid URL.

### `page_finished`

`page_finished(url: String, title: String)`

Emitted after Steam reports that an allowed page finished loading. A frame is observed separately.
