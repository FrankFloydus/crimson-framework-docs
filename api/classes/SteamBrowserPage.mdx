**Inherits** `RefCounted`

## Description

Display `texture()` in a UI and forward local keyboard and pointer events only while the panel owns focus. Close the page when removing the panel. The game owns control focus and panel lifetime. Steam dialog, popup, and file chooser requests are dismissed without opening another game UI. This facade exposes no downloads or native script bridge.

## Signals

### `frame_updated`

`frame_updated()`

Emitted after the page texture receives the newest accepted browser frame for this Godot process frame.

### `navigation_blocked`

`navigation_blocked(url: String)`

Emitted when a direct request, native navigation, redirect, or attempted new window is rejected. The URL may be empty if Steam supplied an invalid URL.

### `page_finished`

`page_finished(url: String, title: String)`

Emitted after Steam reports that an allowed page finished loading. A frame is observed separately.
