## Signature

```text
leave() -> Variant
```

## Return value

`Variant`

Await the call to receive [`GameResult`](/api/classes/GameResult).

## Description

An idle game succeeds immediately.

## Example

### Return to the title screen after a match

Use this on the pause menu's Return to Title button. The title screen opens after the match has ended. [Game scope setup](/game-services#find-the-game-from-a-pause-menu)

```gdscript
extends Button

@export var pause_menu: Control
@export var title_menu: Control

func _ready() -> void:
    pressed.connect(_return_to_title)

func _return_to_title() -> void:
    var game: Game = Game.for_node(self)
    if game == null:
        push_error("No game owns this pause menu.")
        return

    disabled = true
    var left: GameResult = await game.leave()
    disabled = false
    if not left.ok:
        push_error(left.message)
        return
    pause_menu.hide()
    title_menu.show()
```
