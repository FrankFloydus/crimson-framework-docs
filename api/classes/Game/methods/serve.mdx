## Return value

`Variant`

Await the call to receive [`GameResult`](/api/classes/GameResult).

## Description

Bind defaults to \*. The optional advertised address defaults to empty.

## Example

### Open a playerless LAN arena

A dedicated arena opens without a local player. Guests can join after the server reports readiness.

```gdscript
extends Node

const GUEST_SEATS: int = 4
const SERVER_PORT: int = 24830
const EXIT_FAILURE: int = 1

@export var arena: PackedScene
@export var player: PackedScene

func _ready() -> void:
    var setup: GameConfig = Game.configure(arena, player).lan(GUEST_SEATS).on_port(SERVER_PORT)
    var server: Game = setup.boot(self)
    var started: GameResult = await server.serve()
    if not started.ok:
        push_error(started.message)
        get_tree().quit(EXIT_FAILURE)
        return
    print("Arena open to guests on UDP port %d." % server.get_port())
```
