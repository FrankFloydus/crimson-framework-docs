**Inherits** `RefCounted`

## Description

Get a view from `SteamInput.controllers()` or a controller signal. A controller view becomes unavailable when its lease ends or the hardware disconnects. Steam supplies the action sets, layers, and state. The game owns player assignment and maps input values to local gameplay commands. Call on the main thread.

## Methods

### Instance methods

#### [`activate_layer`](/api/classes/SteamController/methods/activate_layer)

Asks Steam to apply the named `name` layer to the current set.

#### [`analog`](/api/classes/SteamController/methods/analog)

Reads `action` in the current Steam Input frame.

#### [`deactivate_layer`](/api/classes/SteamController/methods/deactivate_layer)

Asks Steam to remove the named `name` layer from the current set.

#### [`digital`](/api/classes/SteamController/methods/digital)

Reads `action` in the current Steam Input frame.

#### [`glyph`](/api/classes/SteamController/methods/glyph)

Returns a PNG texture at `size` for the first effective Steam binding origin of `action`.

#### [`glyphs`](/api/classes/SteamController/methods/glyphs)

Returns the textures at `size` for the effective Steam binding origins of `action` in origin order.

#### [`is_connected`](/api/classes/SteamController/methods/is_connected)

Returns whether this view still identifies the same live connection in its owning lease.

#### [`open_binding_panel`](/api/classes/SteamController/methods/open_binding_panel)

Requests Steam's binding configuration panel for this controller. `OK` acknowledges the request.

#### [`type`](/api/classes/SteamController/methods/type)

Returns Steam's controller family.

#### [`use_action_set`](/api/classes/SteamController/methods/use_action_set)

Asks Steam to select the `name` action set from the manifest.

#### [`vibrate`](/api/classes/SteamController/methods/vibrate)

Submits normalized `low` and `high` motor amplitudes from 0 to 1.
