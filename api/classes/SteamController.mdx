## Description

Get a view from `SteamInput.controllers()` or a controller signal. A controller view becomes unavailable when its lease ends or the hardware disconnects. Steam supplies the action sets, layers, and state. The game owns player assignment and maps input values to local gameplay commands. Call on the main thread.

### Method details

#### `activate_layer`

`activate_layer(name: StringName) -> Error`

Asks Steam to apply the named `name` layer to the current set. Returns `ERR_DOES_NOT_EXIST` if the published name is unknown, `ERR_INVALID_PARAMETER` if it is empty or exceeds 128 UTF-8 bytes, or `ERR_UNAVAILABLE` when this view or native capability is unavailable.

#### `analog`

`analog(action: StringName) -> SteamAnalogInputResult`

Reads `action` in the current Steam Input frame. Inactive input returns an inactive zero vector. Unknown actions return `ERR_DOES_NOT_EXIST`. An empty or oversized action name returns `ERR_INVALID_PARAMETER`. A retired view or unavailable Steam interface returns `ERR_UNAVAILABLE`.

#### `deactivate_layer`

`deactivate_layer(name: StringName) -> Error`

Asks Steam to remove the named `name` layer from the current set. Returns `ERR_DOES_NOT_EXIST` if the published name is unknown, `ERR_INVALID_PARAMETER` if it is empty or exceeds 128 UTF-8 bytes, or `ERR_UNAVAILABLE` when this view or native capability is unavailable.

#### `digital`

`digital(action: StringName) -> SteamDigitalInputResult`

Reads `action` in the current Steam Input frame. An inactive action reports `active = false`. Unknown actions return `ERR_DOES_NOT_EXIST`. An empty or oversized action name returns `ERR_INVALID_PARAMETER`. A retired view or unavailable Steam interface returns `ERR_UNAVAILABLE`.

#### `glyph`

`glyph(action: StringName, size: SteamController.GlyphSize = 1) -> SteamTextureResult`

Returns a PNG texture at `size` for the first effective Steam binding origin of `action`. An unbound action, unavailable glyph, or retired view returns `ERR_UNAVAILABLE`. An invalid size or action name returns `ERR_INVALID_PARAMETER`.

#### `glyphs`

`glyphs(action: StringName, size: SteamController.GlyphSize = 1) -> SteamTexturesResult`

Returns the textures at `size` for the effective Steam binding origins of `action` in origin order. The highest active layer that supplies origins takes precedence over the base set. An unbound action, unavailable glyph, or retired view returns `ERR_UNAVAILABLE`. An invalid size or action name returns `ERR_INVALID_PARAMETER`.

#### `is_connected`

`is_connected() -> bool`

Returns whether this view still identifies the same live connection in its owning lease.

#### `open_binding_panel`

`open_binding_panel() -> Error`

Requests Steam's binding configuration panel for this controller. `OK` acknowledges the request. Returns `ERR_UNAVAILABLE` if Steam declines or the controller is disconnected.

#### `type`

`type() -> SteamController.Type`

Returns Steam's controller family. Returns `TYPE_UNKNOWN` if the view is unavailable or the reported value is unrecognized.

#### `use_action_set`

`use_action_set(name: StringName) -> Error`

Asks Steam to select the `name` action set from the manifest. Returns `ERR_DOES_NOT_EXIST` if the published name is unknown, `ERR_INVALID_PARAMETER` if it is empty or exceeds 128 UTF-8 bytes, or `ERR_UNAVAILABLE` when this view or native capability is unavailable.

#### `vibrate`

`vibrate(low: float, high: float) -> Error`

Submits normalized `low` and `high` motor amplitudes from 0 to 1. Pass zero for both to clear the request. `OK` acknowledges the SDK submission. A disconnected controller or missing vibration capability returns `ERR_UNAVAILABLE`. Nonfinite or out-of-range values return `ERR_INVALID_PARAMETER`.
