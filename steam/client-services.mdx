Start Steamworks from a persistent scene node for app services alone. If your game already uses a Steam connection, get the services from the same game. Make the calls on Godot's main thread.

## Start a client

### Start a standalone client

Use [`Steamworks.boot(self)`](/api/classes/Steamworks/methods/boot) when your project only needs Steam app services. The [connection script](/steam/overview#connect-your-game-to-steam) prints the confirmed AppID and connection state. It selects [`SteamConfig.spacewar()`](/api/classes/SteamConfig/methods/spacewar) for a development launch or accepts your app's normal Steam launch context. [Launch with an AppID](/steam/setup#launch-with-an-appid)

[`boot_result()`](/api/classes/Steamworks/methods/boot_result) reports how the attachment attempt ended. [`is_ready()`](/api/classes/Steamworks/methods/is_ready) checks whether the original client is still usable. [`is_online()`](/api/classes/Steamworks/methods/is_online) checks the live connection to Steam. Steam Offline Mode can still provide some cached features.

### Reuse a Steam game's attachment

On a Steam multiplayer project, get the service through [`game.steam()`](/api/classes/Game/methods/steam). This startup script reads the configured Steam language from the same scope that will host or join. It uses the scene paths from Getting Started and your normal Steam launch AppID. Use `.steam(SteamConfig.spacewar(TEST_GROUP))` with your own test group for a Spacewar launch as shown in the listen server guide. [Host and join a Steam game](/steam/listen-servers)

```gdscript
extends Node

const LEVEL: PackedScene = preload("res://world.tscn")
const PLAYER: PackedScene = preload("res://player.tscn")

var game: Game
var steam: Steamworks


func _ready() -> void:
    game = Game.configure(LEVEL, PLAYER).steam().boot(self)
    steam = game.steam()
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    print("Steam game language: %s" % steam.apps().current_language())
```

The game facade and standalone Steamworks each belong to one attachment. Removing their owning node from the tree retires its services. A second consumer in the process can continue to use its own Steam scope.

### Recover a standalone client

If Steam loses its local client connection, the standalone facade emits [`runtime_lost`](/api/classes/Steamworks#runtime_lost). This script defers a fresh boot until the callback returns. Run it on a persistent node with your app's launch AppID. It prints the app language again when the fresh attachment is ready.

```gdscript
extends Node

var _steam: Steamworks


func _ready() -> void:
    _attach_steam()


func _attach_steam() -> void:
    _steam = Steamworks.boot(self)
    var startup: SteamResult = _steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _steam.runtime_lost.connect(_on_runtime_lost, CONNECT_ONE_SHOT)
    print("Steam game language: %s" % _steam.apps().current_language())


func _on_runtime_lost() -> void:
    _attach_steam.call_deferred()
```

Resolve new service handles after reattaching. A temporary loss of connectivity to Valve keeps the local scope active. Existing integrations can continue to use [`SteamClient`](/api/classes/SteamClient) and [`SteamServices.for_game(game_runtime)`](/api/classes/SteamServices/methods/for_game).

## Open the Steam Overlay

Attach this script to a persistent node and assign an **Achievements** button. Press it to request the achievements panel through [`Steamworks.open_achievements()`](/api/classes/Steamworks/methods/open_achievements). The example uses your app's launch AppID. On a Steam multiplayer project, use the Steamworks attachment supplied by `game.steam()`.

```gdscript
extends Node

@export var achievements_button: Button

var _steam: Steamworks


func _ready() -> void:
    _steam = Steamworks.boot(self)
    achievements_button.pressed.connect(_open_achievements)


func _open_achievements() -> void:
    var request: SteamResult = _steam.open_achievements()
    if not request.ok:
        push_warning(request.message)
```

A successful result means Steam received the request. Verify that the panel appears in a rendered window. Enable the Overlay in Steam and use the early Overlay argument for direct development launches. Use [`activation_changed(active)`](/api/classes/SteamOverlay#activation_changed) to suspend local gameplay input and restore focus when the Overlay closes. Keep the multiplayer simulation running. [Graphical launch setup](/steam/setup#launch-with-an-appid) · [Overlay test](/steam/testing#check-the-overlay-and-achievements)

## Unlock an achievement

Publish an achievement for your AppID that the client can update. Replace the sample API name and call `record_training_completed()` when your training objective succeeds. Attach this script to a persistent node to keep receiving callbacks when the player changes levels.

```gdscript
extends Node

const TRAINING_COMPLETE: String = "TRAINING_COMPLETE"
const STEAM_RESULT_OK: int = 1

var _steam: Steamworks


func _ready() -> void:
    _steam = Steamworks.boot(self)
    var startup: SteamResult = _steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    var stats: SteamStats = _steam.stats()
    stats.stats_stored.connect(_on_stats_stored)
    stats.achievement_stored.connect(_on_achievement_stored)


func record_training_completed() -> void:
    var submission: SteamStatsSubmissionResult = _steam.achievements().unlock(TRAINING_COMPLETE)
    if not submission.ok:
        push_warning(submission.message)


func _on_stats_stored(steam_result: int) -> void:
    if steam_result != STEAM_RESULT_OK:
        push_warning("Steam could not store stats: %d" % steam_result)


func _on_achievement_stored(name: String, current: int, maximum: int) -> void:
    if name == TRAINING_COMPLETE and current == 0 and maximum == 0:
        print("Steam reported a full training achievement unlock.")
```

[`unlock()`](/api/classes/SteamAchievements/methods/unlock) applies the achievement edit and asks Steam to store it. A successful submission confirms that request. [`stats_stored`](/api/classes/SteamStats#stats_stored) reports the app-wide store callback. [`achievement_stored`](/api/classes/SteamStats#achievement_stored) reports the named achievement, with zero progress and maximum for a full unlock. Confirm persistence by reading the achievement after a fresh launch, and observe a new unlock notification separately in a rendered test. [Valve stats and achievements](https://partner.steamgames.com/doc/features/achievements)

## Record progression

Use your own AppID. In Steamworks, publish an integer stat and an achievement that the client can update. Set the script constants to their exact API names. When one game event changes several values, collect them with [`edit()`](/api/classes/SteamStats/methods/edit) and apply them together with [`submit()`](/api/classes/SteamStatsEdit/methods/submit). Attach this script to a node and call `record_win()` after a victory. Pass the [`SteamStats`](/api/classes/SteamStats) service from [`steam.stats()`](/api/classes/Steamworks/methods/stats) on your standalone or game-owned Steamworks attachment and the player's total number of wins. [Valve stats and achievements](https://partner.steamgames.com/doc/features/achievements)

```gdscript
extends Node

const WIN_STAT: String = "wins"
const FIRST_WIN_ACHIEVEMENT: String = "first_win"

func record_win(stats: SteamStats, total_wins: int) -> void:
    if stats == null:
        push_warning("Steam stats are unavailable.")
        return

    var result: SteamStatsSubmissionResult = stats.edit() \
        .set_int(WIN_STAT, total_wins) \
        .unlock(FIRST_WIN_ACHIEVEMENT) \
        .submit()
    if not result.ok:
        push_warning(result.message)
        return
    print("Steam accepted the progression update for storage.")
```

The result describes the submission. [`value.applied`](/api/classes/SteamStatsSubmission/properties/applied) counts edits accepted into Steam's cache, and [`value.failed_at`](/api/classes/SteamStatsSubmission/properties/failed_at) identifies the first rejected edit when there is one. Accepted edits can remain in the cache after a later error. Observe [`stats_stored`](/api/classes/SteamStats#stats_stored) for Steam's app-wide persistence result. For scores governed by a dedicated authority or trusted backend, use the [dedicated progression](/steam/dedicated-servers#record-server-owned-progression) or [publisher workflow](/steam/publisher) for that authority.

## Save a profile to Cloud

Enable Cloud and allocate quota for your own AppID in Steamworks. Use a test account with access to that app when testing writes. Get a [`SteamCloud`](/api/classes/SteamCloud) service from [`steam.cloud()`](/api/classes/Steamworks/methods/cloud) on your standalone or game-owned Steamworks attachment. Choose one of the scripts below and attach it to a node. Call its save function with that service and your serialized bytes. Use a dedicated file key for the game's profile.

### Await the result directly

Call `save_and_read_profile(cloud, profile_bytes)` when your code only needs the completed results from [`write()`](/api/classes/SteamCloud/methods/write) and [`read()`](/api/classes/SteamCloud/methods/read).

```gdscript
extends Node

const PROFILE_FILE: String = "player-profile.json"

func save_and_read_profile(cloud: SteamCloud, profile_bytes: PackedByteArray) -> void:
    if cloud == null:
        push_warning("Steam Cloud is unavailable.")
        return

    var written: SteamResult = await cloud.write(PROFILE_FILE, profile_bytes)
    if not written.ok:
        push_warning(written.message)
        return

    var loaded: SteamBytesResult = await cloud.read(PROFILE_FILE)
    if loaded.ok:
        print("Read %d bytes from Steam Cloud." % loaded.value.size())
    else:
        push_warning(loaded.message)
```

### Keep the operation handle

Call `save_and_read_with_handles(cloud, profile_bytes)` to retain the operations from [`write_file()`](/api/classes/SteamCloud/methods/write_file) and [`read_file()`](/api/classes/SteamCloud/methods/read_file). The script keeps each pending handle so a screen can call `cancel_pending_requests()` when it closes.

```gdscript
extends Node

const PROFILE_FILE: String = "player-profile.json"

var _write_operation: SteamOperation
var _read_operation: SteamBytesOperation

func save_and_read_with_handles(cloud: SteamCloud, profile_bytes: PackedByteArray) -> void:
    if cloud == null:
        push_warning("Steam Cloud is unavailable.")
        return
    if _write_operation != null or _read_operation != null:
        push_warning("A Steam Cloud request is already pending.")
        return

    _write_operation = cloud.write_file(PROFILE_FILE, profile_bytes)
    var written: SteamResult = await _write_operation.wait()
    _write_operation = null
    if not written.ok:
        push_warning(written.message)
        return

    _read_operation = cloud.read_file(PROFILE_FILE)
    var loaded: SteamBytesResult = await _read_operation.wait()
    _read_operation = null
    if loaded.ok:
        print("Read %d bytes from Steam Cloud." % loaded.value.size())
    else:
        push_warning(loaded.message)

func cancel_pending_requests() -> void:
    if _write_operation != null:
        _write_operation.cancel()
    if _read_operation != null:
        _read_operation.cancel()
```

Calling [`cancel()`](/api/classes/SteamOperation/methods/cancel) stops waiting locally. Steam can still complete a submitted write.

### Group related writes

Call `write_profile_batch(cloud, profile_bytes, settings_bytes)` to group both writes with [`begin_write_batch()`](/api/classes/SteamCloud/methods/begin_write_batch). The script closes the batch after the last result, even if a write fails. Each write still has its own result. [Steam Cloud write batches](https://partner.steamgames.com/doc/api/ISteamRemoteStorage#BeginFileWriteBatch)

```gdscript
extends Node

const PROFILE_FILE: String = "player-profile.json"
const SETTINGS_FILE: String = "settings.json"

func write_profile_batch(
    cloud: SteamCloud, profile_bytes: PackedByteArray, settings_bytes: PackedByteArray
) -> void:
    if cloud == null:
        push_warning("Steam Cloud is unavailable.")
        return

    var opened: SteamCloudWriteBatchResult = cloud.begin_write_batch()
    if not opened.ok:
        push_warning(opened.message)
        return

    var batch: SteamCloudWriteBatch = opened.value
    var files: Dictionary[String, PackedByteArray] = {
        PROFILE_FILE: profile_bytes,
        SETTINGS_FILE: settings_bytes,
    }
    for file_name: String in files:
        var written: SteamResult = await cloud.write(file_name, files[file_name])
        if not written.ok:
            push_warning(written.message)
            break

    var close_error: Error = batch.close()
    if close_error != OK:
        push_warning(error_string(close_error))
```

[`SteamCloudWriteBatch.close()`](/api/classes/SteamCloudWriteBatch/methods/close) ends the hint. Check actual sync on a second device using the same test account. [Verify Steam Cloud sync](/steam/testing#verify-steam-cloud-sync)

## Consume Steam results

Read [`ok`](/api/classes/SteamResult/properties/ok) before using a result's `value`. Some operations expose [`wait()`](/api/classes/SteamOperation/methods/wait) on an operation handle, while convenience methods can be awaited directly. Check the signature in the [API reference](/api/overview). For Steam HTTP, a completed response can still have a 4xx or 5xx status. Check [`response.value.is_successful()`](/api/classes/SteamHttpResponse/methods/is_successful) when you need a 2xx response. For Steam IDs documented as decimal strings, keep them as strings to preserve their full range.
