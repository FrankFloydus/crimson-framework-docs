Start Steamworks from a persistent scene node for app services alone. If your game already uses a Steam connection, get the services from the same game. Make the calls on Godot's main thread. Each example below is a separate script. Unless stated otherwise, launch with your app's Steam AppID. [Steam runtime and launch setup](/steam/setup#launch-with-an-appid)

## Start a client

### Start a standalone client

Save a scene with a `Node` root as `res://steam_services.tscn` and attach the script below. It reads the current language for your app after Steam initializes. For a basic Spacewar connection check, see [Connect to Steam](/steam/connect).

```gdscript
extends Node

var _steam: Steamworks


func _ready() -> void:
    _steam = Steamworks.boot(self)
    var startup: SteamResult = _steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    print("Steam game language: %s" % _steam.apps().current_language())
```

[`boot_result()`](/api/classes/Steamworks/methods/boot_result) reports how the attachment attempt ended. [`is_ready()`](/api/classes/Steamworks/methods/is_ready) checks whether the original client is still usable. [`is_online()`](/api/classes/Steamworks/methods/is_online) checks the live connection to Steam. Steam Offline Mode can still provide some cached features.

### Reuse a Steam game's attachment

On a Steam multiplayer project, get the service through [`game.steam()`](/api/classes/Game/methods/steam). This startup script reads the app's language from the same scope that can host or join later. To try it in a new project, save a `Node3D` scene as `res://steam_services_level.tscn` and another as `res://steam_services_player.tscn`. Attach the script to a separate ordinary `Node` scene and run that scene. This check only attaches the game, so it leaves the level and player unloaded.

```gdscript
extends Node

const LEVEL: PackedScene = preload("res://steam_services_level.tscn")
const PLAYER: PackedScene = preload("res://steam_services_player.tscn")

var game: Game
var steam: Steamworks


func _ready() -> void:
    game = Game.configure(LEVEL, PLAYER).steam().boot(self)
    steam = game.steam()
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    print("Steam game language: %s" % steam.apps().current_language())
```

The game facade and standalone Steamworks each belong to one attachment. Removing their owning node from the tree retires its services. A second consumer in the process can continue to use its own Steam scope.

### Recover a standalone client

If Steam loses its local client connection, the standalone facade emits [`runtime_lost`](/api/classes/Steamworks#runtime_lost). This script defers a fresh boot until the callback returns. Run it on a persistent node with your app's launch AppID. It prints the app language again when the fresh attachment is ready.

```gdscript
extends Node

var _steam: Steamworks


func _ready() -> void:
    _attach_steam()


func _attach_steam() -> void:
    _steam = Steamworks.boot(self)
    var startup: SteamResult = _steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _steam.runtime_lost.connect(_on_runtime_lost, CONNECT_ONE_SHOT)
    print("Steam game language: %s" % _steam.apps().current_language())


func _on_runtime_lost() -> void:
    _attach_steam.call_deferred()
```

Resolve new service handles after reattaching. A temporary loss of connectivity to Valve keeps the local scope active. Existing integrations can continue to use [`SteamClient`](/api/classes/SteamClient) and [`SteamServices.for_game(game_runtime)`](/api/classes/SteamServices/methods/for_game).

## Open the Steam Overlay

Create a scene with a `Node` root and a button labeled **Achievements**. Attach this script to the root and assign the button in the Inspector. Press it to request the panel through [`Steamworks.open_achievements()`](/api/classes/Steamworks/methods/open_achievements).

```gdscript
extends Node

@export var achievements_button: Button

var _steam: Steamworks


func _ready() -> void:
    _steam = Steamworks.boot(self)
    achievements_button.pressed.connect(_open_achievements)


func _open_achievements() -> void:
    var request: SteamResult = _steam.open_achievements()
    if not request.ok:
        push_warning(request.message)
```

A successful result means Steam received the request. Verify that the panel appears in a rendered window. Enable the Overlay in Steam and use the early Overlay argument for direct development launches. Use [`activation_changed(active)`](/api/classes/SteamOverlay#activation_changed) to suspend local gameplay input and restore focus when the Overlay closes. Keep the multiplayer simulation running. [Graphical launch setup](/steam/setup#launch-with-an-appid) · [Overlay test](/steam/testing#check-the-overlay-and-achievements)

## Unlock an achievement

Publish an achievement for your AppID that the client can update. Replace the sample API name with the published name. In a test scene, attach this script to a `Node` root and assign a button labeled **Complete Training**. Press the button on a test account to simulate completing the objective. In a game, connect the actual objective to `record_training_completed()`.

```gdscript
extends Node

const TRAINING_COMPLETE: String = "TRAINING_COMPLETE"
const STEAM_RESULT_OK: int = 1

@export var complete_training_button: Button

var _steam: Steamworks


func _ready() -> void:
    _steam = Steamworks.boot(self)
    var startup: SteamResult = _steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    var stats: SteamStats = _steam.stats()
    stats.stats_stored.connect(_on_stats_stored)
    stats.achievement_stored.connect(_on_achievement_stored)
    complete_training_button.pressed.connect(record_training_completed)

    var saved: SteamAchievement = stats.achievement(StringName(TRAINING_COMPLETE))
    if saved != null and saved.unlocked:
        print("Training achievement is already unlocked.")


func record_training_completed() -> void:
    var submission: SteamStatsSubmissionResult = _steam.achievements().unlock(TRAINING_COMPLETE)
    if not submission.ok:
        push_warning(submission.message)


func _on_stats_stored(steam_result: int) -> void:
    if steam_result != STEAM_RESULT_OK:
        push_warning("Steam could not store stats: %d" % steam_result)


func _on_achievement_stored(name: String, current: int, maximum: int) -> void:
    if name == TRAINING_COMPLETE and current == 0 and maximum == 0:
        print("Steam reported a full training achievement unlock.")
```

[`unlock()`](/api/classes/SteamAchievements/methods/unlock) applies the achievement edit and asks Steam to store it. A successful submission confirms that request. [`stats_stored`](/api/classes/SteamStats#stats_stored) reports the app-wide store callback. [`achievement_stored`](/api/classes/SteamStats#achievement_stored) reports the named achievement, with zero progress and maximum for a full unlock. Check for `Training achievement is already unlocked.` after restarting the example. Observe a new unlock notification separately in a rendered test. [Valve stats and achievements](https://partner.steamgames.com/doc/features/achievements)

## Record progression

Publish an integer stat and achievement the client can update, then set the constants to their exact API names. In a test scene, attach the script to a `Node` and assign a button labeled **Record Test Win**. Press it on a test account to submit one known victory total. A game can call `record_win()` with the actual total at the end of a match. The script collects changes with [`edit()`](/api/classes/SteamStats/methods/edit) and applies them with [`submit()`](/api/classes/SteamStatsEdit/methods/submit). [Valve stats and achievements](https://partner.steamgames.com/doc/features/achievements)

```gdscript
extends Node

const WIN_STAT: String = "wins"
const FIRST_WIN_ACHIEVEMENT: String = "first_win"
const TEST_WIN_TOTAL: int = 1

@export var record_button: Button

var _stats: SteamStats


func _ready() -> void:
    var steam: Steamworks = Steamworks.boot(self)
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _stats = steam.stats()
    record_button.pressed.connect(record_win.bind(TEST_WIN_TOTAL))


func record_win(total_wins: int) -> void:
    var result: SteamStatsSubmissionResult = _stats.edit() \
        .set_int(WIN_STAT, total_wins) \
        .unlock(FIRST_WIN_ACHIEVEMENT) \
        .submit()
    if not result.ok:
        push_warning(result.message)
        return
    print("Steam accepted the progression update for storage.")
```

The result describes the submission. [`value.applied`](/api/classes/SteamStatsSubmission/properties/applied) counts edits accepted into Steam's cache, and [`value.failed_at`](/api/classes/SteamStatsSubmission/properties/failed_at) identifies the first rejected edit when there is one. Accepted edits can remain in the cache after a later error. Observe [`stats_stored`](/api/classes/SteamStats#stats_stored) for Steam's app-wide persistence result. For scores governed by a dedicated authority or trusted backend, use the [dedicated progression](/steam/dedicated-servers#record-server-owned-progression) or [publisher workflow](/steam/publisher) for that authority.

## Save a profile to Cloud

Enable Cloud and allocate quota for your AppID in Steamworks. Use a test account with access to that app. Choose one of the scripts below, attach it to the `Node` root of a new test scene, and assign its buttons. These scripts write sample JSON under dedicated test file names. [`SteamCloud`](/api/classes/SteamCloud)

### Await the result directly

Assign **Save Profile** and **Read Profile** buttons. Save writes a sample profile with [`write()`](/api/classes/SteamCloud/methods/write). Read loads the stored bytes with [`read()`](/api/classes/SteamCloud/methods/read) and prints the profile. Keeping the actions separate lets you read the original file on another machine.

```gdscript
extends Node

const PROFILE_FILE: String = "crimson-example-profile.json"
const STARTING_LEVEL: int = 1

@export var save_button: Button
@export var read_button: Button

var _cloud: SteamCloud


func _ready() -> void:
    var steam: Steamworks = Steamworks.boot(self)
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _cloud = steam.cloud()
    save_button.pressed.connect(_save_profile)
    read_button.pressed.connect(_read_profile)


func _save_profile() -> void:
    _set_busy(true)
    var profile: PackedByteArray = JSON.stringify({"level": STARTING_LEVEL}).to_utf8_buffer()
    var written: SteamResult = await _cloud.write(PROFILE_FILE, profile)
    _set_busy(false)
    if written.ok:
        print("Saved profile: %s" % profile.get_string_from_utf8())
    else:
        push_warning(written.message)


func _read_profile() -> void:
    _set_busy(true)
    var loaded: SteamBytesResult = await _cloud.read(PROFILE_FILE)
    _set_busy(false)
    if loaded.ok:
        print("Read profile: %s" % loaded.value.get_string_from_utf8())
    else:
        push_warning(loaded.message)


func _set_busy(busy: bool) -> void:
    save_button.disabled = busy
    read_button.disabled = busy
```

### Keep the operation handle

Assign **Save and Read** and **Cancel** buttons. The script keeps the operation from [`write_file()`](/api/classes/SteamCloud/methods/write_file) or [`read_file()`](/api/classes/SteamCloud/methods/read_file) so the screen can stop waiting. Press **Cancel** while a request is pending to try that path.

```gdscript
extends Node

const PROFILE_FILE: String = "crimson-example-profile-handles.json"
const STARTING_LEVEL: int = 1

@export var save_button: Button
@export var cancel_button: Button

var _cloud: SteamCloud
var _write_operation: SteamOperation
var _read_operation: SteamBytesOperation


func _ready() -> void:
    var steam: Steamworks = Steamworks.boot(self)
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _cloud = steam.cloud()
    save_button.pressed.connect(_save_and_read_with_handles)
    cancel_button.pressed.connect(cancel_pending_requests)


func _save_and_read_with_handles() -> void:
    if _write_operation != null or _read_operation != null:
        push_warning("A Steam Cloud request is already pending.")
        return

    var profile: PackedByteArray = JSON.stringify({"level": STARTING_LEVEL}).to_utf8_buffer()
    _write_operation = _cloud.write_file(PROFILE_FILE, profile)
    var written: SteamResult = await _write_operation.wait()
    _write_operation = null
    if not written.ok:
        push_warning(written.message)
        return

    _read_operation = _cloud.read_file(PROFILE_FILE)
    var loaded: SteamBytesResult = await _read_operation.wait()
    _read_operation = null
    if loaded.ok:
        print("Read %d bytes from Steam Cloud." % loaded.value.size())
    else:
        push_warning(loaded.message)

func cancel_pending_requests() -> void:
    if _write_operation != null:
        _write_operation.cancel()
    if _read_operation != null:
        _read_operation.cancel()
```

Calling [`cancel()`](/api/classes/SteamOperation/methods/cancel) stops waiting locally. Steam can still complete a submitted write.

### Group related writes

Assign a **Save Profile and Settings** button. Press it to group two writes with [`begin_write_batch()`](/api/classes/SteamCloud/methods/begin_write_batch). Each write still has its own result. The script closes the batch after the last write, including on failure. [Steam Cloud write batches](https://partner.steamgames.com/doc/api/ISteamRemoteStorage#BeginFileWriteBatch)

```gdscript
extends Node

const PROFILE_FILE: String = "crimson-example-batch-profile.json"
const SETTINGS_FILE: String = "crimson-example-batch-settings.json"
const STARTING_LEVEL: int = 1

@export var save_button: Button

var _cloud: SteamCloud


func _ready() -> void:
    var steam: Steamworks = Steamworks.boot(self)
    var startup: SteamResult = steam.boot_result()
    if not startup.ok:
        push_warning(startup.message)
        return

    _cloud = steam.cloud()
    save_button.pressed.connect(_write_profile_batch)


func _write_profile_batch() -> void:
    var opened: SteamCloudWriteBatchResult = _cloud.begin_write_batch()
    if not opened.ok:
        push_warning(opened.message)
        return

    save_button.disabled = true
    var batch: SteamCloudWriteBatch = opened.value
    var files: Dictionary[String, PackedByteArray] = {
        PROFILE_FILE: JSON.stringify({"level": STARTING_LEVEL}).to_utf8_buffer(),
        SETTINGS_FILE: JSON.stringify({"subtitles": true}).to_utf8_buffer(),
    }
    var all_written: bool = true
    for file_name: String in files:
        var written: SteamResult = await _cloud.write(file_name, files[file_name])
        if not written.ok:
            push_warning(written.message)
            all_written = false
            break

    var close_error: Error = batch.close()
    save_button.disabled = false
    if close_error != OK:
        push_warning(error_string(close_error))
    elif all_written:
        print("Profile and settings written. Batch closed.")
```

[`SteamCloudWriteBatch.close()`](/api/classes/SteamCloudWriteBatch/methods/close) ends the hint. Check actual sync on a second device using the same test account. [Verify Steam Cloud sync](/steam/testing#verify-steam-cloud-sync)

## Consume Steam results

Read [`ok`](/api/classes/SteamResult/properties/ok) before using a result's `value`. Some operations expose [`wait()`](/api/classes/SteamOperation/methods/wait) on an operation handle, while convenience methods can be awaited directly. Check the signature in the [API reference](/api/overview). For Steam HTTP, a completed response can still have a 4xx or 5xx status. Check [`response.value.is_successful()`](/api/classes/SteamHttpResponse/methods/is_successful) when you need a 2xx response. For Steam IDs documented as decimal strings, keep them as strings to preserve their full range.
