Use the Steam client services when you want player features in your game. You can start with one feature, such as saving a profile to Steam Cloud, and add others as you need them.

## Start a client

Choose the path that owns your Steam connection. A game can start a standalone client for player features, or reuse the Steam scope already attached by its multiplayer provider. [Steamworks setup](/steam/setup)

### Start a standalone client

Attach this script to a node that stays in the scene tree when your game changes levels. [`SteamClient.boot()`](/api/classes/SteamClient#boot) connects when the node is ready. The example uses Valve's Spacewar AppID. Replace `480` with your game's AppID.

```gdscript
extends Node

func _ready() -> void:
    var steam := SteamClient.boot(self, 480)
    if steam == null:
        push_error("Could not attach the Steam client.")
        return
    if not steam.is_ready():
        push_error(steam.get_initialization_error())
        return

    var apps: SteamApps = steam.apps()
    if apps != null:
        print("Steam game language: ", apps.current_language())
    print("Steam online: ", steam.is_online())
```

[`is_ready()`](/api/classes/SteamClient#is_ready) tells you whether the local Steam client initialized. [`is_online()`](/api/classes/SteamClient#is_online) checks whether it is connected. In Steam Offline Mode, some cached features may still be available. Call Steam services from Godot's main thread.

### Reuse a game's Steam provider

Once your [`GameRuntime`](/api/classes/GameRuntime) has been attached with a Steam provider, call the function below with that game. [`SteamServices.for_game(game)`](/api/classes/SteamServices#for_game) returns its [`SteamScope`](/api/classes/SteamScope). A missing scope and a scope that failed to initialize are separate cases. [Set up a Steam game](/steam/listen-servers)

```gdscript
func print_game_steam_language(game: GameRuntime) -> void:
    var scope: SteamScope = SteamServices.for_game(game)
    if scope == null:
        push_warning("This game has no Steam scope.")
        return
    if not scope.is_ready():
        var reason := scope.get_initialization_error()
        push_warning(reason if not reason.is_empty() else "The Steam scope is unavailable.")
        return

    var apps: SteamApps = scope.apps()
    if apps != null:
        print("Steam game language: ", apps.current_language())
```

Use the scope's [`is_ready()`](/api/classes/SteamScope#is_ready) and [`get_initialization_error()`](/api/classes/SteamScope#get_initialization_error) to check that attachment. Get the scope and service handles again when you replace the game. This function resolves both handles each time it runs.

### Recover a standalone client

If your game loses its local connection to the Steam client process, a standalone [`SteamClient`](/api/classes/SteamClient) emits [`runtime_lost`](/api/classes/SteamClient#runtime_lost). To try once per failure, add these functions to your startup script and call `watch_steam_client(steam, 480)` after the client starts. Use the same AppID as your startup code.

```gdscript
func watch_steam_client(client: SteamClient, app_id: int) -> void:
    client.runtime_lost.connect(_restart_steam_client.bind(client, app_id), CONNECT_DEFERRED)

func _restart_steam_client(client: SteamClient, app_id: int) -> void:
    if not is_instance_valid(client) or not client.is_inside_tree():
        return
    if client.start(app_id) != OK:
        push_warning(client.get_initialization_error())
        return

    var apps: SteamApps = client.apps()
    if apps != null:
        print("Steam game language after restart: ", apps.current_language())
```

The deferred connection calls [`start()`](/api/classes/SteamClient#start) after the failure callback returns. After a successful restart, ask the client for fresh handles, as shown by the call to [`apps()`](/api/classes/SteamClient#apps). A temporary loss of connectivity to Valve keeps the local scope active.

## Choose a service

| Use case | Service |
| --- | --- |
| App language, installed DLC, branch, and notification launch IDs | [SteamApps](/api/classes/SteamApps) through [`apps()`](/api/classes/SteamClient#apps) |
| Friends, localized display status, and Steam panes | [SteamFriends](/api/classes/SteamFriends), [SteamPresence](/api/classes/SteamPresence), and [SteamOverlay](/api/classes/SteamOverlay) |
| Stats, achievements, and ranked results | [SteamStats](/api/classes/SteamStats) and [SteamLeaderboards](/api/classes/SteamLeaderboards) |
| Files, quota, shared files, and write batch hints | [SteamCloud](/api/classes/SteamCloud) |
| Workshop and Steam Inventory | [SteamWorkshop](/api/classes/SteamWorkshop) and [SteamInventory](/api/classes/SteamInventory) |
| Gamepad actions, device settings, and on-screen keyboard | [SteamInput](/api/classes/SteamInput) and [SteamDevice](/api/classes/SteamDevice) |
| Game Recording, screenshots, and Remote Play | [SteamTimeline](/api/classes/SteamTimeline), [SteamScreenshots](/api/classes/SteamScreenshots), and [SteamRemotePlay](/api/classes/SteamRemotePlay) |
| Steam HTTP requests and redacted SDK warnings | [SteamHttp](/api/classes/SteamHttp) and [SteamDiagnostics](/api/classes/SteamDiagnostics) |
| Web tickets and checkout | [SteamAuth](/api/classes/SteamAuth) and [SteamPurchases](/api/classes/SteamPurchases), with a [publisher backend](/steam/publisher) |

## Record progression

Publish the stat and achievement definitions for your AppID in Steamworks. Use their exact API names. When one game event changes several values, collect them with [`edit()`](/api/classes/SteamStats#edit) and apply them together with [`submit()`](/api/classes/SteamStatsEdit#submit). Pass the [`SteamStats`](/api/classes/SteamStats) service from your client or game scope and the player's total number of wins.

```gdscript
func record_win(stats: SteamStats, total_wins: int) -> void:
    var result := stats.edit() \
        .set_int("wins", total_wins) \
        .unlock("first_win") \
        .submit()
    if not result.ok:
        push_warning(result.message)
```

The result describes the submission. [`value.applied`](/api/classes/SteamStatsSubmission#properties) counts edits accepted into Steam's cache, and [`value.failed_at`](/api/classes/SteamStatsSubmission#properties) identifies the first rejected edit when there is one. Accepted edits can remain in the cache after a later error. Observe [`stats_stored`](/api/classes/SteamStats#stats_stored) for Steam's app-wide persistence result. For scores governed by a dedicated authority or trusted backend, use the [dedicated progression](/steam/dedicated-servers#record-server-owned-progression) or [publisher workflow](/steam/publisher) for that authority.

## Save a profile to Cloud

Enable Cloud and allocate quota for your AppID in Steamworks. Get a [`SteamCloud`](/api/classes/SteamCloud) service from a ready [`SteamClient`](/api/classes/SteamClient#cloud) or [`SteamScope`](/api/classes/SteamScope#cloud). Pass a non-null service and your serialized profile bytes to the examples below. Use a dedicated file key for the game's profile.

### Await the result directly

Use [`write()`](/api/classes/SteamCloud#write) and [`read()`](/api/classes/SteamCloud#read) when your code only needs the completed results.

```gdscript
func save_and_read_profile(cloud: SteamCloud, profile_bytes: PackedByteArray) -> void:
    var written: SteamResult = await cloud.write("player-profile.json", profile_bytes)
    if not written.ok:
        push_warning(written.message)
        return

    var loaded: SteamBytesResult = await cloud.read("player-profile.json")
    if loaded.ok:
        print("Read %d bytes from Steam Cloud." % loaded.value.size())
    else:
        push_warning(loaded.message)
```

### Keep the operation handle

Use [`write_file()`](/api/classes/SteamCloud#write_file) and [`read_file()`](/api/classes/SteamCloud#read_file) when you want a handle that your code can keep and check while the request is pending. Here the function waits on each handle before using its result.

```gdscript
func save_and_read_with_handles(cloud: SteamCloud, profile_bytes: PackedByteArray) -> void:
    var write_op: SteamOperation = cloud.write_file("player-profile.json", profile_bytes)
    var written: SteamResult = await write_op.wait()
    if not written.ok:
        push_warning(written.message)
        return

    var read_op: SteamBytesOperation = cloud.read_file("player-profile.json")
    var loaded: SteamBytesResult = await read_op.wait()
    if loaded.ok:
        print("Read %d bytes from Steam Cloud." % loaded.value.size())
    else:
        push_warning(loaded.message)
```

If a screen keeps the write handle, it can call [`cancel()`](/api/classes/SteamOperation#cancel) when it closes. That stops waiting locally. Steam can still complete a submitted write.

### Group related writes

Use [`begin_write_batch()`](/api/classes/SteamCloud#begin_write_batch) to tell Steam that a group of writes belongs together. Close the batch after the last result, even if a write fails. Each write still has its own result. [Steam Cloud write batches](https://partner.steamgames.com/doc/api/ISteamRemoteStorage#BeginFileWriteBatch)

```gdscript
func write_profile_batch(
    cloud: SteamCloud, profile_bytes: PackedByteArray, settings_bytes: PackedByteArray
) -> void:
    var opened: SteamCloudWriteBatchResult = cloud.begin_write_batch()
    if not opened.ok:
        push_warning(opened.message)
        return

    var batch: SteamCloudWriteBatch = opened.value
    var files := {"player-profile.json": profile_bytes, "settings.json": settings_bytes}
    for file_name: String in files:
        var written: SteamResult = await cloud.write(file_name, files[file_name])
        if not written.ok:
            push_warning(written.message)
            break

    var close_error := batch.close()
    if close_error != OK:
        push_warning(error_string(close_error))
```

[`SteamCloudWriteBatch.close()`](/api/classes/SteamCloudWriteBatch#close) ends the hint. Check actual sync on a second device using the same test account. [Verify Steam Cloud sync](/steam/testing#verify-steam-cloud-sync)

## Open the Steam Overlay

From your achievements button's pressed handler, pass a fresh Overlay service from [`SteamClient.overlay()`](/api/classes/SteamClient#overlay) or [`SteamScope.overlay()`](/api/classes/SteamScope#overlay) to this function. It checks [`is_ready()`](/api/classes/SteamOverlay#is_ready) before calling [`open_achievements()`](/api/classes/SteamOverlay#open_achievements).

```gdscript
func open_steam_achievements(overlay: SteamOverlay) -> void:
    if overlay == null or not overlay.is_ready():
        return
    var requested := overlay.open_achievements()
    if requested != OK:
        push_warning(error_string(requested))
```

`OK` confirms that Crimson submitted the request. Confirm the rendered pane during testing. Use [`activation_changed(active)`](/api/classes/SteamOverlay#activation_changed) to suspend local gameplay input and restore the relevant focus when the Overlay closes. Keep the multiplayer simulation running.

For a direct, windowed development launch, pass `--crimson-steam-overlay=480` as a user argument after Godot's `--` separator, using the launch AppID. Crimson initializes Steam before Godot creates the display. Enable the Overlay in Steam and run the [rendered test](/steam/testing#check-the-overlay-and-achievements). [Valve's Overlay requirements](https://partner.steamgames.com/doc/features/overlay#requirements)

## Consume Steam results

Read [`ok`](/api/classes/SteamResult#properties) before using a result's `value`. Some operations expose [`wait()`](/api/classes/SteamOperation#wait) on an operation handle, while convenience methods can be awaited directly. Check the signature in the [API reference](/api/overview). For Steam HTTP, a completed response can still have a 4xx or 5xx status. Check [`response.value.is_successful()`](/api/classes/SteamHttpResponse#is_successful) when you need a 2xx response. For Steam IDs documented as decimal strings, keep them as strings to preserve their full range.
