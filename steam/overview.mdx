Add Steam to the parts of your game that need it. A solo game can award achievements, sync a player profile to Steam Cloud, or use Steam Input. A multiplayer game can let friends invite each other into a session or give players a dedicated server to join.

## Connect your game to Steam

Add Valve's runtime to your Crimson installation and sign in to Steam. For a development launch, configure the same AppID in the launch environment and in this script. The default is Valve's Spacewar test app. [Steamworks setup](/steam/setup#launch-with-an-appid)

Attach this script to a `Node` in a scene that stays loaded, such as your main menu. Run the scene and check **Output**. A successful connection prints the AppID Steam reports.

```gdscript
extends Node

const SPACEWAR_APP_ID: int = 480

@export var steam_app_id: int = SPACEWAR_APP_ID

var _steam: SteamClient


func _ready() -> void:
    _steam = SteamClient.boot(self, steam_app_id)
    if _steam == null:
        push_error("Could not attach the Steam client.")
        return
    if not _steam.is_ready():
        push_error(_steam.get_initialization_error())
        return

    if not _steam.is_online():
        push_warning("Steam initialized locally. Steam is currently offline.")
        return

    print("Connected to Steamworks for AppID %d." % _steam.get_app_id())
```

[`SteamClient.boot()`](/api/classes/SteamClient/methods/boot) attaches and initializes the client. [`is_ready()`](/api/classes/SteamClient/methods/is_ready) checks local initialization. [`is_online()`](/api/classes/SteamClient/methods/is_online) checks the connection to Steam. If initialization fails, use the diagnostic in **Output** to check your runtime and launch setup. [Test and troubleshoot](/steam/testing#diagnose-common-failures)
