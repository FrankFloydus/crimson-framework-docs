Add Steam to the parts of your game that need it. A solo game can award achievements, sync a player profile to Steam Cloud, or use Steam Input. A multiplayer game can let friends invite each other into a session or give players a dedicated server to join.

| What you want to build | Start here |
| --- | --- |
| Add achievements, Cloud saves, or Steam Input | [Use Steam client services](/steam/client-services) |
| Let players host and invite friends | [Set up lobbies and listen servers](/steam/listen-servers) |
| Run a server that players can join without a player hosting it | [Set up a dedicated server](/steam/dedicated-servers) |
| Verify player ownership or process Steam Wallet purchases | [Set up a trusted publisher backend](/steam/publisher) |

Start by adding Valve's Steam runtime to your installed Crimson addon. Then follow the guide for the features you want and verify them in a Windows export. [Steamworks setup](/steam/setup) · [Test and troubleshoot](/steam/testing)
