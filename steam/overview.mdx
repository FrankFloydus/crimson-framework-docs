Use Steam for app services such as achievements and Cloud, or add it as the connection for a multiplayer game. Both use the Steam client and the AppID supplied at launch.

## Connect your game to Steam

Attach this script to a persistent `Node` in your main scene. Launch with the Steam client running and signed in. For a direct Spacewar test, follow the setup guide to launch under AppID `480`. The script reports which app connected and whether Steam is online. [Launch with an AppID](/steam/setup#launch-with-an-appid)

```gdscript
extends Node

const TEST_GROUP: String = "my-studio-training"

@export var use_spacewar: bool = false

var _steam: Steamworks


func _ready() -> void:
    var settings: SteamConfig
    if use_spacewar:
        settings = SteamConfig.spacewar(TEST_GROUP)

    _steam = Steamworks.boot(self, settings)
    var result: SteamResult = _steam.boot_result()
    if not result.ok:
        push_error(result.message)
        return

    print("Steam AppID %d ready. Online: %s" % [_steam.get_app_id(), _steam.is_online()])
```

Enable **Use Spacewar** when running this script under AppID `480`. For your own app, leave it off to use the AppID Steam supplies. [SteamConfig](/api/classes/SteamConfig) · [Steamworks.boot()](/api/classes/Steamworks/methods/boot)

A multiplayer game that boots with [`Game.configure(LEVEL, PLAYER).steam().boot(self)`](/api/classes/GameConfig/methods/steam) already has Steam services. Read them through [`game.steam()`](/api/classes/Game/methods/steam). [Host and join a Steam game](/steam/listen-servers)
