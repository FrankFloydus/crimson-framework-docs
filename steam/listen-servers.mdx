A listen server runs on a player's machine. Steam lobbies help that player invite friends and help guests find the game. You can also use a lobby for a social space such as a waiting room before a game starts.

## Host a game from a player's machine

Use the world and player scenes from the quickstart. In the node that owns your game, add a Steam provider to your game setup and call [`host_online()`](/api/classes/GameRuntime#host_online) when the player chooses to host. Use the same AppID, lobby namespace, virtual port, and compatible build for the host and guests. Keep the returned game in a menu or controller that stays in the scene tree. [Getting started](/quickstart)

```gdscript
var provider := SteamProvider.configure().for_app(480) \
    .with_lobby_namespace("my-studio-crimson-demo").friends_only()
var game := GameRuntime.configure() \
    .with_starting_world(&"training_room", preload("res://world.tscn")) \
    .with_player(preload("res://player.tscn")).with_provider(provider).boot(self)
if game == null:
    return
var steam := SteamServices.for_game(game)
if steam == null:
    push_error("The game did not attach a Steam scope.")
    return
if not steam.is_ready():
    push_error(steam.get_initialization_error())
    return

var hosted: Dictionary = await game.host_online().wait()
if not hosted.ok:
    push_error("Could not host a Steam game: %s" % hosted.message)
```

Use an authorized AppID for your game. [`SteamProvider.configure()`](/api/classes/SteamProvider#configure) defaults to a private invitation lobby and virtual port `0`. Call [`friends_only()`](/api/classes/SteamProvider#friends_only) for a friend lobby or [`public_lobbies()`](/api/classes/SteamProvider#public_lobbies) for public discovery. The hosted world and admission must be ready before the listing accepts players. Call [`game.leave()`](/api/classes/GameRuntime#leave) when the host closes the session. [Steam matchmaking](https://partner.steamgames.com/doc/api/ISteamMatchmaking)

## Invite and join

Once hosting succeeds, get the invite gateway with [`game.invites()`](/api/classes/GameRuntime#invites). Call [`open_overlay()`](/api/classes/GameInvites#open_overlay) to request the Steam invite dialog. `ERR_BUSY` means the Overlay is still unavailable in that active scope. To send an invitation to a selected account, call [`send(steam_id)`](/api/classes/GameInvites#send) with its decimal SteamID64 string. `OK` acknowledges the submission to Steam.

On the guest, read [`game.invites().pending()`](/api/classes/GameInvites#pending) on startup and listen to the [`received`](/api/classes/GameInvites#received) signal from the persistent menu. Present the candidate. After the player confirms, pass the invite's [`listing`](/api/classes/SteamInvite#properties) to [`game.join_listing()`](/api/classes/GameRuntime#join_listing) and await the [operation](/api/classes/GameOperation#wait).

```gdscript
func join_invited_game(game: GameRuntime, invite: SteamInvite) -> Dictionary:
    return await game.join_listing(invite.listing).wait()
```

Enable **Use launch command line** in Steamworks to receive Steam launch and Rich Presence arguments. [Valve launch arguments](https://partner.steamgames.com/doc/api/ISteamApps#GetLaunchCommandLine)

If Steam has already granted lobby access and you know the lobby ID, call [`game.join_online(lobby_id)`](/api/classes/GameRuntime#join_online) and await the result.

```gdscript
func join_known_lobby(game: GameRuntime, lobby_id: String) -> Dictionary:
    return await game.join_online(lobby_id).wait()
```

The provider refreshes the lobby before joining. Crimson verifies the AppID, namespace, membership, and host identity. The host binds the guest's Steam ticket to its certified transport identity and checks current lobby membership and AppID ownership before admitting the peer. [Valve session tickets](https://partner.steamgames.com/doc/features/auth)

## Find an open game

Use a lobby query to find a listing with room. The lobby's map filter must match the published map value.

```gdscript
var found: SteamListingsResult = await steam.lobbies().query() \
    .on_map(&"training_room").with_room_for(2).fetch()
if found.ok and not found.value.is_empty():
    var joined: Dictionary = await game.join_listing(found.value[0]).wait()
    if not joined.ok:
        push_warning("The Steam lobby could not be joined.")
```

Use [`friend_lobby(friend_id)`](/api/classes/SteamLobbies#friend_lobby) to look up a friend's lobby. [`fetch_operation()`](/api/classes/SteamLobbyQuery#fetch_operation) returns a cancellable search handle. Steam processes one native search at a time, so an abandoned search may briefly hold the query lane while it drains.

A ready public or friends-only host advertises Join Game through Steam Rich Presence while admission is open and seats remain. To hide that join route, call [`steam.presence().clear_joinable()`](/api/classes/SteamPresence#clear_joinable). To restore it, pass the current owned lobby's [`listing()`](/api/classes/SteamLobby#listing) to [`steam.presence().joinable()`](/api/classes/SteamPresence#joinable). [Valve Rich Presence](https://partner.steamgames.com/doc/features/enhancedrichpresence)

## Run a social lobby without a game

Use a [standalone Steam client](/steam/client-services#start-a-client) for a social lobby that needs membership, metadata, and chat.

```gdscript
var created: SteamLobbyResult = await steam.lobbies().create().wait()
if created.ok:
    created.value.edit().named("Crew staging").tag(&"mode", "practice").submit()
```

The default social lobby is private with four seats including its owner, in the `crimson` namespace. To customize it, use [`SteamLobbyOptions.configure()`](/api/classes/SteamLobbyOptions#configure) and set its namespace, player limit, and visibility with [`in_namespace()`](/api/classes/SteamLobbyOptions#in_namespace), [`for_players()`](/api/classes/SteamLobbyOptions#for_players), and [`with_visibility()`](/api/classes/SteamLobbyOptions#with_visibility). Pass the options to [`create()`](/api/classes/SteamLobbies#create). This example creates an eight-player [public lobby](/api/classes/SteamLobbyOptions#visibility).

```gdscript
var options := SteamLobbyOptions.configure().in_namespace(&"my_game") \
    .for_players(8).with_visibility(SteamLobbyOptions.PUBLIC)
var created: SteamLobbyResult = await steam.lobbies().create(options).wait()
if not created.ok:
    push_warning(created.message)
```

To find social listings, start with [`steam.lobbies().query()`](/api/classes/SteamLobbies#query), select [`social()`](/api/classes/SteamLobbyQuery#social), then call [`fetch()`](/api/classes/SteamLobbyQuery#fetch). Call [`steam.lobbies().join(listing)`](/api/classes/SteamLobbies#join) and await its [`wait()`](/api/classes/SteamLobbyOperation#wait) result. Game joins accept gameplay listings.

```gdscript
var found: SteamListingsResult = await steam.lobbies().query(&"my_game").social().fetch()
if found.ok and not found.value.is_empty():
    var joined: SteamLobbyResult = await steam.lobbies().join(found.value[0]).wait()
    if not joined.ok:
        push_warning(joined.message)
```

One signed-in Steam account can hold one lobby membership across standalone clients and games in a process. A standalone member can leave with [`lobby.leave()`](/api/classes/SteamLobby#leave). A game member leaves through [`game.leave()`](/api/classes/GameRuntime#leave). Render text from [`chat_received(member, text)`](/api/classes/SteamLobby#chat_received) as plain text and use the game session's verified peer state for gameplay decisions.

## Use Steam networking and social features

- For game transport diagnostics, call [`steam.networking().peer_path(peer_id)`](/api/classes/SteamNetworking#peer_path) for an admitted peer. [`SteamProvider.prefer_relay()`](/api/classes/SteamProvider#prefer_relay) biases a listen connection toward relay. Check [`kind`](/api/classes/SteamConnectionPath#properties) on the observed path because Steam can choose direct routing.
- Use [SteamSockets](/api/classes/SteamSockets) when you own the connection protocol. Pin the expected peer for a direct connection or use a P2P endpoint with the expected Steam account. Wait for the connection before consuming remote identity or sending data.
- Use [SteamMessages](/api/classes/SteamMessages) for bounded side-channel messages. Supply your game's channel allowlist with [`with_message_channels()`](/api/classes/SteamProvider#with_message_channels) and request the scoped handle with [`steam.messages().for_peer(peer_id)`](/api/classes/SteamMessages#for_peer) after that peer reaches the game.
- Use [SteamParties](/api/classes/SteamParties) to publish a beacon for a ready, non-private hosted lobby at an eligible group-chat location. A guest reserves through Steam and then joins the returned listing through normal Game admission.
- Use [GameVoice](/api/classes/GameVoice) through [`game.voice()`](/api/classes/GameRuntime#voice) for push-to-talk and authority-owned recipient policy. Get player consent before capture and feed decoded PCM to your game's audio sink.

Use two distinct signed-in accounts for a real invite and remote join. Run the [multiplayer checks](/steam/testing#verify-multiplayer) before shipping.
